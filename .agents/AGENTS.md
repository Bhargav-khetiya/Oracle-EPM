# Oracle EPM Knowledge Base — Project Instructions

## CONTEXT
This folder is a self-study knowledge base for Oracle EPBCS/PBCS.
Goal: Transform every .md file so someone with ZERO knowledge becomes a PRO.

## STANDARDS (Non-Negotiable)
Every file MUST follow this structure:
1. **WHY** — What real-world problem does this solve?
2. **WHAT** — Plain English definition (no jargon assumed)
3. **HOW** — Step-by-step mechanics with ASCII diagrams
4. **SHOW ME** — Worked example using "Hotel Pvt Ltd" scenario
5. **MISTAKES** — Common errors with fixes
6. **TEST ME** — Interview questions at Beginner/Intermediate/Architect levels

## RUNNING EXAMPLE
- Company: "Hotel Pvt Ltd" — 5-star hotel chain across India
- Revenue: ~₹26Cr/year, 5 hotels, 500 rooms total
- Use this scenario in EVERY file to bridge theory to practice

## SIZE TARGETS
- Core Topics (Essbase, Forms, Calc, Dims): 15-25KB, 10+ code blocks
- Supporting Topics (Security, SV, DI): 10-15KB, 5+ code blocks
- Reference files (Functions, Errors): 8-12KB, 8+ code blocks
- CheatSheets: 4-8KB, quick reference format
- Labs: 12-20KB, full step-by-step walkthrough

## RULES
- NO broken Oracle doc links (remove any oracle.com URLs)
- Cross-reference other files using relative paths (../Module/file.md)
- Use ASCII diagrams, NOT image references
- All code blocks must be copy-paste ready
- INR (₹) for Indian context, USD ($) for US context
