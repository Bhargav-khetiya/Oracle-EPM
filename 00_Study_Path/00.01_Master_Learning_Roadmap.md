# WHY YOU NEED A ROADMAP

---

## The Problem

This repository contains **200+ files** across 33 modules. If you read them randomly, you'll:
- Read about FIX statements before you know what a dimension is
- Try to write Groovy before understanding how Essbase stores data
- Skip the finance concepts and then fail every interview question about P&L

## The Solution: Follow the Data Flow

```
The secret to mastering Oracle EPM is ONE principle:

  FOLLOW THE DATA.

  1. Where does data COME FROM?    → Finance/Business (Module 01-02)
  2. Where is data STORED?         → Essbase Engine (Module 03)
  3. How is the CONTAINER built?   → Planning App + Dimensions (Module 04-05)
  4. How does the USER see it?     → Forms + Smart View (Module 06, 10)
  5. How is data CALCULATED?       → Business Rules + Calc Mgr (Module 07-08)
  6. How does data GET IN/OUT?     → Data Integration + REST (Module 11, 13)
  7. How is it SECURED?            → Security + Administration (Module 12, 15)
  8. How do you EXTEND it?         → Groovy + EPM Automate (Module 09, 14)

  Learn in THIS order. Not alphabetically. Not randomly.
```

## Time Commitment

|-----------------|-------------------|----------------|
| **IT professional, no finance** | 15-20 hrs/week | 12 weeks |
| **Finance professional, some IT** | 12-15 hrs/week | 10 weeks |
| **Fresh graduate** | 20-25 hrs/week | 14-16 weeks |
| **Experienced Hyperion consultant** | 8-10 hrs/week | 6 weeks (review mode) |

## Study Modes

```
📖 READ    = Study the module file (concepts + diagrams)
✍️  PRACTICE = Do the lab exercises in Module 22
🧠 TEST    = Answer the interview questions WITHOUT looking at answers
📝 REVIEW  = Re-read your weak areas from the checkpoint quiz
```

## What "Mastery" Looks Like at Each Level

```
Level 1 — BEGINNER (Week 1-4):
  "I can explain what EPM is, what Essbase does, and why
   companies use it instead of Excel. I can draw the
   architecture on a whiteboard."

Level 2 — CONSULTANT (Week 5-8):
  "I can build a Planning application from scratch, create
   forms and dimensions, and write basic calc scripts.
   I can pass an interview for a Junior EPM Consultant role."

Level 3 — SENIOR CONSULTANT (Week 9-12):
  "I can write complex business rules, use Groovy for
   dynamic calculations, set up data integrations, and
   troubleshoot performance issues."

Level 4 — ARCHITECT (Beyond Week 12):
  "I can design an entire EPM solution from requirements
   to go-live. I can optimize Essbase performance, handle
   multi-currency consolidation, and mentor junior consultants."
```
