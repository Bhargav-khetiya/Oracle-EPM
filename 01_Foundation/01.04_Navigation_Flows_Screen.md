# 01.04 Navigation Flows Screen Configuration

> **Module:** 01_Foundation  
> **Topic:** 04 - Navigation Flows (The Homepage UI)  
> **Target Audience:** Administrator / Architect  

---

## Navigation
**Navigator -> Tools -> Navigation Flows**

## Overview
Navigation Flows replaced the old "Task Lists" as the primary way users navigate Oracle EPM. They allow you to completely customize the Homepage icons (Clusters and Cards) based on the user's security role. A Sales Manager logs in and sees a blue "Revenue Planning" icon. The CFO logs in and sees a red "Executive Dashboards" icon. 

## The Screen Mechanics

### 1. The Default Flow
When you open the screen, you will see a flow called `Default`. 
- **Architect Rule:** You CANNOT edit the Default flow. You must duplicate it, rename it (e.g., `Finance_Flow`), edit the duplicate, and set the duplicate to **Active**.

### 2. Clusters vs. Cards
- **Cluster:** The large folder icon on the homepage. (e.g., `Financials`).
- **Card:** The specific icon inside the cluster that actually opens a form or dashboard. (e.g., `Balance Sheet Input`).
- **Sub-Tab (Vertical / Horizontal):** Inside a Card, you can attach multiple Web Forms. They appear as vertical or horizontal tabs on the screen.

## Every Configuration Property

### 1. Assigning Access (The Role Mapping)
- **What it does:** Dictates who sees this entire Navigation Flow.
- **How to apply:** Click the `Role` column next to your custom flow. You must assign an Access Control Group (e.g., `Group_Sales_Users`).
- **The Trap:** If a user belongs to `Group_Sales_Users` AND `Group_Finance_Users`, and both groups have different Navigation Flows assigned, EPM will randomly assign them one upon login unless you configure a fallback priority.

### 2. Card Properties
When you click into a Card to configure it, you see the following properties:

#### "Artifact"
- **What it does:** This is where you actually link the physical object (Form, Dashboard, Business Rule, or URL) to the icon.
- **How to apply:** Click the magnifying glass and select the specific Web Form from the repository tree.

#### "Icon" and "Color"
- **What it does:** The visual aesthetics. 
- **Architect Note:** Do not underestimate this. Users hate ugly software. Use distinct, logical colors (Green for Revenue, Red for Expenses) and modern icons.

#### "Visible" (Checkbox)
- **What it does:** Instantly hides the icon from the homepage without deleting the underlying configuration.
- **When to use:** If you are building a new Dashboard that isn't ready for Go-Live, uncheck this.

## 25. Interview Questions

### Intermediate
**Q: You build a beautiful Navigation Flow for the Sales team. You activate it. A Sales user logs in, but they still see the standard, out-of-the-box Oracle icons. Why?**
> A: You forgot to assign the Access Control Group to the Navigation Flow. Even if a flow is Active, if no specific user group is mapped to it, the system defaults to showing the standard, un-customized homepage. You must click the Role column and map the Sales group.

### Architect
**Q: You want to embed a live PowerBI dashboard directly inside the Oracle EPBCS homepage so users don't have to switch applications. Can you do this in Navigation Flows?**
> A: Yes. When configuring a Card, instead of selecting a Web Form as the Artifact, you can select **URL**. You paste the PowerBI embedded link into the URL field. When the user clicks the icon in Oracle EPM, the PowerBI dashboard renders seamlessly inside the EPM iframe wrapper.
