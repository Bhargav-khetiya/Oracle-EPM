# 06.06 Flex Forms in Smart View

> **Module:** 06_Forms  
> **Topic:** 06 - Flex Forms  
> **Target Audience:** Consultant

## 1. Learning Objectives
- Understand the limitation of standard Web Forms in Smart View.
- Define what a Flex Form is.
- Configure Flex Forms to allow dynamic user sorting and filtering.

## 3. Introduction
When a user opens a standard EPBCS Web Form in Excel (via Smart View), the grid is completely locked. They cannot sort the rows (e.g., A-Z), they cannot filter out specific accounts, and they cannot insert blank rows. It is functionally a picture of the web form. 

Excel power users hate this. They want to sort and filter. **Flex Forms** solve this problem.

## 7. Core Concepts: The Flex Form

A Flex Form is a property applied to a standard Web Form that fundamentally changes how it behaves when opened in Smart View.

### Standard Form (Smart View)
- The row definitions are controlled strictly by the server. 
- If the server sends 10 rows, the user sees 10 rows.
- If the user uses Excel's native "Filter" button to hide Row 5, and then clicks "Submit Data", Smart View will often throw an error because the physical grid layout was tampered with.

### Flex Form (Smart View)
- The row definitions become flexible.
- The user can use native Excel sorting (e.g., sort Top 10 Customers by Revenue).
- The user can use native Excel filters to hide rows they don't care about.
- The user can insert blank rows in the middle of the form.
- **The Magic:** When the user clicks "Submit Data", Smart View intelligently rebuilds the XML payload, figures out what the user did, and successfully pushes the data to Essbase without throwing a formatting error.

## 13. Configuration: Enabling Flex Forms
1. The Admin opens the Form definition in the EPBCS Web UI.
2. Go to the **Smart View** options tab on the form.
3. Check the box for **"Enable Flex Form"**.
4. (Optional) Check the box for **"Enable Flex Form for Columns"** (Added in recent cloud updates, allowing columns to be flexible as well).

## 18. Architect Notes: The Danger of Flex Forms
If you enable Flex Forms, you give up control over the visual presentation of the data. 
- If you built a Form with complex Data Validation rules (e.g., Cell turns Red if X > Y), sorting the Flex Form in Excel might break the visual logic of the Data Validation rules because the rows are no longer in the order the JavaScript engine expects.
- **Rule of Thumb:** Use Flex Forms for heavy data-entry templates where users are uploading hundreds of lines (like CapEx asset entry). Use Standard Forms for executive summary boards where formatting must remain pixel-perfect.

## 25. Interview Questions

### Intermediate
**Q: A user opens a Data Form in Smart View, sorts the rows alphabetically using Excel's sort button, types in some numbers, and clicks Submit. The system throws a "Grid Formatting Error" and refuses to save the data. Why?**
> A: The form is a standard form. Standard forms lock the row and column headers to the server's definition. Tampering with the layout via Excel sorting breaks the grid mapping. The Admin must enable the "Flex Form" property on the form definition to allow native Excel sorting and filtering prior to submission.

## 27. Summary
Flex Forms bridge the gap between the strict control of a Web Form and the absolute chaos of an Ad-Hoc grid. Enable them to keep your Excel power users happy.
