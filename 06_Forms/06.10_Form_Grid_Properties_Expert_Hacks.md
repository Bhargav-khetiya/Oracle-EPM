## 2. THE GOLDEN RULES OF FORM PERFORMANCE

```
Rule 1: Dense dimensions on columns, Sparse on rows (or Page/POV)
Rule 2: Period/Account on columns is FASTEST (both Dense)
Rule 3: Entity on rows + Suppress Missing Blocks = manageable
Rule 4: Never put 2+ sparse dims on rows (cross-join explosion)
Rule 5: Use Page axis for any dimension users need to toggle
```

## 3. EXPERT PROPERTY COMBINATIONS

### Combo 1: "Lean Data Entry" (Most Common)

```
Use for: Budget entry forms, forecast entry forms
Grid Properties:
  ☑ Suppress Missing Data
  ☐ Suppress Missing Blocks (off — users need to see empty rows for entry)
  ☐ Use Database Suppression
  Enable Autosave: ☐
  Enable Calc On the Fly: ☐

Display Properties:
  ☑ Display Missing as Blank (cleaner look)
  ☑ Enable Grid Spread (users love this)
  ☐ Make Form Read-Only

Why: Empty rows visible for new data entry, clean look, fast save.
```

### Combo 2: "High-Volume Summary" (P&L Reports)

```
Use for: P&L summaries, variance reports, dashboards
Grid Properties:
  ☑ Suppress Missing Data
  ☑ Suppress Missing Blocks
  ☑ Use Database Suppression (⚠️ only if NO formula columns)
  Enable Autosave: ☐

Display Properties:
  ☑ Display Missing as Blank
  ☐ Enable Grid Spread (read-only, no spreading)
  ☑ Make Form Read-Only

Why: Maximum suppression = fastest load. Read-only = less processing.
```

### Combo 3: "Interactive What-If" (Scenario Analysis)

```
Use for: Scenario planning, what-if forms with live calculations
Grid Properties:
  ☑ Suppress Missing Data
  ☐ Suppress Missing Blocks
  ☑ Enable Autosave (immediate feedback)
  ☑ Run Form Calc on Autosave (see dynamic calcs update live)
  ☑ Enable Calc On the Fly

Display Properties:
  ☑ Display Missing as Blank
  ☑ Enable Grid Spread
  ☐ Make Form Read-Only

⚠️ WARNING: Only use this combo with DENSE dimensions on rows AND columns.
   Sparse on rows + Autosave = extremely slow.
```

### Combo 4: "Smart View Power User" (Export-Friendly)

```
Use for: Forms frequently exported to Excel or used in Smart View
Grid Properties:
  ☑ Suppress Missing Data
  ☑ Suppress Missing Blocks
  ☐ Enable Autosave (Smart View has its own save)

Smart View Options:
  ☑ Repeat Member Labels (clean Excel layout)
  ☐ Disable Spreading (keep spreading in Smart View)
  ☐ Disable Formatting (faster Smart View load)
  ☑ Enable Flex Form for Rows (power user flexibility)
  ☑ Show Invalid Members for Flex Form

Why: Flex + Repeat Labels = excellent Smart View experience.
```

### Combo 5: "Massive Grid" (1000+ rows)

```
Use for: Employee listing, product-level budget, room-level data
Grid Properties:
  ☑ Suppress Missing Data
  ☑ Suppress Missing Blocks
  ☑ Use Database Suppression (essential for performance)
  ☐ Enable Autosave (too many rows for autosave)
  ☐ Enable Calc On the Fly (too heavy)

Segment Properties:
  Enable Dropdown for Dimensions: ☑ (let users filter)
  Suppress Missing Data: ☑ (per-segment override)

Display Properties:
  ☑ Display Missing as Blank
  ☑ Enable Grid Spread

Why: Database suppression at Essbase level prevents browser crash.
     Dropdown selectors let users filter to manageable subsets.
```

## 4. PERFORMANCE ANTI-PATTERNS (NEVER DO THIS)

| Anti-Pattern | Why It's Slow | Fix |
|-------------|-------------|-----|
| 2 sparse dims on rows | Cross-join: 100 entities × 200 accounts = 20,000 rows | Move one dim to Page axis |
| Autosave + sparse rows | Saves to Essbase on every cell change for sparse data | Disable Autosave |
| No suppression + 10,000 rows | Browser renders 10,000 HTML rows | Enable Suppress Missing Blocks |
| Formula column + Database Suppression | Formula rows suppressed before evaluation | Use regular Suppress Missing instead |
| Calc On the Fly on large form | Calculates formulas per-cell on hover | Disable — use attached rules instead |
| All dims on rows, none on Page | No filtering capability | Move Entity/Department to Page |

```
Form: "Revenue_Entry" (currently slow — 15 sec load)

  Fix: Move Department to Page axis
  Result: Load time drops to 3 seconds
```

## 7. INTERVIEW QUESTIONS

### Intermediate
**Q: A form with Entity and Account on rows takes 20 seconds to load. Account has 200 members, Entity has 100. What's happening and how do you fix it?**
> The form is doing a **cross-join** of Entity (sparse) × Account (dense) on rows = 20,000 potential rows. With no suppression, all 20,000 rows render. Fix: (1) Move Entity to the Page axis — users select one entity at a time, reducing to 200 rows. (2) Enable Suppress Missing Data and Suppress Missing Blocks. (3) If it must show multiple entities, use "Enable Dropdown for Dimensions" on the Entity segment so users can filter.

### Architect
**Q: Design form properties for a 500-room hotel inventory tracker showing 500 rooms × 12 months with formula columns for Occupancy% and RevPAR.**
> Use the "Massive Grid" combo with modifications: Suppress Missing Data ☑, Suppress Missing Blocks ☑, Use Database Suppression **☐** (has formula columns!). Put Room dimension on rows, Period on columns. Add Floor dimension to Page axis so users see one floor at a time (~50 rooms per floor). Enable Grid Spread ☑. Don't enable Autosave (sparse on rows). Key insight: Database Suppression would suppress formula column rows before the formula evaluates — so we use regular suppression instead. Expected load: 3-5 seconds per floor.
