## 💡 2. Grid Spread

Grid Spread allows users to distribute a value across multiple cells.

### Example:
```
User enters ₹120 Cr in YearTotal for Revenue.
Grid Spread distributes equally:
Jan = ₹10 Cr, Feb = ₹10 Cr, ... Dec = ₹10 Cr (120/12 = 10 each)

Or proportionally based on existing data.
```

### 💡 Logic & Purpose
Grid Spread eliminates the need for manual calculator usage outside the system. Instead of calculating seasonal spread in Excel and typing 12 numbers into EPBCS, users can just type the annual target (₹120 Cr) into YearTotal and let the database push the values down to the base periods based on a defined logic (Evenly, Proportional to last year, etc.).

### 🌀 Confusion Resolution
> **Misconception:** "I entered ₹120 Cr into YearTotal and hit spread, but it failed with a read-only error."
> **Reality:** You cannot spread data *into* a Dynamic Calc parent member. YearTotal must be explicitly set up to allow top-down spreading, or you must invoke Grid Spread from the right-click menu and target the base level periods directly.

### 😈 Twisted Interview Question
**Question:** A user uses Grid Spread to allocate ₹1,000 proportionally across 12 months. The previous year's actuals are used as the basis. However, 3 of those months have `#MISSING` data in the prior year. What happens to the allocation for those 3 months?
> **Answer:** If spreading proportionally based on existing data, any cell that is `#MISSING` (or zero) in the reference data will receive exactly 0% of the allocated value. The ₹1,000 will only be distributed across the 9 months that actually had historical data. If the user wanted the missing months to receive a share, they must use "Even Spread" instead of "Proportional."

## 🛠 3. Mass Allocate

Mass Allocate allows spreading a value based on a pattern:
- **Equal spread** — divide equally
- **Proportional spread** — based on existing values
- **Fill** — same value in all cells

## ️ 4. Supporting Detail

Supporting Detail lets users break down a cell value into components:

```
Cell: Marketing Expense (Jan) = ₹5 Cr

Supporting Detail:
├── Online Marketing    = ₹2 Cr
├── Print Advertising   = ₹1.5 Cr
├── Events              = ₹1 Cr
└── Misc                = ₹0.5 Cr
                          ────────
Total                   = ₹5 Cr ✅
```
