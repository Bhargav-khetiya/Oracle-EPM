## WHY — What Problem Does This Solve? <a name="why"></a>

Imagine you're the CFO of Hotel Pvt Ltd. You have 5 hotels, 500 rooms, ₹26Cr revenue. Every month you need:

1. **A P&L statement** for each hotel — formatted, printable, PDF-ready
2. **A KPI dashboard** showing Occupancy %, Revenue Per Room, and Cost Per Guest at a glance
3. **An executive home page** where you log in and immediately see red/green tiles for key metrics
4. **Automated monthly reports** emailed to each hotel's General Manager — with only THEIR hotel's data

Without EPM Reports + Dashboard Tiles, you'd be:
- Manually exporting data from Smart View → pasting into PowerPoint → emailing 5 different people
- Building Excel dashboards that break every month
- Having no single source of truth for executives

**EPM Reports + Dashboard Tiles + Infolets solve all of this in one unified platform.**

## WHAT — Plain English Definitions <a name="what"></a>

| Term | Plain English | Hotel Pvt Ltd Example |
|------|--------------|----------------------|
| **EPM Report** | A formatted document (like a Word doc) that pulls live data from the Essbase cube — grids, charts, logos, text | Monthly P&L Report for Mumbai Taj Hotel |
| **Dashboard 2.0** | A single-screen canvas where you drop forms, charts, tiles, and URLs side by side | Executive Overview showing Revenue + Occupancy + Expense Trend |
| **Tile** | A large number box on a dashboard showing ONE KPI value with conditional coloring | "₹5.2Cr" in green = Total Revenue this month |
| **Gauge** | A speedometer/dial showing a metric against a target range | Occupancy at 78% (target: 75%) = green zone |
| **Infolet** | A widget on the EPM Home Page (the login landing screen) showing a quick summary | CFO logs in → sees "Revenue: ₹2.1Cr MTD" tile |
| **Report Book** | A bundle of multiple reports compiled into one PDF with table of contents | "Hotel Pvt Ltd Monthly Board Pack" = P&L + Balance Sheet + Cash Flow |
| **Bursting** | Auto-generating personalized reports per entity and emailing each one | Mumbai GM gets Mumbai P&L, Delhi GM gets Delhi P&L |
| **Navigation Flow** | The configuration of what icons/cards appear on the EPM Home page springboard | CFO sees: "My Reports" card, "Revenue Dashboard" card, "Data Entry" card |

### Part A: EPM Reports (Cloud-Native) <a name="part-a-epm-reports"></a>

#### A.1 What Lives Inside an EPM Report

An EPM Report is a **canvas** (like a PowerPoint slide) where you place components:

│  │  📝 TEXT BOX: <<MemberName("Scenario")>> |           │    │

#### A.2 Report Components — Complete Reference

| Component | What It Does | Key Properties |
|-----------|-------------|----------------|
| **Grid** | Data table connected to Essbase cube | Data Source, Rows, Columns, POV, Suppress Missing/Zero, Formatting |
| **Chart** | Visual graph linked to a grid's data | Chart Type (17 types), Colors, Legend, Data Labels |
| **Text Box** | Static or dynamic text | Font, Alignment, Text Functions (<<MemberName>>, <<CurrentDate>>) |
| **Image** | Company logos, icons, signatures | Source file, Size, Position |
| **Page** | Multi-page layout | Size (A4/Letter/Legal), Orientation, Margins, Headers/Footers |

#### A.3 Creating a Report — Complete Step-by-Step

```
NAVIGATION: Home → Reports (Springboard Cluster) → Reports → Create

Step 1: SET CANVAS
   └── Page Size: A4 (most common in India) or Letter (US)
   └── Orientation: Portrait (P&L) or Landscape (wide reports)
   └── Margins: Top=1", Bottom=1", Left=0.75", Right=0.75"

Step 2: ADD GRID
   └── Drag "Grid" from palette → drop on canvas
   └── Select Data Source:
       ├── Application: HotelPlan
       └── Cube: HotelPlan_BSO (or _ASO for reporting)
   └── Design Grid Layout:
       ├── ROWS: Account dimension
       │   └── Member Selection: IDescendants("Total_Revenue")
       ├── COLUMNS: Period dimension
       │   └── Member Selection: IChildren("Qtr1"), IChildren("Qtr2")...
       │   OR: ILvl0Descendants("YearTotal") → All months
       └── POV (Fixed Context):
           ├── Scenario: Actual
           ├── Version: Final
           ├── Year: FY26
           ├── Entity: [User Prompt]  ← Runtime selection
           └── Currency: INR

Step 3: ADD FORMULA COLUMNS (inside Grid)
   └── Right-click column header → "Insert Formula Column"
   └── Variance = [Actual] - [Budget]
   └── Variance% = ([Actual] - [Budget]) / [Budget] * 100
   └── YoY Growth = ([FY26] - [FY25]) / [FY25] * 100

Step 4: ADD FORMATTING
   └── Grid Formatting:
       ├── Header Row: Bold, Dark Blue Background, White Text
       ├── Parent Members: Bold, Light Gray Background
       ├── Leaf Members: Normal, Indented
       ├── Currency Format: ₹ #,##0 (Indian Lakh/Crore)
       └── Negative Values: Red, Parentheses
   └── Conditional Formatting:
       ├── Rule 1: If Variance% > 0 → Green text + ▲ icon
       ├── Rule 2: If Variance% < 0 → Red text + ▼ icon
       ├── Rule 3: If Variance% < -10% → Red background (ALERT)
       ├── Rule 4: If cell = #Missing → Display "–"
       └── Rule 5: If member level = 0 → Normal font
                   If member level > 0 → Bold font

Step 5: ADD CHART
   └── Drag "Chart" from palette → drop below grid
   └── Link to Grid: Select "Grid1"
   └── Chart Type: Combination (Bar + Line)
       ├── Bar: Actual Revenue by Quarter
       └── Line: Budget Revenue by Quarter
   └── Set Colors: Actual=Blue (#2E86AB), Budget=Gray (#A0A0A0)

Step 6: ADD TEXT BOXES
   └── Header: "HOTEL PVT LTD — Monthly P&L Statement"
   └── Sub-Header: Dynamic text using functions:
       "Scenario: <<MemberName("Scenario")>> | 
        Year: <<MemberName("Year")>> | 
        Entity: <<MemberName("Entity")>>"
   └── Footer: "Page <<PageNumber>> of <<TotalPages>>"
   └── Date Stamp: "Generated: <<CurrentDateTime("dd-MMM-yyyy HH:mm")>>"

Step 7: ADD IMAGE
   └── Upload Hotel Pvt Ltd logo (PNG, max 2MB)
   └── Position: Top-Left corner
   └── Size: 150x50 pixels

Step 8: SAVE AND RUN
   └── Save: File → Save As → "Monthly_PnL_Report"
   └── Folder: /Reports/Finance/Monthly
   └── Run: Click "Run" → select output format:
       ├── HTML (interactive, in-browser viewing)
       ├── PDF (pixel-perfect, for printing/emailing)
       └── Excel (formatted grid export)
```

#### A.4 Grid Properties — Every Option Explained

| Property | What It Does | When to Use | Hotel Example |
|----------|-------------|-------------|---------------|
| **Data Source** | Which app + cube to connect | Always required | HotelPlan → HotelPlan_BSO |
| **Rows** | Which dimension on Y-axis | Always | Account |
| **Columns** | Which dimension on X-axis | Always | Period |
| **POV** | Fixed dimensions not on rows/columns | Always | Scenario, Version, Year, Entity, Currency |
| **Page Dimension** | Dropdown dimension (user switches) | Interactive reports | Entity → user picks "Mumbai" or "Delhi" |
| **Suppress Missing Rows** | Hide rows where ALL cells = #Missing | Reporting (never for data entry) | Hide accounts with no transactions |
| **Suppress Zero Rows** | Hide rows where ALL cells = 0 | Reporting on active accounts only | Hide inactive cost centers |
| **Suppress Missing Blocks** | Skip entire empty data blocks | Large cubes with sparse data | Skip hotels with no bookings |
| **Member Selection - Static** | Hardcoded members: Jan, Feb, Mar | Fixed-format reports | Board pack always shows Q1-Q4 |
| **Member Selection - Function** | Dynamic: IChildren(Year) | Auto-adapting reports | Automatically shows new months |
| **Member Selection - Range** | @RANGE(Period, &StartMonth, &EndMonth) | SubVar-driven reports | Rolling 6-month view |
| **Member Selection - Prompt** | User selects at runtime | Interactive exploration | "Select Entity" dropdown |
| **Drill-Through** | Enable click-to-expand on members | Web (HTML) output only | Click "Total Revenue" → see child accounts |
| **Conditional Format** | Color/style based on data values | All reports | Red for negative variance |
| **Formula Row/Column** | Calculated rows not in the cube | Variance, %, ratios | Var% = (Act-Bud)/Bud*100 |
| **Zoom** | Expand/collapse hierarchy dynamically | HTML output only | Click a parent to see children |

#### A.5 Member Selection Methods — Complete

```
METHOD 1: STATIC (Hardcoded)
   Members: [Jan], [Feb], [Mar], [Apr]
   Use When: Fixed layout that never changes
   Hotel Example: Board pack always shows all 12 months

METHOD 2: FUNCTION (Dynamic)
   IChildren("YearTotal")        → Q1, Q2, Q3, Q4
   IDescendants("Total_Revenue") → All revenue accounts + children
   ILvl0Descendants("Entity")    → All leaf entities (individual hotels)
   Ancestors("Mumbai")           → Mumbai, West_Region, India, Total_Entity
   Use When: Hierarchy may change (new hotels added)
   Hotel Example: New "Udaipur" hotel added → auto-appears in report

METHOD 3: RANGE (SubVar Driven)
   @RANGE(Period, &ForecastStart, Dec)
   Use When: Report window shifts monthly (rolling forecast)
   Hotel Example: &ForecastStart = "Jul" → shows Jul-Dec

METHOD 4: PROMPT (User Selection)
   Create Runtime Prompt: "Select Entity"
   Type: Member selector
   Dimension: Entity
   Default: "Total_Entity"
   Use When: One report template serves multiple users
   Hotel Example: Mumbai GM runs it → selects "Mumbai"

METHOD 5: ATTRIBUTE-BASED
   Filter by attribute: @ATTRIBUTE("Hotel_Type", "5-Star")
   Use When: Report should only show members matching a property
   Hotel Example: Show only 5-star properties, exclude budget hotels
```

#### A.8 Conditional Formatting — Complete Rule Engine

```
FORMAT HIERARCHY (Who Wins):
   Cell Format > Row/Column Format > Grid Format
   (Most specific wins)

RULE TYPES:
┌──────────────────┬──────────────────────────────────────────┐
│ Condition Type   │ Example                                  │
├──────────────────┼──────────────────────────────────────────┤
│ Value-Based      │ If Cell Value > 1,00,00,000 → Bold Green │
│ Member-Based     │ If Member Level > 0 → Bold (parents)     │
│ Property-Based   │ If Account Type = "Expense" → Red if +ve │
│ Cross-Cell       │ If [Actual] > [Budget] → Green Actual    │
│ Formula-Based    │ If ([Act]-[Bud])/[Bud]*100 < -10 → RED  │
│ #Missing         │ If Cell = #Missing → Display "–"         │
│ Zero             │ If Cell = 0 → Display "–" or hide row    │
└──────────────────┴──────────────────────────────────────────┘

HOTEL EXAMPLE — P&L Conditional Formatting:
Rule 1: Revenue Accounts (Account Type = Revenue)
   Actual > Budget → GREEN (favorable = earned more)
   Actual < Budget → RED   (unfavorable = earned less)

Rule 2: Expense Accounts (Account Type = Expense)
   Actual > Budget → RED   (unfavorable = spent more)
   Actual < Budget → GREEN (favorable = saved money)

Rule 3: Net Income
   > 0  → GREEN Bold
   < 0  → RED Bold + Red Background (LOSS!)
   = 0  → YELLOW (break-even warning)
```

#### B.2 Creating a Dashboard Tile — Step-by-Step

```
NAVIGATION: Home → Dashboards → Create Dashboard

Step 1: NAME AND LAYOUT
   └── Name: "Hotel_Executive_Dashboard"
   └── Folder: /Dashboards/Executive
   └── Layout: 3-column (top), Full-width (bottom)

Step 2: ADD TILE COMPONENT
   └── From Object Palette (left panel) → drag "Tile" onto canvas
   └── Properties Panel (right side):
       ├── Title: "Total Revenue"
       ├── Data Source: Select Form "KPI_Summary_Form"
       │   (This form must exist first — create it as a simple
       │    read-only grid with the KPI intersections)
       ├── Value: First cell of first column
       │   (Row 1 = "Total Revenue", Column 1 = "Actual")
       ├── Scaling: Auto (K=Thousands, L=Lakhs, Cr=Crore)
       ├── Conditional Color:
       │   ├── Green: Value > Budget value
       │   ├── Yellow: Value = Budget value (±2%)
       │   └── Red: Value < Budget value
       └── Size: Height = 33% of canvas

Step 3: ADD MORE TILES
   └── Repeat for "Occupancy %", "Net Income", "RevPAR"
   └── Each tile can point to a different row of the same form
       OR a different form entirely

Step 4: ADD CHART BELOW TILES
   └── Drag "Chart" component → drop below tiles
   └── Link to Form: "Monthly_Revenue_Trend_Form"
   └── Chart Type: Combination (Bar = Actual, Line = Budget)
   └── Height: 40% of canvas

Step 5: ADD DETAIL GRID
   └── Drag "Form" component → bottom-left
   └── Select Form: "PnL_Summary_Form"
   └── Make it Read-Only (for viewing, not data entry)

Step 6: ADD PIE CHART
   └── Drag "Chart" → bottom-right
   └── Link to: "Revenue_Mix_Form"
   └── Chart Type: Doughnut
   └── Colors: Custom palette (Blue=Room, Orange=F&B, Green=Events)

Step 7: MASTER-DETAIL LINKING
   └── Select "PnL_Summary_Form" → Tag as Master
   └── Select "Revenue_Trend_Chart" → Tag as Detail
   └── Map Dimension: Entity
   └── Effect: Click "Mumbai" in the grid → chart shows Mumbai trend

Step 8: SAVE AND RUN
   └── Save → Run → verify all tiles render
   └── Test Master-Detail: click different entities → charts update
```

#### B.3 Tile Properties — Every Configuration Option

|----------|---------|---------|---------------|

| **Data Source** | Any saved Form | None | KPI_Summary_Form |

#### B.5 Dashboard Object Limits & Constraints

| Constraint | Limit | Why It Matters |
|-----------|-------|---------------|
| **Max components per dashboard** | 12 (recommended 4-6) | Browser rendering performance |
| **Max tiles per tile component** | 10 | Each tile = 1 Essbase query |
| **Max data cells per dashboard** | ~50,000 total across all forms | Beyond this → timeout |
| **Recommended load time** | < 3 seconds | Users abandon slow dashboards |
| **Max concurrent Essbase queries** | = number of components | 6 forms = 6 simultaneous queries |
| **External URL components** | Must be HTTPS | HTTP blocked by modern browsers |
| **Image size** | Max 2MB per image | Large images slow rendering |

### Part D: Embedding Reports in Dashboards <a name="part-d-embedding-reports"></a>

#### D.1 Can You Put an EPM Report Inside a Dashboard?

**No — not directly.** EPM Reports and Dashboards 2.0 are separate systems:

```
COMMON CONFUSION:
   "I want to show my formatted P&L Report inside my Dashboard."

REALITY:
   ┌─────────────────────────────────────────────────┐
   │  EPM Report (Reports module)                     │
   │  → Pixel-perfect PDF/HTML document               │
   │  → Cannot be embedded as a Dashboard component   │
   │  → Lives in the Reports section of the navigator │
   └─────────────────────────────────────────────────┘

   ┌─────────────────────────────────────────────────┐
   │  Dashboard 2.0 (Dashboards module)               │
   │  → Interactive canvas with forms + charts        │
   │  → Components are Forms (grids) and Charts       │
   │  → Lives in the Dashboards section               │
   └─────────────────────────────────────────────────┘

WORKAROUND — How to show "report-like" content in a Dashboard:
   1. Create a READ-ONLY form with the same layout as your report
   2. Add that form to the dashboard
   3. Add charts linked to the form
   4. Add tiles for KPIs
   → Result looks like a "report in a dashboard"

ALTERNATIVE — Using URLs:
   1. Generate an EPM Report as HTML
   2. Copy the HTML report URL
   3. Add a "URL" component to the Dashboard
   4. Paste the report URL
   → The report renders inside the dashboard iframe
   → ⚠️ May not work if cross-origin policies block it
```

#### E.2 Report Bursting — Complete Walkthrough

```
THE PROBLEM:
   Hotel Pvt Ltd has 5 hotels. Each General Manager needs their
   OWN P&L report emailed monthly. Currently, the FP&A analyst:
   1. Opens the P&L Report
   2. Changes Entity POV to "Mumbai"
   3. Exports to PDF
   4. Emails to Mumbai GM
   5. Repeats 4 more times for Delhi, Goa, Jaipur, Udaipur
   → Total time: 45 minutes of manual work, EVERY MONTH

THE SOLUTION: BURSTING
   → Create ONE template report
   → Define a bursting definition
   → System generates 5 PDFs automatically
   → Emails each GM their specific report
   → Time: 2 minutes (setup once, runs forever)

STEP-BY-STEP:

Step 1: CREATE REPORT TEMPLATE
   └── Create a standard P&L report (as described in Part A)
   └── Set Entity as PAGE DIMENSION (not fixed POV)
   └── This allows the entity to be "switched" during bursting

Step 2: CREATE BURSTING DEFINITION
   └── Navigator → Reports → Bursting → Create
   └── Name: "Monthly_PnL_Burst"
   └── Select Report: "Monthly_PnL_Report"
   └── Burst Dimension: Entity
   └── Members: ILvl0Descendants("Total_Entity")
       → Mumbai_Taj, Delhi_Palace, Goa_Beach, Jaipur_Fort, Udaipur_Lake

Step 3: CREATE DISTRIBUTION FILE (CSV)
   └── Upload CSV mapping members to email addresses:
   
   Entity_Member,Email_Address,Output_Format
   Mumbai_Taj,gm.mumbai@hotelpvtltd.com,PDF
   Delhi_Palace,gm.delhi@hotelpvtltd.com,PDF
   Goa_Beach,gm.goa@hotelpvtltd.com,PDF
   Jaipur_Fort,gm.jaipur@hotelpvtltd.com,PDF
   Udaipur_Lake,gm.udaipur@hotelpvtltd.com,PDF

Step 4: CONFIGURE EMAIL TEMPLATE
   └── Subject: "Monthly P&L Report — <<MemberAlias("Entity")>>"
   └── Body: "Dear GM, please find attached your monthly P&L report
              for <<MemberAlias("Entity")>>. 
              Period: <<MemberName("Period")>>.
              Generated: <<CurrentDate>>"

Step 5: RUN BURST
   └── Click "Run" → system generates:
       ├── Monthly_PnL_Mumbai_Taj.pdf → emails gm.mumbai@...
       ├── Monthly_PnL_Delhi_Palace.pdf → emails gm.delhi@...
       ├── Monthly_PnL_Goa_Beach.pdf → emails gm.goa@...
       ├── Monthly_PnL_Jaipur_Fort.pdf → emails gm.jaipur@...
       └── Monthly_PnL_Udaipur_Lake.pdf → emails gm.udaipur@...

Step 6: SCHEDULE (See Part F)
   └── Schedule bursting to run on 5th of every month at 6 AM
```

#### E.3 Bursting Security Model

```
SECURITY QUESTION: "Does bursting bypass data security?"

ANSWER: It depends on the execution mode.

MODE 1: RUN AS ADMIN (Default)
   └── The admin's security is used
   └── Admin has access to ALL entities
   └── All 5 PDFs contain full data
   └── ⚠️ Risk: If a GM forwards their PDF, data is visible

MODE 2: RUN AS RECIPIENT
   └── Each PDF is generated using the RECIPIENT's security
   └── If Delhi GM only has access to Delhi data:
       └── Their PDF shows Delhi data
       └── Even if bursting includes Mumbai, it won't show
   └── ✅ Most secure option
   └── ⚠️ Slower (runs 5 separate security contexts)

HOTEL EXAMPLE:
   GM Mumbai has Read access to: Mumbai_Taj ONLY
   GM Delhi has Read access to: Delhi_Palace ONLY
   
   If bursting runs "As Recipient":
   Mumbai PDF → shows Mumbai data (accessible)
   Delhi PDF → shows Delhi data (accessible)
   
   If bursting runs "As Admin":
   Mumbai PDF → shows Mumbai data (admin sees everything)
   Delhi PDF → shows Delhi data (admin sees everything)
   Both PDFs have full data regardless of GM's security
```

## MISTAKES — Common Errors & Fixes <a name="mistakes"></a>

### Mistake 1: Tile Shows Wrong Value

```
SYMPTOM: Dashboard Tile shows "₹0" even though data exists.

ROOT CAUSE: The underlying form has hidden/collapsed columns.
   The Tile reads the FIRST VISIBLE column of the form.
   If you collapsed Column A (which has Actual data),
   the Tile reads Column B (which might be empty).

FIX:
   1. Open the source form in Form Designer
   2. Verify the first column contains the KPI value
   3. Remove any hidden columns that precede the data column
   4. Save form → refresh dashboard
```

### Mistake 2: Dashboard Timeout

```
SYMPTOM: Dashboard shows spinning wheel for 30+ seconds, then errors.

ROOT CAUSE: Too many components pulling too much data.
   6 forms × 10,000 cells each = 60,000 cells = timeout

FIX:
   1. Reduce form complexity:
      └── Enable "Suppress Missing Blocks" on ALL forms
      └── Limit rows: Use ILvl0Descendants instead of IDescendants
      └── Limit columns: Show 6 months, not 12
   2. Reduce components: Keep to 4-6 per dashboard
   3. Use ASO reporting cube for chart data (faster retrieval)
   4. Use "Edit Without Data" mode to adjust layout
      (avoids triggering queries during design)
```

### Mistake 3: Report Bursting Generates Blank PDFs

```
SYMPTOM: Mumbai GM receives email with PDF attached, but PDF is blank.

ROOT CAUSES:
   A. Data Security: GM's user account lacks Read access to Mumbai
      in the Essbase cube. Bursting ran with "As Recipient" mode.
      FIX: Grant Read access to Mumbai entity in Access Control.

   B. #Missing Data: No data loaded for the period/entity.
      FIX: Verify data exists using Smart View ad-hoc.

   C. Suppress Missing = ON: All rows have #Missing, so they're
      all suppressed, leaving an empty report.
      FIX: Turn off "Suppress Missing Rows" or load data first.
```

### Mistake 4: Master-Detail Linking Doesn't Work

```
SYMPTOM: Clicking a row in the Master form does nothing.
   Detail form doesn't refresh.

ROOT CAUSES:
   A. Forgot to "Tag as Master"
      FIX: Select the Master form → Properties → "Tag as Master"

   B. Dimension mismatch
      FIX: The linked dimension must exist on BOTH forms.
      If Master has Entity but Detail doesn't have Entity → fails.

   C. User doesn't right-click → "Apply Context"
      FIX: Users must right-click on the member → "Apply Context"
      It does NOT auto-apply on left-click in all versions.

   D. Detail form uses a different cube
      FIX: Ensure both forms point to the same application/cube
      OR use the same Entity dimension name across cubes.
```

### Mistake 5: Infolet Not Visible to Users

```
SYMPTOM: Admin created an Infolet, but planners can't see it.

ROOT CAUSES:
   A. Navigation Flow not updated
      FIX: Navigator → Navigation Flows → Edit
      → Enable the Infolet page → Assign to correct flow

   B. Security: User role doesn't include Infolet access
      FIX: Check the user's assigned navigation flow
      → Ensure infolets are enabled in THEIR flow

   C. Infolet not saved / not published
      FIX: Re-open infolet designer → verify "Save" was clicked

   D. Pod restriction (25.10+): New infolet creation disabled
      FIX: Use Dashboard Tiles instead (Oracle's new direction)
```

### Mistake 6: Report Formula Column Shows Wrong Calculation

```
SYMPTOM: Variance % shows "100%" for everything.

ROOT CAUSE: Formula references wrong column index.
   Formula: =[Column2] - [Column1]
   But Column1 = "Account" (text), Column2 = "Actual"
   You meant: =[Column3] - [Column2] (Actual - Budget)

FIX:
   1. Open report grid → edit formula column
   2. Verify column references:
      Column A = Account (text label)
      Column B = Actual
      Column C = Budget
      Formula: =[B] - [C] (not =[2] - [1])
   3. For Variance%: =([B] - [C]) / [C] * 100
   4. Handle division by zero: =IF([C]=0, 0, ([B]-[C])/[C]*100)
```

## EDGE CASES — Things That Break Silently <a name="edge-cases"></a>

### Edge Case 1: Dashboard After Form Restructure

```
SCENARIO: Admin deletes a column from Form "Revenue_Summary".
   Dashboard still references the old form structure.

RESULT: Dashboard component shows error or blank data.

WHY: Dashboards don't store data — they render the underlying form.
   If the form structure changes, the dashboard can't find expected columns.

PREVENTION:
   → Always check "Usage" before modifying a form
   → Navigator → Forms → [Right-click form] → "Show Usage"
   → This lists all dashboards, infolets, and task lists using this form
```

### Edge Case 2: Cross-Cube Tile in Dashboard

```
SCENARIO: You want a tile showing BSO Actual data next to
   an ASO Reporting cube Variance.

PROBLEM: A single form can only connect to ONE cube.
   Dashboard tiles are powered by forms.

WORKAROUND:
   → Create Form 1 (BSO cube) → Tile 1
   → Create Form 2 (ASO cube) → Tile 2
   → Place both on the same dashboard
   → They appear side-by-side but query different cubes

RISK: If BSO and ASO are out of sync (Smart Push hasn't run),
   the tiles will show inconsistent numbers.
```

### Edge Case 3: Bursting with Shared Members

```
SCENARIO: Entity hierarchy has shared members:
   Total_Entity
   ├── West_Region
   │   ├── Mumbai_Taj
   │   └── Goa_Beach (SHARED from South_Region)
   └── South_Region
       └── Goa_Beach (PRIMARY)

PROBLEM: Bursting on ILvl0Descendants("Total_Entity") may
   generate TWO PDFs for Goa_Beach (once from each region).

FIX: Use explicit member list instead of function:
   Members: Mumbai_Taj, Delhi_Palace, Goa_Beach, Jaipur_Fort, Udaipur_Lake
   OR: Filter bursting to PRIMARY members only
```

### Edge Case 4: Report with 10,000+ Rows

```
SCENARIO: Report grid uses IDescendants("Total_Account")
   which has 10,000 members across all hotels.

RESULT: Report generation takes 15+ minutes, may timeout.

FIX:
   1. Use ILvl0Descendants (leaf members only) instead of IDescendants
   2. Add filters: Only accounts with data > 0
   3. Use "Suppress Missing Rows" and "Suppress Zero Rows"
   4. Use ASO reporting cube (faster for large retrievals)
   5. Split into multiple reports (one per Entity)
```

### Edge Case 5: Gauge Showing Wrong Color

```
SCENARIO: Gauge configured with ranges:
   Red: 0-60, Yellow: 60-75, Green: 75-100
   Value = 75.0

RESULT: Shows YELLOW, not GREEN.

WHY: Range boundary is EXCLUSIVE on the upper end.
   Yellow: 60 ≤ value < 75 (includes 60, excludes 75)
   Green: 75 ≤ value ≤ 100

FIX: Adjust ranges to avoid boundary conflicts:
   Red: 0 to 59.99
   Yellow: 60 to 74.99
   Green: 75 to 100
```

### Edge Case 6: Scheduled Report Shows Stale Data

```
SCENARIO: Monthly board pack scheduled for 5th at 6AM.
   But data load runs at 7AM on the 5th.

RESULT: Board pack PDF contains LAST month's data.

FIX:
   1. Schedule data load first (5AM)
   2. Schedule report generation AFTER load completes (8AM)
   3. Better: Use EPM Automate to chain:
      Step 1: epmautomate importdata
      Step 2: epmautomate runbusinessrule "Aggregation"
      Step 3: epmautomate runreport "Monthly_Board_Pack"
      → Guarantees sequence
```

### Edge Case 7: External URL Tile in Dashboard

```
SCENARIO: You add a URL component to embed Google Analytics.

RESULT: Shows blank white box or "Refused to connect" error.

WHY: Cross-Origin Resource Sharing (CORS) policy.
   Google Analytics (or any external site) blocks being loaded
   inside an iframe from a different domain (oracle.com).

WHAT WORKS:
   → Internal Oracle URLs (same EPM domain)
   → Sites that explicitly allow iframe embedding
   → HTTPS only (HTTP is blocked)

WHAT DOESN'T WORK:
   → Google, Salesforce, most SaaS tools
   → Any site with X-Frame-Options: DENY header
```

## TEST ME — Interview Questions <a name="test-me"></a>

### 🟢 Beginner Level

**Q1: What are the three reporting tools in Oracle EPM Cloud?**
> **A:** (1) **EPM Reports** — cloud-native, web-based, Oracle's go-forward direction. Grid + Chart + Text on a canvas. (2) **Financial Reporting (FR)** — legacy Java-based, pixel-perfect, being deprecated. Uses FR Web Studio. (3) **Smart View** — Excel-based ad-hoc reporting with HsGetValue functions and free-form grids.

**Q2: What is a Dashboard Tile in EPM Cloud?**
> **A:** A Tile is a large, prominent KPI display box inside a Dashboard 2.0. It shows a single metric value (like "₹6.3Cr Total Revenue") with conditional coloring (green = above target, red = below). It's powered by an underlying form's data.

**Q3: What is the difference between an Infolet and a Dashboard?**
> **A:** An **Infolet** lives on the EPM Home Page — it's visible immediately at login. It has 3 views (Front, Back, Expanded) and is read-only. A **Dashboard** is a separate page you navigate to — it can contain forms, charts, tiles, and supports data entry and master-detail interaction.

**Q4: What components can you place in an EPM Report?**
> **A:** Grid (data table from Essbase), Chart (17 types), Text Box (static or dynamic with functions like <<MemberName>>), Image (logos), and Pages (multi-page layout with headers/footers).

**Q5: What is report bursting?**
> **A:** Bursting automatically generates separate reports for each member of a dimension (usually Entity) and emails personalized PDFs to the respective managers. Example: Mumbai GM gets Mumbai-only P&L, Delhi GM gets Delhi-only P&L.

---

### 🟡 Intermediate Level

**Q6: You create a Dashboard with 6 forms. It times out. Why?**
> **A:** When a dashboard loads, it fires simultaneous Essbase queries for ALL components. 6 forms = 6 parallel queries. If those forms are poorly designed (no "Suppress Missing Blocks", too many members selected, large row counts), Essbase gets overwhelmed. Fix: reduce to 4 forms, enable suppression, use ASO cube for read-only charts, limit member selections with ILvl0Descendants.

**Q7: How do you configure Master-Detail linking in a Dashboard?**
> **A:** (1) Create two forms with a shared dimension (e.g., Entity). (2) Add both to a dashboard. (3) Select the summary form → Properties → "Tag as Master". (4) Map the linking dimension (Entity). (5) When the user right-clicks a member in the Master and clicks "Apply Context", the Detail form refreshes to show that member's data.

**Q8: A Dashboard Tile shows "₹0" even though data exists in the cube. What's wrong?**
> **A:** The tile reads the first visible column of its source form. If the form has hidden/collapsed columns preceding the data column, the tile picks up the wrong column. Fix: open the form designer, remove hidden columns, ensure the value column is the first visible column.

**Q9: What is the formatting hierarchy in EPM Reports?**
> **A:** Cell Format overrides Row/Column Format, which overrides Grid Format. Most specific wins. Example: If the grid has "Blue text" format, but a specific row has "Red text" format, and cell [3,2] has "Green text" format — cell [3,2] will be green, the rest of that row will be red, and all other cells will be blue.

**Q10: How do you create a variance report that correctly colors Revenue vs Expense variances?**
> **A:** Revenue and Expense have OPPOSITE variance logic. Revenue: Actual > Budget = favorable (GREEN). Expense: Actual > Budget = unfavorable (RED, you overspent). Use conditional formatting with TWO rules: Rule 1 (Revenue accounts): If Variance > 0 → Green. Rule 2 (Expense accounts): If Variance > 0 → Red. Use Account Type property or UDA to distinguish them in the conditional rule.

---

### 🔴 Architect Level

**Q11: Design the complete reporting architecture for a 500-entity global organization using Oracle EPM Cloud.**
> **A:**
> 1. **Cube Design:** BSO for data entry (write-back), ASO Reporting cube for fast read-only reporting. Smart Push from BSO to ASO on save.
> 2. **Reports:** Create 5-6 standard EPM Report templates (P&L, BS, CF, KPI, Variance). Use Page Dimension = Entity so one template serves all entities.
> 3. **Bursting:** Configure bursting on Entity dimension with CSV distribution mapping 500 entity managers to their email addresses. Run in "As Recipient" mode for security.
> 4. **Dashboards:** Create role-specific dashboards:
>    - Executive Dashboard: 3 tiles (Revenue, Profit, Growth) + trend chart + summary grid with master-detail
>    - Regional Dashboard: Entity selector (master) + regional P&L (detail) + geographic map
>    - Operational Dashboard: Editable forms + action buttons (run business rules)
> 5. **Infolets:** 3 infolet pages — Financial KPIs, Operational KPIs, Forecast Status
> 6. **Report Books:** "Board Pack" combining P&L + BS + CF + KPIs. Scheduled monthly.
> 7. **Navigation Flow:** Role-based — CFO sees dashboards + reports. Planners see data entry + reports. Viewers see reports only.
> 8. **Automation:** EPM Automate script chains: Data Load → Aggregation → Smart Push → Report Generation → Bursting → Email notification.

**Q12: A client wants a real-time dashboard that updates the P&L chart when a planner saves data in the same dashboard. The chart uses the ASO reporting cube. How do you architect this?**
> **A:** The data entry form writes to BSO. The chart reads from ASO. When the planner saves, BSO is updated but ASO is NOT. You must configure **Smart Push** on the data entry form with "Run After Save" enabled. Smart Push moves data from BSO → ASO. Then configure the dashboard to **refresh linked components on save**. The sequence becomes: User saves → BSO writes → Smart Push fires → ASO updates → Dashboard refreshes chart → chart shows new data. Edge case: If Smart Push takes 10+ seconds, the chart may show stale data briefly. Consider adding a "Refresh" button or showing a loading spinner.

**Q13: You burst a P&L report to 500 entities. 3 entities receive blank PDFs. How do you troubleshoot?**
> **A:** Step-by-step:
> 1. **Check data:** Open Smart View → set POV to each of the 3 entities → run ad-hoc → verify data exists.
> 2. **Check security:** If bursting runs "As Recipient", verify those 3 GMs have Read access to their entity in Access Control.
> 3. **Check member name:** The distribution CSV may have a typo in the entity member name (e.g., "Delhi_Palce" instead of "Delhi_Palace").
> 4. **Check suppress settings:** If the report has "Suppress Missing Rows = Yes" and those entities have ALL #Missing data, every row gets suppressed = blank PDF.
> 5. **Check data load status:** Those 3 entities' data may not have been loaded yet (data load file was incomplete).
> 6. **Validate:** Run the report manually with each entity in the POV to reproduce the blank output.

**Q14: Oracle deprecated infolets in newer pods (25.10+). A client's CFO insists on "tiles on the home page." What do you recommend?**
> **A:** Three alternatives:
> 1. **Dashboard as Home Page:** Create a KPI Dashboard with tiles → set it as the default landing page via Navigation Flow → "Set as Home" option. The CFO logs in and sees the dashboard immediately.
> 2. **Custom Navigation Flow Card:** Design a card that opens a dashboard — make it the first card, prominently placed. Visual effect is similar to infolets.
> 3. **Narrative Reporting:** If the client has an Enterprise license, use Oracle Narrative Reporting to create rich, Word-style dashboards with embedded EPM data that can be pinned to the home page.
> 4. **Custom URL Tab:** Use a Navigation Flow tab that loads a URL pointing to a lightweight HTML report generated nightly — acts as a static "infolet" substitute.

**Q15: A report generates correctly in HTML but the PDF export has misaligned columns and truncated text. How do you fix it?**
> **A:** HTML and PDF renderers handle layout differently:
> 1. **Column widths:** PDF uses fixed pixel widths, HTML is flexible. Set explicit column widths in the grid properties (don't rely on auto-width).
> 2. **Font size:** Use a smaller font (8-9pt) for columns with long text. PDF doesn't word-wrap the same way HTML does.
> 3. **Page orientation:** Switch to Landscape if columns are too wide for Portrait.
> 4. **Margins:** Reduce margins (0.5" instead of 1") to give more horizontal space.
> 5. **Text truncation:** Enable "Wrap Text" in column formatting (off by default in PDF).
> 6. **Test iteratively:** Always preview as PDF during design (not just HTML) — toggle the preview mode.
