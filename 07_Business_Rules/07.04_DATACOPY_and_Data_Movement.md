# 07.04 — DATACOPY and Data Movement: Complete Guide

> **Module:** 07_Business_Rules | **Topic:** DATACOPY, Copy Version, Data Movement Patterns
> **Audience:** Service Administrator / Rule Developer

---

## 1. WHY — What Real-World Problem Does This Solve?

**The problem:** Every budget cycle starts by seeding Budget numbers from last year's Actuals. Every forecast starts by copying Actuals for closed months and Budget for remaining months. Every version lock requires copying Working to Final. These copy operations are the most common operations in EPM.

**The solution:** DATACOPY is the Essbase command for bulk data movement between members of the same dimension. Combined with FIX statements, it's the fastest way to seed, copy, and migrate data.

---

## 2. DATACOPY — SYNTAX AND BEHAVIOR

### Basic Syntax

```essbase
DATACOPY SourceMember TO TargetMember;

/* Copies data from one member to another within the same dimension */
DATACOPY "Actual" TO "Budget";        /* Copy Scenario */
DATACOPY "Working" TO "Final";        /* Copy Version */
DATACOPY "FY2025" TO "FY2026";        /* Copy Year */
DATACOPY "Mumbai_Hotel" TO "Test_Hotel"; /* Copy Entity */
```

### How DATACOPY Works

```
DATACOPY "Actual" TO "Budget":

Before:                            After:
Actual:  Jan=100, Feb=200          Actual:  Jan=100, Feb=200  (unchanged)
Budget:  Jan=0,   Feb=0            Budget:  Jan=100, Feb=200  (copied!)

Key behaviors:
  ✅ Copies ALL intersections within the FIX scope
  ✅ Creates new blocks if they don't exist in the target
  ✅ Overwrites existing data in target
  ❌ Does NOT delete target data outside FIX scope
```

### DATACOPY with FIX (Always Use!)

```essbase
/* ❌ BAD — copies EVERYTHING (all entities, all periods, all years) */
DATACOPY "Actual" TO "Budget";

/* ✅ GOOD — scoped copy */
FIX("Working", "FY2026", @RELATIVE("All_Hotels", 0))
  DATACOPY "Actual" TO "Budget";
ENDFIX
/* Only copies FY2026, Working version, leaf entities */
```

## 3. CLEAR BEFORE COPY — CRITICAL PATTERN

```essbase
/* THE MOST IMPORTANT PATTERN IN EPBCS */
/* Always clear the target BEFORE copying to avoid stale data */

/* Step 1: Clear target */
FIX("Budget", "Working", "FY2026")
  CLEARDATA "Budget";
ENDFIX

/* Step 2: Remove empty blocks created by CLEARDATA */
CLEARBLOCK ALL;

/* Step 3: Copy fresh data */
FIX("Working", "FY2026", @RELATIVE("All_Hotels", 0))
  DATACOPY "Actual" TO "Budget";
ENDFIX

/* WHY: Without clearing, if Delhi_Hotel was deleted from Actuals
   but had Budget data from last cycle, the old Budget data persists.
   CLEARDATA removes it. CLEARBLOCK removes the empty blocks. */
```

## 4. ALL DATA MOVEMENT COMMANDS

| Command | What It Does | Creates Blocks? | Speed |
|---------|-------------|----------------|-------|
| **DATACOPY** | Copies data between members of same dim | ✅ Yes | ⚡ Fast |
| **CLEARDATA** | Sets all data to #MISSING in scope | ❌ No (blocks remain) | ⚡ Fast |
| **CLEARBLOCK ALL** | Removes blocks that are 100% empty | ❌ Removes blocks | ⚡ Fast |
| **CLEARBLOCK UPPER** | Removes empty upper-level blocks | ❌ Removes blocks | Fast |
| **Assignment (=)** | Sets cell values via formula | Depends on SET | Varies |
| **SET CREATEBLOCKONEQ** | Controls block creation on `=` | Controls flag | N/A |

## 5. COPY PATTERNS — THE BIG 5

### Pattern 1: Seed Budget from Prior Year Actual

```essbase
/* Budget FY2027 = Actual FY2026 as starting point */

/* Clear existing budget */
FIX("Budget", "Working", "FY2027")
  CLEARDATA "Budget";
ENDFIX
CLEARBLOCK ALL;

/* Copy actual to budget with year shift */
SET CREATENONMISSINGBLK ON;
FIX("Working", @RELATIVE("All_Hotels", 0))
  DATACOPY "Actual"->"FY2026" TO "Budget"->"FY2027";
ENDFIX
SET CREATENONMISSINGBLK OFF;

/* Apply growth rate */
FIX("Budget", "Working", "FY2027", @RELATIVE("All_Hotels", 0))
  "Total_Revenue" = "Total_Revenue" * 1.05;  /* 5% growth */
  "Total_Expenses" = "Total_Expenses" * 1.03; /* 3% inflation */
ENDFIX
```

### Pattern 2: Lock Version (Working → Final)

```essbase
/* Copy Working version to Final after approval */
FIX("Budget", "FY2026", @RELATIVE("All_Hotels", 0))
  DATACOPY "Working" TO "Final";
ENDFIX
```

### Pattern 3: Rolling Forecast (Actuals + Forecast Blend)

```essbase
/* Closed months = Actual, Open months = Forecast */
/* If current month is Sep, then Jan-Aug = Actual, Sep-Dec = Forecast */

/* Step 1: Copy Actuals for closed months */
FIX("Forecast", "Working", "FY2026", @RELATIVE("All_Hotels", 0))
  FIX(@RANGE("Period", "Jan", &PriorMonth))
    DATACOPY "Actual" TO "Forecast";
  ENDFIX
ENDFIX

/* Step 2: Keep existing forecast for open months (don't touch) */
/* Sep-Dec already has user-entered forecast data */
```

### Pattern 4: Copy Entity (Clone a Hotel)

```essbase
/* Create test hotel with Mumbai's data */
SET CREATENONMISSINGBLK ON;
FIX("Budget", "Working", "FY2026")
  DATACOPY "Mumbai_Hotel" TO "Test_Hotel";
ENDFIX
SET CREATENONMISSINGBLK OFF;
```

### Pattern 5: Clear and Reset

```essbase
/* Nuclear option — clear ALL data for a scenario/version */
FIX("Forecast", "Working", "FY2026")
  CLEARDATA "Forecast";
ENDFIX
CLEARBLOCK ALL;

/* Verify: Check block count in App Statistics */
/* Should decrease significantly */
```

## 6. DATACOPY vs ASSIGNMENT vs SMART PUSH

| Feature | DATACOPY | Assignment (=) | Smart Push |
|---------|----------|---------------|------------|
| **Speed** | ⚡ Fastest | Medium | Medium |
| **Scope** | Entire dimension member | Per-cell formula | Cross-cube |
| **Creates blocks** | ✅ Always | Depends on SET | ✅ |
| **Cross-cube** | ❌ Same cube only | ❌ Same cube | ✅ Cross-cube |
| **Transformation** | ❌ Exact copy | ✅ Apply formulas | ❌ Exact copy |
| **Use case** | Bulk copy (seed budget) | Calculated copy (growth) | Copy to reporting cube |

## 7. SHOW ME — Hotel Pvt Ltd Annual Budget Cycle

```essbase
/* ===== Annual Budget Seeding Process ===== */
/* Run once per year when Budget cycle opens */

SET LOCKBLOCK ON;

/* ===== Phase 1: Clear prior budget ===== */
@CalcMgrLogMessageTrace("Phase 1: Clearing old budget data");
FIX("Budget", "Working", "FY2027")
  CLEARDATA "Budget";
ENDFIX
CLEARBLOCK ALL;

/* ===== Phase 2: Copy prior year actuals ===== */
@CalcMgrLogMessageTrace("Phase 2: Copying FY2026 Actuals to FY2027 Budget");
SET CREATENONMISSINGBLK ON;
FIX("Working", @RELATIVE("All_Hotels", 0))
  DATACOPY "Actual"->"FY2026" TO "Budget"->"FY2027";
ENDFIX
SET CREATENONMISSINGBLK OFF;

/* ===== Phase 3: Apply growth assumptions ===== */
@CalcMgrLogMessageTrace("Phase 3: Applying growth rates");
FIX("Budget", "Working", "FY2027", @RELATIVE("All_Hotels", 0))
  /* Revenue: 5% growth */
  "Room_Revenue" = "Room_Revenue" * 1.05;
  "F&B_Revenue" = "F&B_Revenue" * 1.08;
  "Spa_Revenue" = "Spa_Revenue" * 1.10;
  
  /* Expenses: 3% inflation */
  "Labor" = "Labor" * 1.03;
  "Maintenance" = "Maintenance" * 1.03;
  "Utilities" = "Utilities" * 1.05;
  
  /* Recalculate totals */
  "Total_Revenue" = "Room_Revenue" + "F&B_Revenue" + "Spa_Revenue";
  "Total_Expenses" = "Labor" + "Maintenance" + "Utilities" + "Amenities";
  "Net_Income" = "Total_Revenue" - "Total_Expenses";
  
  IF("Total_Revenue" <> 0)
    "Profit_Margin" = "Net_Income" / "Total_Revenue" * 100;
  ENDIF
ENDFIX

/* ===== Phase 4: Aggregate ===== */
@CalcMgrLogMessageTrace("Phase 4: Aggregating Entity dimension");
FIX("Budget", "Working", "FY2027")
  AGG("Entity");
ENDFIX

SET LOCKBLOCK OFF;
@CalcMgrLogMessageTrace("Budget seeding complete!");
```

## 8. COMMON MISTAKES

| Mistake | Symptom | Fix |
|---------|---------|-----|
| DATACOPY without CLEARDATA first | Old target data persists | Always clear before copy |
| DATACOPY without FIX | Copies entire cube — takes hours | Always scope with FIX |
| Forgot CREATENONMISSINGBLK ON for cross-year copy | No data appears in target year | Turn ON for cross-year/cross-entity |
| Forgot to turn CREATENONMISSINGBLK OFF | Block explosion on subsequent formulas | Turn OFF immediately after DATACOPY |
| CLEARDATA without CLEARBLOCK | Empty blocks waste space | Always CLEARBLOCK ALL after CLEARDATA |
| DATACOPY across cubes | Error — DATACOPY is same-cube only | Use Smart Push for cross-cube |

## 9. INTERVIEW QUESTIONS

### Beginner
**Q: What is DATACOPY and when do you use it?**
> DATACOPY copies data from one dimension member to another within the same cube. For example, `DATACOPY "Actual" TO "Budget"` copies all Actual data to the Budget scenario. It's the fastest way to seed budgets from actuals, lock versions (Working → Final), or clone entities. Always use a FIX statement to scope the copy, and always CLEARDATA + CLEARBLOCK on the target before copying to avoid stale data.

### Architect
**Q: Design the annual budget seeding process for Hotel Pvt Ltd.**
> Four phases: (1) **Clear:** CLEARDATA + CLEARBLOCK on Budget/FY2027 to remove any prior budget data. (2) **Copy:** DATACOPY Actual→FY2026 TO Budget→FY2027 with CREATENONMISSINGBLK ON (cross-year needs block creation). Turn CREATENONMISSINGBLK OFF immediately after. (3) **Transform:** Apply growth rates per account (Revenue +5%, Expenses +3%). Recalculate totals and ratios. (4) **Aggregate:** AGG Entity dimension. Run as a scheduled EPM Automate job. Total expected runtime: < 30 seconds for 5 hotels. Key risk: Forgetting CREATENONMISSINGBLK OFF → causes block explosion in Phase 3.
