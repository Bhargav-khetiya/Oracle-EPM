# PATTERN 1: Monthly Spreading (Annual to Months)

**Scenario:** User enters an annual budget of $120,000. Spread it evenly across 12 months.

```essbase
SET UPDATECALC OFF;
SET MSG SUMMARY;

FIX("Budget", "Working", "FY24", @RELATIVE("Total_Entity", 0))
    @CHILDREN("YearTotal")(
        IF("YearTotal" <> #Missing AND "YearTotal" <> 0)
            @CHILDREN("YearTotal") = "YearTotal" / 12;
        ENDIF
    )
ENDFIX
```

**Variation: Seasonal Spreading (using driver)**
```essbase
FIX("Budget", "Working", "FY24", @RELATIVE("Total_Entity", 0))
    @CHILDREN("YearTotal")(
        IF("YearTotal" <> #Missing AND "Seasonal_Factor" <> 0 AND "Seasonal_Factor" <> #Missing)
            @CHILDREN("YearTotal") = "YearTotal" * "Seasonal_Factor";
        ENDIF
    )
ENDFIX
```

# PATTERN 2: Seeding Budget from Actuals with Growth Rate

**Scenario:** Create next year's budget by copying last year's actuals and applying a 5% increase.

```essbase
SET UPDATECALC OFF;
SET MSG SUMMARY;

/* Step 1: Clear target */
FIX("Budget", "Working", "FY25")
    CLEARBLOCK ALL;
ENDFIX

/* Step 2: Copy Actuals to Budget with 5% increase */
FIX("Working", @RELATIVE("Total_Entity", 0))
    DATACOPY "Actual" -> "FY24" TO "Budget" -> "FY25";
ENDFIX

/* Step 3: Apply growth rate */
FIX("Budget", "Working", "FY25", @RELATIVE("Total_Entity", 0))
    @UDA("Account", "Revenue_Account")(
        "Revenue" = "Revenue" * 1.05;
    )
    @UDA("Account", "Expense_Account")(
        "Expense" = "Expense" * 1.03;  /* 3% inflation on expenses */
    )
ENDFIX
```

# PATTERN 3: Intercompany Elimination

**Scenario:** Company US sells $500K to Company UK. Both record the transaction. At the consolidated level, this $500K must be eliminated to avoid double-counting.

```essbase
SET UPDATECALC OFF;
SET MSG SUMMARY;
SET CREATEBLOCKONEQ ON;

FIX("Actual", "Working", &CurrYear)
    /* Write elimination entries to the Elimination entity */
    FIX("Corp_Elim")
        "IC_Revenue" = "IC_Revenue" -> "US_Entity" * -1;
        "IC_COGS" = "IC_COGS" -> "UK_Entity" * -1;
        "IC_Receivable" = "IC_Receivable" -> "US_Entity" * -1;
        "IC_Payable" = "IC_Payable" -> "UK_Entity" * -1;
    ENDFIX
ENDFIX

SET CREATEBLOCKONEQ OFF;
```

# PATTERN 4: YTD to Periodic Conversion

**Scenario:** ERP sends Year-to-Date data (Jan=100, Feb=250, Mar=400). Convert to periodic (Jan=100, Feb=150, Mar=150).

```essbase
SET UPDATECALC OFF;
SET MSG SUMMARY;

FIX("Actual", "Working", &CurrYear, @RELATIVE("Total_Entity", 0))
    /* Store YTD values temporarily */
    "YTD_Temp" = "YTD_Source";

    /* Convert to periodic */
    @CHILDREN("YearTotal")(
        IF(@ISMBR("Jan"))
            "Periodic_Value" = "YTD_Temp";
        ELSE
            "Periodic_Value" = "YTD_Temp" - @PRIOR("YTD_Temp", 1);
        ENDIF
    )
ENDFIX
```

# PATTERN 5: Weighted Average Price

**Scenario:** Calculate the weighted average price across products: `Avg_Price = Total_Revenue / Total_Units`.

```essbase
SET UPDATECALC OFF;
SET MSG SUMMARY;

FIX("Budget", "Working", &CurrYear, @RELATIVE("Total_Entity", 0))
    "Weighted_Avg_Price"(
        IF(@SUM("Product", @CHILDREN("All_Products"), "Units") <> 0 AND 
           @SUM("Product", @CHILDREN("All_Products"), "Units") <> #Missing)
            "Weighted_Avg_Price" = @SUM("Product", @CHILDREN("All_Products"), "Revenue") / 
                                   @SUM("Product", @CHILDREN("All_Products"), "Units");
        ELSE
            "Weighted_Avg_Price" = #Missing;
        ENDIF
    )
ENDFIX
```

# PATTERN 6: Conditional Aggregation (Skip Inactive Entities)

**Scenario:** Only aggregate entities tagged with UDA "Active". Skip inactive entities to prevent stale data from polluting rollups.

```essbase
SET UPDATECALC OFF;
SET MSG SUMMARY;

/* Step 1: Clear parent entity data */
FIX("Budget", "Working", &CurrYear)
    CLEARDATA @RELATIVE("Total_Entity", 1);  /* Clear Level 1+ */
ENDFIX

/* Step 2: Aggregate only active entities */
FIX("Budget", "Working", &CurrYear, @UDA("Entity", "Active"))
    AGG("Entity");
ENDFIX
```

# PATTERN 7: Balance Sheet Carryforward

**Scenario:** At the start of a new year, carry forward the ending balance sheet accounts from the last month of the prior year to BegBalance of the new year.

```essbase
SET UPDATECALC OFF;
SET CREATEBLOCKONEQ ON;
SET MSG SUMMARY;

FIX("Actual", "Working", &CurrYear, @RELATIVE("Total_Entity", 0))
    FIX(@UDA("Account", "BS_Account"))
        "BegBalance" = "Dec" -> &PriorYear;
    ENDFIX
ENDFIX

SET CREATEBLOCKONEQ OFF;
```

# PATTERN 8: Dynamic Percentage Allocation

**Scenario:** Allocate corporate overhead ($1M) to departments based on each department's revenue as a percentage of total revenue.

```essbase
SET UPDATECALC OFF;
SET CREATEBLOCKONEQ ON;
SET MSG SUMMARY;

/* Step 1: Clear previous allocation */
FIX("Budget", "Working", &CurrYear, @RELATIVE("Total_Dept", 0))
    CLEARDATA "Allocated_Overhead";
ENDFIX

/* Step 2: Allocate */
FIX("Budget", "Working", &CurrYear, @RELATIVE("Total_Dept", 0))
    "Allocated_Overhead"(
        IF("Revenue" <> #Missing AND "Revenue" <> 0 AND
           "Revenue" -> "Total_Dept" <> 0 AND "Revenue" -> "Total_Dept" <> #Missing)
            "Allocated_Overhead" = "Corp_Overhead" -> "Corporate" * 
                                   ("Revenue" / "Revenue" -> "Total_Dept");
        ELSE
            "Allocated_Overhead" = 0;
        ENDIF
    )
ENDFIX

SET CREATEBLOCKONEQ OFF;

/* Step 3: Create offset in Corporate entity */
FIX("Budget", "Working", &CurrYear, "Corporate")
    "Allocated_Overhead" = "Corp_Overhead" * -1;
ENDFIX
```

# PATTERN 10: Multi-Currency Conversion (Complete)

**Scenario:** Convert all entities' local currency data to USD reporting.

```essbase
SET UPDATECALC OFF;
SET MSG SUMMARY;
SET CREATEBLOCKONEQ ON;

FIX("Budget", "Working", &CurrYear, @RELATIVE("Total_Entity", 0), "USD_Reporting")
    /* P&L: Average Rate */
    FIX(@UDA("Account", "PL_Account"))
        @CHILDREN("YearTotal")(
            IF("Local" <> #Missing AND "Avg_Rate" -> "FX_Rates" <> #Missing)
                "USD_Reporting" = "Local" * ("Avg_Rate" -> "FX_Rates");
            ELSE
                "USD_Reporting" = #Missing;
            ENDIF
        )
    ENDFIX

    /* Balance Sheet: Ending Rate */
    FIX(@UDA("Account", "BS_Account"))
        @CHILDREN("YearTotal")(
            IF("Local" <> #Missing AND "End_Rate" -> "FX_Rates" <> #Missing)
                "USD_Reporting" = "Local" * ("End_Rate" -> "FX_Rates");
            ELSE
                "USD_Reporting" = #Missing;
            ENDIF
        )
    ENDFIX

    /* Statistical: No conversion */
    FIX(@UDA("Account", "Statistical"))
        @CHILDREN("YearTotal")(
            "USD_Reporting" = "Local";
        )
    ENDFIX
ENDFIX

SET CREATEBLOCKONEQ OFF;
```

# PATTERN 11: CapEx Depreciation Schedule

**Scenario:** Calculate monthly straight-line depreciation for capital assets.

```essbase
SET UPDATECALC OFF;
SET MSG SUMMARY;

FIX("Budget", "Working", &CurrYear, @RELATIVE("Total_Entity", 0), @UDA("Account", "CapEx_Asset"))
    "Monthly_Depreciation"(
        IF("Asset_Cost" <> #Missing AND "Useful_Life_Months" <> #Missing AND "Useful_Life_Months" > 0)
            /* Straight-line: Cost / Life */
            "Monthly_Depreciation" = "Asset_Cost" / "Useful_Life_Months";
        ELSE
            "Monthly_Depreciation" = #Missing;
        ENDIF
    )

    /* Accumulated Depreciation (running total) */
    "Accum_Depreciation"(
        IF(@ISMBR("Jan"))
            "Accum_Depreciation" = "BegBal_Accum_Depr" + "Monthly_Depreciation";
        ELSE
            "Accum_Depreciation" = @PRIOR("Accum_Depreciation", 1) + "Monthly_Depreciation";
        ENDIF
    )

    /* Net Book Value */
    "Net_Book_Value" = "Asset_Cost" - "Accum_Depreciation";
ENDFIX
```

# PATTERN 12: Data Validation Script (Pre-Calculation Check)

**Scenario:** Before running the main calculation, validate that required data exists. If not, stop and alert the user.

```essbase
SET MSG SUMMARY;

FIX("Budget", "Working", &CurrYear, @RELATIVE("Total_Entity", 0))
    /* Check if Revenue data exists */
    IF(@SUM("Account", "Revenue") == #Missing OR @SUM("Account", "Revenue") == 0)
        @RETURN("ERROR: No Revenue data found for the selected scope. Please enter Revenue before running this calculation.", ERROR);
    ENDIF

    /* Check if Headcount data exists */
    IF("Headcount_FTE" == #Missing OR "Headcount_FTE" == 0)
        @RETURN("WARNING: Headcount is zero or missing. Salary calculations will produce #Missing results.", WARNING);
    ENDIF
ENDFIX
```

## Summary

| Pattern | Business Scenario | Key Commands |
|---------|-------------------|-------------|
| 1 | Monthly spreading | Division + @CHILDREN loop |
| 2 | Budget seeding | DATACOPY + percentage math |
| 3 | Intercompany elimination | Cross-dim `->` + negative offset |
| 4 | YTD to periodic | @PRIOR subtraction |
| 5 | Weighted average | @SUM division |
| 6 | Conditional aggregation | @UDA filter + AGG |
| 7 | BS carryforward | Cross-year `->` + BegBalance |
| 8 | Percentage allocation | Driver ratio + offset |
| 9 | Rolling forecast shift | DATACOPY per period |
| 10 | Multi-currency FX | @UDA (PL/BS) + FX rate cross-dim |
| 11 | CapEx depreciation | @PRIOR running total |
| 12 | Pre-calc validation | @RETURN with ERROR/WARNING |
