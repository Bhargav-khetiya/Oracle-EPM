# 08.09 — Rounding and Truncation Math: Complete Guide

> **Module:** 08_Calculation_Manager | **Topic:** Rounding, Precision, Numeric Limits
> **Audience:** Rule Developer

---

## 1. WHY — Precision Matters in Finance

₹8,47,32,156.50 stored in Essbase becomes 84732156.5. When divided and multiplied across allocations, rounding errors compound. A ₹0.01 rounding error per cell × 10,000 cells = ₹100 variance. Auditors notice.

---

## 2. ESSBASE NUMERIC PRECISION

```
Essbase stores: 64-bit double-precision floating point (IEEE 754)
  Max value: ~1.8 × 10^308
  Precision: ~15-16 significant digits
  
  ✅ ₹84,73,21,56.50 → stored as 84732156.5 (exact)
  ⚠️ ₹84,73,21,56.001 → may have floating-point rounding
```

## 3. ROUNDING FUNCTIONS

### In Calc Scripts

```essbase
/* @ROUND — round to N decimal places */
"Rounded_Revenue" = @ROUND("Revenue", 2);
/* 8473215.6789 → 8473215.68 */

"Rounded_Revenue" = @ROUND("Revenue", 0);
/* 8473215.6789 → 8473216 */

"Rounded_Revenue" = @ROUND("Revenue", -3);
/* 8473215.6789 → 8473000 (round to nearest thousand) */

/* @TRUNCATE — truncate (chop off) decimal places */
"Truncated" = @TRUNCATE("Revenue", 2);
/* 8473215.6789 → 8473215.67 (no rounding, just chop) */

/* Integer conversion */
"Integer_Revenue" = @TRUNCATE("Revenue", 0);
/* 8473215.6789 → 8473215 */
```

### In Groovy

```groovy
/* Math.round — nearest integer */
cell.data = Math.round(cell.data)  // 8473215.68 → 8473216

/* Custom rounding to N places */
cell.data = Math.round(cell.data * 100) / 100.0  // → 2 decimal places

/* Floor and Ceil */
cell.data = Math.floor(cell.data)   // 8473215.68 → 8473215
cell.data = Math.ceil(cell.data)    // 8473215.12 → 8473216

/* BigDecimal for exact precision */
def bd = new BigDecimal(cell.data).setScale(2, BigDecimal.ROUND_HALF_UP)
cell.data = bd.doubleValue()
```

## 4. COMMON ROUNDING PATTERNS

### Pattern 1: Allocate with Rounding Residual

```essbase
/* Problem: 100 allocated 3 ways = 33.33 + 33.33 + 33.33 = 99.99 (missing 0.01!) */

/* Solution: Give residual to last member */
VAR v_Total = 100;
VAR v_Allocated = 0;

FIX(@CHILDREN("All_Hotels") - "Chennai_Hotel")  /* First 4 hotels */
  "Allocated" = @ROUND(v_Total / 5, 2);
  v_Allocated = v_Allocated + "Allocated";
ENDFIX

FIX("Chennai_Hotel")  /* Last hotel gets residual */
  "Allocated" = v_Total - v_Allocated;
  /* 100 - 80.00 = 20.00 (exact!) */
ENDFIX
```

### Pattern 2: Percentage to Whole Numbers

```essbase
/* Occupancy 78.4% → display as 78% on dashboard */
"Occupancy_Display" = @ROUND("Occupancy_Rate", 0);

/* Margin 18.756% → display as 18.8% */
"Margin_Display" = @ROUND("Profit_Margin", 1);
```

### Pattern 3: Currency Conversion Rounding

```essbase
/* INR to USD: ₹84,73,216 ÷ 83.50 = $101,475.0419... */
"USD_Revenue" = @ROUND("Local_Revenue" / v_ExchangeRate, 2);
/* Result: $101,475.04 */
```

## 5. COMMON MISTAKES

| Mistake | Impact | Fix |
|---------|--------|-----|
| No rounding after division | Trailing decimals (18.756234%) | @ROUND after every division |
| Rounding each step vs final | Compounding rounding errors | Round only the FINAL result |
| Allocation without residual | Sum ≠ original total | Give residual to last member |
| Using @TRUNCATE for rounding | Always rounds down | Use @ROUND for half-up rounding |
