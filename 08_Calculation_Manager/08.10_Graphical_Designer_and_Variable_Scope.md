## 1. GRAPHICAL DESIGNER

The Graphical Designer is an alternative to writing calc scripts by hand. You drag and drop components to build rules visually.

### How to Access

```
Calc Manager → Rules → Right-click rule → Open in Graphical Designer

Interface:
┌── Palette (left) ──────┐  ┌── Canvas (center) ──────────────┐
│ Components:             │  │                                  │
│  ├── Formula            │  │  [Start]                        │
│  ├── Script             │  │     │                            │
│  ├── Condition          │  │  [FIX Statement]                │
│  ├── Loop               │  │     │                            │
│  ├── Fixed Loop         │  │  [Formula: Revenue Calc]        │
│  ├── Member Range       │  │     │                            │
│  ├── System Template    │  │  [Condition: IF Revenue > 0]    │
│  ├── Comments           │  │     ├── True: [Formula: Margin]  │
│  └── ...                │  │     └── False: [Set to 0]       │
│                         │  │     │                            │
│ Drag components to →    │  │  [AGG Entity]                   │
│ canvas to build rule    │  │     │                            │
│                         │  │  [End]                           │
└─────────────────────────┘  └──────────────────────────────────┘
```

### When to Use Graphical vs Script

| Feature | Graphical Designer | Script Editor |
|---------|-------------------|---------------|
| Best for | Simple rules, visual learners | Complex rules, experienced devs |
| IF/ELSE | Drag Condition component | Write IF/ENDIF |
| FIX | Right-click → Add FIX | Write FIX/ENDFIX |
| Reusable components | Drag from palette | Copy-paste code |
| Debugging | Visual flow tracing | @CalcMgrLogMessageTrace |
| Performance | Same (generates same calc script) | Same |

## 2. VARIABLE SCOPE IN CALC MANAGER

### Variable Types

| Type | Scope | Lifetime | Syntax |
|------|-------|----------|--------|
| **VAR** | Within script block | Single execution | `VAR v_Total;` |
| **ARRAY** | Within script block | Single execution | `ARRAY a_Months[12];` |
| **RTP** | Per rule execution | Until rule completes | `{RTP_Scenario}` |
| **SubVar** | Application-wide | Until admin changes | `&CurrMonth` |
| **DTP** | Template-level | Fixed at design time | `{{DTP_Cube}}` |

### VAR Scope Rules

```essbase
/* VAR is scoped to the SCRIPT BLOCK where it's declared */

VAR v_Total;  /* Declared at top → visible to entire script */

FIX("Budget", "Working", &CurrYear)
  
  /* Read a value into the variable */
  FIX("All_Hotels", "YearTotal")
    v_Total = "Total_Revenue";  /* ✅ v_Total accessible here */
  ENDFIX
  
  /* Use the variable in a different FIX */
  FIX(@RELATIVE("All_Hotels", 0), "YearTotal")
    IF(v_Total <> 0)
      "Pct_of_Total" = "Total_Revenue" / v_Total * 100;  /* ✅ works */
    ENDIF
  ENDFIX
  
ENDFIX

/* ⚠️ VAR holds only ONE value at a time — last assignment wins */
/* ⚠️ VAR cannot hold member names, only numeric values */
```

### ARRAY Scope

```essbase
/* ARRAY holds multiple values indexed by position */
ARRAY a_Rates[5];

/* Load rates for 5 hotels */
a_Rates[0] = 83.50;  /* Mumbai exchange rate */
a_Rates[1] = 83.50;  /* Delhi */
a_Rates[2] = 83.50;  /* Bangalore */
a_Rates[3] = 83.50;  /* Kolkata */
a_Rates[4] = 83.50;  /* Chennai */

/* Use in calculation */
FIX(@RELATIVE("All_Hotels", 0))
  IF(@ISMBR("Mumbai_Hotel"))
    "USD_Revenue" = "Local_Revenue" / a_Rates[0];
  ELSEIF(@ISMBR("Delhi_Hotel"))
    "USD_Revenue" = "Local_Revenue" / a_Rates[1];
  ENDIF
ENDFIX
```

## 3. COMMON MISTAKES

| Mistake | Fix |
|---------|-----|
| VAR declared inside FIX → not visible outside | Declare VAR at top of script |
| Expecting VAR to hold per-member values | VAR is scalar — use ARRAY or member formula |
| Using Graphical Designer for complex rules | Switch to Script Editor for 20+ lines |
| Not validating after graphical changes | Always Validate before Deploy |
