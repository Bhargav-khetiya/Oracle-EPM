# Calc Manager Templates: Code Examples

This document demonstrates how to build the raw script backend of a Custom Template in Calculation Manager, utilizing Design Time Prompts (DTPs) and complex validation logic.

## 1. The Core Template Script

Imagine you are building a reusable template for calculating a standard Year-over-Year (YoY) growth percentage. You want developers to be able to drag this into any rule and just supply the Account and the Target Variance Account.

**Step 1: Define the DTPs in the UI**
*   `[Source_Account]`: Type = Member, Dimension = Account.
*   `[Target_Variance_Account]`: Type = Member, Dimension = Account.
*   `[Year_To_Calc]`: Type = Member, Dimension = Years.

**Step 2: Write the Template Script**
```essbase
/* Template Name: Calc_YoY_Variance */
/* Description: Calculates the YoY percentage growth for a given account. */

FIX ( [Year_To_Calc], "Actual", @RELATIVE("Total_Geography", 0) )
    
    [Target_Variance_Account] (
        
        /* Ensure we don't divide by zero if the prior year was empty */
        IF ( @PRIOR([Source_Account], 1, "Years") <> 0 AND @PRIOR([Source_Account], 1, "Years") <> #MISSING )
            
            /* (Current - Prior) / Prior */
            [Target_Variance_Account] = 
                ([Source_Account] - @PRIOR([Source_Account], 1, "Years")) 
                / @PRIOR([Source_Account], 1, "Years");
                
        ELSE
            [Target_Variance_Account] = #MISSING;
        ENDIF
    )

ENDFIX
```

## 2. Using Template Conditions (Macros)

Calc Manager allows you to embed macro-style conditions *inside* the template that are evaluated before the script is even sent to Essbase. This is done using `#IF` (Note the hashtag).

```essbase
/* Scenario: We have a DTP called [Round_Data] which is a Boolean (True/False) checkbox. */

FIX ( [Year_To_Calc] )
    
    #IF ( [Round_Data] == "True" )
        /* If the developer checked the box, compile this version: */
        [Target_Variance_Account] = @ROUND( ([Source_Account] - @PRIOR([Source_Account], 1, "Years")) / @PRIOR([Source_Account], 1, "Years"), 2 );
    #ELSE
        /* If they didn't check the box, compile this version: */
        [Target_Variance_Account] = ([Source_Account] - @PRIOR([Source_Account], 1, "Years")) / @PRIOR([Source_Account], 1, "Years");
    #ENDIF

ENDFIX
```
*Why this is powerful:* Essbase never sees the `#IF`. Calc Manager reads the DTP, decides which block of code is relevant, and deletes the other block entirely before sending the final `.csc` file to the database. This keeps the final script clean and fast.
