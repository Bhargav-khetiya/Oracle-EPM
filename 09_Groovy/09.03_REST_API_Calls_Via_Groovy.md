## 3. Introduction
Essbase is historically an island. It calculates its own data. But modern finance requires real-time external data. If you are budgeting in Europe, you need today's Live Euro Exchange Rate. You shouldn't wait for the nightly ETL batch. You should click a button on the form, reach out to the European Central Bank via REST API, pull the live rate, and instantly apply it to the budget. **Groovy makes this possible.**

## 7. Core Concepts: The Connection

You never hardcode external URLs or API keys directly into a Groovy script. 

### Step 1: EPM Connections (The Secure Vault)
Before writing Groovy, the Admin goes to **Tools -> Connections**.
- Create a new "Other Web Service Provider" connection.
- Name: `ECB_Rates`
- URL: `https://api.ecb.europa.eu/`
- Authentication: (Provide the OAuth token or Basic Auth credentials).
This securely stores the credentials outside the script.

### Step 2: The Groovy API Call
In Calculation Manager, you write the Groovy rule to call that Connection.

```groovy
// 1. Establish the connection to the secure vault
def connection = operation.application.getConnection("ECB_Rates")

// 2. Execute the GET request to the specific API endpoint
HttpResponse<String> response = connection.get("/latest?base=USD&symbols=EUR")

// 3. Check for a 200 OK status
if (response.status == 200) {
    // 4. Parse the JSON payload returned by the bank
    def jsonResponse = new groovy.json.JsonSlurper().parseText(response.body)
    def liveRate = jsonResponse.rates.EUR
    
    // 5. Build an Essbase Calc Script string to save the rate to the cube
    String calcScript = """
    FIX("Working", "Budget")
        "FX_Rate_EUR" = ${liveRate};
    ENDFIX;
    """
    // 6. Send the string to the Essbase engine
    operation.application.evaluateCalcScript(calcScript)
} else {
    throw new VetoException("Failed to fetch exchange rates. Bank API returned: ${response.status}")
}
```

## 18. Architect Notes: Synchronous vs Asynchronous
When a user clicks a button to run this Groovy rule, their screen freezes with a "Processing" spinner until the rule finishes. 
- **The Danger:** If the European Central Bank API is down and takes 60 seconds to timeout, the user is staring at a frozen screen for 60 seconds. 
- **The Solution:** Always wrap external API calls in a `try/catch` block and define a strict HTTP timeout on the Connection settings (e.g., 5 seconds) so the user gets an immediate error message rather than a hung application.

## 25. Interview Questions

### Advanced
**Q: Why should you use EPM Connections instead of hardcoding `def url = "https://api.../?key=123"` in your Groovy script?**
> A: Security and Maintenance. Hardcoding an API key into a script exposes it to any developer who can open Calculation Manager. Furthermore, if the API key rotates every 90 days, you would have to edit and re-deploy the code. By using EPM Connections, the credentials are encrypted, and an Admin can update the password centrally without touching the Groovy code.

## 27. Summary
Groovy transforms EPBCS from a closed database into an interconnected node on the corporate network. Use REST APIs to fetch live drivers, trigger external data pipelines, or post alerts to Slack/Teams.
