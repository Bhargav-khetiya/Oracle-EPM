# Groovy REST API Callout Script

One of the most powerful features of Groovy in Oracle EPM is the ability to break out of the EPM ecosystem and make HTTP REST calls to external services.

## The Scenario
A user inputs a Zip Code on an EPM form. When they click Save, a Groovy rule triggers, takes that Zip Code, calls an external public Weather API, retrieves the average winter temperature, and writes that temperature into the Essbase block to be used as a driver for Utility Cost allocations.

## The Code Structure

### 1. Define the Connection
In EPM Cloud (under `Connections`), the Administrator must first create a connection to the external API (e.g., `Weather_API` pointing to `https://api.weather.com`). *Groovy cannot call random URLs for security reasons; it can only call pre-approved Connections.*

### 2. The Groovy Script

```groovy
// 1. Get the Zip Code from the current grid (assuming it was entered in a specific cell)
String zipCode = ""
operation.grid.dataCellIterator({DataCell cell -> cell.isEdited()}).each { DataCell cell ->
    // Logic to grab the Zip Code based on column headers
    zipCode = cell.data
}

if (!zipCode) {
    println "No Zip Code entered."
    return
}

// 2. Prepare the REST API Call
HttpResponse<String> jsonResponse = null
try {
    // We use the pre-defined 'Weather_API' connection
    Connection weatherConn = connection("Weather_API")
    
    // Append the Zip Code to the endpoint path
    jsonResponse = weatherConn.get("/forecast?zip=" + zipCode).asString()
    
} catch (Exception e) {
    throw new VetoException("Failed to connect to the Weather API: " + e.message)
}

// 3. Parse the JSON Response
if (jsonResponse != null && jsonResponse.status >= 200 && jsonResponse.status < 300) {
    def jsonParser = new groovy.json.JsonSlurper()
    def parsedData = jsonParser.parseText(jsonResponse.body)
    
    double avgTemp = parsedData.forecast.avgWinterTemp
    println "Successfully retrieved Temp: " + avgTemp

} else {
    throw new VetoException("API returned an error. HTTP Status: " + jsonResponse.status)
}
```

## Security Traps
*   **Whitelisting:** You cannot run `new java.net.URL("http://google.com").openConnection()` in EPM Groovy. The Oracle sandbox blocks raw network calls. You *must* use the `connection("Name")` wrapper.
*   **Timeout:** External API calls halt the user's screen. If the Weather API takes 30 seconds to respond, the user's EPM Form will spin with "Processing..." for 30 seconds. Always implement short timeouts on external connections.
