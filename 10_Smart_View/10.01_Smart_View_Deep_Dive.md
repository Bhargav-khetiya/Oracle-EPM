# Smart View Deep Dive

Oracle Smart View for Office is the primary interface for power users, finance analysts, and administrators. It connects Microsoft Excel, Word, and PowerPoint directly to EPM Cloud.

## 1. Ad Hoc Analysis vs. Forms

Smart View allows users to interact with data in two primary ways:

*   **Forms:** Opening a pre-built web form in Excel. The layout is locked. Users can only input data where the form allows.
*   **Ad Hoc Analysis:** The free-form grid. Users start with a basic slice of data and can Pivot, Zoom In (drill down), Zoom Out, and Keep/Remove Only members. 

### The "Ad Hoc Behavior" Application Setting
Administrators must choose the Ad Hoc behavior for the application:
*   **Native:** The older, classic Essbase behavior.
*   **Standard:** The modern EPM Cloud behavior. *Crucial Difference:* Standard behavior allows users to type member names directly into empty cells and hit Refresh. Native behavior requires users to use the Member Selection dialog or Zoom options.

## 2. Key Smart View Options (Performance Impacts)

Users control their own Smart View Options, which can drastically impact system performance.

*   **Suppress Missing Blocks / Missing Rows:** If these are *unchecked*, Essbase attempts to return every possible combination of members on the sheet, even if no data exists. This will crash Excel and spike CPU on the server. *Always check suppression options.*
*   **No Data / Missing Label:** By default, it's `#Missing`. Change it to numeric `0` for easier Excel formulas, but be aware that submitting a `0` is different than submitting `#Missing` (which clears the data block).
*   **Use Excel Formatting:** If enabled, Smart View retains the user's bolding and colors on Refresh. If disabled, it uses the server-side Cell Styles.

## 3. Submit Data vs. Calculate

*   **Submit Data:** Pushes the numbers from Excel to the Essbase cube. It *does not* run aggregations (unless a rule is set to Run on Save on a form).
*   **Calculate:** Users must separately trigger a Business Rule from the Smart View panel to roll up their data after submitting.

## 4. Smart View VBA Basics

For advanced automation, Smart View provides a massive VBA API library (`HsAddin`).

*   **HypConnect:** Authenticates and connects to a specific cube.
*   **HypRetrieve:** Refreshes the active sheet.
*   **HypSubmitData:** Submits the sheet's data.
*   **Use Case:** A finance user has 50 different tabs in a workbook. Instead of clicking "Refresh" 50 times, they use a VBA macro that loops through every sheet, calls `HypRetrieve`, and updates the entire workbook in one click.
