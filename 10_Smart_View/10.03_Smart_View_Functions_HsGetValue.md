# 10.03 Smart View Functions (HsGetValue)

> **Module:** 10_Smart_View  
> **Topic:** 03 - Smart View Excel Functions  
> **Target Audience:** Consultant to Power User  

---

## 1. Learning Objectives
- Differentiate between Ad-Hoc grids and Smart View Functions.
- Master `HsGetValue` and `HsSetValue`.
- Design highly customized, pixel-perfect executive reports in Excel.

## 3. Introduction
An Ad-Hoc grid is rigid. The rows and columns must be perfectly aligned. But what if the CFO wants a report where Cell A1 is "Total Revenue for Q1", Cell D5 is a custom Excel pie chart, and Cell Z100 is "Travel Expense for Q4"? You cannot build that using a standard Ad-Hoc grid because the cells are completely disjointed. 

To build pixel-perfect, highly customized Excel reports, you use **Smart View Functions**.

## 7. Core Concepts: The Functions

Smart View provides a suite of custom Excel formulas (just like `=VLOOKUP` or `=SUM`) that directly query the Essbase cube.

### 1. `HsGetValue` (Read Data)
- **Purpose:** Fetches a single data point from the cube into a specific Excel cell.
- **Syntax:** `=HsGetValue("ConnectionName", "Dimension1#Member1", "Dimension2#Member2", ...)`
- **Example:** `=HsGetValue("My_EPBCS_Conn", "Account#Revenue", "Period#Jan", "Year#FY24", "Scenario#Actual", "Version#Working", "Entity#Total_Geography")`
- **Benefit:** You can place this formula anywhere in the Excel workbook. It does not rely on a grid structure. 

### 2. `HsSetValue` (Write Data)
- **Purpose:** Sends a value from a specific Excel cell back into the Essbase cube.
- **Use Case:** Highly customized data entry templates where the user inputs a number in a heavily formatted cell, and Smart View pushes it to the database when they click Submit.

### 3. `HsDescription`
- **Purpose:** Fetches the Alias (Description) of a member name.
- **Example:** `=HsDescription("My_EPBCS_Conn", "Entity#100")` returns "IT Department".

## 14. Examples: The "Build-a-Board" Report
Executive boards do not want to look at massive data grids. They want heavily formatted, branded, 1-page summary sheets.
- **The Design:** An architect builds the 1-page summary using standard Excel formatting (colors, logos, charts). 
- **The Data:** Behind the scenes, the architect populates the key metric cells with `=HsGetValue` formulas pointing to the ASO reporting cube.
- **The Result:** The CFO opens the file, clicks Refresh, and the pixel-perfect board package updates instantly with live data.

## 18. Architect Notes: Performance Destruction
`HsGetValue` is incredibly powerful, but it is the #1 cause of Smart View crashes.
- **The Problem:** When you execute an Ad-Hoc grid with 1,000 cells, Smart View sends **ONE** query to the server asking for 1,000 intersections. When you have 1,000 `=HsGetValue` formulas scattered across a workbook, Excel evaluates them sequentially. Smart View sends **1,000 individual queries** to the server. The network latency of 1,000 round-trips will freeze Excel for minutes.
- **The Solution:** Use `HsGetValue` sparingly. For massive data pulls, use an Ad-Hoc grid on a hidden "Data" tab, and use standard Excel `=VLOOKUP` or `INDEX/MATCH` to pull the numbers from the hidden grid onto the formatted presentation tab.

## 25. Interview Questions

### Intermediate
**Q: A user copies an `=HsGetValue` formula from a colleague's spreadsheet. When they click Refresh, the cell returns `#NoConnection`. Why?**
> A: The formula hardcodes the connection name (e.g., `"My_EPBCS_Conn"`). The colleague had a Private Connection named exactly that on their laptop. The user who copied the file does not have a connection with that exact name. This is why you should always use **Shared Connections** with standardized naming conventions across the enterprise.

### Architect
**Q: How do you optimize a workbook that contains 5,000 `HsGetValue` formulas?**
> A: I would completely redesign the workbook. 5,000 independent network calls will crush performance. I would build a standard Ad-Hoc grid on a hidden worksheet to pull all 5,000 data points in a single, lightning-fast query. Then, I would replace the `HsGetValue` formulas on the presentation sheet with standard native Excel references (e.g., `=DataSheet!B5`) pointing to the hidden grid.

## 27. Summary
`HsGetValue` allows you to break free from the grid and build pixel-perfect reports. But respect the network latency; do not use it to pull thousands of data points.
