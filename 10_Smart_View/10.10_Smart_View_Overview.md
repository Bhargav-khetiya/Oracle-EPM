## 🏢 Overview

**Oracle Smart View for Office** is an Excel add-in that connects Microsoft Excel, Word, and PowerPoint directly to Oracle EPM Cloud. It allows users to interact with EPM data using familiar Excel features — entering data, running ad-hoc queries, building reports, and submitting budgets.

---

## 📌 Why Smart View?

| For End Users | For Consultants |
|---------------|-----------------|
| Work in familiar Excel interface | Build reports faster than web forms |
| Use Excel formulas alongside EPM data | Debug data issues with ad-hoc analysis |
| Copy/paste between EPM and local files | Test calculations and verify results |
| Create custom reports with formatting | Validate data loads |

## 📌 Installation & Setup

### System Requirements
- Microsoft Office 365 or Office 2016/2019/2021 (Windows)
- Smart View installer from Oracle (downloaded from EPM Cloud instance)
- .NET Framework 4.7.2+

### Installation Steps

1. **Download:** EPM Cloud → Navigator → Downloads → Smart View
2. **Install:** Run `SmartView.exe` → follow wizard → restart Office
3. **Connect:** In Excel → Smart View ribbon → Panel → Create new connection

### Connection Setup

```
Connection URL Format:
https://<instance>.pbcs.us2.oraclecloud.com/HyperionPlanning/SmartView

Example:
https://mycompany.pbcs.us2.oraclecloud.com/HyperionPlanning/SmartView
```

**Connection Properties:**
| Property | Value |
|----------|-------|
| Provider | Oracle Planning and Budgeting Cloud |
| URL | Your EPM Cloud Smart View URL |
| SSO | Uses same login as web interface |

## 📌 Core Features

### 1. Forms (Structured Data Entry)

Forms in Smart View look identical to web forms but run inside Excel.

```
Open Form:
Smart View Panel → Expand Application → FinPlan → Forms → Select Form → Open
```

**Form Operations:**
| Operation | How |
|-----------|-----|
| **Open** | Double-click form in Smart View panel |
| **Refresh** | Ctrl+F5 or Smart View → Refresh |
| **Submit** | Smart View → Submit Data |
| **Change POV** | Click POV cell → select new member |
| **Drill Down** | Double-click parent member → expands children |
| **Drill Up** | Smart View → Zoom Out |

### 2. Ad-Hoc Analysis

Ad-hoc is the most powerful Smart View feature — it lets you build custom reports on the fly.

```
Start Ad-Hoc:
Smart View Panel → Expand Application → FinPlan → Right-click Cube → Ad-Hoc Analysis
```

**Ad-Hoc Operations:**

| Action | How | What It Does |
|--------|-----|-------------|
| **Zoom In** | Double-click a member | Shows children (drill down) |
| **Zoom Out** | Smart View → Zoom Out | Shows parent (roll up) |
| **Pivot** | Drag member from row to column | Reorients the grid |
| **Remove** | Select column → Smart View → Remove | Removes a member from view |
| **Keep Only** | Select column → Smart View → Keep Only | Removes all except selected |
| **Member Selection** | Right-click member → Member Selection | Pick specific members |
| **Submit** | Smart View → Submit Data | Save changes back to EPM |

### Member Selection Dialog

```
Member Selection allows you to choose:
├── Individual members (Jan, Feb, Mar)
├── Functions:
│   ├── IChildren(Period) → direct children only
│   ├── IDescendants(Period) → all descendants
│   ├── ILvl0Descendants(Period) → leaf members only
│   ├── Siblings(Jan) → same-level members
│   ├── IParent(Jan) → parent of Jan
│   └── Ancestors(Jan) → all parents up to root
└── Attribute-based selection
```

### 3. Free-Form Reports

Build custom Excel-based reports by typing member names directly into cells.

### 💡 Logic & Purpose
While Ad-Hoc grids are incredibly fast for analysis, they are rigidly structured (a strict block of rows and columns). Free-Form reporting allows an analyst to type "Revenue" in cell A1, "Jan" in cell B1, and leave rows empty for formatting or Excel formulas, and then hit "Refresh" to pull the data. This bridges the gap between database querying and highly formatted Excel financial modeling.

### 🌀 Confusion Resolution
> **Misconception:** "I built a beautiful Free-Form report with blank rows and custom Excel formulas. I clicked 'Refresh' and it worked. Then I clicked 'Zoom In' on a member, and my entire report structure was destroyed!"
> **Reality:** When you execute an Ad-Hoc operation like "Zoom In" or "Pivot", Smart View takes absolute control of the Excel sheet and forces it back into a rigid, contiguous grid. It will overwrite your blank rows, delete your custom Excel formulas, and wipe out your formatting. Free-Form grids must ONLY be "Refreshed" or "Submitted" — never Zoomed or Pivoted.

### 😈 Twisted Interview Question
**Question:** A user creates a Free-Form grid. They type "Budget" in cell A1, "FY26" in A2, "Revenue" in B3, and "Jan" in C2. They click Refresh. Smart View throws an error: "Invalid Grid: Multiple dimensions on the same row". Why?
> **Answer:** In a Free-Form grid, the POV members (Budget, FY26) must be typed in the very first row, starting at column A, going continuously left to right. By placing "Budget" in A1 and "FY26" in A2, the user violated the strict parser rules for identifying the POV. All POV members must be on Row 1.

```
Step 1: Start Ad-Hoc on the cube
Step 2: Clear the grid
Step 3: Type dimension members:
        Row 1: [Leave blank] | Jan | Feb | Mar | Q1
        Row 2: Revenue      |     |     |     |
        Row 3: COGS         |     |     |     |
        Row 4: Gross Profit  |     |     |     |
Step 4: Refresh → data fills in
```

### 4. Smart View Functions

Use these Excel functions to pull EPM data into any cell:

| Function | Purpose | Example |
|----------|---------|---------|
| `HsGetValue` | Get a single data value | `=HsGetValue("FinPlan","Account#Revenue","Period#Jan","Entity#E10001","Scenario#Actual","Version#Final","Year#FY26")` |
| `HsSetValue` | Set a data value | `=HsSetValue(1000,"FinPlan","Account#Revenue",...)` |
| `HsGetSheetInfo` | Get connection info | `=HsGetSheetInfo("url")` |
| `HsCurrency` | Get currency code | `=HsCurrency("FinPlan","Entity#E10001")` |

### HsGetValue Deep Dive

```excel
=HsGetValue("ConnectionName",
    "Dimension1#Member1",
    "Dimension2#Member2",
    ...
)

/* Example: Get Jan Revenue for Hotel Pvt Ltd, Budget */
=HsGetValue("FinPlan",
    "Account#Revenue",
    "Period#Jan",
    "Entity#E10001",
    "Scenario#Budget",
    "Version#Working",
    "Year#FY26",
    "Currency#Local"
)
```

> **Interview Tip:** HsGetValue requires ALL dimensions to be specified. If you miss one, it returns #NoData or uses the default member.

## 🔧 Smart View Troubleshooting

| Issue | Cause | Fix |
|-------|-------|-----|
| "Unable to connect" | Wrong URL or SSO issue | Verify URL, clear cookies, check proxy |
| #NoData in cells | Wrong member combination | Check POV, verify data exists |
| #Missing | No data at intersection | Expected behavior — enter data or check form |
| Slow refresh | Too many cells or complex form | Reduce form size, enable suppression |
| "Smart View not loading" | Office conflict or version | Repair install, check .NET version |
| Data not submitting | Read-only intersection | Check cell status colors, verify write access |
| "Session expired" | Idle timeout | Re-login via Smart View panel |

### Cell Status Colors

| Color | Meaning |
|-------|---------|
| **White** | Writable — you can enter data |
| **Yellow** | Changed but not submitted |
| **Light Blue** | Read-only (Dynamic Calc or no access) |
| **Gray** | Not editable |

## ⭐ Best Practices

| Practice | Reason |
|----------|--------|
| Use named connections | Avoid manual URL entry |
| Refresh before editing | Get latest data |
| Submit frequently | Avoid losing changes |
| Use HsGetValue for dashboards | Pull live data into formatted sheets |
| Don't use VLOOKUP on EPM cells | EPM data isn't stored locally |
| Close unused connections | Each consumes a server session |
| Use Flex Forms for analysis | More flexible than regular forms |

## 🎓 Interview Questions

**Q: What is Smart View and why is it used?**
> A: Smart View is Oracle's Excel add-in that connects to EPM Cloud. Users prefer it because they work in familiar Excel while accessing EPM data — for data entry, ad-hoc analysis, and custom reporting.

**Q: What is the difference between a Form and Ad-Hoc in Smart View?**
> A: A Form is a pre-designed data entry layout (fixed structure). Ad-Hoc lets users build custom queries on-the-fly — zoom in/out, pivot, keep/remove members freely.

**Q: What is HsGetValue and when would you use it?**
> A: HsGetValue is an Excel function that retrieves a single data value from EPM. Use it for building custom dashboards or pulling specific data points into Excel reports that need live EPM data.

**Q: What is a Flex Form?**
> A: A Flex Form is a Smart View form that allows Excel-native features (sorting, filtering, Excel formulas) while still supporting data submission back to EPM. It combines the structure of a form with the flexibility of ad-hoc.

**Q: How do you troubleshoot "Unable to connect" in Smart View?**
> A: Check: (1) URL is correct, (2) VPN/proxy settings, (3) clear browser cookies and Smart View cache, (4) verify SSO credentials, (5) check if EPM instance is up, (6) verify Office/Smart View version compatibility.
