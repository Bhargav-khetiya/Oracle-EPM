# 11.02 — Flat File Import Patterns: Complete Guide

> **Module:** 11_Data_Integration | **Topic:** CSV/TXT File Formats, Import Rules, Error Handling
> **Audience:** Service Administrator

---

## 1. WHY — Why Master Flat File Imports?

Flat files (CSV/TXT) are the most common data source for EPBCS. Hotel Pvt Ltd's PMS exports daily revenue as CSV, the ERP exports GL balances as pipe-delimited text, and finance teams send budget adjustments in Excel (saved as CSV). Getting the format right the first time saves hours of debugging.

---

## 2. FILE FORMAT OPTIONS

### Column-Based (Most Common)

```csv
Account,Entity,Scenario,Version,Year,Period,Amount
Room_Revenue,Mumbai_Hotel,Actual,Final,FY2026,Aug,8500000
F&B_Revenue,Mumbai_Hotel,Actual,Final,FY2026,Aug,2200000
Spa_Revenue,Mumbai_Hotel,Actual,Final,FY2026,Aug,500000
Room_Revenue,Delhi_Hotel,Actual,Final,FY2026,Aug,7200000
```

### Fixed-Width Columns

```
Account         Entity          Scenario  Amount
Room_Revenue    Mumbai_Hotel    Actual    8500000
F&B_Revenue     Mumbai_Hotel    Actual    2200000
```

### Multi-Column Data (Multiple Periods)

```csv
Account,Entity,Scenario,Version,Year,Jan,Feb,Mar,Apr,May,Jun
Room_Revenue,Mumbai_Hotel,Actual,Final,FY2026,8500000,9000000,7600000,8100000,6500000,6800000
F&B_Revenue,Mumbai_Hotel,Actual,Final,FY2026,2200000,2400000,2100000,2300000,1900000,2000000
```

### Delimiter Options

| Delimiter | Symbol | File Extension | Use When |
|-----------|--------|---------------|----------|
| Comma | `,` | .csv | Standard (no commas in data) |
| Tab | `\t` | .txt | Data may contain commas |
| Pipe | `\|` | .txt | Safe — pipe rarely in data |
| Semicolon | `;` | .csv | European format |

## 3. FILE PREPARATION RULES

```
✅ DO:
  • First row = header (dimension names + "Amount" or period names)
  • Member names must EXACTLY match EPBCS dimension members
  • Numbers only in data columns (no currency symbols, no commas)
  • UTF-8 encoding (no special characters)
  • Consistent delimiter (every row, same delimiter)
  • No trailing blank rows

❌ DON'T:
  • Don't include ₹ or $ symbols in data → 8500000 not ₹85,00,000
  • Don't use commas in numbers → 8500000 not 8,500,000
  • Don't include blank rows in the middle
  • Don't include "N/A" or "null" — use empty cell or 0
  • Don't include calculated rows (totals) — EPBCS calculates those
  • Don't include members that don't exist in the cube
```

## 4. IMPORT RULE SETUP

```
Data Management → Data Load Rules → Create

Rule Name: DL_Revenue_Actuals
Source Type: File
File Name: Aug_Revenue.csv
Target Application: HotelApp
Target Cube: OEP_FS

Import Format:
  Delimiter: Comma
  Header Rows: 1 (skip first row)
  
  Column Mapping:
    Column 1 (Account)  → Account dimension
    Column 2 (Entity)   → Entity dimension
    Column 3 (Scenario) → Scenario dimension (or fixed: "Actual")
    Column 4 (Version)  → Version dimension (or fixed: "Final")
    Column 5 (Year)     → Year dimension (or fixed: &CurrYear)
    Column 6 (Period)   → Period dimension
    Column 7 (Amount)   → Data value

  Fixed dimension values (not in file):
    Currency → "Local"
    Department → "All_Departments"
```

## 5. COMMON DATA PATTERNS

### Pattern 1: Single Period Load (Monthly Actuals)

```csv
Account,Entity,Amount
Room_Revenue,Mumbai_Hotel,8500000
F&B_Revenue,Mumbai_Hotel,2200000
Spa_Revenue,Mumbai_Hotel,500000
Labor,Mumbai_Hotel,3200000
Maintenance,Mumbai_Hotel,800000

Fixed in import rule:
  Scenario = Actual
  Version = Final
  Year = &CurrYear
  Period = &CurrMonth
  Currency = Local
```

### Pattern 2: Multi-Period Load (Full Year)

```csv
Account,Entity,Jan,Feb,Mar,Apr,May,Jun,Jul,Aug,Sep,Oct,Nov,Dec
Room_Revenue,Mumbai_Hotel,8500000,9000000,7600000,8100000,6500000,6800000,7200000,8500000,8800000,9200000,10500000,12000000
F&B_Revenue,Mumbai_Hotel,2200000,2400000,2100000,2300000,1900000,2000000,2100000,2200000,2500000,2800000,3200000,3800000
```

### Pattern 3: Metadata Import (Add/Update Members)

```csv
Parent,Member,Alias,DataStorage,AccountType
Total_Revenue,Room_Revenue,Room Revenue,Store,Revenue
Total_Revenue,F&B_Revenue,Food & Beverage Revenue,Store,Revenue
Total_Revenue,Spa_Revenue,Spa Revenue,Store,Revenue
Total_Expenses,Labor,Labor Cost,Store,Expense
Total_Expenses,Utilities,Utilities,Store,Expense
```

## 6. MEMBER MAPPING

When source member names don't match EPBCS:

```
Source File:              EPBCS Member:
"MUMBAI"           →     "Mumbai_Hotel"
"ROOM REV"         →     "Room_Revenue"
"2026"             →     "FY2026"
"January"          →     "Jan"

Set up in Data Management → Import Format → Mapping:
  Source Value        Target Member
  MUMBAI              Mumbai_Hotel
  DELHI               Delhi_Hotel
  ROOM REV            Room_Revenue
  FNB REV             F&B_Revenue
```

## 7. SHOW ME — Hotel Pvt Ltd Monthly Data Load

```
Source: PMS exports daily_revenue_202608.csv
Format:
  hotel_code,room_type,date,revenue_inr
  MUM,Deluxe,2026-08-01,285000
  MUM,Suite,2026-08-01,180000
  MUM,Standard,2026-08-01,120000
  DEL,Deluxe,2026-08-01,240000

Transformation needed:
  hotel_code → Entity mapping (MUM → Mumbai_Hotel)
  room_type → not used (aggregate to Room_Revenue)
  date → Period (extract month: Aug)
  revenue_inr → Amount (aggregate daily to monthly)

Pre-processing (Python/Excel):
  1. Aggregate daily → monthly by hotel
  2. Map hotel codes → EPBCS member names
  3. Add Account column (Room_Revenue)
  4. Output clean CSV:
  
  Account,Entity,Amount
  Room_Revenue,Mumbai_Hotel,8500000
  Room_Revenue,Delhi_Hotel,7200000
  Room_Revenue,Bangalore_Hotel,4800000
  Room_Revenue,Kolkata_Hotel,3600000
  Room_Revenue,Chennai_Hotel,2700000
```

## 8. ERROR HANDLING

```
Common load errors and fixes:

Error: "Member not found: MUMMBAI_HOTEL"
Fix: Fix typo in source file or add mapping rule

Error: "Invalid data value: N/A"  
Fix: Replace "N/A" with empty cell or 0 before loading

Error: "Duplicate records for same intersection"
Fix: Aggregate duplicates in source or use Accumulate mode

Error: "Column count mismatch in row 247"
Fix: Check for missing/extra delimiters in that row

Error: "Character encoding error"
Fix: Save file as UTF-8 (not ANSI or Latin-1)

Post-load validation:
  1. Check Jobs Console for record count
  2. Open a form → verify key numbers
  3. Compare source file totals to cube totals
  4. Check for unexpected #MISSING (records rejected)
```

## 9. INTERVIEW QUESTIONS

### Beginner
**Q: What file format does EPBCS expect for data imports?**
> CSV or TXT with a header row, one column per dimension plus a data column. Member names must exactly match EPBCS member names. Numbers only in data columns (no currency symbols or thousand separators). Common delimiters: comma, tab, pipe. Fixed dimensions (Scenario, Version) can be hardcoded in the import rule instead of repeated in every row.

### Architect
**Q: The PMS exports daily revenue with hotel codes. Design the data pipeline.**
> Pre-processing step (Python/Excel): (1) Aggregate daily to monthly by hotel. (2) Map hotel codes to EPBCS member names (MUM→Mumbai_Hotel). (3) Map revenue categories to Account members. (4) Generate clean CSV matching import format. Load step: Upload CSV via EPM Automate → run import rule → validate in Jobs Console. Schedule: Daily at 2 AM via Task Scheduler + EPM Automate batch script. Error handling: Check return code, email admin on failure.
