# Access Control (User and Group Security)

Oracle EPM Cloud utilizes a two-tiered security model: Identity Cloud Service (IDCS) or Oracle Cloud Infrastructure (OCI) IAM for authentication, and EPM native Access Control for authorization.

## 1. Authentication (IDCS / OCI IAM)

Before a user can see any data, they must exist in the Oracle Cloud identity domain.
*   **Provisioning:** Users are created in IDCS.
*   **Roles:** In IDCS, users are assigned one of four fundamental EPM roles:
    1.  **Service Administrator:** Can do everything.
    2.  **Power User:** Can manage forms, rules, and local security.
    3.  **User:** Can input data and run rules (the standard planner role).
    4.  **Viewer:** Can only read data (read-only access to forms and reports).

## 2. Authorization (Native EPM Access Control)

Once a user logs in, EPM determines *what* specific data they can see (e.g., Can they see "Cost Center 100" or "Cost Center 200"?).

*   **Groups:** Never assign access to individual users. Always create Native EPM Groups (e.g., `GRP_NA_Planners`), put users in those groups via IDCS/EPM, and assign access to the groups.
*   **Artifact Security:** Groups are assigned read/write access to Forms, Dashboards, and Business Rules.
*   **Data Security:** Groups are assigned read/write access to dimension members (e.g., `GRP_NA_Planners` gets "Write" access to `@IDESCENDANTS("North_America")`).

## 3. The Security Evaluation Matrix

When a user opens a form, EPM evaluates security in this order:
1.  **IDCS Role:** Are they a Viewer? If yes, everything is read-only, regardless of Data Security.
2.  **Artifact Security:** Can they see the Form? If not, they can't open it.
3.  **Data Security:** They open the form. Can they write to the specific Entity and Account? 
4.  **Valid Intersections:** They have write access to the Entity and Account, but is that specific *combination* of Entity and Account blocked globally? If yes, the cell is read-only.
5.  **Approval Status:** Is the Approval Unit locked or promoted away from them? If yes, the cell is read-only.
