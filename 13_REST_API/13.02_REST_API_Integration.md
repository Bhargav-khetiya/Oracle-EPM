> **Module:** 13_REST_API | **Topic:** REST API Endpoints, Authentication, Automation
> **Audience:** Developer / Architect

## 1. WHY — What Real-World Problem Does This Solve?

**The problem:** EPM Automate is great for scripted operations, but you can't embed it inside a web application, mobile app, or custom dashboard. When the CTO says "Build a real-time KPI dashboard in our internal portal that pulls live budget data from EPBCS" — you need REST API.

**The solution:** EPBCS exposes a comprehensive REST API that allows any application to: authenticate, retrieve data, submit data, run rules, manage jobs, and administer the application — all via standard HTTP calls.

## 2. AUTHENTICATION

### Getting an Access Token

```bash
# OAuth 2.0 — Resource Owner Password Grant
curl -X POST \
  "https://idcs-xxxxx.identity.oraclecloud.com/oauth2/v1/token" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -u "client_id:client_secret" \
  -d "grant_type=password&username=admin@hotel.com&password=MyP@ss&scope=urn:opc:serviceInstanceID=xxxxx"

# Response:
{
  "access_token": "eyJ0eXAiOiJKV1QiLCJhbGciOi...",
  "token_type": "Bearer",
  "expires_in": 3600
}
```

### Basic Authentication (Simpler)

```bash
# Base64 encode username:password
# Use in Authorization header

curl -X GET \
  "https://instance.oraclecloud.com/HyperionPlanning/rest/v3/applications" \
  -H "Authorization: Basic YWRtaW5AaG90ZWwuY29tOk15UEBzcw==" \
  -H "Content-Type: application/json"
```

### Business Rules

### Metadata Operations


## 4. COMMON INTEGRATION PATTERNS

### Pattern 1: Custom KPI Dashboard (Web App → EPBCS)

```python
# Python example: Pull KPIs for dashboard
import requests
import json

BASE_URL = "https://instance.oraclecloud.com/HyperionPlanning/rest/v3"
AUTH = ("admin@hotel.com", "password")

# Fetch revenue data
response = requests.post(
    f"{BASE_URL}/applications/HotelApp/plantypes/OEP_FS/exportdataslice",
    auth=AUTH,
    json={
        "gridDefinition": {
            "pov": {"dimensions": ["Scenario","Version","Year"],
                    "members": [["Actual"],["Final"],["FY2026"]]},
            "columns": [{"dimensions": ["Period"], "members": [["Aug"]]}],
            "rows": [{"dimensions": ["Account","Entity"],
                      "members": [["Total_Revenue","Net_Income","Profit_Margin"],
                                  ["All_Hotels"]]}]
        }
    }
)

data = response.json()
for row in data["rows"]:
    print(f"{row['headers'][0]}: {row['data'][0]}")

# Output:
# Total_Revenue: 1120000000
# Net_Income: 470000000
# Profit_Margin: 41.96
```

### Pattern 2: Automated Monthly Close (Script → EPBCS)

```python
# Monthly close automation via REST API
import requests, time

BASE = "https://instance.oraclecloud.com/HyperionPlanning/rest/v3"
AUTH = ("admin@hotel.com", "password")
APP = "HotelApp"

def run_rule(rule_name, params):
    """Run a business rule and wait for completion"""
    # Launch rule
    resp = requests.post(f"{BASE}/applications/{APP}/jobs",
        auth=AUTH,
        json={"jobType": "RULES", "jobName": rule_name, "parameters": params})
    job_id = resp.json()["jobId"]
    
    # Poll until complete
    while True:
        status = requests.get(f"{BASE}/applications/{APP}/jobs/{job_id}",
            auth=AUTH).json()
        if status["status"] in ["COMPLETED", "SUCCESS"]:
            print(f"✅ {rule_name}: {status['executionTime']}ms")
            return True
        elif status["status"] in ["FAILED", "ERROR"]:
            print(f"❌ {rule_name}: FAILED")
            return False
        time.sleep(5)

# Execute monthly close sequence
params = {"RTP_Scenario": "Actual", "RTP_Year": "FY2026"}
run_rule("CALC_Revenue_Totals", params)
run_rule("CALC_PnL_Complete", params)
run_rule("CALC_Currency_Conversion", params)
run_rule("AGG_Entity", params)
print("Monthly close complete!")
```

## 6. COMMON MISTAKES

| Mistake | Fix |
|---------|-----|
| Using Basic Auth in production | Use OAuth 2.0 with token refresh |
| Not checking job status after launch | Always poll until COMPLETED/FAILED |
| Hardcoding credentials in scripts | Use environment variables or vaults |
| Sending too many concurrent requests | Rate limit: max 5-10 parallel requests |
| Not handling HTTP 429 (rate limited) | Implement exponential backoff |
| Forgetting to refresh database after metadata import | Add CUBE_REFRESH job after member adds |
