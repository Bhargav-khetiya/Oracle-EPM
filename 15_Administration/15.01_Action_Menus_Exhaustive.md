# Action Menus Exhaustive

Action menus provide right-click contextual functionality within Data Forms and Ad Hoc Grids. They are critical for guiding user workflow without overwhelming the UI with buttons.

## 1. Objects That Can Be Attached

You can attach a wide variety of EPM objects to an Action Menu item:
*   **Business Rules & RuleSets:** Executes a calculation script. Context (the POV/cell clicked) is passed to runtime prompts if the names match.
*   **Forms:** Navigates the user to another data entry form. Context is passed so the new form opens to the same Entity/Period.
*   **Dashboards:** Navigates to a specific Dashboard.
*   **URLs (External Links):** Opens a web page. You can pass POV members in the URL string (e.g., `http://myerp.com/cost_center=$Entity$`).
*   **Manage Approvals:** Opens the Approval unit screen for the selected entity.
*   **Cell Text / Supporting Detail:** Launches the standard dialogs for these cell attachments.

## 2. Text, Naming, and Alphabet Limitations (Front End)

*   **Menu Name Limit:** Action menu names (the label the user clicks) are typically limited to **80 characters**.
*   **Menu Grouping:** You can create folders (parent nodes) in an Action Menu to group related tasks (e.g., a "Calculations" folder containing 5 different business rules).
*   **Contextual Display:** You can restrict menu items to only appear on specific rows or columns. For example, a "Calculate Depreciation" menu item will only show up when the user right-clicks on the "Capital Expenditures" row, keeping the menu clean.

## 3. Back End Architecture

Action Menus are stored as XML definitions within the LCM (Lifecycle Management) snapshot under the `Relational Data -> Action Menus` artifact.
*   **Portability:** They can be exported and imported across environments.
*   **Dependencies:** When exporting an Action Menu, LCM does *not* automatically pull the Business Rules or Forms attached to it. You must ensure the target environment has the dependent objects, or the menu will fail to load or result in "Object not found" errors on the front end.

## 4. Best Practices and Limitations
*   **Ad Hoc Support:** Historically, action menus only worked on Web Forms. Recent EPM Cloud updates allow attaching Action Menus to the *Cube*, making them available in Smart View Ad Hoc grids. This is a game-changer for users who refuse to use web forms.
*   **Overloading:** Do not attach 30 items to a single form's action menu. Use folders, or better yet, restrict items to specific rows/columns to reduce cognitive load on the user.
