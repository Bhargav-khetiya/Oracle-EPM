# Navigation Flows

Navigation Flows dictate the entire user interface experience in Oracle EPM Cloud. They allow administrators to customize the homepage clusters (icons), cards, and tabs for different user roles.

## 1. Objects That Can Be Attached

You can attach almost any EPM component to a Navigation Flow card or tab:
*   **Forms & Dashboards:** The most common attachments for planners.
*   **Business Rules:** You can create a card that explicitly launches a business rule (e.g., "Run Nightly Aggregation").
*   **Financial Reports (Web Studio):** Embed static or dynamic reports.
*   **URLs:** Embed external websites (e.g., a corporate intranet or PowerBI dashboard) directly into the EPM interface via an iframe.
*   **System Screens:** Give access to the Job Console, Approval screen, or Data Management.

## 2. Navigation Flows for Different Sets of Users (Front End)

The core purpose of Navigation Flows is role-based UI customization.
*   **The "Executive" Flow:** Might only have a single Cluster called "Reporting" containing Dashboards and Financial Reports. No data entry forms.
*   **The "Contributor" Flow:** Has Clusters for "Expenses", "Revenue", and "Workforce", each containing the specific forms needed for input, plus an "Approvals" card.
*   **The "Admin" Flow:** Has the default "Application" and "Tools" clusters to manage the system.

### How it Works (Assignment)
1.  You build a Navigation Flow.
2.  You assign it to a specific **Group** (e.g., `GRP_Executives`) or a specific **Role** (e.g., `Power User`).
3.  When a user logs in, EPM evaluates their groups. If they belong to multiple groups with different flows, they can switch between them using the dropdown menu on the homepage.

## 3. Back End Architecture & LCM

*   **Customization Limit:** You cannot edit the "Default" Oracle navigation flow. You must duplicate it, edit the copy, and mark the copy as "Active".
*   **Lifecycle Management (LCM):** Navigation flows are stored in the `Relational Data -> Navigation Flows` artifact. 
*   **The Missing Object Trap:** Similar to Action Menus, if a Navigation Flow references a Dashboard that does not exist in the target environment, the LCM import will fail or the card will throw an error when clicked. Always migrate dependencies first.

## 4. Best Practices
*   **Keep it Clean:** Don't give planners access to the "Rules" card where they see every calc script in the system. Embed the specific rules they need onto Forms via Action Menus, or create specific Navigation Cards for them.
*   **Tabs vs. Vertical Tabs:** When designing a cluster, use horizontal tabs for a small number of related tasks (e.g., 3 forms for Revenue). Use the newer vertical tabs (infolets) for dashboards and highly visual, multi-step processes.
