## 1. WHY — Quick Resolution Guide

This is your go-to reference when something breaks. Each error includes: what the user sees, what's actually wrong, and exact steps to fix it.

## 2. TOP 20 ERRORS AND FIXES

### Error 1: "Unknown member name"

```
User sees:   Rule fails in Jobs Console
Log shows:   ERROR 1200585: Unknown member name [Maintainence]

Root cause:  Typo in rule or member was renamed/deleted
Fix time:    2 minutes

Steps:
  1. Note the exact member name from the log: "Maintainence"
  2. Open Calc Manager → find the rule
  3. Search the script for "Maintainence"
  4. Correct to "Maintenance"
  5. Validate → Deploy → Re-run
```

### Error 2: "Form loads but shows #MISSING everywhere"

```
User sees:   Blank form with all zeros or #MISSING
Root cause:  Multiple possible causes

Diagnostic checklist:
  ☐ Does data exist? → Check with ad hoc on exact intersection
  ☐ Is dimension security blocking? → Check user's entity access
  ☐ Is User Variable set? → Check user's UserEntity preference
  ☐ Is aggregation pending? → Run AGG if parents show #MISSING
  ☐ Did SubVars update? → Check &CurrMonth and &CurrYear
```

### Error 3: "Form is extremely slow (>15 seconds)"

```
Root cause:  Form design or query performance

Fix priority:
  1. ☐ Suppress Missing Data? → Enable ☑ (50-80% improvement)
  2. ☐ Two sparse dims on rows? → Move one to Page (60-90%)
  3. ☐ Cell count > 5,000? → Reduce rows or columns (50-80%)
  4. ☐ Heavy On Load rule? → Move to batch/On Save (50-90%)
  5. ☐ Check block count in App Statistics → if exploded, CLEARBLOCK ALL
```

### Error 4: "Business rule times out"

```
User sees:   Rule shows "Error" after long wait
Log shows:   Execution timeout after 3600 seconds

Root cause:  Rule processes too much data (no FIX or bad algorithm)

Steps:
  1. Open rule in Calc Manager
  2. ☐ FIX statement present? If no → add tight FIX
  3. ☐ Cross-dim on sparse? → Two-pass pattern with VAR
  4. ☐ SET CALCPARALLEL? → Add SET CALCPARALLEL 4
  5. ☐ SET LOCKBLOCK? → Add SET LOCKBLOCK ON
  6. Expected improvement: 3600 seconds → 3 seconds
```

### Error 5: "Data was doubled after load"

```
User sees:   Revenue shows ₹17,00,000 instead of ₹8,50,000
Root cause:  Import mode = Accumulate (added to existing)

Steps:
  1. Check import rule → Import Mode
  2. Change Accumulate → Replace
  3. Clear the bad data: CLEARDATA on affected intersection
  4. Re-run the load with Replace mode
```

### Error 6: "User can see Delhi data but shouldn't"

```
Root cause:  Security inheritance — parent Write cascading

Steps:
  1. Check entity security for user's group
  2. If All_Hotels = Write → it cascades to ALL children
  3. Set explicit None on Delhi (and other non-assigned hotels)
  4. Verify: Log in as test user → confirm Delhi is hidden
```

### Error 7: "Smart View won't connect"

```
Steps:
  1. ☐ VPN connected? (if required)
  2. ☐ URL correct? Try in browser: .../HyperionPlanning/SmartView
  3. ☐ Credentials correct? Try browser EPBCS login
  4. ☐ Proxy settings match browser?
  5. ☐ TLS 1.2 enabled? Internet Options → Advanced
  6. ☐ Clear credentials: Control Panel → Credential Manager
  7. ☐ Reinstall Smart View as last resort
```

### Error 8: "Rule runs but produces wrong numbers"

```
Root cause:  Logic error (most difficult to debug)

Steps:
  1. Add @CalcMgrLogMessageTrace messages between each step
  2. Isolate: Disable all components, enable one at a time
  3. Check FIX scope — is it targeting the right intersections?
  4. Check formula logic — are operators correct?
  5. Check SubVar values — is &CurrMonth current?
  6. Check if rule is idempotent — run twice, same result?
```

### Error 9: "Block explosion (block count 100× expected)"

```
User sees:   Everything is slow, cache hit ratio crashed
Root cause:  CREATEBLOCKONEQ or CREATENONMISSINGBLK left ON

Steps:
  1. Check Application Statistics → existing block count
  2. CLEARBLOCK ALL (removes all empty blocks)
  3. Find the causing rule → search for SET CREATEBLOCKONEQ ON
  4. Add SET CREATEBLOCKONEQ OFF immediately after the DATACOPY
  5. Verify block count returns to baseline
```

### Error 10: "SubVar not updated — rules process wrong month"

```
Root cause:  Admin forgot to update &CurrMonth

Steps:
  1. Check: Navigator → Administration → Variables
  2. Update &CurrMonth, &PriorMonth, &ForecastStart
  3. Automate: EPM Automate script with setsubstvars
  4. Prevention: Schedule monthly update script
```

### Error 11: "HsGetValue returns #NoData"

```
Steps:
  1. ☐ All dimensions specified? (must have ALL dims)
  2. ☐ Connection name exact match? (case-sensitive)
  3. ☐ Member names correct? (check for spaces/typos)
  4. ☐ Connected to EPBCS? (try Refresh)
  5. ☐ Data exists at intersection? (check form in browser)
```

### Error 12: "Groovy NullPointerException"

```
Root cause:  Accessing property of null object

Steps:
  1. Read job log → find line number
  2. Check: cell.data on a missing cell → add cell.isMissing() check
  3. Check: crossDimCell with wrong member → verify member name
  4. Add null checks: if (cell != null && !cell.isMissing())
```

### Error 13: "Deploy fails — component not validated"

```
Steps:
  1. Open rule in Calc Manager
  2. Click Validate button
  3. Fix all validation errors (member names, syntax)
  4. Set as Deployable (right-click → Set Deployable)
  5. Deploy
```

### Error 14: "Data load — member not found"

```
Steps:
  1. Open job log → find exact member name
  2. Search Dimension Editor → member doesn't exist
  3. Fix option A: Correct source file
  4. Fix option B: Add mapping rule in Data Management
  5. Fix option C: Add missing member to dimension
  6. Re-upload and re-run
```

### Error 15: "Form shows old data after rule execution"

```
Root cause:  Browser cache or Dynamic Calc not refreshing

Steps:
  1. Clear browser cache (Ctrl+Shift+Delete)
  2. Close form → re-open
  3. Check: Is the member Dynamic Calc? → data should refresh automatically
  4. Check: Did AGG run after the calc? → parents may be stale
  5. Check: Is there a Smart Push pending? → reporting cube may be stale
```

```
Level 2 (Admin):     Check Jobs Console, security, SubVars
Level 3 (Developer): Debug rule logic, optimize, trace messages
Level 4 (Oracle SR):  Infrastructure issues, cloud service problems
```
