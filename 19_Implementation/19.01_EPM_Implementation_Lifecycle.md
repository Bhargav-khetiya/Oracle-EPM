# EPM Implementation Lifecycle

Deploying Oracle EPM is a major transformation project, often taking 3 to 9 months depending on the scope. Architects must follow a structured lifecycle to ensure success.

## 1. Requirements & Design (Phase 1)

The most critical phase. Mistakes here compound exponentially.
*   **The Chart of Accounts (CoA) Mapping:** How does the ERP CoA map to the EPM dimensions? If ERP has 12 segments, do you bring all 12 into EPM? *(Usually no, EPM should be summarized).*
*   **Dense/Sparse Design:** Establishing the physical block structure of the Essbase cube.
*   **Output-Driven Design:** Start by asking "What reports do the executives need?" Design the dimensions backward from the final reporting requirement.

## 2. Build (Phase 2)

The hands-on technical configuration.
*   **Metadata Build:** Creating the hierarchies (usually via EDMCS or flat files).
*   **Data Integration:** Building the Data Management connections to the source systems.
*   **Forms & Rules:** Building the user interface and the Calculation Manager scripts.
*   **Security:** Configuring IDCS groups and Access Control.

## 3. Testing (Phase 3)

EPM requires distinct testing gates.
*   **Unit Testing:** The developer proves the calculation script math works.
*   **SIT (System Integration Testing):** Does the end-to-end flow work? (Data loads from ERP -> Rules run -> Forms display data -> Reports render).
*   **UAT (User Acceptance Testing):** The most stressful phase. Real finance users log into the system, attempt to do their actual jobs, and log defects. *Sign-off here is mandatory before go-live.*

## 4. Training & Deployment (Phase 4)

*   **Training:** EPM is complex. Users must be trained on Smart View, Web Forms, and the specific business process (Task Lists/Flows).
*   **Cutover (Go-Live):** The sequence of events over a weekend to move the code to Production.
    1. Lock users out of Prod.
    2. Import the final LCM Snapshot from Test to Prod.
    3. Run a full data load from the ERP to sync actuals.
    4. Run full aggregations.
    5. Open the system to end users.

## 5. Hypercare (Phase 5)

The 2-4 week period immediately following go-live where the implementation team provides high-touch support to resolve the inevitable wave of "I forgot my password" or "The numbers don't match" tickets.
