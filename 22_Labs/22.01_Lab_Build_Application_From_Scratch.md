# 22.01 — Lab: Build a Planning Application from Scratch

> **Module:** 22_Labs | **Topic:** End-to-End Application Build
> **Duration:** 4-6 hours | **Level:** Beginner → Intermediate

---

## 1. LAB OBJECTIVE

Build a complete EPBCS FreeForm application for **Hotel Pvt Ltd** from an empty environment. By the end, you'll have: dimensions, members, forms, business rules, Smart Lists, dashboards, and security — all working together.

---

## 2. PRE-REQUISITES

```
✅ Service Administrator access to EPBCS instance
✅ Smart View installed in Excel
✅ Basic understanding of EPBCS navigation
```

---

## 3. STEP-BY-STEP WALKTHROUGH

### Step 1: Create Application (15 min)

```
Navigator → Application → Create

Application Name: HotelApp
Application Type: FreeForm

Create Cube:
  Cube Name: HotelFS
  Cube Type: Block Storage (BSO)
  
Dimensions (automatic):
  Account (Dense, Accounts type)
  Period (Dense, Time type)
  Entity (Sparse)
  Scenario (Sparse, Scenario type)
  Version (Sparse, Version type)
  Year (Sparse, Year type)
  Currency (Dense, Currency type)
```

### Step 2: Build Dimension Hierarchies (30 min)

```
Navigator → Dimensions → Account

Build this hierarchy:
  Total_PnL
  ├── Total_Revenue
  │   ├── Room_Revenue          (Store, Revenue, Currency)
  │   ├── F&B_Revenue           (Store, Revenue, Currency)
  │   └── Spa_Revenue           (Store, Revenue, Currency)
  ├── Total_Expenses
  │   ├── Labor                 (Store, Expense, Currency)
  │   ├── Maintenance           (Store, Expense, Currency)
  │   └── Utilities             (Store, Expense, Currency)
  ├── Net_Income                (Dynamic Calc: Total_Revenue - Total_Expenses)
  └── Profit_Margin             (Dynamic Calc: Net_Income / Total_Revenue * 100)

For each parent (Total_Revenue, Total_Expenses):
  Data Storage: Dynamic Calc
  
For each leaf (Room_Revenue, Labor, etc.):
  Data Storage: Store
  Account Type: Revenue or Expense
  Data Type: Currency
```

```
Navigator → Dimensions → Entity

Build:
  All_Hotels
  ├── Mumbai_Hotel
  ├── Delhi_Hotel
  ├── Bangalore_Hotel
  ├── Kolkata_Hotel
  └── Chennai_Hotel

Data Storage for All_Hotels: Dynamic Calc
Data Storage for leaves: Store
```

Navigator → Dimensions → Scenario

### Step 3: Refresh Database (5 min)

```
Navigator → Application → Refresh Database

☑ Create New Members

Click Refresh → Wait for completion

```

### Step 4: Create Substitution Variables (5 min)

```
Navigator → Administration → Variables → Substitution Variables

Create:
  CurrMonth = Aug (Plan Type: All)
  PriorMonth = Jul (Plan Type: All)
  CurrYear = FY2026 (Plan Type: All)
  PriorYear = FY2025 (Plan Type: All)
```

### Step 5: Create Smart List (10 min)

```
Navigator → Create and Manage → Smart Lists → Create

Name: Budget_Status
Type: Smart List

Entries:
  ID: 1, Name: Not Started
  ID: 2, Name: In Progress
  ID: 3, Name: Submitted
  ID: 4, Name: Approved
  ID: 5, Name: Rejected
```

### Step 6: Build Forms (45 min)

```
Navigator → Create and Manage → Forms → Create

Form 1: Revenue_Entry
  Plan Type: HotelFS
  
  POV: Scenario (Budget), Version (Working), Year (&CurrYear)
  Page: Entity (User Variable: UserEntity)
  Rows: Account (@CHILDREN("Total_Revenue"))
  Columns: Period (@CHILDREN("YearTotal") — Jan through Dec)
  
  Properties:
    ☑ Suppress Missing Data
    ☑ Display Missing as Blank
    ☑ Enable Grid Spread

Form 2: PnL_Summary
  Rows: Account (@DESCENDANTS("Total_PnL"))
  Columns: Period (Jan, Feb, Mar, Q1, Apr, May, Jun, Q2, ...)
  Page: Entity, Scenario
  
  Properties:
    ☑ Make Read Only (summary form)
    ☑ Suppress Missing Data
```

### Step 7: Build Business Rules (30 min)

```
Calc Manager → New Rule

Rule: CALC_PnL
Plan Type: HotelFS

Script:
  SET LOCKBLOCK ON;
  
  FIX({RTP_Scenario}, "Working", &CurrYear)
    FIX(@RELATIVE("All_Hotels", 0))
      "Total_Revenue" = "Room_Revenue" + "F&B_Revenue" + "Spa_Revenue";
      "Total_Expenses" = "Labor" + "Maintenance" + "Utilities";
      "Net_Income" = "Total_Revenue" - "Total_Expenses";
      IF("Total_Revenue" <> 0)
        "Profit_Margin" = "Net_Income" / "Total_Revenue" * 100;
      ENDIF
    ENDFIX
    AGG("Entity");
  ENDFIX
  
  SET LOCKBLOCK OFF;

Variables:
  RTP_Scenario: Member, Dimension=Scenario, Default=Budget

→ Validate → Set Deployable → Deploy
→ Attach to Revenue_Entry as On Save rule
```

### Step 8: Enter Test Data (15 min)

```
Open Revenue_Entry form:
  Select Entity: Mumbai_Hotel
  
  Enter test data:
            Jan         Feb         Mar
  Room Rev  8,500,000   9,000,000   7,600,000
  F&B Rev   2,200,000   2,400,000   2,100,000
  Spa Rev     500,000     600,000     450,000
  
  Click Save → Rule runs → Open PnL_Summary
  
  Verify:
    Total Revenue = 11,200,000 (Jan) ✅
    Net Income calculated ✅
    Profit Margin calculated ✅
    All_Hotels aggregated ✅
```

### Step 9: Set Up Security (15 min)

```
Navigator → Application → Provisioning

Groups:
  Mumbai_Planners → assign: Planner role
  Finance_Team → assign: Power User role
  Executive_Board → assign: Viewer role

Dimension Security:
  Entity: Mumbai_Planners → Write on Mumbai_Hotel, None on others
  Scenario: All planners → Read on Actual, Write on Budget/Forecast
```

### Step 10: Verify End-to-End (15 min)

```
Test checklist:
  ☐ Login as admin → see all forms
  ☐ Login as Mumbai_Planner → see only Mumbai data
  ☐ Enter revenue → Save → P&L calculates
  ☐ Open PnL_Summary → verify totals
  ☐ Open Smart View → connect → ad hoc → zoom
  ☐ Run business rule manually with RTPs
```
