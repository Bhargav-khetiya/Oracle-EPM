# 22.01 Lab: Build Your First BSO Cube

> **Module:** 22_Labs  
> **Topic:** 01 - Custom Cube Creation  
> **Difficulty:** Medium  

---

## 1. Objective
You will create a custom Oracle EPBCS Planning application from scratch, define the physical dimensionality, and configure a basic Web Form for data entry.

## 2. Prerequisites
- Service Administrator access to a blank Oracle EPM Cloud environment.

## 3. Steps

### Phase 1: Application Creation
1. Log into the EPM Cloud environment.
2. If presented with a blank screen, click **Create a new application**.
3. Select **Custom** (Do not select Modules).
4. Name the application `DEMOAPP`.
5. Under Setup, enable **Hybrid BSO** (This is crucial for modern performance).
6. Set the base time periods: 
   - Start Year: 2024
   - End Year: 2034
   - First Month: January
7. Click **Create**. (Wait 5-10 minutes for the relational repository and Essbase engine to instantiate).

### Phase 2: Metadata Configuration
1. Navigate to **Navigator -> Dimensions**.
2. Select the `Account` dimension.
3. Add a new child to `Account` called `Net_Income`. (Data Storage: `Dynamic Calc`).
4. Add two children to `Net_Income`:
   - `Total_Revenue` (Data Storage: `Store`, Consolidation: `+`)
   - `Total_Expenses` (Data Storage: `Store`, Consolidation: `-`)
5. Select the `Entity` dimension.
6. Create `Total_Geography` -> `North_America` -> `New_York`. (Set New_York to `Store`).
7. Click **Refresh Database** in the top right. (This pushes your changes into the Essbase `.otl` file).

### Phase 3: Web Form Design
1. Navigate to **Navigator -> Forms**.
2. Create a new Form named `Income_Input`.
3. Go to the **Layout** tab.
4. **POV:** `Year`, `Scenario`, `Version`. (Select `FY24`, `Plan`, `Working`).
5. **Columns:** `Period`. (Select `Jan`, `Feb`, `Mar`).
6. **Rows:** `Account`. (Select `Total_Revenue`, `Total_Expenses`, `Net_Income`).
7. **Page:** `Entity`. (Select `New_York`).
8. Save the form.

## 4. Expected Result
When you click **Preview** on the Form layout, a grid should appear. You should be able to type `$1000` into the `Total_Revenue` cell for `Jan`, type `$200` into the `Total_Expenses` cell for `Jan`, and click Save. 
Because `Net_Income` is a `Dynamic Calc` parent with `Total_Expenses` set to subtract, the `Net_Income` cell should instantly calculate and display `$800` without running any business rules.

## 5. Common Errors
- **The cells are gray and read-only:** You likely set `Total_Revenue` to `Dynamic Calc` instead of `Store`. You cannot type data directly into a dynamically calculated member.
- **The Refresh Database step failed:** You may have used illegal characters (like a hyphen `-`) in a member name. Use underscores `_`.

## 6. Cleanup
Go to Application -> Overview -> Actions -> **Remove Application** to reset your environment for the next lab.
