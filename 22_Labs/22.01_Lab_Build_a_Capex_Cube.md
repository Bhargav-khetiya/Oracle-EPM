# Hands-On Lab: Build a CapEx Cube

This lab outlines the high-level steps to construct a Capital Expenditure (CapEx) tracking cube in FreeForm.

## Objective
Build a lightweight ASO reporting cube to track capital asset purchases by Department.

## Prerequisites
*   Access to an EPM Enterprise Cloud environment.
*   Administrator role.

## Lab Steps

### Step 1: Initialize the FreeForm Application
1.  Log into EPM Cloud and select **Create a new Application**.
2.  Select **FreeForm**.
3.  Name the application `CAPEX_RPT`.
4.  Choose **ASO (Aggregate Storage Option)** for the cube type. *Why ASO? Because we are purely reporting on CapEx totals, not calculating complex depreciation schedules in this specific cube.*

### Step 2: Build the Dimensions
You will need a minimum of 4 dimensions. Navigate to **Dimensions** and create:
1.  **Account:** (Tag as Accounts). Add members: `CAP_001` (Servers), `CAP_002` (Software), `Total_CapEx` (Parent).
2.  **Period:** (Tag as Time). Add: `Jan`, `Feb`, `Mar`, `Q1` (Parent).
3.  **Department:** (Tag as Entity). Add: `IT`, `HR`, `Finance`, `Total_Company` (Parent).
4.  **Scenario:** Add: `Actual`, `Budget`.

### Step 3: Configure Dimension Hierarchies
Ensure that all Parent members have their Data Storage set to **Dynamic Calc** or **Addition (+)** depending on ASO hierarchy settings. In ASO, parents aggregate automatically.

### Step 4: Create a Data Entry Form
Even though it's ASO, you can load data. Let's create a quick web form.
1.  Navigate to **Forms** -> **Create**.
2.  Name it `CapEx_Input`.
3.  **Point of View (POV):** Scenario (Budget).
4.  **Page:** Department.
5.  **Columns:** Period (Descendants of Q1).
6.  **Rows:** Account (Descendants of Total_CapEx).

### Step 5: Test the Application
1.  Open the `CapEx_Input` form.
2.  Select `IT` Department.
3.  Enter `10000` into `CAP_001` (Servers) for `Jan`.
4.  Click Save.
5.  Check the `Total_CapEx` and `Q1` totals. Because this is ASO, they should instantly aggregate and display `10000` without running a calculation script.
