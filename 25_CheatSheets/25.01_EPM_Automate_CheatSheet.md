# EPM Automate Cheat Sheet

A quick reference guide for the most critical EPM Automate commands used by administrators.

## 1. Authentication
*   **Log In:** `epmautomate login [username] [password_file.epw] [URL] [identity_domain]`
*   **Encrypt Password:** `epmautomate encrypt [password] [key_file] [password_file.epw]` *(Do this once locally, then use the .epw file in all scripts).*
*   **Log Out:** `epmautomate logout`

## 2. Daily Backups (The Holy Trinity)
These three commands form the core of every nightly backup script.
1.  `epmautomate exportSnapshot "Nightly_Backup"` *(Creates the LCM snapshot on the cloud).*
2.  `epmautomate downloadFile "Nightly_Backup"` *(Downloads it to your local C:\ drive).*
3.  `epmautomate deleteFile "Nightly_Backup"` *(Cleans up the cloud server to save space).*

## 3. Jobs & Logic
*   **Run a Calc Script:** `epmautomate runBusinessRule "RuleName" Entity="USA"` *(Passes RTPs directly).*
*   **Run Data Management:** `epmautomate runDataRule "Load_Actuals" "Jan-24" "Jan-24" "REPLACE"`
*   **Clear a Cube:** `epmautomate clearCube "Plan1" "Clear_Actuals_Job"`

## 4. Metadata & Cube Restructures
*   **Import Dimensions:** `epmautomate importMetadata "Import_Job_Name" "Entity.csv"`
*   **Refresh Database:** `epmautomate refreshCube` *(Mandatory after a metadata import to restructure the index).*

## 5. Audit & Maintenance
*   **Export Audit Logs:** `epmautomate exportAppAudit "Jan_Audit" nDays=30`
*   **Restart the Service:** `epmautomate resetService` *(Use only in emergencies if the pod is completely frozen; takes 15-30 minutes).*
