# 25.01 EPM Automate Cheat Sheet

> **Module:** 25_CheatSheets  
> **Topic:** 01 - EPM Automate Commands  
> **Target Audience:** Architect / Admin  

---

## The Essentials

**Login securely (Requires prior use of `encrypt` command):**
`epmautomate login ServiceAdmin https://epm-cloud-url.oraclecloud.com password.epw`

**Logout (Always the last line of a script):**
`epmautomate logout`

---

## Data Integration & Movement

**Run a Data Rule (Data Management / Data Integration):**
`epmautomate rundatarule "Rule_Name" "Start_Period" "End_Period" "Import_Mode" "Export_Mode"`
*Example:* `epmautomate rundatarule "Load_GL_Actuals" "Jan-24" "Jan-24" "REPLACE" "STORE_DATA"`

**Run a Business Rule:**
`epmautomate runbusinessrule "Rule_Name" "Prompt1=Value1" "Prompt2=Value2"`
*Example:* `epmautomate runbusinessrule "Calc_Depreciation" "Entity=Total_NA" "Period=Q1"`

**Run a Data Map (Smart Push):**
`epmautomate rundatamap "Map_Name" clearData=true`
*Example:* `epmautomate rundatamap "Push_Fin_to_Rep" clearData=true`

---

## File Management (Inbox/Outbox)

**Upload a file from Local to Cloud:**
`epmautomate uploadfile "C:\local\path\data.csv" "inbox/data.csv"`

**Download a file from Cloud to Local:**
`epmautomate downloadfile "outbox/export.csv" "C:\local\path\export.csv"`

**Delete a file from Cloud to save space:**
`epmautomate deletefile "inbox/data.csv"`

---

## Maintenance & Backups (The Daily Routine)

**Copy the daily snapshot to a new name:**
`epmautomate copysnapshotfrominstance "Artifact Snapshot" "Backup_YYYYMMDD"`

**Download the snapshot locally:**
`epmautomate downloadfile "Backup_YYYYMMDD"`

**Clear the Audit Log (Crucial for performance):**
`epmautomate clearAudit "30"` *(Clears logs older than 30 days)*

**Clear the Data Management Staging Tables:**
`epmautomate maintainDataManagement "ClearData=true" "ClearSetup=false" "DaysToKeep=30"`

---

## Metadata Management

**Import Metadata from a CSV:**
`epmautomate importmetadata "Job_Name_in_UI" "data_file.csv"`

**Restructure the Cube (Defragmentation):**
`epmautomate restructureCube "FinPlan"`

---

## Architect Tips for Batch Scripting

1. **Error Catching:** In Windows batch scripts, always check the `%errorlevel%`. If EPM Automate fails, it returns a non-zero error level.
   ```bat
   epmautomate runbusinessrule "Calc_All"
   IF %ERRORLEVEL% NEQ 0 (
       echo "Rule Failed! Triggering email alert."
       exit /b %ERRORLEVEL%
   )
   ```
2. **Never hardcode passwords:** Use `epmautomate encrypt password keyfile.epw` to securely store credentials.
