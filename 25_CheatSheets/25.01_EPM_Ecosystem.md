## Oracle EPM Cloud Modules

| Module | Full Name | Purpose |
|--------|-----------|---------|
| **EPBCS** | Enterprise Planning & Budgeting Cloud | Budgeting, Forecasting, Planning |
| **PBCS** | Planning & Budgeting Cloud | Simpler version of EPBCS |
| **FCCS** | Financial Consolidation Cloud | Multi-entity consolidation |
| **ARCS** | Account Reconciliation Cloud | Account matching, reconciliation |
| **PCMCS** | Profitability & Cost Management | Cost allocation, profitability |
| **EDMCS** | Enterprise Data Management Cloud | Master data governance |
| **NRCS** | Narrative Reporting Cloud | Management reports, board books |
| **Tax Reporting** | Tax Reporting Cloud | Tax provision, country-by-country |

## EPBCS vs PBCS

| Feature | EPBCS | PBCS |
|---------|-------|------|
| Pre-built modules | ✅ FinPlan, Workforce, CapEx | ❌ Blank app |
| Best-practice dims | ✅ Pre-configured | ❌ Build from scratch |
| Pre-built forms | ✅ 100+ templates | ❌ None |
| Flexibility | Medium (within framework) | High (total freedom) |
| Setup time | Days | Weeks |
| Best for | Standardized FP&A | Custom planning apps |

## Technology Stack

```
User Layer:    Browser (Chrome) + Smart View (Excel)
App Layer:     Oracle Planning (Java-based)
Calc Layer:    Essbase (BSO/ASO/Hybrid) + Calc Manager
Data Layer:    Essbase cubes (multidimensional database)
Integration:   EPM Automate (CLI) + REST API + Data Management
Cloud:         Oracle Cloud Infrastructure (OCI)
```

## Key Terminology

| Term | Meaning |
|------|---------|
| **Cube** | Multidimensional database (Essbase) |
| **Plan Type** | A cube within the application |
| **Dense** | Dimension stored within blocks (Account, Period) |
| **Sparse** | Dimension that defines blocks (Entity, Scenario) |
| **Block** | Physical data storage unit (one per sparse combo) |
| **Form** | Data entry grid in the browser |
| **Business Rule** | Calc script or Groovy that processes data |
| **Smart View** | Excel add-in for EPBCS access |
| **SubVar** | Substitution Variable (&CurrMonth) |
| **RTP** | Runtime Prompt ({RTP_Scenario}) |
| **LCM** | Lifecycle Management (backup/migration) |
| **ASO** | Aggregate Storage Option (read-only, fast queries) |
| **BSO** | Block Storage Option (read-write, input data) |
| **Hybrid BSO** | BSO + ASO features combined |
