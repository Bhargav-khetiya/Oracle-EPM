# Calculation Manager Functions Cheat Sheet

A quick reference for the most commonly used `@` functions in Essbase Calculation Manager (BSO).

## 1. Navigating the Hierarchy
These functions determine *where* in the outline you are working.

*   `@CHILDREN("Member")`: Returns the immediate children (Level 1 below).
*   `@DESCENDANTS("Member")`: Returns ALL members below (Level 1, Level 2, Level 0...).
*   `@IDESCENDANTS("Member")`: Returns ALL members below PLUS the parent member itself (Inclusive).
*   `@RELATIVE("Member", 0)`: Returns ONLY the Level 0 (bottom-level) members. *This is the most common function used in FIX statements.*
*   `@ANCESTORS("Member")`: Returns all parents all the way up to the top of the dimension.
*   `@SIBLINGS("Member")`: Returns members that share the same parent.

## 2. Boolean Checks (IF Statements)
These return True/False and are used inside `IF` blocks.

*   `@ISMBR("Member")`: Is the calculation currently sitting on "Member"?
*   `@ISDESC("Member")`: Is the calculation currently sitting on a descendant of "Member"?
*   `@ISUDA("Dimension", "UDA_Name")`: Does the current member have this User Defined Attribute?
*   `@ISLEV("Dimension", 0)`: Is the current member a Level 0 member?

## 3. Mathematical & Allocation
Functions for moving and altering data.

*   `@SUM(@CHILDREN("Member"))`: Adds up the values of the children. (Rarely used manually; usually handled by normal dimension rollups).
*   `@PRIOR(Account, 1, Period)`: Grabs the data from the previous period (e.g., To calculate Month-over-Month variance).
*   `@NEXT(Account, 1, Period)`: Grabs the data from the next period.
*   `@ALLOCATE(Amount, AllocationRange, BasisMember, [options])`: The cornerstone of top-down allocations. Spreads an amount down to children based on a driver (like Headcount or Square Footage).

## 4. System Variables
*   `#MISSING`: Represents a null cell (no data block exists, or the block is empty).
*   `&VarName`: A Substitution Variable.
*   `{rtpName}`: A Runtime Prompt.

## 5. Typical Syntax Structure
```essbase
/* 1. Set engine parameters */
SET UPDATECALC OFF;

/* 2. Isolate the exact blocks to calculate (The FIX) */
FIX ("Actual", "FY24", @RELATIVE("Total_Geography", 0))

    /* 3. The Math (Always place on a Dense dimension like Account) */
    "Gross_Margin" (
        IF (@ISMBR("Jan"))
            "Gross_Margin" = "Revenue" - "COGS";
        ENDIF
    )

ENDFIX
```
