# 25.03 — Account Properties Cheat Sheet

> **Quick Reference** | Print-friendly | Bookmark this

---

## Account Type

| Type | What It Does | Use For |
|------|-------------|---------|
| **Revenue** | Time Balance = Flow, Variance = Non-Expense | Revenue, Income |
| **Expense** | Time Balance = Flow, Variance = Expense | Costs, Expenses |
| **Asset** | Time Balance = Balance, Variance = Non-Expense | Assets, Receivables |
| **Liability** | Time Balance = Balance, Variance = Expense | Liabilities, Payables |
| **Equity** | Time Balance = Balance, Variance = Non-Expense | Equity accounts |
| **Saved Assumption** | Not in rollups | Rates, ratios, drivers |

## Data Storage

| Storage | Behavior | Use For |
|---------|----------|---------|
| **Store** | Physically stored on disk | Input cells (user-entered data) |
| **Dynamic Calc** | Calculated on-the-fly | Totals, ratios, aggregations |
| **Dynamic Calc & Store** | Calc on-the-fly + stored | Expensive calcs (cache result) |
| **Never Share** | Prevents shared members | Override shared member behavior |
| **Label Only** | No data — just a label | Headings, groupings |
| **Shared** | Points to another member's data | Alternate hierarchies |

## Time Balance

| Setting | How It Aggregates to Parent Period | Example |
|---------|----------------------------------|---------|
| **Flow** | SUM (Jan + Feb + Mar = Q1) | Revenue, Expenses |
| **First** | First child (Jan = Q1) | Opening Balance |
| **Last** | Last child (Mar = Q1) | Closing Balance |
| **Average** | AVG (Jan + Feb + Mar) / 3 | Rates, Ratios |
| **None** | No time aggregation | Standalone values |

## Skip Value

| Setting | What It Skips During Aggregation |
|---------|--------------------------------|
| **None** | Nothing skipped (include all) |
| **Missing** | Skip #MISSING values |
| **Zeros** | Skip zero values |
| **Missing and Zeros** | Skip both |

## Variance Reporting

| Setting | Positive Variance = | Use For |
|---------|---------------------|---------|
| **Non-Expense** | Actual > Budget = Favorable ✅ | Revenue |
| **Expense** | Actual < Budget = Favorable ✅ | Expenses |
