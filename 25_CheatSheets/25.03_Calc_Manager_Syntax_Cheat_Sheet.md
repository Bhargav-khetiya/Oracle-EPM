# 25.03 Calc Manager Syntax Cheat Sheet

> **Module:** 25_CheatSheets  
> **Topic:** 03 - Essbase Syntax Operators  
> **Target Audience:** Developer / Admin  

---

## 1. The Block Bounding Box (FIX)
Every Business Rule must have a scope.
```essbase
FIX("FY24", "Working", "USD", @IDESCENDANTS("Total Geography"))
    /* Math goes here */
ENDFIX
```

## 2. The Terminators (;)
Every single mathematical statement and command must end with a semicolon. If you forget it, the entire script fails validation.
```essbase
"Margin" = "Profit" / "Revenue";
```

## 3. The Operators
- **Add:** `+`
- **Subtract:** `-`
- **Multiply:** `*`
- **Divide:** `/`
- **Cross-Dimensional (The Arrow):** `->`
- **Equal To (Evaluation):** `==`
- **Not Equal To:** `<>` or `!=`

## 4. The Conditional Logic (IF)
Always wrap conditions in an `IF` and terminate with `ENDIF`.
```essbase
IF("Revenue" > 100000)
    "Bonus" = 5000;
ELSEIF("Revenue" > 50000)
    "Bonus" = 1000;
ELSE
    "Bonus" = 0;
ENDIF
```

## 5. The Dangerous Commands (Use with Caution)

**Create blocks out of thin air:**
`SET CREATENONMISSINGBLK ON;`
*(Warning: Will crash the server if the FIX is too broad).*

**Turn off Smart Aggregation:**
`SET AGGMISSG OFF;`
*(Warning: Forces the engine to evaluate every single missing block during a rollup. Massively slows down performance).*

**Force execution regardless of block status:**
`SET UPDATECALC OFF;`
*(Rule: Always include this at the top of EPM Cloud scripts).*

## 6. The Dynamic List Generators (Functions)

Instead of hardcoding `"New York", "Boston", "Chicago"`, use dynamic functions:
- **`@CHILDREN("USA")`**: Gets just the immediate children (NY, MA, IL).
- **`@DESCENDANTS("USA")`**: Gets children, grandchildren, and all leaf nodes.
- **`@IDESCENDANTS("USA")`**: Gets the descendants AND includes the parent "USA" itself.
- **`@RELATIVE("USA", 0)`**: Gets ONLY the Level-0 leaf members under USA (The absolute best function for isolating data-entry intersections).

## 7. Comments
Document your code. The engine ignores comments.
```essbase
/* This is a multi-line comment.
   It spans multiple lines. */

// This is a single line comment.
```
