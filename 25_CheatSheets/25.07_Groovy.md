## Groovy Rule Template

```groovy
/* Groovy Rule in Calc Manager */
/* RTPS: {RTP_Scenario} {RTP_Year} */

// Get RTP values
String scenario = rtps.RTP_Scenario.toString()
String year = rtps.RTP_Year.toString()

// Iterate cells on form
operation.grid.dataCellIterator().each { DataCell cell ->
    // Process each cell
}
```

## Cell Access Patterns

```groovy
/* Read cell value */
double value = cell.data
String memberName = cell.getMemberName("Account")

/* Write cell value */
cell.data = 100000
cell.data = cell.data * 1.05  // 5% growth

/* Check if missing */
if (cell.isMissing()) {
    cell.data = 0
}

/* Get Smart List value */
String status = cell.getSmartListValue()
int statusId = cell.data as int

/* Get cross-dimensional value */
double actual = cell.crossDimCell("Scenario#Actual").data
double budget = cell.crossDimCell("Scenario#Budget").data
```

## Iteration Patterns

```groovy
/* All data cells on form */
operation.grid.dataCellIterator().each { cell ->
    println "${cell.getMemberName('Account')}: ${cell.data}"
}

/* Filtered iterator — specific Account */
operation.grid.dataCellIterator("Account#Room_Revenue").each { cell ->
    cell.data = cell.data * 1.05
}

/* Multiple filters */
operation.grid.dataCellIterator(
    "Account#Room_Revenue",
    "Entity#Mumbai_Hotel"
).each { cell ->
    cell.data = cell.data * 1.10
}
```

## Data Map (Cross-Cube Read)

```groovy
/* Read from another cube */
DataMap map = operation.dataMap("MapName")

/* Use in cell iteration */
operation.grid.dataCellIterator().each { cell ->
    double wfpSalary = cell.crossDimCell(map, "Account#Basic_Salary").data
    cell.data = wfpSalary  // Copy from Workforce to FinPlan
}
```

## Grid Builder (Custom Data Retrieval)

```groovy
/* Build a custom grid to read specific data */
def grid = operation.application.getGridDefinitionBuilder()

grid.addDimension("Account", "Room_Revenue")
grid.addDimension("Entity", "Mumbai_Hotel")
grid.addDimension("Scenario", "Actual")
grid.addDimension("Year", "FY2026")

def dataGrid = grid.build()
double value = dataGrid.dataCellIterator().next().data
```

## Logging and Messages

```groovy
/* Print to job log */
println "Processing entity: ${entity}"

/* Throw error (stops rule) */
throwVetoException("Revenue cannot be negative!")

/* Conditional veto */
operation.grid.dataCellIterator("Account#Revenue").each { cell ->
    if (cell.data < 0) {
        throwVetoException("Negative revenue at ${cell.getMemberName('Entity')}")
    }
}
```

## Common Calculations

```groovy
/* ===== Variance Calculation ===== */
operation.grid.dataCellIterator("Account#Variance").each { cell ->
    double actual = cell.crossDimCell("Scenario#Actual").data
    double budget = cell.crossDimCell("Scenario#Budget").data
    cell.data = actual - budget
}

/* ===== Percentage ===== */
operation.grid.dataCellIterator("Account#Margin_Pct").each { cell ->
    double revenue = cell.crossDimCell("Account#Total_Revenue").data
    double profit = cell.crossDimCell("Account#Net_Income").data
    cell.data = (revenue != 0) ? (profit / revenue * 100) : 0
}

/* ===== Copy Actual to Forecast ===== */
operation.grid.dataCellIterator("Scenario#Forecast").each { cell ->
    cell.data = cell.crossDimCell("Scenario#Actual").data
}

/* ===== Apply Growth Rate ===== */
double growthRate = 1.05  // 5%
operation.grid.dataCellIterator("Account#Room_Revenue", "Scenario#Budget").each { cell ->
    double priorYear = cell.crossDimCell("Year#FY2025").data
    cell.data = priorYear * growthRate
}
```

## Essbase Calc from Groovy

```groovy
/* Run an Essbase calc script from Groovy */
def calcScript = """
FIX("Budget", "Working", "FY2026")
  FIX(@RELATIVE("All_Hotels", 0))
    "Net_Income" = "Total_Revenue" - "Total_Expenses";
  ENDFIX
ENDFIX
"""
operation.application.getEssbaseServer()
    .getApplication("HotelApp")
    .getCube("OEP_FS")
    .executeCalcScript(calcScript)
```

## Data Type Reference

```groovy
double  → cell.data (numeric values)
String  → cell.getMemberName("Dim"), cell.getSmartListValue()
boolean → cell.isMissing(), cell.isReadOnly()
int     → cell.data as int (Smart List IDs)
```

## Quick Rules

| Pattern | Code |
|---------|------|
| Safe division | `(denom != 0) ? (num/denom*100) : 0` |
| Check missing | `if (cell.isMissing()) { ... }` |
| Stop execution | `throwVetoException("msg")` |
| Debug output | `println "debug: ${variable}"` |
| Access RTP | `rtps.RTP_Name.toString()` |
| Cross-dim read | `cell.crossDimCell("Dim#Member").data` |
| Filter iterator | `dataCellIterator("Dim#Member")` |
| Write data | `cell.data = newValue` |
