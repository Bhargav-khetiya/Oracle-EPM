## Data Loading Methods

| Method | Speed | Complexity | Best For |
|--------|-------|-----------|----------|
| Manual form entry | Slow | None | Ad hoc adjustments |
| Smart View paste | Slow | Low | Small Excel datasets |
| Flat file import | Medium | Low | Monthly actuals |
| Data Integration | Fast | Medium | Cloud-to-cloud |
| Data Management | Fast | High | Complex ERP with drill-back |
| EPM Automate | Fast | Medium | Scheduled automation |
| REST API | Fast | High | Custom app integration |

## Flat File Format

```csv
Account,Entity,Scenario,Version,Year,Period,Amount
Room_Revenue,Mumbai_Hotel,Actual,Final,FY2026,Aug,8500000
F&B_Revenue,Mumbai_Hotel,Actual,Final,FY2026,Aug,2200000
```

## Import Modes

| Mode | Behavior | When |
|------|----------|------|
| **Replace** | Clear existing → load new | Monthly actuals (full refresh) |
| **Merge (Accumulate)** | Add to existing values | Journal entries |
| **Replace All** | Clear ALL data in scope → load | Full reload |

## Data Management vs Data Integration

| Feature | Data Management | Data Integration |
|---------|----------------|-----------------|
| UI | Complex (FDMEE) | Simple (modern) |
| Mapping | Explicit rules | Auto + overrides |
| Drill-back | ✅ Full | ✅ Limited |
| Scripting | Jython/SQL | Visual mapping |
| Best for | Complex ERP | Simple file loads |

## EPM Automate Data Commands

```bash
# Upload file
epmautomate uploadfile "C:\data\Actuals.csv"

# Run import rule
epmautomate importdata "DL_Revenue_Actuals"

# Run import with specific file
epmautomate importdata "DL_Revenue_Actuals" "Actuals.csv"

# Export data
epmautomate exportdata "DE_Revenue_Export"

# Import metadata
epmautomate importmetadata "MD_Entity_Load"

# Export metadata
epmautomate exportmetadata "MD_Entity_Export"
```

## EPM Integration Agent (On-Premise)

```
On-Premise DB → Agent (Windows Service) → HTTPS → EPM Cloud

Setup:
1. Install Agent on-premise server
2. Register Agent in EPM Cloud
3. Create JDBC connection to local DB
4. Create Data Integration rule
5. Schedule in EPM Automate
```

## Common Errors and Fixes

| Error | Cause | Fix |
|-------|-------|-----|
| "Member not found" | Typo in data file | Fix member names |
| "Invalid data value" | Text in numeric column | Clean data (remove N/A, blanks) |
| "File not found" | File not uploaded | Upload before running load |
| Records skipped | Header row counted as data | Configure header skip |
| Data doubled | Import mode = Accumulate | Use Replace mode |

## Data Load Checklist


## Monthly Close Data Flow

```
1. Update SubVars (CurrMonth, PriorMonth)
2. Upload data file
3. Run import data rule
4. Refresh database
5. Run aggregation rule
6. Run currency conversion
7. Smart Push to reporting cube
8. Backup (LCM export)
```
