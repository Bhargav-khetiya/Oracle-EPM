## 📌 Login/Logout
```bash
epmautomate login user@co.com password.epw URL EncKey
epmautomate logout
epmautomate encrypt MyPass EncKey C:\pwd.epw
```

## 📌 Data Operations
```bash
epmautomate uploadFile data.csv
epmautomate downloadFile report.csv
epmautomate importData LoadRuleName
epmautomate exportData ExportRuleName
epmautomate deleteFile data.csv
epmautomate listFiles
```

## 📌 Rules & Calculations
```bash
epmautomate runBusinessRule "RuleName"
epmautomate runRuleSet "RuleSetName"
epmautomate runCalc CalcName PlanType
```

## 📌 Metadata
```bash
epmautomate importMetadata MetadataFile
epmautomate exportMetadata MetadataFile
epmautomate refreshCube
```

## 📌 Administration
```bash
epmautomate exportSnapshot "BackupName"
epmautomate importSnapshot "BackupName"
epmautomate copySnapshotFromInstance "Name" user pwd URL key
epmautomate recreate -f
epmautomate resetService
```

## 📌 Variables
```bash
epmautomate setSubstVars ALL CurrentMonth=Jul
epmautomate getSubstVars
```

## 🔒 Security
```bash
epmautomate assignRole user@co.com User
epmautomate removeRole user@co.com User
```

## 📌 Script Template
```bash
@echo off
epmautomate login %USER% %PWD% %URL% %KEY%
IF ERRORLEVEL 1 (echo FAILED & exit /b 1)
epmautomate uploadFile data.csv
epmautomate importData LoadActuals
epmautomate runBusinessRule "Aggregate"
epmautomate logout
```

## 📌 Exit Codes
0=Success | 1=Error | 2=Invalid | 3=Auth Failed | 4=File Missing

### 💡 Pro Tip: Password File Hardware Binding
> **Misconception:** You can encrypt a password on your laptop (`epmautomate encrypt`), email the `.epw` file to the IT team, and they can use it on the production Windows server.
> **Reality:** EPM Automate password encryption binds the `.epw` file to the *hardware MAC address* and OS profile of the machine that generated it! If you move the file to another server, it immediately throws an "Invalid Password" error. You must run the `encrypt` command directly on the server that will be executing the automated scripts.
