# 26.01 Oracle EPM Glossary

> **Module:** 26_Glossary  
> **Topic:** 01 - The Master Dictionary  
> **Target Audience:** Beginner to Architect  

---

## A
- **Alias:** An alternate, user-friendly name for a dimension member. (e.g., Member Name: `1000`, Alias: `Cash`).
- **ASO (Aggregate Storage Option):** The Essbase reporting engine. It has no calculation scripts and calculates massive hierarchies dynamically on the fly.
- **AMW (Automated Maintenance Window):** The 1-hour daily window where Oracle restarts the cloud services and takes the artifact snapshot backup.
- **AUH (Approval Unit Hierarchy):** The routing map used for the budget approval workflow.

## B
- **BSO (Block Storage Option):** The primary calculation and data-entry engine of Essbase. It stores data in fixed-size blocks and requires calculation scripts to roll data up.

## C
- **Calculation Manager:** The web-based UI used to write, design, and deploy Business Rules and Groovy scripts.
- **CoE (Center of Excellence):** The hybrid IT/Finance team that governs and maintains the EPM ecosystem after Go-Live.
- **Cross-Dimensional Operator (`->`):** An Essbase syntax operator used to fetch or push data to an intersection outside of the current `FIX` statement.

## D
- **Dense Dimension:** A dimension (usually Account and Period) that defines the physical geometry of an Essbase block. 
- **Dynamic Calc:** A storage property that prevents data from being saved to the hard drive, forcing the engine to calculate the answer in RAM when a user requests it.
- **Data Management (FDMEE):** The internal ETL tool used to map and transform data from flat files or ERPs into Essbase.

## E
- **EPM Automate:** A command-line utility used to automate daily administrative tasks (like data loads and backups) via batch scripting.
- **EDMCS (Enterprise Data Management Cloud Service):** Oracle's master data management tool used to synchronize dimension hierarchies across multiple applications (ERP, EPM, FCCS).

## F
- **Flex Form:** A Smart View form property that allows a user to use native Excel sorting and filtering without breaking the ability to submit data back to the server.
- **FIX Statement:** The core bounding box of an Essbase Calc Script. It isolates the engine to only process a specific slice of the database (e.g., `FIX("FY24", "Budget")`).

## G
- **Groovy:** An object-oriented Java-like scripting language available in EPM Enterprise used to intercept web form saves, run REST APIs, and perform dynamic validations.

## H
- **Hybrid BSO:** A modern Essbase configuration that uses BSO blocks for data entry, but ASO dynamic math for sparse parent rollups, combining the best of both engines.

## P
- **POV (Point of View):** The current intersection context of a report or web form. It tells the system exactly which slice of data the user is looking at.

## R
- **RTP (Runtime Prompt):** A pop-up variable in a Business Rule that asks the user a question (e.g., "Which Cost Center do you want to calculate?") before executing the logic.
- **REST API:** A web standard for system integration. Allows external tools to trigger EPM jobs or pull data via HTTP JSON payloads.

## S
- **Sparse Dimension:** A dimension (usually Entity and Product) that creates the index of blocks. Calculating sparse dimensions requires heavy disk I/O.
- **Smart View:** The Oracle add-in that allows users to interact with the Essbase database directly through Microsoft Excel, Word, and PowerPoint.
- **Smart Push (Data Maps):** A feature that instantly copies data from a BSO input cube to an ASO reporting cube after a user clicks save on a form.
- **Substitution Variable:** A global placeholder (e.g., `&CurYr`) used in scripts and forms to avoid hardcoding static time periods.
