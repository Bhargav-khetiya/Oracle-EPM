## 1. Exam Overview & Strategy

The Oracle EPBCS Implementation Professional exam proves your foundational capability to configure standard planning modules, manage metadata, build forms, and execute security.

- **Duration:** 90 Minutes
- **Number of Questions:** 60 Multiple Choice
- **Passing Score:** 66% (Subject to slight changes per year)
- **Format:** Online Proctored (via Pearson VUE / Oracle University)

### 💡 Pro Tip: Certification vs Experience
> **Misconception:** "Passing the 1Z0 certification proves I am a senior EPM consultant."
> **Reality:** The certification tests your knowledge of Oracle's official documentation and button placements. Real-world architecture—like diagnosing block explosions, writing memory-safe Groovy, or tuning Hybrid BSO—is rarely covered on the exam. Use the certification to get past HR filters, but rely on your internal mastery (this repository) to pass the technical interview.

## 3. The "Oracle Way" vs "Real World" Trap

When taking the exam, you must answer how **Oracle documentation says to do it**, NOT how you would hack it in the real world.

- **Real World:** "I write a Groovy script using DataGridBuilder to move data between cubes because Data Maps are too slow for this edge case."
- **Exam Answer:** "To move data between cubes, you configure a Data Map and attach it to a Smart Push on a web form." (Always choose the native UI feature over custom code on the exam).

## 4. Top 10 Certification Gotchas

1. **Clear Data vs Clear Block:** The exam will try to trick you. `CLEARBLOCK` removes the physical Essbase block. `CLEARDATA` just turns the numbers to #MISSING but leaves the empty block taking up space.
2. **Dynamic Calc vs Store:** If a question asks how to optimize reporting performance for a high-level parent, the answer is usually to change it from Dynamic Calc to Store and run an Aggregation rule (unless it's Hybrid).
3. **Data Management Sequence:** Memorize the exact sequence: `Source System -> Target Application -> Import Format -> Location -> Period -> Data Load Rule`.
4. **Approval Units:** Understand that an Approval Unit is always driven by the **Entity** dimension, combined with Scenario and Version.
5. **Valid Intersections:** If a Valid Intersection rule conflicts with Cell-Level Security, Cell-Level Security always wins.
6. **Time Balance:** Understand the difference between `Flow` (Sum of months) and `Balance` (Value of the final month, e.g., for Bank Accounts).
7. **EPM Automate:** Memorize the exact spelling of commands. It's `epmautomate runBusinessRule`, not `executeRule`.
8. **Navigation Flows:** Know that you can hide default Oracle clusters (like the "Academy" icon) using Navigation Flows assigned to specific User Groups.
9. **Smart Lists:** Know that Smart Lists are technically stored as Integers in the Essbase kernel, even though they display as text to the user.
10. **Rolling Forecasts:** Know that configuring a rolling forecast allows data to cross fiscal year boundaries seamlessly without needing custom member formulas.
