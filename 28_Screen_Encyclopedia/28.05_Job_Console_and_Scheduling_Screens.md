## Job Types

| Type | What It Runs | Triggered By |
|------|-------------|-------------|
| Rules | Business rules/rulesets | Form save, manual, schedule |
| Data Load | Import data from file | Manual or EPM Automate |
| Maintenance | Refresh DB, restructure | Admin action |
| Export | Data/metadata export | Manual or EPM Automate |
| Smart Push | Cross-cube data push | Form save rule |
| Clear Cube | Clear data intersections | Admin action |

## Key Actions
- **View Log**: See detailed error messages for failed jobs
- **Download Log**: Export log for analysis
- **Re-run**: Re-execute failed job
- **Cancel**: Stop a running job
- **Schedule**: Set up recurring execution
