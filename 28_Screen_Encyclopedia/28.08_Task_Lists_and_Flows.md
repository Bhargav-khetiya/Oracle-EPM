# Task Lists and Task Flows

Task Lists are classic EPM features that guide a user step-by-step through a business process (like month-end close or annual budgeting). 

*Note: While Navigation Flows provide a role-based homepage, Task Lists provide a rigid, sequential checklist of activities.*

## 1. Task List End-to-End Flow

A standard Task List flow operates as follows:
1.  **Creation:** An administrator defines the Task List (e.g., "Annual Budget Process").
2.  **Tasks:** Individual tasks are added (e.g., Step 1: Update Drivers, Step 2: Enter OpEx, Step 3: Run Allocations).
3.  **Assignment:** The Task List is assigned to a user or group. Crucially, a Task List can be driven by a specific dimension (usually Entity). This means "Cost Center 100" has its own instance of the Task List, separate from "Cost Center 200".
4.  **Execution (Front End):** The planner opens the Task List, clicks the first task, completes the work, and clicks "Complete". The system tracks completion percentages.
5.  **Monitoring:** Administrators use the Task List Status reports to see which planners are falling behind schedule.

## 2. Objects That Can Be Attached

A single "Task" is basically a pointer to an EPM object. You can attach:
*   **Forms:** Opens the grid for data entry.
*   **Business Rules:** Launches a calc script.
*   **URLs:** Links out to a policy document.
*   **Approval Units:** Triggers the promotion of an entity to the next level of management.
*   **Descriptive Tasks:** A pure "check-the-box" task with no attached object (e.g., "Verify numbers with HR").

## 3. Back End Configuration

*   **Task List Folders:** Tasks must be organized into folders.
*   **Due Dates and Alerts:** You can assign explicit due dates and configure the system to send email alerts if a task is overdue.
*   **Successor/Predecessor Logic:** You can lock tasks so Step 2 cannot be opened until Step 1 is marked Complete.

> [!TIP]
> **Modern Alternative:** In EPM Cloud, the older "Task List" feature is slowly being superseded by **Task Manager** (formerly part of FCCS, now available across the platform). Task Manager offers infinitely superior workflow orchestration, integration with external systems (like sending an API call to Oracle ERP), and deeper dashboarding for close cycles.
