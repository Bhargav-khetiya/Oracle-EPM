## Key Features
| Feature | Description |
|---------|------------|
| **Task Dependencies** | Task B waits for Task A completion |
| **Alerts** | Email when task becomes available |
| **Due Dates** | Relative or absolute deadlines |
| **Progress Tracking** | Dashboard shows % complete per list |
| **Task Types** | Can link to forms, rules, URLs, approvals |
