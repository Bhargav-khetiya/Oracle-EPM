## 1. WHY — What Problem Does the Jobs Console Solve?

**The problem:** EPBCS runs many operations in the background — rules, data loads, exports, refreshes, snapshots. Users need to know: Did my rule finish? Did the data load succeed? How long did it take? Can I schedule it to run tonight?

**The solution:** The Jobs Console is the **centralized job management dashboard** showing all past, current, and scheduled background operations with their status, duration, and error logs.

## 7. ERROR HANDLING — VIEWING LOGS

### For Failed Jobs
```
1. Click the failed job row (❌ status)
2. Click "View Log" or "Download Log"
3. Log shows:
   - Timestamp of each step
   - Error message (e.g., "Member 'XYZ' not found in dimension 'Account'")
   - Stack trace (for Groovy errors)
   - Number of records processed/rejected (for data loads)
```

### Common Error Patterns

| Error | Cause | Fix |
|-------|-------|-----|
| "Member not found" | Rule references a deleted/renamed member | Update rule with correct member name |
| "Insufficient privileges" | User lacks launch permission | Grant Launch access in Calc Manager |
| "Database locked" | Another operation is running | Wait for it to finish, then retry |
| "Import rejected N records" | Data format mismatch | Check import file format, mappings |
| "Out of memory" | Rule processing too much data | Optimize FIX statement, reduce scope |
| "Timeout exceeded" | Rule took too long | Optimize rule or increase timeout |

## 9. INTERVIEW QUESTIONS

### Beginner
**Q: A user launches a business rule and it shows "Processing" for 20 minutes. How do you check what's happening?**
> **A:** Go to Navigator → Tools → Jobs. Find the job in the list (filter by user and "Processing" status). Click the job row to see details — the start time, elapsed duration. If the rule is truly stuck (no progress), you can click "Cancel" to kill it. After cancelling, check the execution log for errors. Common causes: the rule is processing too many blocks (missing FIX), database lock contention, or an infinite loop.

### Intermediate
**Q: How do you set up a nightly automated job that imports actuals, runs aggregation, and creates a backup?**
> **A:** Create a Business Ruleset containing three rules in sequential order: (1) Import rule that loads data from Inbox, (2) Aggregation rule, (3) A Groovy rule that triggers snapshot creation. Schedule the ruleset: Jobs → Schedule → Ruleset → select the ruleset → Daily at 2:00 AM → set runtime prompts. **Alternatively** (preferred for complex chains): Use EPM Automate scripting with a .bat/.sh script on a scheduled server. EPM Automate commands: `importData`, `runBusinessRule`, `exportSnapshot` — chained with error handling. Schedule via Windows Task Scheduler or crontab.
