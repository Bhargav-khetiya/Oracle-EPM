# Exhaustive List: All Form & Grid Properties

This document serves as the absolute, exhaustive reference manual for every single property available in the EPM Form Designer UI.

## 1. Form Properties (The Global Level)
These properties apply to the entire form envelope.

*   **Name:** The physical name of the form (Cannot contain special characters).
*   **Description:** Tooltip text visible to the end user.
*   **Form Type:** Simple, Composite (Legacy), or Dashboard.
*   **Cube (Application):** The specific Essbase cube (e.g., Plan1) this form connects to.
*   **Instructions:** Rich text displayed at the top of the form for the user.
*   **Smart View Options:**
    *   *Hide form in Smart View:* Prevents the form from opening in Excel.
    *   *Enable Save on Open:* Forces a calculation the moment the form is opened.
*   **Data Validation:** Attach data validation rules (e.g., "Color cell red if > 100").
*   **Business Rules:** Attach Calc Manager rules.
    *   *Run Before Load:* Runs before the grid renders.
    *   *Run After Load:* Runs after the grid renders.
    *   *Run Before Save:* Runs when the user clicks save, *before* data hits Essbase (Groovy validation).
    *   *Run After Save:* Runs when the user clicks save, *after* data hits Essbase (Standard aggregation).
    *   *Run on Form Save:* The trigger event.
    *   *Run in Background:* Submits the rule to the Job Console asynchronously to prevent 504 Gateway Timeouts.

## 2. Grid Properties (The Layout Level)
These properties dictate how the data grid behaves.

### Display Options
*   **Scale:** None, Tens, Hundreds, Thousands, Millions, Billions. (Applies to all cells).
*   **Precision:**
    *   *Minimum:* The minimum decimal places to display (e.g., `2` forces `100.00`).
    *   *Maximum:* The maximum decimal places before visual rounding occurs.
*   **Show Missing As:** What to display when a block is `#MISSING`. (Blank or `0`).
*   **Missing Text:** Text to display instead of blank (e.g., `#MISSING` or `No Data`).
*   **Read-Only:** Locks the entire grid from input.

### Suppression Options (The Performance Keys)
*   **Suppress Missing Blocks:** (Row/Column). Crucial for performance. Stops Essbase from generating empty blocks.
*   **Suppress Missing Data:** (Row/Column). Hides rows/columns where blocks exist but the value is `#MISSING`.
*   **Suppress Invalid Data:** (Row/Column). Hides intersections that violate Valid Intersection rules.
*   **Suppress Unmapped Members:** Hides members that have no data mapping.

### Formatting Options
*   **Apply Formatting:** Enable or disable custom cell colors/fonts.
*   **Row/Column Width:** Set absolute pixel widths or percentages.
*   **Wrap Text:** Allow long text in row headers to wrap.

## 3. Dimension Properties (The Axis Level)
When you place a dimension on the Page, Row, or Column axis, you configure these.

*   **Member Selection:** The logic used to pull members (e.g., `@IDESCENDANTS(Entity)`).
*   **Display:**
    *   *Member Name:* Shows `A_100`.
    *   *Alias:* Shows `Revenue`.
    *   *Member Name and Alias:* Shows `A_100: Revenue`.
*   **Indentation:** None, Subitems, Totals (Creates a cascading visual effect for hierarchies).
*   **Hide:** Hides the dimension visually while keeping it in the query.
*   **Enable Dropdown:** (Page POV only). Allows users to click and select a different member.

## 4. Segment Properties
Within a Row or Column, you can create multiple Segments (e.g., Segment 1: Q1, Segment 2: Q2).
*   **Read-Only:** Lock a specific segment (e.g., Lock Actuals, open Budget).
*   **Override Precision:** Apply a specific decimal precision to just this segment.
*   **Apply Style:** Apply a specific CSS style/color to just this segment (e.g., Make the "Variance" column red).
