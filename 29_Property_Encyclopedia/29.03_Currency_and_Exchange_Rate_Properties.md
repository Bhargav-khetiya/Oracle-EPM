# 29.03 — Currency and Exchange Rate Properties

> **Module:** 29_Property_Encyclopedia | **Topic:** Currency Settings, Exchange Rate Types

---

## 1. APPLICATION CURRENCY SETTINGS

| Property | Options | Impact |
|----------|---------|--------|
| **Multiple Currencies** | Enabled/Disabled | Enables Currency dimension |
| **Base Currency** | INR, USD, EUR, etc. | Default reporting currency |
| **Triangulation Currency** | Any currency | Intermediate for cross-conversion |
| **Input Currency** | Per entity | Currency members enter data in |
| **Reporting Currencies** | List | Currencies available for reports |

## 2. EXCHANGE RATE TYPES

| Type | Use For | When Applied | Example |
|------|---------|-------------|---------|
| **Average** | P&L items (Revenue, Expenses) | Monthly average rate | ₹83.50/USD (Aug avg) |
| **Ending** | Balance Sheet items (Assets, Liabilities) | End-of-month rate | ₹83.80/USD (Aug 31) |
| **Historical** | Equity items (Share Capital) | Locked at transaction date | ₹75.00/USD (fixed) |

## 3. ACCOUNT-LEVEL CURRENCY PROPERTIES

| Property | Options | Effect |
|----------|---------|--------|
| **Exchange Rate Type** | Average, Ending, Historical, None | Which rate to apply |
| **Data Type** | Currency, Non-Currency | Currency members get converted; non-currency skip |
| **Skip Currency Conversion** | On/Off | Override: don't convert this account |
