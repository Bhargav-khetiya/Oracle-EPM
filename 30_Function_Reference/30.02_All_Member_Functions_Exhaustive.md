# Exhaustive List: All @ Member Functions

This document serves as the absolute, exhaustive reference manual for the `@` functions used in Essbase Calc Scripts and Member Formulas.

## 1. Hierarchy & Navigation Functions
Used to select members based on the outline structure.

*   `@ANCESTORS`: Returns all ancestors of a member up to the root.
*   `@CHILDREN`: Returns the immediate children of a member.
*   `@DESCENDANTS`: Returns all descendants of a member.
*   `@IDESCENDANTS`: Returns all descendants PLUS the specified member.
*   `@PARENT`: Returns the immediate parent of a member.
*   `@RELATIVE`: Returns members at a specific level or generation (e.g., `@RELATIVE(Entity, 0)`).
*   `@SIBLINGS`: Returns all members that share the same parent.
*   `@ISIBLINGS`: Returns siblings PLUS the specified member.
*   `@MEMBER`: Converts a string to a valid member name (e.g., `@MEMBER("Jan")`).

## 2. Boolean Logic Functions (IF Conditions)
Used inside `IF` statements; return True or False.

*   `@ISMBR`: Returns True if the calculation is on the specified member(s).
*   `@ISDESC`: Returns True if on a descendant of the member.
*   `@ISLEV`: Returns True if the member is at the specified level (0 = bottom).
*   `@ISGEN`: Returns True if the member is at the specified generation (1 = top).
*   `@ISUDA`: Returns True if the member has the specified User Defined Attribute.
*   `@ISACCTYPE`: Returns True if the account matches a type (Expense, Revenue).
*   `@ISCHILD`: Returns True if the member is a direct child of another.

## 3. Time Series & Prior/Next Functions
Used for period-over-period math.

*   `@PRIOR`: Returns the value from `n` periods ago.
*   `@NEXT`: Returns the value from `n` periods in the future.
*   `@MDSHIFT`: A multi-dimensional version of PRIOR/NEXT.
*   *(Dynamic Time Series)* `H-T-D`, `Y-T-D`, `Q-T-D`, `M-T-D`: History-to-date, Year-to-date, Quarter-to-date, Month-to-date. (Must be enabled in the application settings first).

## 4. Mathematical & Allocation Functions

*   `@SUM`: Adds the values of a member list.
*   `@AVG`: Averages the values of a member list (ignores #MISSING).
*   `@MIN` / `@MAX`: Returns the lowest/highest value in a list.
*   `@ROUND`: Rounds a value to a specific number of decimal places.
*   `@TRUNCATE`: Removes decimals without rounding.
*   `@ABS`: Returns the absolute (positive) value.
*   `@ALLOCATE`: Distributes a parent value down to children based on a driver.
*   `@MDALLOCATE`: Distributes values across multiple dimensions simultaneously.

## 5. System & Cross-Cube Functions

*   `@XREF`: Pulls a value from a different Essbase cube.
*   `@XWRITE`: Pushes a value to a different Essbase cube.
*   `@RETURN`: Immediately stops the calculation script and throws a custom error message to the user. (Used for script validation).
*   `@CONCAT`: Joins two strings together.
*   `@SUBSTRING`: Extracts a portion of a string.

## 6. Financial Functions (Rarely Used Manually)
*   `@NPV`: Net Present Value.
*   `@IRR`: Internal Rate of Return.
*   `@DEPRECIATION`: Calculates standard depreciation (Straight Line, Declining Balance). *Note: The Capital module usually handles this automatically.*
