# 30.02 — Groovy API Function Reference: Complete Guide

> **Module:** 30_Function_Reference | **Topic:** All Groovy API Methods
> **Audience:** Groovy Developer

---

## 1. OPERATION OBJECT — THE ENTRY POINT

| Method | Returns | Purpose |
|--------|---------|---------|
| `operation.grid` | DataGrid | Access current form grid |
| `operation.application` | Application | Access app metadata, cubes |
| `operation.cube` | Cube | Current Plan Type |
| `rtps.RTP_Name` | RuntimePrompt | Access runtime prompt value |

---

## 2. DATA CELL METHODS

| Method | Returns | Purpose |
|--------|---------|---------|
| `cell.data` | double | Get/set cell value |
| `cell.isMissing()` | boolean | True if #MISSING |
| `cell.isReadOnly()` | boolean | True if read-only |
| `cell.isChanged()` | boolean | True if user modified |
| `cell.getMemberName("Dim")` | String | Get member name for dimension |
| `cell.crossDimCell("Dim#Member")` | DataCell | Get cell at different member |
| `cell.crossDimCell(dataMap, "Dim#Member")` | DataCell | Cross-cube cell via DataMap |
| `cell.getSmartListValue()` | String | Get Smart List display text |
| `cell.setSmartListValue(id)` | void | Set Smart List by ID |
| `cell.getFormattedValue()` | String | Formatted display value |

---

## 3. GRID METHODS

| Method | Returns | Purpose |
|--------|---------|---------|
| `grid.dataCellIterator()` | Iterator | All data cells |
| `grid.dataCellIterator("Dim#Member")` | Iterator | Filtered cells |
| `grid.dataCellIterator("Dim1#M1","Dim2#M2")` | Iterator | Multi-filter |
| `grid.getCellWithMembers(map)` | DataCell | Single specific cell |
| `grid.getHeaderCell(row, col)` | HeaderCell | Header cell |

## 4. APPLICATION METHODS

| Method | Returns | Purpose |
|--------|---------|---------|
| `app.getCube("name")` | Cube | Get cube reference |
| `app.getDimension("name")` | Dimension | Get dimension |
| `app.getEssbaseServer()` | EssbaseServer | Execute calc scripts |
| `app.getEmailService()` | EmailService | Send emails |

## 5. DIMENSION/MEMBER METHODS

| Method | Returns | Purpose |
|--------|---------|---------|
| `dim.getMember("name")` | Member | Get specific member |
| `dim.hasMember("name")` | boolean | Check if member exists |
| `dim.getEvaluatedMembers("@CHILDREN('X')")` | List | Evaluate function |
| `member.getName()` | String | Member name |
| `member.getParent()` | Member | Parent member |
| `member.getLevel()` | int | Member level |
| `member.getGeneration()` | int | Member generation |

## 6. EMAIL SERVICE

```groovy
def emailSvc = operation.application.getEmailService()

// Simple email
emailSvc.sendMail("to@email.com", "Subject", "Body text")

// With HTML body
emailSvc.sendMail("cfo@hotel.com", "Monthly Report",
    "<h1>Report</h1><p>Revenue: ₹12.5 Cr</p>")
```

---

## 7. EMBEDDED CALC SCRIPT

```groovy
operation.application.getEssbaseServer()
    .getApplication(operation.application.getName())
    .getCube("OEP_FS")
    .executeCalcScript("""
SET LOCKBLOCK ON;
FIX("Budget", "Working", "FY2026")
  AGG("Entity");
ENDFIX
SET LOCKBLOCK OFF;
""")
```
