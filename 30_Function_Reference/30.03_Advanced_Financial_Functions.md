## 3. Introduction
Why reinvent the wheel? If you need to calculate Straight-Line Depreciation across 120 months based on a Capital Expenditure input, you *could* write a massive Groovy loop. Or, you could just use the native Essbase `@SLN` function which does it instantly.

## 7. The Core Financial Functions

### `@SLN` (Straight-Line Depreciation)
- **Purpose:** Calculates depreciation evenly over the useful life of an asset.
- **Syntax:** `@SLN (cost, salvage, life)`
- **Example:**
  ```essbase
  "Depreciation_Exp" = @SLN("CapEx_Purchases", 0, "Useful_Life_Months");
  ```
- **Architect Note:** The formula must be evaluated across a Time-Series (e.g., across `Jan` to `Dec`). Essbase will automatically spread the cost minus salvage value across the designated life periods.

### `@NPV` (Net Present Value)
- **Purpose:** Calculates the current value of a future series of cash flows, discounted back to today.
- **Syntax:** `@NPV (cashflow_range, discount_rate)`
- **Example:**
  ```essbase
  "Project_NPV" = @NPV("Cash_Flow"->"Jan":"Dec", "Discount_Rate");
  ```
- **Architect Note:** Highly used in the Capital and Projects modules to evaluate the ROI of buying new machinery or launching a new initiative.

### `@TREND`
- **Purpose:** Calculates a statistical trend line (linear regression) based on historical data, and projects it into the future.
- **Syntax:** `@TREND (historical_range, projection_range)`
- **Example:**
  ```essbase
  "Forecast_Sales" = @TREND("Actual_Sales"->"FY23", "Forecast_Sales"->"FY24");
  ```
- **Architect Note:** This is the poor-man's Predictive Planning. It is a fantastic, lightweight way to generate a baseline forecast mathematically before manual user adjustments.

### `@COMPOUND`
- **Purpose:** Calculates compound interest growth.
- **Syntax:** `@COMPOUND (principal, rate)`
- **Example:**
  ```essbase
  "Investment_Value" = @COMPOUND("Initial_Deposit", "Interest_Rate");
  ```

## 18. Architect Notes: Function Performance
Native Essbase financial functions (like `@TREND` and `@SLN`) are incredibly optimized C-code compiled directly into the Essbase engine kernel. 
If you try to recreate Straight-Line depreciation manually using `IF` statements, Cross-Dimensional pointers (`->`), and `@PRIOR` functions, it will run 10x slower than simply using the native `@SLN` function.

**The Golden Rule of Calc Scripts:** Before you write a complex mathematical formula, open the Essbase Technical Reference manual and check if Oracle already built an `@` function for it.

## 25. Interview Questions

### Architect
**Q: A client wants to calculate a 12-month trailing moving average of Revenue. You could write: `(Jan + Feb + Mar...)/12`, but that hardcodes the months and breaks if the user wants an 18-month average. What is the dynamic function approach?**
> A: You should use the `@MOVAVG` (Moving Average) function. The syntax is `@MOVAVG("Revenue", 12)`. This dynamically looks back 12 periods from the current evaluated time period, handles `#Missing` values intelligently based on the skip parameter, and requires zero hardcoding of specific month names.
