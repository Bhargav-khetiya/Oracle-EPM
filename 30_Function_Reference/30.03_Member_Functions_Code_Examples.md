# Member Functions: Exhaustive Code Examples

This document expands on `29.02` by providing working Essbase Calc Script examples for the most critical member functions.

## 1. Hierarchy Functions (The `FIX` Statement)

The most common place for `@RELATIVE` and `@IDESCENDANTS` is defining the scope of the calculation.

```essbase
/* GOOD: Fixing on all Level 0 Entities */
FIX (@RELATIVE("Total_Geography", 0))
    /* Calculation logic here */
ENDFIX

/* BAD: Fixing on descendants includes parents, which forces dynamic calcs to materialize */
FIX (@DESCENDANTS("Total_Geography"))
    /* Warning: This will be extremely slow */
ENDFIX
```

## 2. Boolean Functions (The `IF` Statement)

Boolean functions prevent calculations from running where they shouldn't.

```essbase
/* Scenario: Only apply the tax rate to the "USA" entity, but calculate it for all months */
FIX ("FY24", @RELATIVE("YearTotal", 0))
    "Tax_Expense" (
        IF (@ISMBR("USA"))
            "Tax_Expense" = "Net_Income" * 0.21;
        ELSE
            "Tax_Expense" = "Net_Income" * 0.15; /* Global Rate */
        ENDIF
    )
ENDFIX
```

## 3. Time Series Functions

Calculating variances across time requires strict syntax.

```essbase
/* Scenario: Calculate Month-over-Month Variance */
/* Note: You must FIX on the entire year, but write the formula on the Account */

FIX ("FY24", "Actual")
    "MoM_Variance" (
        /* If we are in Jan, there is no prior month in this year, so check for it */
        IF (NOT @ISMBR("Jan"))
            "MoM_Variance" = "Revenue" - @PRIOR("Revenue", 1, "Period");
        ENDIF
    )
ENDFIX
```

## 4. Allocation Math

The `@ALLOCATE` function is massive and takes multiple arguments.

```essbase
/* Syntax: @ALLOCATE (Amount, AllocationRange, BasisMember, [RoundMode], [ShareMode]) */

/* Scenario: Allocate Corporate IT Rent down to all Departments based on Headcount */
FIX ("Actual", "FY24")
    "IT_Rent_Expense" (
        @ALLOCATE(
            "IT_Rent_Expense"->"Corporate",      /* The Amount to allocate */
            @RELATIVE("Total_Departments", 0), /* Who gets the money */
            "Headcount",                       /* The driver */
            ,                                  /* (Optional) Rounding */
            share                              /* Distribute proportionally */
        );
    )
ENDFIX
```
