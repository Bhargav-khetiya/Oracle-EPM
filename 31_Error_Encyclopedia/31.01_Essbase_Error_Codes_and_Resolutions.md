# 31.01 — Essbase Error Codes and Resolutions: Complete Guide

> **Module:** 31_Error_Encyclopedia | **Topic:** All Essbase Error Codes
> **Audience:** Service Administrator / Developer

---

## 1. WHY — Master Error Codes

When a rule fails at 2 AM during month-end close, the job log shows a cryptic error code. Knowing what each code means — and how to fix it — is the difference between a 5-minute fix and a 3-hour investigation.

---

## 2. ERROR CODE REFERENCE — BY CATEGORY

### Calculation Errors (1200xxx)

| Code | Message | Cause | Fix |
|------|---------|-------|-----|
| 1200480 | Syntax error in formula | Missing `;`, bracket, keyword | Check matching FIX/ENDFIX, IF/ENDIF |
| 1200485 | Unexpected token | Wrong keyword or operator | Fix typo in keyword |
| 1200490 | ENDFIX without matching FIX | Extra ENDFIX | Count FIX/ENDFIX pairs |
| 1200495 | FIX without ENDFIX | Missing ENDFIX | Add missing ENDFIX |
| 1200500 | IF without ENDIF | Missing ENDIF | Add missing ENDIF |
| 1200585 | Unknown member name | Typo or member deleted | Verify member name in dimension editor |
| 1200586 | Duplicate member name | Same name in 2+ dims | Use qualified: `[Dim].[Member]` |
| 1200588 | Member not in dimension | Wrong dimension context | Check rule's Plan Type assignment |
| 1200600 | Unknown function | Function name misspelled | Check @function name spelling |
| 1200700 | Divide by zero | Denominator = 0 or #MISSING | Add `IF(denom <> 0)` check |
| 1200705 | Numeric overflow | Number exceeds limit | Check formula logic |
| 1200800 | Insufficient memory | Cube too large for cache | Optimize block size, increase cache |

### Database Errors (1013xxx)

| Code | Message | Cause | Fix |
|------|---------|-------|-----|
| 1013060 | Execution timeout | Rule exceeded time limit | Optimize rule or increase timeout |
| 1013100 | Cannot lock database | Another operation running | Wait or cancel conflicting job |
| 1013200 | Database restructure needed | Outline changed, not restructured | Refresh/Restructure database |
| 1013300 | Database not found | Wrong cube name | Verify cube name |
| 1013400 | Block limit exceeded | Too many blocks | CLEARBLOCK ALL, fix block explosion |

### Data Load Errors (3303xxx)

| Code | Message | Cause | Fix |
|------|---------|-------|-----|
| 3303001 | Member not found | Data file has invalid member name | Fix member name in source file |
| 3303002 | Invalid data value | Non-numeric in data column | Clean source: remove "N/A", text |
| 3303003 | Duplicate record | Same intersection loaded twice | De-duplicate source file |
| 3303010 | File format error | Wrong delimiter or encoding | Check file format settings |
| 3303020 | Missing required column | Dimension column not mapped | Update import format mapping |

### Security Errors

| Code | Message | Cause | Fix |
|------|---------|-------|-----|
| — | Access denied to member | Dimension security = None | Grant Read/Write access |
| — | Insufficient privileges | Wrong application role | Assign correct role |
| — | Rule launch not permitted | User can't run this rule | Grant rule launch permission |

### Connection/Network Errors

| Code | Message | Cause | Fix |
|------|---------|-------|-----|
| — | Connection refused | Instance down or wrong URL | Check URL, try again |
| — | SSL handshake failed | Certificate issue | Update certificates |
| — | Session expired | Timeout | Re-login |

## 3. ERROR RESOLUTION PATTERNS

### Pattern 1: Member-Related Errors

```
Error: "Unknown member name [Maintainence]"

Step 1: Note the exact member name from the error
Step 2: Open Dimension Editor → Search for "Maintainence"
Step 3: Not found → it's a typo. Search for "Maintenance" → found!
Step 4: Open the rule in Calc Manager
Step 5: Find & Replace: "Maintainence" → "Maintenance"
Step 6: Validate → Deploy → Re-run
```

### Pattern 2: Syntax Errors

```
Error: "Syntax error at line 15"

Step 1: Open rule → go to line 15
Step 2: Count brackets: FIX ( ) pairs, IF/ENDIF pairs
Step 3: Check for missing semicolons at end of formulas
Step 4: Common culprits:
  - Missing ; at end of assignment
  - Missing ENDFIX
  - Missing ENDIF
  - Using = instead of == for comparison
  - Using != instead of <> for "not equal"
Step 5: Fix → Validate → Deploy → Re-run
```

### Pattern 3: Performance/Timeout Errors

```
Error: "Execution timeout"

Step 1: Check rule execution time in Jobs Console
Step 2: Check if rule has a FIX statement → if no, add one
Step 3: Check for cross-dim on sparse dimension → use two-pass
Step 4: Check block count → if exploded, CLEARBLOCK ALL
Step 5: Add SET CALCPARALLEL 4 for multi-threading
Step 6: Add SET LOCKBLOCK ON for block caching
Step 7: Re-run → should be 10-100× faster
```

## 4. SHOW ME — Hotel Pvt Ltd Common Errors

```
Scenario 1: Monthly close rule fails
  Error: 1200585 "Unknown member name [Spa_Reveneu]"
  Fix: Typo → change to "Spa_Revenue"
  Time to fix: 2 minutes

Scenario 2: Data load fails
  Error: 3303001 "Member not found: Mummbai_Hotel"
  Fix: Fix source CSV → "Mumbai_Hotel"
  Time to fix: 5 minutes

Scenario 3: Rule timeout
  Error: 1013060 "Execution timeout after 3600 seconds"
  Cause: No FIX statement, processing all 135 block combinations
  Fix: Add FIX("Budget", "Working", &CurrYear, @RELATIVE("All_Hotels", 0))
  Before: 3600+ seconds. After: 3 seconds
  Time to fix: 10 minutes

Scenario 4: Block explosion
  Error: 1200800 "Insufficient memory"
  Cause: CREATEBLOCKONEQ ON left active, 500,000 blocks created
  Fix: CLEARBLOCK ALL → fix the rule → re-run
  Time to fix: 30 minutes
```

## 5. DIAGNOSTIC DECISION TREE

```
Error in Jobs Console?
├── "Unknown member name" → Fix member spelling (1200585)
├── "Syntax error" → Check brackets/semicolons (1200480)
├── "Divide by zero" → Add IF check (1200700)
├── "Timeout" → Optimize rule (1013060)
├── "Member not found" in data load → Fix source file (3303001)
├── "Access denied" → Check security
├── "Database not found" → Wrong cube name
└── "Connection refused" → Check URL/VPN
```
