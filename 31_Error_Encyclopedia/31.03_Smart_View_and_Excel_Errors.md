# 30.03 Smart View and Excel Errors

> **Module:** 30_Error_Encyclopedia  
> **Topic:** 03 - Local Desktop Failures  
> **Target Audience:** Support Analyst / L1 / L2  

---

## Overview
When the EPM Cloud server is perfectly healthy, users will still call the Helpdesk screaming that "The system is down!" 90% of the time, the issue is entirely isolated to Microsoft Excel and the local COM Add-in on their laptop.

## The Encyclopedia of Desktop Failure

### ERROR: The Smart View Ribbon Completely Disappears
- **What it means:** Microsoft Excel panicked and forcefully disabled the Smart View Add-in.
- **The Cause:** The user ran a massive query that consumed 100% of their laptop's RAM. Excel crashed. When the user reopened Excel, Excel put Smart View in the "Disabled Items" penalty box to protect itself.
- **Resolution:** 
  1. Go to Excel -> File -> Options -> Add-ins.
  2. Change the dropdown at the bottom to **Disabled Items** and click Go.
  3. Select `Oracle Smart View` and click Enable.
  4. Restart Excel.

### ERROR: "Cannot connect to the provider. The connection has timed out."
- **What it means:** Excel sent a request to Oracle Cloud, but Oracle took too long to answer, so Excel gave up.
- **The Cause:** 
  1. The user's home Wi-Fi dropped for 2 seconds.
  2. The user submitted a massive Business Rule from the form, and the Server took 5 minutes to run it. Excel's default local timeout is usually 15 minutes, but IT might have changed it via a registry key.
- **Resolution:** Ask the user if they were on a VPN. Advise them to wait 5 minutes and try again. If it is a Business Rule timeout, the Architect must optimize the Essbase script.

### ERROR: "Grid is not well formed" or "Cannot submit data to a dynamic calc member"
- **What it means:** The user is trying to push data into a read-only cell in an Ad-Hoc grid.
- **The Cause:** The user built a free-form grid. They typed a number into `Net_Income` (which is a Dynamic Calc parent). You cannot write data to a formula.
- **Resolution:** Instruct the user to change their Smart View Options -> Formatting to `Cell Styles` so the grid visually paints the Dynamic Calc cells gray. 

### ERROR: "Invalid Session" or "Session Expired"
- **What it means:** The SSO token connecting Excel to Oracle Cloud has died.
- **The Cause:** The user left Excel open overnight. The Oracle server automatically terminates inactive sessions after 60-120 minutes for security.
- **Resolution:** Click the Disconnect button on the Smart View ribbon, then click Connect and log in again.

### ERROR: `HsGetValue` Returns `#No Connection`
- **What it means:** The physical formula in the Excel cell (e.g., `=HsGetValue("Connection1", "Account#Sales")`) cannot find the connection name.
- **The Cause:** The user emailed the spreadsheet to a coworker. The coworker's laptop has their Smart View connection named `EPBCS_Prod`, but the original user named it `Connection1`. The names must match exactly.
- **Resolution:** The coworker must open the Smart View Panel, create a Private Connection, and name it exactly `Connection1`, or they must use the Smart View "Replace Connection" utility.
