# 🏠 33.01 — Home Page: Complete Encyclopedia

> **Source:** Oracle® Fusion Cloud EPM Administering Planning (Aug 2026), Chapter 2
> **Navigation:** This IS the home page — it's what you see after logging in
> **Audience:** All roles (what changes is WHICH cards appear)

---

## 1. WHY — What Problem Does the Home Page Solve?

**The problem:** EPBCS has 100s of screens, admin functions, reports, forms, and rules. Without a central launchpad, every user would need to memorize deep URLs or multi-step navigation paths.

**The solution:** The Home Page is a **personalized launchpad** — a card-based interface that shows each user ONLY the areas they're permitted to access, in a way that can be customized by the Service Administrator using Navigation Flows.

**Consultant Use Case:** When you join a new client project, the Home Page immediately tells you:
- What modules are enabled (FinPlan, Workforce, Capital cards = EPBCS)
- What the admin has customized (custom cards, branding, clusters)
- What your role has access to (missing cards = no permission)

---

## 2. WHAT — Plain English Definition

The Home Page is the **first screen** you see after logging in to EPBCS. It contains:
1. A **Global Header** (top bar) — navigation icons + user menu
2. A **Work Area** — grid of cards/icons linking to functional areas
3. An **Announcements Panel** (right side) — personal activity feed
4. **Infolet dots** (optional) — swipeable dashboard summaries

The appearance is called **Redwood Experience** (Oracle's modern UI framework). You can switch between:
- **Oracle theme** (default light)
- **Custom Light**
- **Custom Dark**

## 5. WORK AREA — Default Cards (EPBCS OOTB)

The Work Area shows **cards** (icon tiles). In a default EPBCS installation, you see:

### Standard EPBCS Cards

| Card Name | Click Destination | Who Sees It |
|-----------|------------------|-------------|
| **Application** | Application overview, cubes, dimensions | Service Admin only |
| **Financials** | FinPlan module forms and dashboards | Users with FinPlan access |
| **Workforce** | Workforce planning forms | Users with Workforce access |
| **Capital** | Capital asset planning | Users with Capital access |
| **Data** | All forms and composite forms | All users with form permission |
| **Dashboards** | All dashboards | Users with dashboard permission |
| **Rules** | Business rules listing | Users with rule access |
| **Reports** | Financial reports | Users with report access |
| **Approvals** | Approval workflow actions | Approvers/Reviewers |
| **Task Lists** | Task list assignments | Task List assignees |
| **Tools** | Admin tools cluster | Service Admins, Power Users |
| **Documents** | Document library | All users |
| **Academy** | Oracle training links and videos | All users |

### The Three-Dots Indicator
When a card label shows **"..."** (three dots above the icon label), it means the card opens a **cluster** — a group of sub-cards. For example, "Tools" might open: Navigation Flows, Access Control, Artifact Labels, etc.

| Panel Section | Purpose | How It Works |
|--------------|---------|-------------|
| **Profile Photo** | Shows user identity | Set via Tools → User Preferences → Profile Picture |
| **Activity** | Shows announcements + open tasks | Flip between views by clicking |
| **Announcements** | Admin-posted messages | Service Admin sets in Application Settings → Announcements |
| **Tasks Due Today** | Task lists with today's due dates | Linked to Task Lists module |
| **Recent** | Last 15 forms/dashboards visited | Auto-populated; click = opens in secondary window |
| **Favorites** | Starred items from Recent list | Click ⭐ in Recent to add to Favorites |
| **Tour** | Video about key features | Click the Tour button; launches Oracle training video |

**Key Behavior Notes:**
- Recent items: Max 15. When full, oldest drops off.
- Favorites: Persist across sessions (Recent list resets if browser cleared)
- Clicking any Recent/Favorite item opens it in a **secondary window** (not replacing the Home page)

## 7. INFOLET NAVIGATION

> ⚠️ **IMPORTANT:** As of October 2025, Oracle has de-supported creating NEW infolets. Existing infolets still work, but no new ones can be created.

If the application has infolets configured, you'll see:
- **Dots** below the global header (like slideshow navigation dots)
- **◄ ► arrows** on the left/right sides of the Home page
- Clicking a dot or arrow **swipes to an Infolet page** (mini-dashboard overview)

## 9. NAVIGATION FLOW CUSTOMIZATION — How Admins Control the Home Page

The cards on the Home page are controlled by **Navigation Flows**. The Service Administrator can:

| Action | Result |
|--------|--------|
| **Hide a card** | Card disappears for that user group |
| **Rename a card** | Card shows custom label (e.g., "Planning" instead of "Financials") |
| **Change card icon** | Custom icon from Oracle's icon library |
| **Add a card cluster** | Group multiple cards under one "parent" icon |
| **Add a URL card** | Embed any HTTPS URL (e.g., Oracle Analytics Cloud dashboard) |
| **Reorder cards** | Up/down arrows in Navigation Flow designer |

**What CANNOT be hidden (mandatory items):**
- The Application cluster and Settings icon inside it
- The Tools cluster and: Access Control, Navigation Flows, Daily Maintenance, Migration

## 11. DO's AND DON'Ts

### ✅ DO
- **DO** set a custom background image for client branding — creates professional first impression
- **DO** use the ⭐ Favorites feature to pin forms you use daily
- **DO** use the Navigation Flow Switcher to test what different user roles see
- **DO** set a profile picture (Tools → User Preferences) for team recognition

### ❌ DON'T
- **DON'T** hide the Tools cluster for Service Admins — they need access to Navigation Flows, Migration
- **DON'T** create new Infolets — Oracle has de-supported this (Oct 2025)
- **DON'T** use Dashboard 1.0 for new work — de-supported same date
- **DON'T** confuse Recent (auto-tracked, max 15) with Favorites (manually starred, persist)

## 12. COMMON MISTAKES & FIXES

| Problem | Root Cause | Fix |
|---------|-----------|-----|
| Card is missing from Home page | Navigation flow has it hidden | Tools → Navigation Flows → edit flow → set Visible = checked |
| User sees wrong cards | Wrong navigation flow assigned to their group | Tools → Navigation Flows → check "Assign To" group assignment |
| Announcements not showing | Not configured | Application → Settings → Announcements → add announcement |
| Background image not loading | File too large or wrong format | Use JPG/PNG, keep under 2MB |
| Tour video won't play | Firewall blocks Oracle URLs | Open in separate browser or whitelist oracle.com CDN |

## 13. INTERVIEW QUESTIONS

### Beginner
**Q: A new user logs in but can't see the Forms icon on the Home page. What are the two possible causes?**
> **A:** (1) The user's group doesn't have the Forms card visible in their Navigation Flow — the Service Admin needs to check Tools → Navigation Flows and ensure the "Data" card is visible for that group. (2) The user has not been granted permission to any forms — even if the card is visible, clicking it would show an empty list.

### Intermediate
**Q: Your client wants the Home page to say "Hotel Budget System" instead of showing the Oracle EPM name, and use their company logo. How do you set this up?**
> **A:** Go to Home → Application → Settings → Appearance tab. (1) Upload the company logo under "Logo Image." (2) The "Display Business Process Name" option controls whether the EPM app name shows — setting it to No hides it. Note: you can't set a completely custom text name here; hiding/showing is the control. For a "Hotel Budget System" title, you'd need to use a custom card label in the Navigation Flow or use a custom background image with the text embedded.

### Architect
**Q: You have 5 user groups at Hotel Pvt Ltd: Mumbai Planners, Delhi Planners, HR, Finance Controllers, and Service Admins. Each group should see a different Home page. How do you design this?**
> **A:** Create 5 custom navigation flows (duplicate the Default for each). Assign each navigation flow to its corresponding group (Tools → Navigation Flows → Assign To). Configure each navigation flow to show only the relevant cards:
> - Mumbai/Delhi Planners: Forms specific to their entity, Approvals, Task Lists
> - HR: Workforce forms only
> - Finance Controllers: All finance forms + Reports + Approvals
> - Service Admins: Everything including Application, Tools
> Remember: Only ONE navigation flow per category (global/role/group) can be active at a time. Each group gets their own navigation flow in the "group" category.
