Oracle Cloud EPM Ecosystem & Process Navigator

OCI Gen 2 Enterprise SaaS

Planning (PBCS / EPBCS)

Hybrid BSO + ASO

Enterprise financial modeling, driver forecasting, Workforce, Capital, and Project planning.

  • Underlying Engine: Level 0 BSO leaf storage + ASO dynamic vector reporting.
  • Write-Back: Full in-place grid spread, Groovy event interceptors, Smart Push.
  • FTE Review Trap: Never store summary parent blocks in modern Cloud Planning.

Financial Consolidation & Close (FCCS)

Consol + Rates Cubes

Statutory multi-GAAP financial close, currency translation, intercompany eliminations.

  • Underlying Engine: Pre-seeded consolidation rules; strict dimensional framework.
  • Translation: CTA (Cumulative Translation Adjustment) & Net Income to Retained Earnings.
  • FTE Review Trap: Custom dimension addition is restricted to preserve out-of-the-box calculations.

Account Reconciliation (ARCS)

Relational + Matching

Automated high-volume transaction matching and balance sheet account reconciliation.

  • Underlying Engine: High-throughput relational matching engine (millions of rows).
  • Compliance: SOX 404 audit compliance, balance sheet variance analysis.
  • FTE Review Trap: ARCS does not use an Essbase cube; it uses relational storage.

Enterprise Data Management (EDMCS)

Graph Master Data

Master data governance, chart of accounts maintenance, cross-system dimension mapping.

  • Underlying Engine: Node-based graph repository; automated change request workflow.
  • Syndication: Exports validated hierarchies to ERP, Planning, FCCS, and data warehouses.
  • FTE Review Trap: EDMCS enforces structural integrity before metadata touches target cubes.
