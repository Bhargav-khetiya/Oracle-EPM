🎯 Solve vs. Evaluation Order

Classic Trap

Never confuse UI display precedence with Essbase math priority.

Evaluation Order (UI Layer)

Controls HOW IT LOOKS. Resolves Smart List vs Currency collisions (fixes $1.00 bug).

Solve Order (Essbase Kernel)

Controls WHAT VALUE IT HAS. Integer 0–127. Highest calculates LAST and wins at collision.

✓ Golden Rule: Accounts (10) > Time (0)
