# Oracle EPM Learning Roadmap

Progress from mental models to configuration. Pace depends on hands-on practice and the service/release being studied.

1. **Business and vocabulary.** Learn actuals, budgets, forecasts, scenarios, versions, periods, dimensions, members, applications, cubes, and cells. Start with [Planning modules](EPBCS_Modules_and_Business_Processes/00_INDEX.md). Explain an illustrative cell through its dimensional coordinates.
2. **Metadata and application shape.** Learn hierarchies, member properties, data types, and sparse/dense concepts where applicable. Read [Dimensions](Dimension_Properties/00_INDEX.md) and [Essbase](Essbase_Internal_Architecture/00_INDEX.md). Draw an illustrative cube; do not infer a client design.
3. **Data entry and experience.** Learn forms, prompts, Smart Lists, valid intersections, cell-level security, and Smart View. Read [Forms](Form_Properties/00_INDEX.md), [Smart Lists](Smart_Lists/00_INDEX.md), [UI](02_User_Interface_and_Navigation/00_INDEX.md), and [Smart View](Smart_View_and_Ad_Hoc/00_INDEX.md). Practice prerequisites → action → result → validation → likely failure.
4. **Workflow and security.** Distinguish tasks, approval states, artifact access, and data access. Read [Security](01_Security_and_Access/00_INDEX.md) and [Workflow](03_Workflow_and_Task_Management/00_INDEX.md). Confirm roles from project evidence.
5. **Calculations.** Learn rule purpose, inputs, dimensional scope, prompts, calculation order, and Groovy where applicable. Read [Calculation Manager](Calc%20Manager/Calculations_and_Allocations/00_INDEX.md). Check each function against the right Oracle source; define expected output and edge cases first.
6. **Data movement and analysis.** Trace source → mapping/transformation → target → reconciliation. Read [Data Integration](Data_Integration/00_INDEX.md), [Data maps](Data_Maps_and_Exchange/00_INDEX.md), and [Smart View](Smart_View_and_Ad_Hoc/00_INDEX.md). Label example systems illustrative.
7. **Operations and lifecycle.** Learn EPM Automate, maintenance, snapshots, migration, change control, validation, and recovery. Read [EPM Automate](EPM_Automate/00_INDEX.md), [Administration](04_System_Administration/00_INDEX.md), and [Lifecycle](05_Application_Creation_and_Lifecycle_Management/00_MASTER_INDEX.md).
8. **Review and teach-back.** Use the [review bible](Techno_Functional_Consultant_Review_Bible/00_INDEX.md) as questions, not proof. State purpose, feature/service, project evidence, Oracle source, validation, tradeoffs, risks, and unknowns.

After each topic, answer recall questions without notes; revisit gaps tomorrow and later in the week. Explain the concept aloud, then check sources and correct yourself. Reading alone does not guarantee mastery.
