# Oracle EPM Cloud Learning Library

This folder is a learning and working reference built from notes, examples, indexes, and source extracts. Follow the [learning roadmap](LEARNING_ROADMAP.md), then use the [master index](00_MASTER_BIBLE_INDEX.md) to enter a topic. Read its folder index before detailed notes and follow source links.

> **Scope:** Folder names show what this library studies. They do not prove that a product, feature, integration, role, or design is configured in a client environment. Treat project facts as unconfirmed until supported by approved evidence. Verify product behavior against Oracle documentation for the applicable service and release.

## Suggested path

**Beginner:** business purpose and EPM vocabulary → dimensions and members → forms and Smart Lists → workflow and approvals → security.

**Practitioner:** calculations and Calculation Manager → data maps and integrations → Smart View → EPM Automate → administration and lifecycle.

**Reviewer:** trace a requirement through metadata, security, calculations, data movement, validation, migration, and support. Separate Oracle behavior from project decisions.

## Evidence labels

**Oracle documented** = linked source supports it; check product/release. **Project evidence** = approved artifact. **Recommendation** = practice, not requirement. **Illustrative** = teaching example, not client fact. **Unverified/open** = needs source, owner, or test.

Before using commands, security designs, or migration procedures in production, check prerequisites, access, impact, approval, and recovery. Destructive steps require change control.
