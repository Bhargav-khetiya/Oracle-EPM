# SECTION 1: WHY EPM IS A GOLD-MINE CAREER

---

## The Market Reality

```
DEMAND vs SUPPLY — Oracle EPM Cloud

  ┌─────────────────────────────────────────────┐
  │ DEMAND: Thousands of companies migrating    │
  │         from Hyperion On-Premise to Cloud   │
  │                                             │
  │ SUPPLY: Very few consultants know EPBCS     │
  │         (most still know only Hyperion)      │
  │                                             │
  │ RESULT: High salaries, low competition      │
  │         Companies CANNOT find enough people │
  └─────────────────────────────────────────────┘

Why This Gap Exists:
  - Oracle forced migration to Cloud (Hyperion EOL approaching)
  - 10,000+ Hyperion customers need EPBCS consultants
  - University programs DON'T teach EPM (it's niche)
  - Learning curve is steep → most quit before mastering it
  - YOU are reading this guide → you WON'T quit
```

# SECTION 4: JOB ROLES IN DETAIL

---

## Role 1: Junior EPM Consultant / Analyst

```
TYPICAL DAY:
  09:00 — Load test data into EPBCS using flat files
  10:00 — Test forms created by senior consultant
  11:00 — Document test cases and results
  12:00 — Lunch
  13:00 — Attend design workshop (take notes)
  14:00 — Help with metadata loads (dimension members)
  15:00 — Fix data mapping errors in Data Integration
  16:00 — Update project tracker / JIRA tickets
  17:00 — Study calc scripts (self-learning time)

MUST-HAVE SKILLS:
  ✅ Excel (VLOOKUP, Pivot Tables, Macros)
  ✅ Basic SQL (SELECT, JOIN, WHERE)
  ✅ EPM Cloud navigation (forms, dimensions, Smart View)
  ✅ Data loading concepts
  ✅ Strong documentation skills
  ✅ Basic accounting (P&L, Balance Sheet)

NICE-TO-HAVE:
  ○ Smart View ad hoc analysis
  ○ Basic calc script reading
  ○ Oracle Cloud account provisioning
```

## Role 2: EPM Consultant

```
TYPICAL DAY:
  09:00 — Design and build forms for the Revenue module
  10:30 — Write calc scripts for driver-based planning
  11:30 — Client call — demo the forms, gather feedback
  12:30 — Lunch
  13:30 — Set up Data Integration pipeline (flat file → EPBCS)
  15:00 — Configure substitution variables and sub var rules
  16:00 — Debug a form that's showing wrong data
  17:00 — Mentor junior consultant on Smart View

MUST-HAVE SKILLS:
  ✅ Everything from Level 1
  ✅ Dimension design (Account, Entity, Period, Custom)
  ✅ Form creation (all tabs: Properties, Layout, Business Rules)
  ✅ Calc script writing (FIX, IF, member formulas)
  ✅ Smart Push and Data Maps
  ✅ Smart View (ad hoc, HsGetValue, basic VBA)
  ✅ Data Integration setup
  ✅ Runtime Prompts and Substitution Variables
  ✅ Valid Intersections
  ✅ Security basics (roles, access control)
```

## Role 3: Senior EPM Consultant

```
TYPICAL DAY:
  09:00 — Lead design workshop with client CFO team
  10:30 — Review calc scripts written by team (code review)
  11:30 — Design complex allocation business rule
  12:30 — Lunch
  13:30 — Write Groovy script for dynamic form validation
  15:00 — Performance-tune a slow calc (FIX optimization)
  16:00 — Client steering committee — present project status
  17:00 — Architecture review for Phase 2 go-live

ADDITIONAL SKILLS:
  ✅ Everything from Level 2
  ✅ Groovy scripting (DataGridBuilder, REST calls)
  ✅ Complex calc scripts (allocation, currency, cross-dim)
  ✅ Performance optimization (block size, dense/sparse)
  ✅ Multi-cube architecture (Plan Type Map, @XREF)

  ✅ Client-facing skills (workshops, demos, escalations)
  ✅ Mentoring junior team members
  ✅ OOTB module configuration (Financials, Workforce)
```

TYPICAL DAY:
  09:00 — Architecture review with client CIO/CTO

  11:30 — Define integration strategy (ERP → EPM → BI)

# SECTION 9: FREELANCE AND INDEPENDENT CONSULTING

---

## When to Go Independent

```
GO INDEPENDENT WHEN:
  ✅ You have 6+ years of experience
  ✅ You have a strong network (past clients, recruiters)
  ✅ You can handle the sales cycle (proposals, SOWs)
  ✅ You're comfortable with income variability
  ✅ You've built a personal brand (LinkedIn, conferences)

DON'T GO INDEPENDENT IF:
  ❌ You have less than 4 years of experience
  ❌ You rely on your employer for learning opportunities
  ❌ You haven't built any professional network
  ❌ You can't handle 1-2 months without income between contracts
```

## Freelance Rate Calculation

```
FORMULA:
  Target Annual Income ÷ Billable Hours = Hourly Rate

  Example (India, Senior Consultant):
    Target: ₹30 LPA (₹30,00,000)
    Billable hours: 1,600/year (80% of 2,000 — account for gaps)
    Rate: ₹30,00,000 ÷ 1,600 = ₹1,875/hr ≈ $22/hr

  Example (USA, Architect):
    Target: $250,000
    Billable hours: 1,700/year
    Rate: $250,000 ÷ 1,700 = $147/hr → bill at $150/hr

  ADD 20% for taxes, insurance, equipment:
    India: ₹1,875 × 1.2 = ₹2,250/hr ≈ $27/hr
    USA: $150 × 1.2 = $180/hr
```

# SECTION 10: COMMON CAREER MISTAKES

---

| Mistake | Why It Hurts | What To Do Instead |
|---------|-------------|-------------------|
| Staying in testing/support too long | You become pigeonholed as "the testing guy" | Push for design tasks by Week 6 of any project |
| Ignoring finance knowledge | 40% of interviews test finance, not technology | Study Module 01-02 before ANY technical module |
| Not learning Groovy | Groovy is the #1 differentiator; most don't know it | Invest 4 weeks in Module 09 — it's your salary multiplier |
| Only knowing one module | "I only do Planning forms" limits your career | Learn at least 3 modules deeply (Planning + Calc + DI) |
| Not getting certified | Recruiters filter by certification | Get 1Z0-1086 within your first 2 years |
| Staying at the same company for 5+ years | EPM salary grows fastest through job changes | Move every 2-3 years until you hit Architect level |
| Not networking | Most EPM jobs come through referrals | Attend ODTUG Kscope, Oracle CloudWorld, local meetups |
| Ignoring soft skills | Architects must run workshops, not just code | Practice presenting technical concepts to non-technical people |
