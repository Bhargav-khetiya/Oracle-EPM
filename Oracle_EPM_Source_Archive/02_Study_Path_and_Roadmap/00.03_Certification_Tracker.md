### Domain 1 Practice Questions

**Q1: You are creating a new EPBCS application. The client needs Workforce Planning capabilities. Which application type should you select—**
> A) Standard  
> B) Enterprise  
> C) Free Form  
> **Answer: B) Enterprise** — Only Enterprise applications support OOTB modules like Financials, Workforce, Capital, and Projects. Standard applications only support custom plan types.

**Q2: How many BSO plan types can an Enterprise application have—**
> A) 2  
> B) 3  
> C) 4  
> D) 6  
> **Answer: D) 6** — An Enterprise application supports up to 6 BSO plan types and 1 ASO plan type (Reporting).

**Q3: Which substitution variable is commonly used to represent the current forecasting month—**
> A) &CurYear  
> B) &CurMonth  
> C) &CurScenario  
> D) &FcstStart  
> **Answer: B) &CurMonth** — While &FcstStart is also used, &CurMonth is the most standard substitution variable for the current month in EPBCS implementations.

**Q4: In an EPBCS application, which of the following are standard dimensions— (Choose THREE)**
> ☑ A) Account  
> ☑ B) Entity  
> ☐ C) Product  
> ☑ D) Scenario  
> ☐ E) Department  
> **Answer: A, B, D** — Account, Entity, Period, Year, Scenario, Version, and Currency are standard. Product and Department are custom dimensions.

**Q5: What happens if you change the Fiscal Year Start Month after data has been loaded—**
> **Answer:** You should NEVER change the fiscal year start month after the application has data. It will cause the calendar dimension to rebuild, potentially misaligning all existing data with the wrong periods. This is a destructive operation that requires a fresh application build or very careful data migration.

### Domain 2 Practice Questions

**Q6: An account member called "Cash_Balance" should show the last month's value at the quarter level (not the sum). Which Time Balance property should you use—**
> A) Flow  
> B) First  
> C) Balance (Ending)  
> D) Average  
> **Answer: C) Balance (Ending)** — Balance/Ending Time Balance pulls the value from the LAST child period. Q1 Cash = March Cash (not Jan+Feb+Mar).

**Q7: Which data storage property should you assign to a member whose value is calculated using a formula and should NOT be stored in the database—**
> A) Store  
> B) Dynamic Calc  
> C) Shared  
> D) Label Only  
> **Answer: B) Dynamic Calc** — Dynamic Calc members are calculated on-the-fly when retrieved and not stored in the database, saving storage space.

**Q8: What is a Shared Member—**
> **Answer:** A Shared Member is a member that appears in multiple locations in the hierarchy but stores data in only ONE location (the original/primary member). It allows the same member to roll up into multiple parents (alternate hierarchies) without duplicating data. The shared member uses the `~` (Ignore) consolidation operator to prevent double-counting in the primary rollup.

**Q9: The Account dimension is typically classified as which storage type—**
> A) Dense  
> B) Sparse  
> **Answer: A) Dense** — Account and Period are almost always Dense because every entity typically has values for every account and every period. Making Account Dense creates the block, and making Entity Sparse creates the index.

**Q10: What happens if you set a parent member's Consolidation Operator to `~` (Tilde)—**
> **Answer:** The tilde operator means "Ignore during consolidation." The parent will NOT include this child's value when aggregating. This is used for: statistical accounts (headcount that shouldn't add to total expenses), driver members (Occupancy Rate that shouldn't add to Revenue), and informational members.

### Domain 3 Practice Questions

**Q11: Which form tab do you use to specify that a business rule should run automatically when the user opens the form—**
> A) Properties  
> B) Layout  
> C) Business Rules  
> D) Other Options  
> **Answer: C) Business Rules** — On the Business Rules tab, you toggle the "Run on Load" checkbox for the desired rule.

**Q12: A user wants to see data from Plan1 (Revenue) and Plan2 (Workforce) on the same form. What form type should you use—**
> A) Regular Form  
> B) Composite Form  
> C) Free Form  
> D) Dashboard  
> **Answer: B) Composite Form** — Composite Forms can display grids from different plan types (cubes) on the same screen.

**Q13: What is the correct syntax for a Runtime Prompt variable in a calc script—**
> A) [RTP_Entity]  
> B) {RTP_Entity}  
> C) &RTP_Entity  
> D) $RTP_Entity$  
> **Answer: C) &RTP_Entity** — Runtime Prompt variables in calc scripts use the substitution variable syntax with the & prefix, but they are SPECIFICALLY defined as RTPs in the Calc Manager variable screen.

### Domain 4 Practice Questions

**Q14: What does the FIX statement do in a calc script—**
> **Answer:** FIX narrows the scope of calculation to specific members. Without FIX, the calculation runs on the ENTIRE database (all intersections), which is slow and often incorrect. FIX is the #1 performance optimization technique.

**Q15: What is the difference between AGG and CALC DIM—**
> AGG: Aggregates data UP the hierarchy using consolidation operators (+, -, etc.) for ALL sparse dimensions at once.  
> CALC DIM: Aggregates only ONE specific dimension, and also executes member formulas. CALC DIM is more targeted.

**Q16: You need to copy data from Budget to Forecast. Which command do you use—**
> A) DATACOPY  
> B) DATAEXPORT  
> C) CLEARDATA  
> D) FIX  
> **Answer: A) DATACOPY** — `DATACOPY Budget TO Forecast;` copies data between members of the same or different dimensions.

## Domain 5: Security & Administration (10-15%)

### Domain 5 Practice Questions

**Q17: Name the predefined roles in EPBCS.**
> Service Administrator, Power User, Planner, Viewer, Ad Hoc User. Service Administrator has full access. Power User can create forms and rules. Planner can enter data on assigned forms. Viewer can only view (read-only).

**Q18: What is LCM (Life Cycle Management)—**
> LCM is the mechanism to migrate artifacts (dimensions, forms, rules, data) between environments (Dev → Test → Prod). You create a "snapshot" of selected artifacts, download it, and import it into the target environment.

## Domain 6: Data Integration & Migration (10-15%)

### Domain 6 Practice Questions

**Q19: What is the difference between Data Management and Data Integration—**
> Data Management (DM/FDMEE): The legacy/older approach with mapping tables, validation scripts, and target application. Still used but being deprecated.  
> Data Integration (DI): The newer, simplified approach with a guided wizard. Supports direct connections to Oracle ERP, files, and on-premise databases via the Integration Agent.

**Q20: What is the EPM Integration Agent—**
> A lightweight Java agent installed on-premise (behind the corporate firewall) that creates a secure tunnel between on-premise data sources (SQL Server, Oracle DB, flat files) and Oracle EPM Cloud. It eliminates the need to open inbound firewall ports.

# SECTION 6: EXAM DAY STRATEGY

---

```
BEFORE THE EXAM:
  □ Test your webcam and microphone (online proctored)
  □ Clean your desk (no notes, no phone)
  □ Ensure stable internet connection
  □ Have your ID ready (passport or driving license)
  □ Close all other applications on your computer
  □ Use the bathroom before starting (90 min with no breaks)

DURING THE EXAM:
  □ Read EVERY word in the question carefully
  □ Watch for "Choose TWO" — many people miss this
  □ Eliminate obviously wrong answers first
  □ If unsure, mark the question and come back later
  □ NEVER leave a question blank (no negative marking)
  □ Time budget: ~90 seconds per question
  □ First pass: Answer confident questions (40 min)
  □ Second pass: Review marked questions (30 min)
  □ Third pass: Final review (20 min)

COMMON TRAPS:
  □ "Which is NOT true— — read carefully for negatives
  □ "Select ALL that apply" — partial credit is usually 0
  □ Distractors that are ALMOST correct but technically wrong
  □ Mixing up BSO and ASO capabilities
  □ Confusing Data Management and Data Integration
```
