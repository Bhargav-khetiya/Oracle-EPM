# HOW TO USE THIS TRACKER

---

## Self-Assessment Rating Scale

```
For each checkpoint question, rate yourself honestly:

  ⬜ LEVEL 0 — "I have no idea what this means"
      → Action: Read the referenced file from scratch
  
  🟥 LEVEL 1 — "I've heard of this but can't explain it"
      → Action: Re-read the file, take notes in YOUR words
  
  🟧 LEVEL 2 — "I can explain it but not to a 5-year-old"
      → Action: Practice explaining aloud without notes
  
  🟨 LEVEL 3 — "I can explain it simply AND give an example"
      → Action: Ready! But do the practice questions
  
  🟩 LEVEL 4 — "I can answer ANY interview question on this topic"
      → Action: Move on. Come back for review before interviews.

TARGET: Every topic at Level 3 or higher = INTERVIEW READY
```

## How to Track Progress

```
WEEKLY ROUTINE:
  Monday:    Start new module (read files)
  Wednesday: Re-read and take notes
  Friday:    Self-test using this tracker
  Weekend:   Mark your levels, identify gaps
  Next Week: Focus on gaps + start next module
```
