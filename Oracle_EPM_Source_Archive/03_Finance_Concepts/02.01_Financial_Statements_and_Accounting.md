# SECTION 1: WHY EPM CONSULTANTS MUST KNOW FINANCE

---

```
SCENARIO: Your first design workshop.

  Client FP&A Manager: "We need Revenue to be Non-Expense 
  with Time Balance Flow, and Cash should be Balance Last 
  with Skip None."
  
  You (without finance knowledge):
    "...what does any of that mean?"
    
  You (with finance knowledge):
    "Understood. Revenue sums across months (Flow), and we show
    favorable variance when Revenue goes UP (Non-Expense). Cash 
    is a Balance Sheet item — Q1 Cash = March Cash, not the sum
    of all 3 months (Balance Last). Skip None means we want to 
    see zero values, not #Missing. I'll also set Account Type
    to Revenue and Variance Reporting to Non-Expense."

  40% of EPM interviews test FINANCE, not technology.
  You WILL fail if you skip this module.
```

# SECTION 2: THE 3 FINANCIAL STATEMENTS

---

```
THE 3 FINANCIAL STATEMENTS — "The Financial Trinity"

  Every company in the world produces these 3 reports:

  ┌────────────────────────────────────────────────────────┐
  │ 1. INCOME STATEMENT (P&L)                              │
  │    "How much did we earn and spend?"                    │
  │    Revenue - Expenses = Net Income                      │
  │    PERIOD: Over a period of time (Jan to Dec)           │
  │    EPM: Time Balance = FLOW (sum across months)         │
  │    Analogy: Your monthly bank statement                 │
  ├────────────────────────────────────────────────────────┤
  │ 2. BALANCE SHEET (BS)                                   │
  │    "What do we own and owe RIGHT NOW?"                  │
  │    Assets = Liabilities + Equity                        │
  │    POINT: At a specific moment (Dec 31, 2026)           │
  │    EPM: Time Balance = BALANCE (last month only)        │
  │    Analogy: Your net worth TODAY                        │
  ├────────────────────────────────────────────────────────┤
  │ 3. CASH FLOW STATEMENT (CF)                             │
  │    "Where did the cash actually go?"                    │
  │    Cash In - Cash Out = Net Change in Cash              │
  │    PERIOD: Over a period of time                        │
  │    EPM: Time Balance = FLOW (sum across months)         │
  │    Analogy: Your bank account movements                 │
  └────────────────────────────────────────────────────────┘

  KEY INSIGHT FOR EPM:
  ┌────────────────────────────────────────────────────────┐
  │ P&L accounts = Time Balance: FLOW                      │
  │ Balance Sheet accounts = Time Balance: BALANCE (Last)   │
  │                                                        │
  │ Getting this WRONG = your quarterly reports are WRONG.  │
  │ Revenue in Q1 should = Jan + Feb + Mar (FLOW).         │
  │ Cash in Q1 should = March value only (BALANCE).        │
  └────────────────────────────────────────────────────────┘
```

# SECTION 3: INCOME STATEMENT (P&L)

---

## What Is a P&L?

```
PLAIN ENGLISH:
  The P&L (Profit & Loss) answers ONE question:
  "Did we make money or lose money this period?"

  Revenue (what we earned)
  - Expenses (what we spent)
  = Net Income (what's left — profit or loss)
```

## P&L Structure — Line by Line

```
INCOME STATEMENT (P&L) — STANDARD STRUCTURE

  ┌────────────────────────────────────────────────────┐
  │                                                    │
  │  REVENUE (Top Line)                                │
  │  ├── Room Revenue         ← Rooms × Occ × ADR     │
  │  ├── F&B Revenue          ← Restaurant + Bar       │
  │  ├── Spa Revenue                                   │
  │  ├── Conference Revenue                            │
  │  └── Other Revenue        ← Parking, Laundry       │
  │  ────────────────────────────────────────────────── │
  │  = TOTAL REVENUE                                   │
  │                                                    │
  │  COST OF GOODS SOLD (COGS)                         │
  │  ├── Food Cost            ← Raw materials          │
  │  ├── Beverage Cost                                 │
  │  └── Amenity Cost         ← Toiletries, linen      │
  │  ────────────────────────────────────────────────── │
  │  = GROSS PROFIT (Revenue - COGS)                   │
  │                                                    │
  │  OPERATING EXPENSES (OpEx)                         │
  │  ├── Salaries & Wages                              │
  │  ├── Rent / Lease                                  │
  │  ├── Utilities            ← Electricity, Water     │
  │  ├── Marketing & Sales                             │
  │  ├── Maintenance                                   │
  │  ├── Insurance                                     │
  │  ├── Technology / IT                               │
  │  └── Travel & Training                             │
  │  ────────────────────────────────────────────────── │
  │  = EBITDA (Gross Profit - OpEx)                    │
  │    "Earnings Before Interest, Tax, Depreciation,   │
  │     and Amortization"                              │
  │                                                    │
  │  ├── Depreciation         ← Building, Equipment    │
  │  ├── Amortization         ← Intangible assets      │
  │  ────────────────────────────────────────────────── │
  │  = EBIT (Operating Income)                         │
  │                                                    │
  │  ├── Interest Expense     ← Loan interest          │
  │  ├── Interest Income      ← Bank deposits          │
  │  ────────────────────────────────────────────────── │
  │  = EBT (Earnings Before Tax)                       │
  │                                                    │
  │  ├── Income Tax           ← Corporate tax          │
  │  ────────────────────────────────────────────────── │
  │  = NET INCOME (Bottom Line)                        │
  │    "The final profit after ALL costs"              │
  │                                                    │
  └────────────────────────────────────────────────────┘

EPM DESIGN IMPLICATIONS:
  Revenue accounts:   Account Type = Revenue, Variance = Non-Expense
  Expense accounts:   Account Type = Expense, Variance = Expense
  ALL P&L accounts:   Time Balance = Flow
  EBITDA, Net Income: Data Storage = Dynamic Calc (calculated members)
```

## P&L KPIs — What the CFO Cares About

```
KEY P&L METRICS:

  GROSS MARGIN %:
    = Gross Profit / Revenue × 100
    Hotel example: ₹18Cr / ₹26Cr × 100 = 69.2%
    "For every ₹100 of revenue, ₹69.20 remains after direct costs"

  EBITDA MARGIN %:
    = EBITDA / Revenue × 100  
    Hotel example: ₹7.8Cr / ₹26Cr × 100 = 30%
    "For every ₹100 of revenue, ₹30 remains as operating profit"
    Industry benchmark: Hotels should target 30-40% EBITDA margin

  NET MARGIN %:
    = Net Income / Revenue × 100
    Hotel example: ₹3.9Cr / ₹26Cr × 100 = 15%
    "For every ₹100 of revenue, ₹15 is actual profit"

  In EPM:
    These are DYNAMIC CALC members with member formulas:
    "Gross_Margin_Pct" = "Gross_Profit" % "Total_Revenue";
    (The % operator = division × 100 in Essbase)
```

# SECTION 4: BALANCE SHEET

---

## What Is a Balance Sheet?

```
PLAIN ENGLISH:
  The Balance Sheet answers: "If we closed the company TODAY,
  what would we own and what would we owe?"

THE ACCOUNTING EQUATION (memorize this):
  ┌─────────────────────────────────────────────────┐
  │                                                  │
  │    ASSETS = LIABILITIES + EQUITY                 │
  │                                                  │
  │    (What we OWN) = (What we OWE) + (Owner's share)│
  │                                                  │
  │    This equation ALWAYS balances.                 │
  │    That's why it's called a "Balance" Sheet.      │
  │                                                  │
  └─────────────────────────────────────────────────┘

ANALOGY (Personal):
  Your house (Asset)     = ₹1Cr
  Your mortgage (Liability) = ₹70L
  Your equity (Owner's share) = ₹30L
  
  ₹1Cr = ₹70L + ₹30L  ✅ BALANCES
```

## Balance Sheet Structure

```
BALANCE SHEET — STANDARD STRUCTURE

  ASSETS (What we OWN):
  ┌────────────────────────────────────────────────────┐
  │  CURRENT ASSETS (can be converted to cash < 1 year)│
  │  ├── Cash & Bank Balances       ← Money in bank   │
  │  ├── Accounts Receivable        ← Customers owe us│
  │  ├── Inventory                  ← Raw materials    │
  │  ├── Prepaid Expenses           ← Paid in advance  │
  │  └── Short-Term Investments                        │
  │                                                    │
  │  NON-CURRENT ASSETS (long-term, > 1 year)         │
  │  ├── Property, Plant, Equipment ← Hotel buildings  │
  │  ├── Land                       ← Hotel land       │
  │  ├── Furniture & Fixtures       ← Rooms, lobby     │
  │  ├── Intangible Assets          ← Brand, licenses  │
  │  └── Accumulated Depreciation   ← Negative (contra)│
  │                                                    │
  │  = TOTAL ASSETS                                    │
  └────────────────────────────────────────────────────┘

  LIABILITIES (What we OWE):
  ┌────────────────────────────────────────────────────┐
  │  CURRENT LIABILITIES (due < 1 year)                │
  │  ├── Accounts Payable           ← We owe suppliers │
  │  ├── Salaries Payable           ← Owe employees    │
  │  ├── Taxes Payable              ← Owe government   │
  │  ├── Short-Term Loans           ← Bank overdraft   │
  │  └── Unearned Revenue           ← Advance bookings │
  │                                                    │
  │  NON-CURRENT LIABILITIES (due > 1 year)            │
  │  ├── Long-Term Debt             ← Hotel mortgage   │
  │  ├── Deferred Tax Liabilities                      │
  │  └── Lease Obligations          ← Building leases  │
  │                                                    │
  │  = TOTAL LIABILITIES                               │
  └────────────────────────────────────────────────────┘

  EQUITY (Owner's Share):
  ┌────────────────────────────────────────────────────┐
  │  ├── Share Capital              ← Initial investment│
  │  ├── Retained Earnings          ← Accumulated profit│
  │  └── Other Reserves             ← Revaluation, etc.│
  │                                                    │
  │  = TOTAL EQUITY                                    │
  └────────────────────────────────────────────────────┘

  TOTAL LIABILITIES + EQUITY = TOTAL ASSETS  ✅

EPM DESIGN IMPLICATIONS:
  ALL Balance Sheet accounts: Time Balance = BALANCE (Last/Ending)
  Asset accounts:     Account Type = Asset
  Liability accounts: Account Type = Liability
  Equity accounts:    Account Type = Equity
  
  Q1 Cash = March Cash (NOT Jan + Feb + Mar)
  Q1 Accounts Receivable = March AR (NOT sum of 3 months)
```

# SECTION 5: CASH FLOW STATEMENT

---

```
WHAT IS CASH FLOW?

  The Cash Flow Statement explains WHY your bank balance changed.

  PROBLEM IT SOLVES:
    Your P&L says: Net Income = ₹3.9Cr (profitable!)
    Your bank account shows: Balance decreased by ₹1Cr
    
    How? You made profit but SPENT cash on new equipment,
    paid off loans, and customers haven't paid you yet.
    
    Cash Flow explains the gap between PROFIT and CASH.

CASH FLOW STRUCTURE:

  ┌────────────────────────────────────────────────────┐
  │ OPERATING ACTIVITIES (from running the business)    │
  │ ├── Net Income                        ₹3.9 Cr      │
  │ ├── + Depreciation (non-cash expense) ₹1.5 Cr      │
  │ ├── - Increase in Accounts Receivable (₹0.8 Cr)    │
  │ ├── + Increase in Accounts Payable    ₹0.3 Cr      │
  │ └── = Cash from Operations            ₹4.9 Cr      │
  ├────────────────────────────────────────────────────┤
  │ INVESTING ACTIVITIES (buying/selling assets)        │
  │ ├── - Purchase of Equipment          (₹3.0 Cr)     │
  │ ├── - Hotel Renovation               (₹2.0 Cr)     │
  │ └── = Cash from Investing            (₹5.0 Cr)     │
  ├────────────────────────────────────────────────────┤
  │ FINANCING ACTIVITIES (loans and equity)             │
  │ ├── + New Long-Term Loan              ₹2.0 Cr      │
  │ ├── - Loan Repayment                 (₹1.5 Cr)     │
  │ ├── - Dividends Paid                 (₹1.4 Cr)     │
  │ └── = Cash from Financing            (₹0.9 Cr)     │
  ├────────────────────────────────────────────────────┤
  │ NET CHANGE IN CASH                   (₹1.0 Cr)     │
  │ + Opening Cash Balance                ₹5.0 Cr      │
  │ = CLOSING CASH BALANCE                ₹4.0 Cr      │
  └────────────────────────────────────────────────────┘

  NOW IT MAKES SENSE:
    Profit = ₹3.9Cr ✅
    But we SPENT ₹5Cr on equipment and renovation.
    We BORROWED ₹2Cr but REPAID ₹1.5Cr and paid ₹1.4Cr dividends.
    Net: Cash decreased by ₹1Cr.
```

# SECTION 6: HOW THE 3 STATEMENTS CONNECT

---

```
THE CONNECTIONS — "Financial Statement Triangle"

  ┌──────────────┐
  │ INCOME       │
  │ STATEMENT    │──── Net Income ──────────┐
  │ (P&L)        │                          │
  └──────────────┘                          ▼
                                   ┌──────────────┐
  ┌──────────────┐                 │ BALANCE      │
  │ CASH FLOW    │── Closing Cash ─│ SHEET        │
  │ STATEMENT    │──▶              │              │
  │              │  Net Income ───▶│ (Retained    │
  │              │                 │  Earnings)   │
  └──────────────┘                 └──────────────┘

  CONNECTION 1: P&L → Balance Sheet
    Net Income from P&L flows into Retained Earnings on BS.
    If you made ₹3.9Cr profit, Retained Earnings increases by ₹3.9Cr.

  CONNECTION 2: P&L → Cash Flow
    Cash Flow STARTS with Net Income from P&L.
    Then adjusts for non-cash items (depreciation, AR changes).

  CONNECTION 3: Cash Flow → Balance Sheet
    Closing Cash from Cash Flow = Cash balance on Balance Sheet.
    ₹4.0Cr Closing Cash = ₹4.0Cr Cash on BS. They MUST match.

  IN EPM:
    These connections are implemented via:
    ├── Member formulas (Retained Earnings = Prior Year RE + Net Income)
    ├── Calc scripts (Cash Flow calculation)
    └── @XREF (if P&L is in Plan1 and BS is in Plan2)
```

# SECTION 7: ACCOUNTING CONCEPTS FOR ESSBASE

---

```
CONCEPTS EVERY EPM CONSULTANT MUST KNOW:

  1. ACCRUAL vs CASH ACCOUNTING
     Accrual: Record revenue WHEN EARNED, not when cash received.
     Cash:    Record revenue WHEN CASH IS RECEIVED.
     
     Hotel books ₹10L conference in March (accrual).
     Client pays in May (cash).
     P&L shows ₹10L in March. Cash Flow shows ₹10L in May.
     EPM models ACCRUAL accounting.

  2. DEPRECIATION
     A ₹50L kitchen renovation lasts 10 years.
     You don't expense ₹50L in Year 1.
     You expense ₹5L per year for 10 years (straight-line).
     
     EPM formula: Annual Depreciation = Asset Cost / Useful Life
     Monthly: ₹5L / 12 = ₹41,667/month
     
     In Essbase: Depreciation member has Account Type = Expense

  3. AMORTIZATION
     Same as depreciation but for INTANGIBLE assets.
     Software license ₹20L, useful life 5 years.
     Annual amortization = ₹4L/year.

  4. ACCOUNTS RECEIVABLE (AR)
     Money OWED TO US by customers.
     Hotel hosted a conference for ₹10L. Client will pay in 30 days.
     AR = ₹10L (asset on Balance Sheet).
     DSO (Days Sales Outstanding) = AR / Daily Revenue.

  5. ACCOUNTS PAYABLE (AP)
     Money WE OWE to suppliers.
     Hotel received ₹3L of food supplies. Payment due in 45 days.
     AP = ₹3L (liability on Balance Sheet).

  6. WORKING CAPITAL
     = Current Assets - Current Liabilities
     If positive: company can pay its short-term bills.
     If negative: DANGER — may not be able to pay suppliers.

  7. CAPEX vs OPEX
     CapEx (Capital Expenditure): Buying long-term assets (building, equipment)
     OpEx (Operating Expenditure): Daily running costs (salaries, utilities)
     
     CapEx goes on BALANCE SHEET (as an asset).
     OpEx goes on P&L (as an expense).
     EPM models BOTH: CapEx module + P&L planning.
```

# SECTION 8: DEBITS AND CREDITS — THE EPM IMPACT

---

```
THE SIGN CONVENTION — CRITICAL FOR ESSBASE

  In accounting:
    Revenue = CREDIT (negative in ledger)
    Expense = DEBIT  (positive in ledger)

  In Essbase:
    Revenue is stored as a POSITIVE number.
    Expense is stored as a POSITIVE number.
    
  HOW? The Account Type property handles the sign flip:
    Account Type = Revenue → system knows to flip sign for variance
    Account Type = Expense → system knows expense UP = bad

  PRACTICAL IMPACT:

  Revenue:  Budget = ₹26Cr, Actual = ₹28Cr
    Variance = Actual - Budget = ₹2Cr (FAVORABLE ✅)
    Because Account Type = Revenue (Non-Expense),
    positive variance = GOOD.

  Expense:  Budget = ₹18Cr, Actual = ₹20Cr
    Variance = Actual - Budget = ₹2Cr
    But this is UNFAVORABLE ❌ (we spent MORE than planned)
    Because Account Type = Expense,
    positive variance = BAD (needs sign flip for display).

  IN ESSBASE:
    Variance Reporting = Non-Expense → Revenue (up = good)
    Variance Reporting = Expense    → Expense (up = bad)
    
    This property controls the color coding in forms:
    Green = favorable, Red = unfavorable.
```

# SECTION 9: TIME BALANCE — THE MOST CRITICAL PROPERTY

---

```
TIME BALANCE — WHAT IT DOES

  Time Balance controls HOW data aggregates across TIME.
  (How does January + February + March = Q1?)

  ┌────────────────────────────────────────────────────────┐
  │                                                        │
  │  TIME BALANCE: FLOW                                    │
  │  ────────────────────────────────                      │
  │  Q1 = Jan + Feb + Mar (SUM of children)                │
  │                                                        │
  │  Used for: Revenue, Expenses, Units Sold, Cash Flow    │
  │  Why: Revenue in Q1 = total of all 3 months            │
  │                                                        │
  │  Example:                                              │
  │    Jan Revenue = ₹2.0Cr                                │
  │    Feb Revenue = ₹2.2Cr                                │
  │    Mar Revenue = ₹2.5Cr                                │
  │    Q1 Revenue  = ₹6.7Cr ← SUM (correct!)              │
  │                                                        │
  ├────────────────────────────────────────────────────────┤
  │                                                        │
  │  TIME BALANCE: BALANCE (Last / Ending)                 │
  │  ────────────────────────────────────                  │
  │  Q1 = March value only (LAST child)                    │
  │                                                        │
  │  Used for: Cash, AR, AP, Inventory, Headcount          │
  │  Why: Cash in Q1 = cash at END of Q1 (March 31)        │
  │  NOT the sum of Jan + Feb + Mar cash.                  │
  │                                                        │
  │  Example:                                              │
  │    Jan Cash = ₹5.0Cr                                   │
  │    Feb Cash = ₹4.5Cr                                   │
  │    Mar Cash = ₹4.0Cr                                   │
  │    Q1 Cash  = ₹4.0Cr ← LAST period (correct!)         │
  │    NOT ₹13.5Cr (that would be nonsensical)             │
  │                                                        │
  ├────────────────────────────────────────────────────────┤
  │                                                        │
  │  TIME BALANCE: FIRST                                   │
  │  ────────────────────────                              │
  │  Q1 = January value only (FIRST child)                 │
  │                                                        │
  │  Used for: Opening Balances                            │
  │  Why: Opening balance of Q1 = January 1st value        │
  │                                                        │
  ├────────────────────────────────────────────────────────┤
  │                                                        │
  │  TIME BALANCE: AVERAGE                                 │
  │  ────────────────────────                              │
  │  Q1 = (Jan + Feb + Mar) / 3 (AVERAGE of children)     │
  │                                                        │
  │  Used for: Exchange Rates, Headcount (sometimes)       │
  │  Why: Average exchange rate over Q1 = mean of 3 months │
  │                                                        │
  └────────────────────────────────────────────────────────┘

  THE #1 MISTAKE IN ALL OF EPM:
  ┌────────────────────────────────────────────────────────┐
  │ Setting Cash to "Flow" instead of "Balance"            │
  │                                                        │
  │ If Cash = Flow:                                        │
  │   Q1 Cash = Jan(₹5Cr) + Feb(₹4.5Cr) + Mar(₹4Cr)     │
  │   Q1 Cash = ₹13.5Cr ← WRONG! (Cash doesn't add up)  │
  │                                                        │
  │ If Cash = Balance:                                     │
  │   Q1 Cash = Mar(₹4Cr) ← CORRECT!                     │
  │                                                        │
  │ This error has caused companies to restate financials. │
  │ ALWAYS verify Time Balance settings for every account. │
  └────────────────────────────────────────────────────────┘
```

### Skip Property (Used with Time Balance)

```
SKIP PROPERTY — What to do with #Missing and Zero

  ┌────────────────────────────────────────────────────────┐
  │ SKIP: NONE                                             │
  │   Include all values (even #Missing and zero)          │
  │   Q1 Balance = March (even if March = 0)               │
  │                                                        │
  │ SKIP: MISSING                                          │
  │   Skip #Missing cells when determining "last" value    │
  │   If March = #Missing, Q1 = February value             │
  │                                                        │
  │ SKIP: ZEROS                                            │
  │   Skip zero cells when determining "last" value        │
  │   If March = 0, Q1 = February value                    │
  │                                                        │
  │ SKIP: MISSING AND ZEROS                                │
  │   Skip both #Missing AND zero                          │
  │   Q1 = last non-zero, non-missing month                │
  └────────────────────────────────────────────────────────┘

  MOST COMMON SETTING:
    P&L accounts: Skip = None (we want to see zeros)
    BS accounts:  Skip = Missing (if no data, use prior month)
```

# SECTION 10: VARIANCE REPORTING

---

```
VARIANCE = ACTUAL - BUDGET

  But IS variance good or bad? It depends on the account type:

  REVENUE (Non-Expense Variance Reporting):
    Actual = ₹28Cr, Budget = ₹26Cr
    Variance = +₹2Cr → FAVORABLE ✅ (More revenue = good)
    Display: GREEN

  EXPENSE (Expense Variance Reporting):
    Actual = ₹20Cr, Budget = ₹18Cr
    Variance = +₹2Cr → UNFAVORABLE ❌ (More expense = bad)
    Display: RED

  THE EPM SETTING:
    Account Property: "Variance Reporting"
    Values: "Expense" or "Non-Expense"
    
    Revenue, Other Income → Non-Expense
    Salaries, COGS, Rent  → Expense
    Statistical (Rooms)   → Non-Expense (more rooms = good)

  COMMON INTERVIEW QUESTION:
    "A member shows +₹5L variance. Is that good or bad?"
    Answer: "It depends. If the account is Revenue (Non-Expense),
    +₹5L is favorable. If the account is Expense,
    +₹5L is unfavorable. The Variance Reporting property
    in Essbase controls how the system interprets the sign."
```

# SECTION 12: COMMON MISTAKES

---

| Mistake | Impact | Correct Approach |
|---------|--------|-----------------|
| Setting Cash to Time Balance = Flow | Q1 Cash = sum of 3 months (nonsense) | Balance Sheet accounts = Time Balance: Balance |
| Not setting Variance Reporting on Expense accounts | Expense overruns show as "Favorable" (green) | Expenses = Variance Reporting: Expense |
| Mixing Account Types | Revenue accounts with Type "Expense" | Revenue = Revenue type, Expenses = Expense type |
| Ignoring Skip property | BS accounts show #Missing instead of last known value | BS accounts: Skip = Missing |
| Not understanding COGS vs OpEx | All expenses lumped together | COGS = direct costs (food), OpEx = operating costs (salaries) |
| Thinking Net Income = Cash | Company has profit but no cash to pay bills | Profit ≠ Cash. Cash Flow explains the difference |
| Not knowing the accounting equation | Can't validate Balance Sheet | Assets = Liabilities + Equity. Always. |

# SECTION 13: INTERVIEW QUESTIONS

---

### Beginner

**Q1: What are the 3 financial statements?**
> 1) Income Statement (P&L) — shows Revenue - Expenses = Net Income over a period. 2) Balance Sheet — shows Assets = Liabilities + Equity at a point in time. 3) Cash Flow Statement — shows where cash came from and where it went.

**Q2: What is the difference between Revenue and Expense in Essbase?**
> Both are stored as positive numbers in Essbase. The Account Type property (Revenue vs Expense) and Variance Reporting property (Non-Expense vs Expense) tell the system how to interpret variance. Revenue up = favorable (Non-Expense). Expense up = unfavorable (Expense).

**Q3: What is Time Balance? Why does it matter?**
> Time Balance controls how data aggregates across time periods. Flow = sum (Jan+Feb+Mar = Q1). Balance = last month only (Q1 = March). Getting this wrong means quarterly and yearly reports will be incorrect. P&L uses Flow. Balance Sheet uses Balance.

### Intermediate

**Q4: Design the Account Type and Time Balance settings for these members: Revenue, Salaries, Cash, Headcount, Exchange Rate.**
> Revenue: Account Type = Revenue, Time Balance = Flow, Variance = Non-Expense. Salaries: Account Type = Expense, Time Balance = Flow, Variance = Expense. Cash: Account Type = Asset, Time Balance = Balance (Last), Skip = Missing. Headcount: Account Type = Saved Assumption, Time Balance = Balance (Last). Exchange Rate: Account Type = Saved Assumption, Time Balance = Average.

### Architect

**Q5: A client's Q1 Balance Sheet doesn't match their ERP. Cash in EPBCS shows ₹13.5Cr but ERP shows ₹4Cr. What's wrong?**
> The Cash account's Time Balance is set to "Flow" instead of "Balance." With Flow, Q1 Cash = Jan(₹5Cr) + Feb(₹4.5Cr) + Mar(₹4Cr) = ₹13.5Cr. With Balance (Last), Q1 Cash = March value = ₹4Cr. Fix: Change the Time Balance property to "Balance" on the Cash account member and refresh the cube. This will recalculate all time-aggregated values.
