# 12.03 — Security Audit and Compliance: Complete Guide

> **Module:** 12_Security | **Topic:** Audit Trail, Compliance Reviews, Access Reports
> **Audience:** Service Administrator / Compliance Officer

---

## 1. WHY — Why Security Audit Matters

**The problem:** An auditor asks: "Who had access to salary data in March 2026— Can you prove only HR could edit it— Without audit trails, you can't answer. SOX compliance (US) and Companies Act 2013 (India) require demonstrable access controls with evidence of reviews.

## 2. WHAT GETS AUDITED

| Event | What's Recorded | Where to View |
|-------|----------------|---------------|
| User login/logout | Username, timestamp, IP | Activity Reports |
| Failed login attempts | Username, reason, IP | Activity Reports |
| Role assignment/removal | User, role, admin who changed | Provisioning Report |
| Data entry (cell changes) | Form, cell, old value, new value | Audit Trail |
| Business rule execution | Rule name, user, parameters, status | Jobs Console |
| Dimension member add/delete | Member, action, admin | Audit Trail |
| SubVar changes | Variable, old/new value, admin | Audit Trail |
| LCM import/export | Snapshot name, artifacts, admin | Activity Reports |
| Security changes | Dimension security grants/revokes | Audit Trail |

## 4. QUARTERLY SECURITY REVIEW PROCESS

```
Every quarter, the Security Admin must:

Week 1: Generate Reports
  ☐ Provisioning report (all users + roles)
  ☐ Dimension security export (who has access to what)
  ☐ Form permission report (which forms each group can access)

Week 2: Review and Validate
  ☐ Cross-reference users with HR active employee list
  ☐ Remove departed employees (immediate!)
  ☐ Review role assignments — anyone have excessive access—
  ☐ Review dimension security — any unintended entity access—
  ☐ Review salary/confidential account access — only HR/CFO—

Week 3: Remediate
  ☐ Remove access for departed users
  ☐ Downgrade roles where excessive (Admin → Planner)
  ☐ Fix dimension security gaps
  ☐ Document all changes made

Week 4: Sign-Off
  ☐ Generate final reports (post-remediation)
  ☐ Manager sign-off on access lists
  ☐ Archive reports for audit trail
  ☐ File in compliance folder
```

## 5. COMPLIANCE FRAMEWORKS

### SOX Compliance (US Publicly Traded)

```
SOX Section 404: Internal Controls over Financial Reporting

Required for EPBCS:
  ✅ Segregation of duties (no one user can both enter AND approve)
  ✅ Access reviews (quarterly minimum)
  ✅ Audit trail for all data changes
  ✅ Approval workflows for budget finalization
  ✅ Version locking (Final = immutable)
  ✅ Change management (LCM for rule changes)

Evidence required:
  📄 Provisioning reports (quarterly)
  📄 Activity reports (data change audit)
  📄 Jobs Console logs (rule execution history)
  📄 LCM export logs (deployment history)
  📄 Access review sign-off documents
```

### Companies Act 2013 (India)

```
Section 134: Financial Statements must be accurate

Required for EPBCS:
  ✅ Actual data = Read-only for non-admins
  ✅ Approved budget = locked (Final version)
  ✅ Data entry audit trail enabled
  ✅ User access documented and reviewed
```

## 7. COMMON MISTAKES

| Mistake | Risk | Fix |
|---------|------|-----|
| No quarterly access review | Departed users retain access | Schedule quarterly review |
| Everyone is Service Admin | No segregation of duties | Least-privilege model |
| Audit trail not enabled | No evidence for auditors | Enable Day 1 |
| No version locking | Approved budgets can be changed | Lock Final after approval |
| Planners can edit Actuals | Financial data integrity risk | Actual = Read for planners |
| No provisioning report archived | Can't prove past compliance | Archive quarterly |

## 8. INTERVIEW QUESTIONS

### Architect
**Q: Design the security compliance framework for Hotel Pvt Ltd to meet SOX requirements.**
> **Segregation of duties:** 4 roles — Admin (load + deploy), Controller (review + approve), Planner (enter budget), Viewer (read-only). No single user can both enter and approve. **Access controls:** Entity security per hotel, Scenario security (Actual=Read), Account security (Salary=HR only), Version lock (Final=Read). **Audit:** Enable data audit trail, enable security change audit, retain logs for 7 years. **Reviews:** Quarterly provisioning report + access review + manager sign-off. Automated via EPM Automate script. **Evidence:** Archive provisioning reports, Activity Reports, Jobs Console exports, LCM deployment logs — all timestamped and stored in compliance folder.
