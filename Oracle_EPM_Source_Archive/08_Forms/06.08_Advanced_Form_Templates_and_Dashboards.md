# 06.08 — Advanced Form Templates and Dashboards: Complete Guide

> **Module:** 06_Forms | **Topic:** Dashboards, Infolets, Tiles, Form Templates
> **Audience:** Service Administrator / Power User

---

## 1. WHY — What Real-World Problem Does This Solve—

**The problem:** Users don't want to navigate through 20 forms to understand the business. A hotel GM should open ONE dashboard and see: revenue trends (chart), headcount (table), KPIs (cards), and P&L (grid) — all on one screen.

**The solution:** Dashboards combine forms, charts, tiles, and web content into **single-page executive views** that tell a story with data.

---

## 2. DASHBOARD vs COMPOSITE FORM vs INFOLET

| Feature | Dashboard | Composite Form | Infolet |
|---------|-----------|---------------|---------|
| **Components** | Forms, Charts, URLs, Tiles, Text | Multiple forms only | Single metric card |
| **Multi-cube** | ✅ | ✅ | ❌ (single value) |
| **Charts** | ✅ Built-in charting | ❌ | ❌ |
| **Data entry** | ✅ (embedded forms) | ✅ | ❌ (display only) |
| **Customization** | Highly flexible layout | Grid-based layout | Fixed card format |
| **Where shown** | Navigator, Nav Flows | Forms listing | Home Page |
| **Best for** | Executive summaries | Multi-form data entry | KPI at-a-glance |

```

  │                             └──────────────────────────────┘│
  │  ┌─ KPI Cards ──────────┐  ┌─ Headcount ──────┐  ┌─ URL ──┐│

```

### Dashboard Component Types

| Component | Description | Data Source |
|-----------|-------------|-------------|
| **Form** | Embed any existing form | Planning cube |
| **Chart** | Bar, Line, Pie, Area, Combo charts | Data from a form |
| **Tile** | Single metric with icon/color | Member formula or form cell |
| **URL** | Embed external webpage | Any URL |
| **Text** | Static text/instructions | Manual text |
| **Separator** | Visual divider line | None |

## 4. CHART TYPES IN DASHBOARDS

| Chart Type | Best For | Example |
|-----------|---------|---------|
| **Line** | Trends over time | Monthly revenue trend Jan-Dec |
| **Bar** | Comparison across categories | Revenue by hotel |
| **Stacked Bar** | Part-to-whole comparison | Revenue breakdown by category per hotel |
| **Pie/Donut** | Percentage distribution | Expense breakdown |
| **Area** | Volume trends | Cumulative revenue growth |
| **Combo** | Two metrics on one chart | Revenue (bars) + Profit Margin (line) |
| **Gauge** | Single KPI against target | Occupancy vs 85% target |
| **Waterfall** | Bridge/flow analysis | Revenue → Expenses → Net Income |

### Creating a Chart

```
Dashboard Designer → Drag "Chart" component to grid position

Chart Properties:
  Source Form: Revenue_Summary (data comes from this form)
  Chart Type: Line
  Category Axis (X): Period (Jan, Feb, Mar, ...)
  Value Axis (Y): Total_Revenue
  Series: Entity (separate line per hotel)
  
  Options:
    ☑ Show data labels
    ☑ Show legend
    ☐ Show grid lines
    Color palette: [Blue gradient ▾]
```

## 5. TILES (KPI CARDS)

### What They Are
Tiles are **single-value KPI cards** that display one metric with optional formatting (color, icon, sparkline). Think: the colored squares on the Oracle EPM Home Page.

```
┌─ Tile: Occupancy Rate ──────┐
│       🏨                     │
│    84.0%                     │
│  ▲ +2.3% vs prior month     │
│  ━━━━━━━━━━━━━━ (sparkline) │
│  Target: 85%                 │
└──────────────────────────────┘
```

### Tile Configuration

```
Dashboard Designer → Drag "Tile" to grid

Tile Properties:
  Label: "Occupancy Rate"
  Source: Form cell value or member formula result
  Format: Percentage, 1 decimal
  Conditional Color:
    ≥ 85% → Green
    70-84% → Yellow
    < 70% → Red
  Show: Sparkline trend (last 6 months)
  Icon: 🏨
```

## 6. INFOLETS — HOME PAGE CARDS

### What They Are
Infolets are **tile-like cards on the Home Page** that show summary metrics. Users see them immediately after login without navigating anywhere.

```
EPM Home Page:
┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐
│ Revenue  │ │ Expenses │ │ Net Inc  │ │ Occupancy│
│ ₹1.12Cr  │ │ ₹65L     │ │ ₹47L     │ │ 84%      │
│ ▲ 5.2%   │ │ ▼ -3.1%  │ │ ▲ 8.4%   │ │ ▲ 2.3%   │
└──────────┘ └──────────┘ └──────────┘ └──────────┘
```

### Creating Infolets

```
Navigator → Infolets → Create

Infolet Properties:
  Title: "Revenue"
  Source: form/cell reference
  Drill-through: Link to Revenue_Summary form
  Size: Standard (1×1) or Wide (2×1)
```

## 8. COMMON MISTAKES

| Mistake | Symptom | Fix |
|---------|---------|-----|
| Too many components on one dashboard | Slow load, cluttered UI | Limit to 4-6 components |
| Large forms embedded in dashboard | Dashboard takes 30+ seconds | Use summary forms (few rows) |
| Chart source form not matching | Chart shows wrong data | Verify chart's source form has correct member selections |
| Tiles not refreshing | KPI shows stale data | Ensure source form/cell reference is correct |
| No drill-through on tiles | Dead-end experience | Add drill-through links to detail forms |

## 9. INTERVIEW QUESTIONS

### Beginner
**Q: What is the difference between a Dashboard and a Composite Form—**
> A **Dashboard** can contain forms, charts, tiles, URLs, and text — it's a fully flexible visual layout. A **Composite Form** can only contain multiple forms — no charts, no tiles, no URLs. Dashboards are for executive summaries and visualization; Composite Forms are for multi-cube data entry on one screen.

### Intermediate
**Q: A dashboard has 6 components and takes 25 seconds to load. How do you optimize—**
> (1) Check each embedded form's individual load time — optimize the slowest ones first. (2) Replace full-size forms with summary forms (fewer rows). (3) Ensure all embedded forms have Suppress Missing enabled. (4) Check if charts reference large forms — use small source forms for charts. (5) Consider splitting into 2 dashboards with a navigation link between them. (6) Tiles should reference pre-calculated summary values, not form cells that trigger recalculation.
