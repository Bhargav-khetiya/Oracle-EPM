## MISTAKES â€” Common Errors & Fixes <a name="mistakes"></a>

### Mistake 1: Tile Shows Wrong Value

```
SYMPTOM: Dashboard Tile shows "â‚¹0" even though data exists.

ROOT CAUSE: The underlying form has hidden/collapsed columns.
   The Tile reads the FIRST VISIBLE column of the form.
   If you collapsed Column A (which has Actual data),
   the Tile reads Column B (which might be empty).

FIX:
   1. Open the source form in Form Designer
   2. Verify the first column contains the KPI value
   3. Remove any hidden columns that precede the data column
   4. Save form â†’ refresh dashboard
```

### Mistake 2: Dashboard Timeout

```
SYMPTOM: Dashboard shows spinning wheel for 30+ seconds, then errors.

ROOT CAUSE: Too many components pulling too much data.
   6 forms Ã— 10,000 cells each = 60,000 cells = timeout

FIX:
   1. Reduce form complexity:
      â””â”€â”€ Enable "Suppress Missing Blocks" on ALL forms
      â””â”€â”€ Limit rows: Use ILvl0Descendants instead of IDescendants
      â””â”€â”€ Limit columns: Show 6 months, not 12
   2. Reduce components: Keep to 4-6 per dashboard
   3. Use ASO reporting cube for chart data (faster retrieval)
   4. Use "Edit Without Data" mode to adjust layout
      (avoids triggering queries during design)
```

### Mistake 3: Report Bursting Generates Blank PDFs

```
SYMPTOM: Mumbai GM receives email with PDF attached, but PDF is blank.

ROOT CAUSES:
   A. Data Security: GM's user account lacks Read access to Mumbai
      in the Essbase cube. Bursting ran with "As Recipient" mode.
      FIX: Grant Read access to Mumbai entity in Access Control.

   B. #Missing Data: No data loaded for the period/entity.
      FIX: Verify data exists using Smart View ad-hoc.

   C. Suppress Missing = ON: All rows have #Missing, so they're
      all suppressed, leaving an empty report.
      FIX: Turn off "Suppress Missing Rows" or load data first.
```

### Mistake 4: Master-Detail Linking Doesn't Work

```
SYMPTOM: Clicking a row in the Master form does nothing.
   Detail form doesn't refresh.

ROOT CAUSES:
   A. Forgot to "Tag as Master"
      FIX: Select the Master form â†’ Properties â†’ "Tag as Master"

   B. Dimension mismatch
      FIX: The linked dimension must exist on BOTH forms.
      If Master has Entity but Detail doesn't have Entity â†’ fails.

   C. User doesn't right-click â†’ "Apply Context"
      FIX: Users must right-click on the member â†’ "Apply Context"
      It does NOT auto-apply on left-click in all versions.

   D. Detail form uses a different cube
      FIX: Ensure both forms point to the same application/cube
      OR use the same Entity dimension name across cubes.
```

### Mistake 5: Infolet Not Visible to Users

```
SYMPTOM: Admin created an Infolet, but planners can't see it.

ROOT CAUSES:
   A. Navigation Flow not updated
      FIX: Navigator â†’ Navigation Flows â†’ Edit
      â†’ Enable the Infolet page â†’ Assign to correct flow

   B. Security: User role doesn't include Infolet access
      FIX: Check the user's assigned navigation flow
      â†’ Ensure infolets are enabled in THEIR flow

   C. Infolet not saved / not published
      FIX: Re-open infolet designer â†’ verify "Save" was clicked

   D. Pod restriction (25.10+): New infolet creation disabled
      FIX: Use Dashboard Tiles instead (Oracle's new direction)
```

### Mistake 6: Report Formula Column Shows Wrong Calculation

```
SYMPTOM: Variance % shows "100%" for everything.

ROOT CAUSE: Formula references wrong column index.
   Formula: =[Column2] - [Column1]
   But Column1 = "Account" (text), Column2 = "Actual"

   2. Verify column references:
```

## TEST ME â€” Interview Questions <a name="test-me"></a>

### ðŸŸ¢ Beginner Level

**Q1: What are the three reporting tools in Oracle EPM Cloud?**
> **A:** (1) **EPM Reports** â€” cloud-native, web-based, Oracle's go-forward direction. Grid + Chart + Text on a canvas. **Q2: What is a Dashboard Tile in EPM Cloud?**
> **A:** A Tile is a large, prominent KPI display box inside a Dashboard 2.0. It shows a single metric value (like "â‚¹6.3Cr Total Revenue") with conditional coloring (green = above target, red = below). It's powered by an underlying form's data.

**Q3: What is the difference between an Infolet and a Dashboard?**
> **A:** An **Infolet** lives on the EPM Home Page â€” it's visible immediately at login. It has 3 views (Front, Back, Expanded) and is read-only. A **Dashboard** is a separate page you navigate to â€” it can contain forms, charts, tiles, and supports data entry and master-detail interaction.

> **A:** Grid (data table from Essbase), Chart (17 types), Text Box (static or dynamic with functions like <<MemberName>>), Image (logos), and Pages (multi-page layout with headers/footers).

> **A:** Bursting automatically generates separate reports for each member of a dimension (usually Entity) and emails personalized PDFs to the respective managers. Example: Mumbai GM gets Mumbai-only P&L, Delhi GM gets Delhi-only P&L.

### ðŸŸ¡ Intermediate Level

**Q6: You create a Dashboard with 6 forms. It times out. Why?**
> **A:** When a dashboard loads, it fires simultaneous Essbase queries for ALL components. 6 forms = 6 parallel queries. If those forms are poorly designed (no "Suppress Missing Blocks", too many members selected, large row counts), Essbase gets overwhelmed. Fix: reduce to 4 forms, enable suppression, use ASO cube for read-only charts, limit member selections with ILvl0Descendants.

**Q7: How do you configure Master-Detail linking in a Dashboard?**
> **A:** (1) Create two forms with a shared dimension (e.g., Entity). (2) Add both to a dashboard. (3) Select the summary form â†’ Properties â†’ "Tag as Master". (4) Map the linking dimension (Entity). (5) When the user right-clicks a member in the Master and clicks "Apply Context", the Detail form refreshes to show that member's data.

**Q8: A Dashboard Tile shows "â‚¹0" even though data exists in the cube. What's wrong?**
> **A:** The tile reads the first visible column of its source form. If the form has hidden/collapsed columns preceding the data column, the tile picks up the wrong column. Fix: open the form designer, remove hidden columns, ensure the value column is the first visible column.

**Q9: What is the formatting hierarchy in EPM Reports?**
> **A:** Cell Format overrides Row/Column Format, which overrides Grid Format. Most specific wins. Example: If the grid has "Blue text" format, but a specific row has "Red text" format, and cell [3,2] has "Green text" format â€” cell [3,2] will be green, the rest of that row will be red, and all other cells will be blue.

**Q10: How do you create a variance report that correctly colors Revenue vs Expense variances?**
> **A:** Revenue and Expense have OPPOSITE variance logic. Revenue: Actual > Budget = favorable (GREEN). Expense: Actual > Budget = unfavorable (RED, you overspent). Use conditional formatting with TWO rules: Rule 1 (Revenue accounts): If Variance > 0 â†’ Green. Rule 2 (Expense accounts): If Variance > 0 â†’ Red. Use Account Type property or UDA to distinguish them in the conditional rule.

**Q13: You burst a P&L report to 500 entities. 3 entities receive blank PDFs. How do you troubleshoot?**
> **A:** Step-by-step:
> 1. **Check data:** Open Smart View â†’ set POV to each of the 3 entities â†’ run ad-hoc â†’ verify data exists.
> 2. **Check security:** If bursting runs "As Recipient", verify those 3 GMs have Read access to their entity in Access Control.
