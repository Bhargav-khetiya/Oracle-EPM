# 08.03 — Custom Defined Functions (CDF): Complete Guide

> **Module:** 08_Calculation_Manager | **Topic:** Custom Defined Functions, @CalcMgr Functions
> **Audience:** Service Administrator / Rule Developer

---

## 1. WHY — What Real-World Problem Does This Solve—

**The problem:** Essbase's native calc functions can't do everything. You need to: format dates, manipulate strings, do financial math (NPV, IRR), or perform statistical analysis. Writing raw Essbase code for these is extremely complex and error-prone.

**The solution:** Custom Defined Functions (CDFs) are **Java-based extensions** pre-installed in Calculation Manager that extend Essbase's calculation capabilities. They're prefixed with `@CalcMgr` and provide Excel-like functions inside calc scripts.

## 3. MOST USEFUL CDFs — WITH EXAMPLES

### Date Functions

```essbase
/* Get current date as a number (YYYYMMDD format) */
SET CREATENONMISSINGBLK OFF;
FIX("Budget", "Working", &CurrYear)
  "Last_Updated_Date" = @CalcMgrGetCurrentDate();
  /* Result: 20260812 */
ENDFIX

/* Add 3 months to a date */
"Projected_End" = @CalcMgrAddMonths("Start_Date", 3);
/* If Start_Date = 20260801 → Result: 20261101 */

/* Days between two dates */
"Project_Duration" = @CalcMgrDaysBetween("Start_Date", "End_Date");
/* If Start = 20260101, End = 20260331 → Result: 90 */

/* Get month from a date number */
"Start_Month" = @CalcMgrGetMonth("Start_Date");
/* If Start_Date = 20260815 → Result: 8 (August) */

/* Check if it's a leap year */
"Is_Leap" = @CalcMgrIsLeapYear(2026);
/* Result: 0 (false — 2026 is not a leap year) */
```

### Financial Functions (Excel-Compatible)

```essbase
/* Net Present Value */
/* @CalcMgrExcelNPV(rate, cashflow1, cashflow2, ...) */
"NPV_Result" = @CalcMgrExcelNPV(0.10, -1000000, 300000, 400000, 500000, 300000);
/* 10% discount rate, initial investment of -₹10L, 4 years of cash flows */
/* Result: ₹2,48,685 (positive NPV → good investment) */

/* Internal Rate of Return */
"IRR_Result" = @CalcMgrExcelIRR(-1000000, 300000, 400000, 500000, 300000);
/* Result: 0.157 (15.7% IRR) */

/* Monthly Payment (PMT) */
/* @CalcMgrExcelPMT(rate, nper, pv) */
"Monthly_EMI" = @CalcMgrExcelPMT(0.08/12, 60, -5000000);
/* 8% annual rate, 60 months, ₹50L loan */
/* Result: ₹1,01,389 per month */

/* Straight Line Depreciation */
"Annual_Depr" = @CalcMgrExcelSLN(5000000, 500000, 10);
/* Cost=₹50L, Salvage=₹5L, Life=10 years */
/* Result: ₹4,50,000 per year */

/* Double Declining Balance Depreciation */
"Year3_Depr" = @CalcMgrExcelDDB(5000000, 500000, 10, 3);
/* Cost, Salvage, Life, Period=Year 3 */
```

### Math Functions

```essbase
/* Round up to nearest thousand */
"Budget_Rounded" = @CalcMgrExcelCEILING("Raw_Budget", 1000);
/* 8,523,456 → 8,524,000 */

/* Round down */
"Budget_Floor" = @CalcMgrExcelFLOOR("Raw_Budget", 1000);
/* 8,523,456 → 8,523,000 */

/* Round to N decimal places (up) */
"Rate_Rounded" = @CalcMgrExcelROUNDUP(0.08567, 2);
/* Result: 0.09 */

/* Square root */
"StdDev_Manual" = @CalcMgrExcelSQRT("Variance");
```

### String Functions (Used in Groovy Rules)

```essbase
/* Concatenate strings */
"Member_Label" = @CalcMgrConcat("Hotel_", "Mumbai");
/* Result: "Hotel_Mumbai" */

/* Find text position */
"Pos" = @CalcMgrFindFirst("Revenue_Room_Deluxe", "_");
/* Result: 8 (position of first underscore) */

/* Replace text */
"New_Name" = @CalcMgrReplaceAll("FY2025", "2025", "2026");
/* Result: "FY2026" */
```

### Log/Debug Functions

```essbase
/* Write trace message to calc log */
@CalcMgrLogMessageTrace("Starting P&L calculation for {Entity}");

/* Check if a member exists */
IF(@CalcMgrIsValidMember("Revenue_NewLine"))
  "Revenue_NewLine" = 100;
ENDIF
/* Prevents error if member doesn't exist */

/* Check if Smart List member is valid */
IF(@CalcMgrIsValidSLMember("BudgetStatus", "Approved"))
  /* Process approved records */
ENDIF
```

## 4. COUNTER FUNCTIONS — SPECIAL USE CASE

Counter functions maintain a running count across calculations — useful for numbering, sequencing, or tracking iterations.

```essbase
/* Initialize counter */
@CalcMgrCounterClear("ProcessedCount");

/* Increment inside a loop */
FIX(@RELATIVE("All_Hotels", 0))
  @CalcMgrCounterIncrement("ProcessedCount");
  "Process_Sequence" = @CalcMgrCounterGetNumber("ProcessedCount");
ENDFIX

/* Result: Mumbai=1, Delhi=2, Bangalore=3, Kolkata=4, Chennai=5 */
```

## 6. COMMON MISTAKES

| Mistake | Symptom | Fix |
|---------|---------|-----|
| Wrong date format | Date functions return garbage | Use YYYYMMDD format (20260812) |
| NPV with wrong sign on investment | Positive initial investment gives wrong NPV | Initial investment should be NEGATIVE |
| Division by zero in financial functions | Rule crashes | Validate inputs before calling |
| Using string CDFs in BSO calc scripts | Not all string functions work in BSO | String functions work best in Groovy rules |
| Forgetting @CalcMgr prefix | "Function not found" error | All CDFs start with @CalcMgr |

## 7. INTERVIEW QUESTIONS

### Beginner
**Q: What are @CalcMgr functions and give 3 examples—**
> @CalcMgr functions are Custom Defined Functions pre-installed in Calculation Manager that extend Essbase's native capabilities. Examples: (1) `@CalcMgrGetCurrentDate()` — returns today's date as YYYYMMDD. (2) `@CalcMgrExcelNPV(rate, cf1, cf2...)` — calculates Net Present Value like Excel's NPV function. (3) `@CalcMgrExcelSLN(cost, salvage, life)` — calculates straight-line depreciation. They bring Excel-like financial, date, math, and string functions into calc scripts.

### Architect
**Q: Design the CapEx investment analysis calculation for Hotel Pvt Ltd using @CalcMgr financial functions.**
> Use `@CalcMgrExcelNPV(rate, cashflows)` for Net Present Value at the hotel's WACC (10%). Use `@CalcMgrExcelIRR(cashflows)` for Internal Rate of Return — compare against the hurdle rate. Use `@CalcMgrExcelPMT(rate, periods, principal)` to calculate monthly financing payments. Use `@CalcMgrExcelSLN` or `@CalcMgrExcelDDB` for depreciation schedules (straight-line for buildings, declining balance for equipment). Store results in Account members: Project_NPV, Project_IRR, Monthly_EMI, Annual_Depreciation. Apply decision logic: IF NPV > 0 AND IRR > hurdle rate → set Smart List "Investment_Decision" = "Approved".
