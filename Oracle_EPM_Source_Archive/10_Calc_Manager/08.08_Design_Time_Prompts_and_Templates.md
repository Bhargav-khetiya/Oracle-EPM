# 08.08 — Design-Time Prompts and Templates: Complete Guide

> **Module:** 08_Calculation_Manager | **Topic:** Design-Time Prompts, Template Variables, Reusable Components
> **Audience:** Rule Developer

---

## 1. WHY — Reusable Rule Components

**The problem:** You build the same P&L calculation for 3 cubes. Each has slightly different dimension names. Copy-pasting creates 3 rules to maintain. When logic changes, you must update all 3.

**The solution:** Design-Time Prompts (DTPs) let you build ONE template with placeholders that resolve at design time. Change the template → all rules using it update.

---

## 2. DESIGN-TIME PROMPTS (DTPs)

### What They Are

DTPs are variables that resolve **when the rule is built** (not at runtime). They're like constants that a developer sets when creating a rule from a template.

```
Template: "CALC_PnL_Template"
  DTP: {{CUBE_NAME}} → Set by developer when creating rule
  DTP: {{ENTITY_DIM}} → Set by developer

Rule 1 (from template): CALC_PnL_FinPlan
  {{CUBE_NAME}} = "OEP_FS"
  {{ENTITY_DIM}} = "Entity"

Rule 2 (from template): CALC_PnL_Workforce
  {{CUBE_NAME}} = "OEP_WFP"
  {{ENTITY_DIM}} = "WF_Entity"
```

### DTP vs RTP Comparison

| Feature | Design-Time Prompt (DTP) | Runtime Prompt (RTP) |
|---------|-------------------------|---------------------|
| When resolved | During rule creation | When user launches rule |
| Who sets it | Developer | End user |
| Can change per execution | ❌ No (fixed) | ✅ Yes |
| Purpose | Reusable templates | User-driven parameters |
| Syntax | `{{DTP_Name}}` | `{RTP_Name}` |
| Stored in | Rule definition | Variable definition |

## 3. BUILDING A TEMPLATE

```
Calc Manager → New Template

Template Name: TPL_PnL_Calculation

Design-Time Prompts:
  {{SCENARIO}} → Type: Member, Dimension: Scenario
  {{ENTITY_ROOT}} → Type: Member, Dimension: Entity
  {{YEAR_VAR}} → Type: Text, Default: "&CurrYear"

Script:
  SET LOCKBLOCK ON;
  SET CALCPARALLEL 4;
  
  FIX({{SCENARIO}}, "Working", {{YEAR_VAR}})
    FIX(@RELATIVE("{{ENTITY_ROOT}}", 0))
      "Total_Revenue" = "Room_Revenue" + "F&B_Revenue" + "Spa_Revenue";
      "Total_Expenses" = "Labor" + "Maintenance" + "Utilities";
      "Net_Income" = "Total_Revenue" - "Total_Expenses";
      IF("Total_Revenue" <> 0)
        "Profit_Margin" = "Net_Income" / "Total_Revenue" * 100;
      ENDIF
    ENDFIX
  ENDFIX
  
  SET LOCKBLOCK OFF;
```

### Creating Rules from Template

```
Right-click template → Create Rule from Template

Prompt: Set DTP values
  {{SCENARIO}} → "Budget"
  {{ENTITY_ROOT}} → "All_Hotels"
  {{YEAR_VAR}} → "&CurrYear"

Result: Rule "CALC_PnL_Budget" created with DTPs resolved
```

## 4. TEMPLATE CATEGORIES IN CALC MANAGER

| Category | Templates Available | Purpose |
|----------|-------------------|---------|
| **System** | Consolidation, Currency, Allocation | Pre-built by Oracle |
| **Application** | Custom templates you create | Reusable across rules |
| **Component** | Formula, Script, Condition | Building blocks |
