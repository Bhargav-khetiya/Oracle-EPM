## 1. SYSTEM TEMPLATES (Pre-Built by Oracle)

| Template | Category | What It Does | When to Use |
|----------|----------|-------------|-------------|
| **Aggregation** | System | AGG on selected dimension | When you need to roll up data |
| **Copy Data** | System | DATACOPY between members | Budget seeding, version copy |
| **Clear Data** | System | CLEARDATA on selection | Before data reload or seeding |
| **Currency Conversion** | System | Convert using exchange rates | Multi-currency reporting |
| **Allocation** | System | Distribute amounts using drivers | Corporate cost allocation |
| **Smart Push** | System | Push data to another cube | Cross-cube data sync |
| **Force Calculate** | System | Force calc on specific members | Override Intelligent Calc |
| **Member Formula** | System | Apply member formula | Dynamic calc members |

---

## 2. COMPONENT TEMPLATES (Building Blocks)

| Component | Type | Purpose | Example |
|-----------|------|---------|---------|
| **Formula** | Component | Single calculation line | `"Net" = "Rev" - "Exp"` |
| **Script** | Component | Multi-line calc block | FIX/ENDFIX with multiple calcs |
| **Condition** | Component | IF/ELSEIF/ELSE logic | `IF("Rev" > 0)` |
| **Loop** | Component | Iterate over members | Process each entity |
| **Fixed Loop** | Component | Loop N times | Process 12 months |
| **Member Range** | Component | Select members dynamically | @CHILDREN, @DESCENDANTS |
| **Comments** | Component | Documentation | Rule description |

## 3. HOTEL PVT LTD CUSTOM TEMPLATES

```
TPL_Standard_PnL
  Purpose: Calculate P&L for any scenario
  DTPs: {{SCENARIO}}, {{ENTITY_ROOT}}, {{YEAR}}
  Components: [Script: Revenue] → [Script: Expense] → [Script: P&L] → [AGG]

TPL_Budget_Seed
  Purpose: Clear + Copy + Transform
  DTPs: {{SOURCE_SCENARIO}}, {{TARGET_SCENARIO}}, {{GROWTH_RATE}}
  Components: [Clear] → [Copy] → [Transform]

TPL_Allocation
  Purpose: Distribute by revenue share
  DTPs: {{SOURCE_MEMBER}}, {{TARGET_ACCOUNT}}, {{DRIVER_ACCOUNT}}
  Components: [Get Total] → [Calculate Share] → [Allocate]
```

---

## 4. CREATING RULES FROM TEMPLATES

```
Calc Manager → Templates → Right-click → Create Rule

Step 1: Select template → TPL_Standard_PnL
Step 2: Set DTPs:
  {{SCENARIO}} = "Budget"
  {{ENTITY_ROOT}} = "All_Hotels"
  {{YEAR}} = "&CurrYear"
Step 3: Name the rule → CALC_PnL_Budget
Step 4: Validate → Deploy → Attach to form
```
