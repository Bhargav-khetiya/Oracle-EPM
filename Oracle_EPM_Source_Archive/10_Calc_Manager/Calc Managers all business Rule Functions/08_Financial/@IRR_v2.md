# @IRR

## Overview

`@IRR` is a **financial function** in Oracle EPM Cloud (PBCS/EPBCS) Calc Manager that calculates the **Internal Rate of Return** for a series of cash flows. The IRR is the discount rate that makes the Net Present Value (NPV) of all cash flows (both positive and negative) from a particular investment equal to zero.

### Why Does This Function Exist?

IRR is a universally accepted metric used alongside NPV to evaluate and compare the profitability of investments:
- **Project Selection**: If a project's IRR exceeds the company's hurdle rate (cost of capital), the project is typically approved.
- **Relative Comparison**: Comparing a project with a 15% IRR against one with a 12% IRR to allocate limited capital.
- **Private Equity / Real Estate**: Standard metric for evaluating the performance of an asset over its holding period.

### When to Use It

- In Capital Expense (CapEx) planning models to evaluate asset purchases.
- In strategic workforce planning to evaluate the ROI of hiring initiatives or training programs.
- When discounting cash flows, and you want to know the exact breakeven discount rate.

## Syntax

```essbase
@IRR(cashflowMbr, XrangeList)
```

### Formal Syntax

```
@IRR(cashflowMember, crossDimRange)
```

Where:
- `cashflowMember` — The member containing the periodic cash flows.
- `crossDimRange` — The time range over which the cash flows occur.

---

## Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `cashflowMember` | Member name | ✅ Yes | The account or measure containing the cash flows. The series must contain at least one negative value (outflow, usually the initial investment) and at least one positive value (inflow, the returns). |
| `crossDimRange` | Range | ✅ Yes | The range of periods containing the cash flows. Usually generated by `@XRANGE` (e.g., `@XRANGE("FY24", "FY29")`). |

---

## Return Value

**Return Type**: Numeric (double-precision floating point)

Returns the internal rate of return as a decimal (e.g., `0.15` for 15%). 
If the cash flow series does not contain at least one positive and one negative value, or if the mathematical algorithm fails to converge on a single rate (which can happen with alternating cash flow signs), it returns `#MISSING`.

---

## How It Works (Behind the Scenes)

1. **Iterative Algorithm**: Because there is no algebraic formula to solve for IRR, Essbase uses an iterative mathematical algorithm (similar to Excel's IRR function) to hunt for the rate that makes NPV = 0.
2. **First Cash Flow**: Unlike `@NPV`, which assumes the first period in the range is discounted (Period 1), IRR calculations conceptually assume the first value in the range is Time 0 (the initial investment).
3. **Periodicity**: The IRR returned corresponds to the frequency of the periods in the range. If the range is months, the function returns a *monthly* IRR.

## Syntax Variants & Scenarios

### Variant 1: Annual IRR

```essbase
"Project_IRR" = @IRR("Net_Cash_Flow", @XRANGE("FY24", "FY29"));
```

### Variant 2: Monthly IRR

```essbase
"Monthly_IRR" = @IRR("Net_Cash_Flow", @XRANGE("FY24"->"Jan", "FY29"->"Dec"));
```

### Variant 3: Annualized Monthly IRR

```essbase
/* To convert a monthly IRR to an annual IRR: Annual = (1 + Monthly)^12 - 1 */
VAR vMonthlyIRR = @IRR("Net_Cash_Flow", @XRANGE("FY24"->"Jan", "FY29"->"Dec"));
"Annual_IRR" = @POWER(1 + vMonthlyIRR, 12) - 1;
```

## Practical Examples

### Example 1: Evaluating a Capital Project

**Scenario**: A company invests 500k in FY24 and expects returns in FY25-FY29. Calculate the IRR and compare it to a 10% hurdle rate.

```essbase
FIX("Working", "Project_Beta")
    /* Calculate IRR over the 6-year lifespan (Initial + 5 years return) */
    "Calculated_IRR" = @IRR("Net_Cash_Flow", @XRANGE("FY24", "FY29"));
    
    /* Determine if project meets the 10% hurdle rate */
    IF("Calculated_IRR" >= 0.10)
        "Approval_Status" = 1; /* Approved */
    ELSE
        "Approval_Status" = 0; /* Rejected */
    ENDIF
ENDFIX
```

---

### Example 2: Real Estate Investment Analysis (Monthly)

**Scenario**: Calculate the annualized IRR for a property purchased in Jan FY24 and sold in Dec FY28.

```essbase
FIX("Working", "Property_01")
    /* Calculate the raw monthly IRR */
    VAR vMonthlyIRR = @IRR("Cash_Flow", @XRANGE("FY24"->"Jan", "FY28"->"Dec"));
    
    /* Convert to Annualized IRR for reporting */
    IF(vMonthlyIRR != #MISSING)
        "Annualized_IRR" = @POWER(1 + vMonthlyIRR, 12) - 1;
    ENDIF
ENDFIX
```

## Common Mistakes & Gotchas

| Mistake | Explanation | Fix |
|---------|-------------|-----|
| Missing initial investment | If all cash flows are positive (no investment), IRR cannot be calculated | Ensure the first period contains a negative cash flow (outlay) |
| Assuming Annual Return on Monthly Data | Calling `@IRR` on monthly data returns a monthly rate (e.g., ~1%), not an annual rate (e.g., ~12%) | Annualize the result using `@POWER(1+rate, 12) - 1` |
| Multiple IRRs | If cash flows alternate between positive and negative multiple times, mathematics dictate there can be multiple valid IRRs | The algorithm will return one of them, but be aware of the "Multiple IRR Problem" in finance |
| Not using `@XRANGE` | `@RANGE("FY24":"FY29")` is invalid syntax for cross-dimensional ranges | Always use `@XRANGE` for multi-year cash flows |
