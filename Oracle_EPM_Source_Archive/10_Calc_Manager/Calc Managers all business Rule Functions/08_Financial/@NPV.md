# @NPV

## Overview

`@NPV` is a **financial function** in Oracle EPM Cloud (PBCS/EPBCS) Calc Manager that calculates the **Net Present Value** of an investment. It computes the current value of a series of future cash flows, discounted at a specified rate.

### Why Does This Function Exist?

NPV is a fundamental metric in corporate finance and capital planning:
- **Capital Budgeting**: Evaluating whether a new project or asset purchase will generate a positive return.
- **Investment Appraisal**: Comparing multiple investment options by bringing all future cash flows back to "today's dollars."
- **Valuation**: Determining the value of an asset based on its expected cash generation.
- **Lease Analysis**: Calculating the present value of lease payments.

### When to Use It

- When evaluating the profitability of a proposed project.
- In Capital Asset Planning cubes to evaluate equipment purchases.
- When discounting future revenue streams to a present value.
- To compare projects with different cash flow profiles over time.

## Syntax

```essbase
@NPV(cashflowMbr, rateMbr, XrangeList)
```

### Formal Syntax

```
@NPV(cashflowMember, discountRate, crossDimRange)
```

Where:
- `cashflowMember` — The member containing the periodic cash flows.
- `discountRate` — The discount rate to apply (e.g., 0.08 for 8%).
- `crossDimRange` — The time range over which the cash flows occur.

---

## Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `cashflowMember` | Member name | ✅ Yes | The account or measure containing the cash flows (positive for inflows, negative for outflows). |
| `discountRate` | Numeric/Member | ✅ Yes | The discount rate per period. Can be a constant (e.g., `0.10`), a variable, or a member reference. It must match the period frequency (e.g., an annual rate of 12% must be divided by 12 for monthly cash flows). |
| `crossDimRange` | Range | ✅ Yes | The range of periods to evaluate. Usually generated by `@XRANGE` (e.g., `@XRANGE("FY25"->"Jan", "FY29"->"Dec")`). |

---

## Return Value

**Return Type**: Numeric (double-precision floating point)

Returns the Net Present Value of the cash flows. If any cash flow in the range is `#MISSING`, it is treated as zero.

---

## How It Works (Behind the Scenes)

1. **Mathematical Formula**: 
   `NPV = Σ [ CashFlow_t / (1 + Rate)^t ]`
   Where `t` is the period index (1 for the first period, 2 for the second, etc.).
2. **Initial Cash Flow**: In standard financial theory, period 0 (the initial investment) is not discounted. However, **Essbase `@NPV` discounts the first period in the range as Period 1**. If the first value in your range is the initial investment at Time 0, you should exclude it from the `@NPV` range and add it manually to the result.
3. **Discount Rate Frequency**: The discount rate must match the periodicity of the range. If the range is months, the rate must be a monthly rate.

## Syntax Variants & Scenarios

### Variant 1: Simple NPV (Annual)

```essbase
"Project_NPV" = @NPV("Net_Cash_Flow", "Discount_Rate", @XRANGE("FY25", "FY29"));
```

### Variant 2: Adjusting for Time 0 Investment

```essbase
/* Assuming "FY24" is the initial investment (Time 0) and FY25-FY29 are returns */
"Project_NPV" = "Initial_Investment" -> "FY24" + 
                @NPV("Net_Cash_Flow", 0.08, @XRANGE("FY25", "FY29"));
```

### Variant 3: Monthly NPV

```essbase
"Project_NPV" = @NPV("Net_Cash_Flow", "Annual_Rate"/12, @XRANGE("FY25"->"Jan", "FY29"->"Dec"));
```

## Practical Examples

### Example 1: Capital Project Evaluation

**Scenario**: A company is evaluating a 5-year project. The hurdle rate (discount rate) is 10% annually. The initial investment occurs in Year 0, and cash flows occur in Years 1-5.

```essbase
FIX("Working", "Project_Alpha")
    /* Year 0 Investment */
    VAR vInitialOutlay = "Net_Cash_Flow" -> "FY24"; /* Usually negative */
    
    /* Calculate PV of future cash flows (Years 1-5) */
    VAR vPV_Future = @NPV("Net_Cash_Flow", 0.10, @XRANGE("FY25", "FY29"));
    
    /* Total NPV */
    "Calculated_NPV" = vInitialOutlay + vPV_Future;
    
    /* Determine if project is approved */
    IF("Calculated_NPV" > 0)
        "Project_Status" = 1; /* Approved */
    ELSE
        "Project_Status" = 0; /* Rejected */
    ENDIF
ENDFIX
```

---

### Example 2: Monthly Lease Valuation

**Scenario**: Calculate the present value of monthly lease payments over 3 years.

```essbase
FIX("Working", "Lease_001")
    VAR vMonthlyRate = "Annual_Borrowing_Rate" / 12;
    
    "Present_Value_of_Lease" = @NPV("Lease_Payment", vMonthlyRate, 
                                     @XRANGE("FY25"->"Jan", "FY27"->"Dec"));
ENDFIX
```

## Common Mistakes & Gotchas

| Mistake | Explanation | Fix |
|---------|-------------|-----|
| Including Time 0 in the range | `@NPV` discounts the first period in the range. If that's Day 1, it shouldn't be discounted. | Exclude the initial investment from the `@NPV` range and add it to the result. |
| Mismatched rate frequency | Using a 10% annual rate on monthly cash flows aggressively undervalues them | Divide the annual rate by 12 for monthly ranges: `Rate/12` |
| Using `@RANGE` across years | `@RANGE("Jan":"Dec")` fails if the cash flows cross a year boundary | Always use `@XRANGE` for multi-year cash flows |
| Sign convention | Inflows must be positive, outflows negative for NPV to work correctly | Ensure data input follows standard accounting signs |
