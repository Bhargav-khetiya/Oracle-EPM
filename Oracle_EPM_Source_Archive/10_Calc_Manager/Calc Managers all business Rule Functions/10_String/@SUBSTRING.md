# @SUBSTRING

## Overview

`@SUBSTRING` is a **string manipulation function** in Oracle EPM Cloud (PBCS/EPBCS) Calc Manager that extracts a specific portion (a substring) from a given string. It allows you to parse text by starting at a specific character position and optionally defining how many characters to extract.

### Why Does This Function Exist?

While Essbase is primarily a numeric engine, strings are frequently used for dynamic member names, dates, and variable concatenation:
- **Date Parsing**: Extracting the month `"09"` from a YYYYMMDD string `"20240925"`.
- **Dynamic References**: Stripping prefixes/suffixes from member names (e.g., turning `"Entity_101"` into `"101"` to cross-reference a related account `"Cost_101"`).
- **String Building**: Extracting the year `"24"` from `"FY24"` to use in date math.

### When to Use It

- When you need to parse a dynamic string or variable to extract a usable numeric or text component.
- When dynamically constructing member names using `@CONCATENATE` and you only need part of the source string.
- When working with dates generated by `@TODAY()`.

## Category

**String / Text Manipulation**

---

## Syntax

```essbase
@SUBSTRING(string, startIndex [, length])
```

### Formal Syntax

```
@SUBSTRING("stringExpr", startPosition, [lengthOfSubstring])
```

Where:
- `"stringExpr"` — The source text.
- `startPosition` — The index position to start extracting (1-based index).
- `lengthOfSubstring` — (Optional) How many characters to extract. If omitted, extracts to the end of the string.

---

## Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `string` | String | ✅ Yes | The source string to parse. Can be a literal in quotes (`"Text"`), a string variable, or a function that returns a string. |
| `startIndex` | Integer | ✅ Yes | The starting character position. **Essbase string indices are 1-based** (the first character is 1). |
| `length` | Integer | ❌ No | The number of characters to extract. If omitted, returns everything from the `startIndex` to the end of the string. |

---

## Return Value

**Return Type**: String

Returns the extracted portion of the text as a string.

---

## How It Works (Behind the Scenes)

1. **1-Based Indexing**: If the string is `"FY25"`, position 1 is `F`, position 2 is `Y`, position 3 is `2`, position 4 is `5`.
2. **Length Handling**: If the requested length exceeds the remaining characters in the string, Essbase simply returns all available characters up to the end without throwing an error.
3. **Type Conversion**: `@SUBSTRING` always returns a string. If you extract `"25"` and need to use it in a mathematical formula, you must convert it using `@CalcMgrStringToNumber()`.

---

## Syntax Variants & Scenarios

### Variant 1: Extract to the End (No length specified)

```essbase
@SUBSTRING("FY24", 3)
/* Starts at character 3 ('2'). Returns "24" */
```

### Variant 2: Specific Length

```essbase
@SUBSTRING("20241027", 5, 2)
/* Starts at character 5 ('1'), takes 2 characters. Returns "10" (the month) */
```

### Variant 3: With Member Names

```essbase
@SUBSTRING(@NAME(@CURRMBR("Entity")), 8)
/* If entity is "Entity_405", starts at char 8, returns "405" */
```

## Practical Examples

### Example 1: Parsing the Current Year from @TODAY()

**Scenario**: You want to dynamically determine the current year, month, and day for stamping a record. `@TODAY()` returns `YYYYMMDD` (e.g., `20241027`).

```essbase
VAR vTodayDate = @CalcMgrIntegerToString(@TODAY()); /* Convert numeric date to string "20241027" */

/* Extract components */
VAR vYearStr = @SUBSTRING(vTodayDate, 1, 4);   /* "2024" */
VAR vMonthStr = @SUBSTRING(vTodayDate, 5, 2);  /* "10" */
VAR vDayStr = @SUBSTRING(vTodayDate, 7, 2);    /* "27" */

/* Convert year back to number if needed */
VAR vYearNum = @CalcMgrStringToNumber(vYearStr);
```

---

### Example 2: Dynamic Cross-Referencing

**Scenario**: Your entities are named `E_101`, `E_102`. Your project members are named `P_101`, `P_102`. You want to dynamically push data from the entity to the matching project.

```essbase
FIX("FY25", "Working", @CHILDREN("Total Entity"))
    /* Extract the numeric ID part of the Entity (e.g., "101" from "E_101") */
    VAR vEntityID = @SUBSTRING(@NAME(@CURRMBR("Entity")), 3);
    
    /* Rebuild the project name (e.g., "P_101") */
    VAR vProjectName = @CONCATENATE("P_", vEntityID);
    
    /* Use the dynamically built string to push data */
    "Allocated_Expense" -> @MEMBER(vProjectName) = "Corporate_Overhead" * 0.10;
ENDFIX
```

## Common Mistakes & Gotchas

| Mistake | Explanation | Fix |
|---------|-------------|-----|
| 0-Based Indexing | In Java/Python, the first char is 0. In Essbase, the first char is 1 | Use `1` as the starting index for the first character |
| Using string in math | `"25" + 5` fails because `"25"` is a string | Wrap the result in `@CalcMgrStringToNumber()` before doing math |
| Missing `@NAME` wrapper | `@SUBSTRING(@CURRMBR("Entity"), 1)` fails because `@CURRMBR` returns a member reference, not a string | Use `@NAME(@CURRMBR("Entity"))` to convert the member to a string first |
