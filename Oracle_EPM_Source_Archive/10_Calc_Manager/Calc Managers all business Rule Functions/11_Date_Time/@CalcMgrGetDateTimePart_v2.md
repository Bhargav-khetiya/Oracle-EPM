# @CalcMgrGetDateTimePart

## Overview

`@CalcMgrGetDateTimePart` is a **custom Calc Manager time extraction function** in Oracle EPM Cloud (PBCS/EPBCS). It acts as a scalpel, dissecting a unified **Java Timestamp Object** and extracting one specific Time-of-Day component (such as the Hour, Minute, or Second), returning it as a usable integer.

### Why Does This Function Exist—

While `@CalcMgrGetDatePart` pulls out the Calendar elements (Year, Month, Day) from a Java object, it cannot touch the clock data. If your script uses `@CalcMgrGetCurrentDateTime()` to capture the exact current time to monitor a processing SLA, the resulting Timestamp Object is unreadable to standard Essbase logic. 
If a corporate SLA rule states, "Reject all data submissions that arrive after 6:00 PM", the calculation script must isolate just the "Hour" component from the Timestamp Object to check if it is greater than `18`. 
`@CalcMgrGetDateTimePart` does exactly this. It queries the Java Timestamp architecture directly, pulls out the specific Hour, Minute, or Second integer you requested, and passes it back into the Essbase calc script. This allows you to execute dynamic time-of-day IF statements effortlessly.

### When to Use It

- **Time-of-Day Routing**: Extracting the Hour to determine if a transaction belongs in the "Morning Shift" or "Evening Shift" data bucket.
- **SLA Enforcement**: Extracting the Minute to verify if an automated data integration completed within its 15-minute operational window.
- **Log Parsing**: Shredding a Java Timestamp Object into Hour, Minute, and Second integers so they can be mathematically recombined into a custom Time integer (e.g., `184500`) for storage in a numeric account.

## Syntax

```essbase
@CalcMgrGetDateTimePart(date, date_time_part_ex)
```

---

## Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `date` | Object | ✅ Yes | The Java Date/Timestamp Object to be dissected. |
| `date_time_part_ex` | String | ✅ Yes | A text string specifying exactly which time part to extract. Valid options: <br>`"hour"` (or `"h"`) - Returns 0-23<br>`"minute"` (or `"m"`) - Returns 0-59<br>`"second"` (or `"s"`) - Returns 0-59 |

---

## Return Value

**Return Type**: Numeric (Integer)

Returns the requested time component as an integer.
- **Hours are 24-hour (Military) Time**: If the timestamp is 5:00 PM, extracting the `"hour"` will return `17`. Midnight is `0`.
- If you pass an object generated by `@CalcMgrGetCurrentDate` (which intentionally zeroes out the time), extracting the `"hour"` will always return `0`. You must use a Timestamp object generated by a DateTime function.

---

## How It Works (Behind the Scenes)

1. **Parameter Ingestion**: The Java engine receives the Timestamp Object and the string keyword.
2. **Keyword Routing**: It evaluates the string (e.g., `"hour"`) and calls the corresponding native Java `Calendar.get(Calendar.HOUR_OF_DAY)` method.
3. **Execution**: It extracts the integer value directly from the object's memory.
4. **Return**: Passes the finalized integer back to Essbase.

/* Assumes vTimeObj is exactly 6:45 PM. Returns 18. */
VAR vHour = @CalcMgrGetDateTimePart(vTimeObj, "hour");

## Practical Examples

### Example 1: Creating Shift-Based Activity Logs

**Scenario**: A manufacturing plant runs three shifts (Shift 1: 00:00 - 08:00, Shift 2: 08:00 - 16:00, Shift 3: 16:00 - 24:00). A machine telemetry system pings EPM with the exact time a part was completed. The calculation script must extract the Hour from that timestamp and dynamically assign the production volume to the correct Shift member in the database.

```essbase
FIX("FY25", "Working", @LEVEL0("Products"))
    
    IF("Production_Units" > 0 AND "Telemetry_Timestamp_Raw" != #MISSING)
        
        /* 
           1. Convert the raw telemetry data into a Java Timestamp Object.
           (Assuming the telemetry data arrived as an Excel Serial number).
        */
        VAR vTimeObj = @CalcMgrExcelToDateTime("Telemetry_Timestamp_Raw");
        
        /* 
           2. Extract just the Hour (0-23 format) 
        */
        VAR vProductionHour = @CalcMgrGetDateTimePart(vTimeObj, "hour");
        
        /* 
           3. Map the production volume to the correct Shift member using IF logic.
        */
        IF(vProductionHour < 8)
            "Shift_1_Volume" = "Production_Units";
        ELSEIF(vProductionHour >= 8 AND vProductionHour < 16)
            "Shift_2_Volume" = "Production_Units";
        ELSEIF(vProductionHour >= 16)
            "Shift_3_Volume" = "Production_Units";
        ENDIF
        
    ENDIF
    
ENDFIX
```

## Common Mistakes & Gotchas

| Mistake | Explanation | Fix |
|---------|-------------|-----|
| Passing Essbase Integers | `@CalcMgrGetDateTimePart(20241231, "hour")` | This function explicitly requires a **Java Timestamp Object**. If you pass a native Essbase integer or an Excel Serial Decimal, the Java engine will fail or crash. You must convert serial numbers into Java Objects first using `@CalcMgrExcelToDateTime` |
| 12-Hour vs 24-Hour | Expecting `5` for 5:00 PM | The `"hour"` extraction strictly returns 24-hour time. If your downstream IF statement says `IF(vHour > 12)`, be aware that 1:00 PM (13) will trigger it. There is no AM/PM indicator |
| Spelling Errors | `"hours"` instead of `"hour"` | The `date_time_part_ex` string must perfectly match the documented keywords (singular, not plural). If you pass `"hours"`, the Java engine will throw an IllegalArgumentException and crash the calc script |
