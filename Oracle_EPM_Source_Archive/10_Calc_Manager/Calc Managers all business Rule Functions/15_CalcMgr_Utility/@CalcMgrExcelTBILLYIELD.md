# @CalcMgrExcelTBILLYIELD

## Overview

`@CalcMgrExcelTBILLYIELD` is a **custom Calc Manager financial math function** in Oracle EPM Cloud (PBCS/EPBCS). It perfectly replicates the behavior of the Microsoft Excel `TBILLYIELD` function directly inside an Essbase calculation script. 
It calculates the **Yield** of a Treasury Bill (T-Bill) based on its current market purchase price.

### Why Does This Function Exist?

When a corporate treasury buys a T-Bill in the secondary market, they rarely buy it at the exact quoted discount rate. Market fluctuations mean the price goes up and down. If a company buys a T-Bill for $97.50 (per $100 face value) that matures in 90 days, the CFO wants to know the *true* Yield they are earning on that specific investment. 
To reverse-engineer the true yield from the purchase price requires calculating the exact days remaining until maturity, assuming a 360-day banking year, and running an inverse pricing algebra equation.
`@CalcMgrExcelTBILLYIELD` offloads this calendar math and inverse algebra to the Java engine. It returns the exact true yield instantly, ensuring your EPM portfolio dashboards perfectly match legacy Treasury Excel sheets.

### When to Use It

- **Portfolio Performance**: Calculating the true yield of existing T-Bill holdings based on the historical purchase price, rather than current market rates.
- **Yield Validation**: Verifying that a broker's quoted return matches the mathematical reality of the cash price they are charging.
- Whenever you need to migrate an Excel spreadsheet containing the `TBILLYIELD` function directly into an Essbase calculation.

## Syntax

```essbase
@CalcMgrExcelTBILLYIELD(settlement, maturity, pr)
```

*(Note: The parameters map 1-to-1 with the Excel function).*

---

## Parameters

All date parameters must be passed as `YYYYMMDD` integers, not Java Date objects.

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `settlement` | Integer | ✅ Yes | The settlement date (`YYYYMMDD`). The date the T-Bill is purchased. |
| `maturity` | Integer | ✅ Yes | The maturity date (`YYYYMMDD`). The date the T-Bill expires. Must be > `settlement`. Must be within 1 year of settlement. |
| `pr` | Numeric | ✅ Yes | The price of the T-Bill per $100 of face value (e.g., `97.50`). Must be > 0. |

---

## Return Value

**Return Type**: Numeric (double-precision floating point)

Returns the exact Yield as a decimal.
- E.g., Returns `0.052` (representing a 5.2% true yield).

---

## How It Works (Behind the Scenes)

1. **Parameter Validation**: The Java engine ensures dates are valid integers, `pr` > 0, and the maturity is less than 365 days after the settlement.
2. **Day-Count Math**: It calculates the exact number of days remaining (`DSM`) between the settlement and maturity dates, assuming a standard Actual/360 T-Bill calendar basis.
3. **Inverse Equation**: It executes the standard Treasury yield algorithm: `((100 - pr) / pr) * (360 / DSM)`.
4. **Return**: Passes the finalized yield decimal back to Essbase.

/*

## Practical Examples

### Example 1: Reporting Portfolio Performance

**Scenario**: A corporate treasury dashboard lists their T-Bill holdings. They know exactly how much they paid for each bill (`"Purchase_Price_Per_100"`). The CFO wants a report showing the true annualized yield generated by these investments to compare against the corporate hurdle rate of 4.0%.

```essbase
FIX("FY25", "Working", @LEVEL0("Cash_Equivalents"))
    
    IF("Purchase_Price_Per_100" > 0 AND "Purchase_Date" != #MISSING)
        
        /* 1. Calculate the true Yield */
        "Calculated_True_Yield" = @CalcMgrExcelTBILLYIELD(
            "Purchase_Date", 
            "Maturity_Date", 
            "Purchase_Price_Per_100"
        );
        
        /* 2. Flag under-performing investments */
        IF("Calculated_True_Yield" < "Corporate_Hurdle_Rate")
            "Under_Performance_Flag" = 1;
        ELSE
            "Under_Performance_Flag" = 0;
        ENDIF
        
    ENDIF
    
ENDFIX
```

## Common Mistakes & Gotchas

| Mistake | Explanation | Fix |
|---------|-------------|-----|
| Over 1 Year Maturity | Passing dates 3 years apart | By US Treasury definition, T-Bills have a maturity of 1 year or less (52 weeks). The `TBILLYIELD` formula relies on this assumption. If the maturity date is more than 1 year past the settlement date, the function will fail and return `#MISSING`. If you need to calculate the yield of a longer-term zero-coupon bond, use `@CalcMgrExcelYIELDDISC` |
| Total Value Instead of Price | Passing `$10,000,000` | The `pr` parameter strictly expects the clean price *per $100 of face value* (e.g., `97.50`). If you pass the total cash value of your trade (`9,750,000`), the function's internal algebra `(100 - pr)` will become massively negative, and the function will fail |
| Whole Number Output | Expecting `5` instead of `0.05` | `TBILLYIELD` strictly returns a decimal. If you want to display this on a report as `5.00%`, you must either format the reporting cell as a percentage, or multiply the output by 100 within Essbase |
