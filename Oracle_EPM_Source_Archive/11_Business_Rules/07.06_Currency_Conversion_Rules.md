# 07.06 — Currency Conversion Rules: Complete Guide

> **Module:** 07_Business_Rules | **Topic:** Multi-Currency, Exchange Rates, Conversion Logic
> **Audience:** Service Administrator / Architect

---

## 1. WHY — What Real-World Problem Does This Solve—

**The problem:** Hotel Pvt Ltd operates in India (INR) but reports to global investors in USD. Mumbai's revenue is ₹4.5 Cr — the CFO needs to see it as $540,000 on the consolidated report. If exchange rates change monthly, 5 hotels × 200 accounts × 12 months = 12,000 conversions. Manual conversion is impossible.

**The solution:** A currency conversion rule that applies exchange rates to all accounts, all entities, all periods — converting from local currency (INR) to reporting currency (USD) automatically.

## 2. MULTI-CURRENCY SETUP

### Dimension Requirements

```
Currency Dimension (required for multi-currency apps):
  Local     → Entity's input currency (INR for India hotels)
  USD       → US Dollar (reporting currency)
  EUR       → Euro (if needed)
  GBP       → British Pound (if needed)

Account Property:
  Exchange Rate Type:
    Average  → For P&L items (Revenue, Expenses)
    Ending   → For Balance Sheet items (Assets, Liabilities)
    None     → For ratios/percentages (no conversion needed)
```

### Exchange Rate Table

```
Member: Exchange_Rate_Avg (Average rate)
Member: Exchange_Rate_End (Ending rate)

                │ Jan    │ Feb    │ Mar    │ ...  │ Dec
────────────────┼────────┼────────┼────────┼──────┼────────
INR_to_USD_Avg  │ 0.0120 │ 0.0119 │ 0.0121 │ ...  │ 0.0118
INR_to_USD_End  │ 0.0119 │ 0.0120 │ 0.0120 │ ...  │ 0.0117
INR_to_EUR_Avg  │ 0.0110 │ 0.0109 │ 0.0111 │ ...  │ 0.0108

Rate entry form: Admin enters rates monthly
```

## 3. CONVERSION PATTERNS

### Pattern 1: Simple Conversion (Average Rate for P&L)

```essbase
/* Convert all P&L accounts from Local (INR) to USD */
FIX("Budget", "Working", &CurrYear)
  FIX(@RELATIVE("All_Hotels", 0))
    FIX(@CHILDREN("YearTotal"))  /* Each month */
      FIX(@DESCENDANTS("Net_Income"))  /* All P&L accounts */
        "USD" = "Local" * "Exchange_Rate_Avg" -> "Currency_Rates";
      ENDFIX
    ENDFIX
  ENDFIX
ENDFIX
```

### Pattern 2: Different Rates for Different Account Types

```essbase
/* P&L accounts: Average rate */
FIX("Budget", "Working", &CurrYear)
  FIX(@RELATIVE("All_Hotels", 0))
    FIX(@CHILDREN("YearTotal"))
    
      /* Revenue and Expenses: Average rate */
      FIX(@DESCENDANTS("Total_Revenue"), @DESCENDANTS("Total_Expenses"))
        "USD" = "Local" * "Exchange_Rate_Avg";
      ENDFIX
      
      /* Balance Sheet: Ending rate */
      FIX(@DESCENDANTS("Total_Assets"), @DESCENDANTS("Total_Liabilities"))
        "USD" = "Local" * "Exchange_Rate_End";
      ENDFIX
      
      /* Ratios: No conversion (already percentages) */
      FIX("Profit_Margin", "Occupancy_Rate", "RevPAR_Pct")
        "USD" = "Local";  /* Copy directly — percentages don't convert */
      ENDFIX
      
    ENDFIX
  ENDFIX
ENDFIX
```

### Pattern 3: Triangulation (INR → USD → EUR)

```essbase
/* For currencies without a direct rate, triangulate through USD */
/* INR → USD (direct), then USD → EUR */

/* Step 1: INR to USD */
FIX(@RELATIVE("All_Hotels", 0), @CHILDREN("YearTotal"))
  FIX(@DESCENDANTS("Net_Income"))
    "USD" = "Local" * "INR_to_USD_Rate";
  ENDFIX
ENDFIX

/* Step 2: USD to EUR */
FIX(@RELATIVE("All_Hotels", 0), @CHILDREN("YearTotal"))
  FIX(@DESCENDANTS("Net_Income"))
    "EUR" = "USD" * "USD_to_EUR_Rate";
  ENDFIX
ENDFIX
```

```
Calc Manager → Templates → System Templates → Currency Conversion

Parameters:
  Source Currency: Local
  Target Currency: USD
  Exchange Rate Member: Exchange_Rate_Avg
  Account Range: @DESCENDANTS("Net_Income")

Advantage: Handles edge cases (missing rates, triangulation, HSP_Rates)

### Conversion Result

```
Mumbai Hotel — January Budget:

Account          │ Local (INR)    │ × Rate   │ USD
─────────────────┼────────────────┼──────────┼────────────
Room Revenue     │ ₹85,00,000     │ × 0.0120 │ $102,000
F&B Revenue      │ ₹22,00,000     │ × 0.0120 │ $26,400
Spa Revenue      │ ₹5,00,000      │ × 0.0120 │ $6,000
Total Revenue    │ ₹1,12,00,000   │ × 0.0120 │ $134,400
Labor            │ ₹32,00,000     │ × 0.0120 │ $38,400

### Complete Conversion Rule

```essbase
/* ===== Hotel Pvt Ltd Currency Conversion ===== */
SET LOCKBLOCK ON;

@CalcMgrLogMessageTrace("Starting currency conversion");

FIX({RTP_Scenario}, {RTP_Version}, {RTP_Year})
  FIX(@RELATIVE("All_Hotels", 0))
    FIX(@CHILDREN("YearTotal"))
      
      /* P&L accounts — Average rate */
      FIX(@DESCENDANTS("Total_Revenue"),
          @DESCENDANTS("Total_Expenses"),
          @DESCENDANTS("EBITDA"),
          "Net_Income")
        "USD" = "Local" * "INR_USD_Avg";
      ENDFIX
      
      /* Ratios — direct copy (no conversion) */
      FIX("Profit_Margin", "Expense_Ratio", "Occupancy_Rate",
          "RevPAR_Pct", "ADR")
        "USD" = "Local";
      ENDFIX
      
    ENDFIX
  ENDFIX
  
  /* Aggregate converted values */
  FIX("USD")
    AGG("Entity");
  ENDFIX
ENDFIX

SET LOCKBLOCK OFF;
@CalcMgrLogMessageTrace("Currency conversion complete");
```

## 6. COMMON MISTAKES

| Mistake | Symptom | Fix |
|---------|---------|-----|
| Converting percentages/ratios | Profit Margin becomes 0.4196 instead of 41.96% | Copy ratios directly: `"USD" = "Local"` |
| Missing exchange rate for a month | Converted values = 0 | Validate all 12 months have rates before running |
| Wrong rate type (Average vs Ending) | Balance Sheet items use P&L rates | Map account types to correct rate types |
| Not aggregating after conversion | USD parent-level values are stale | Add `AGG("Entity")` in USD FIX after conversion |
| Rate precision too low | $102,000 shows as $102,000.00000 | Set rate precision to 5-6 decimals |
| Forgot to convert new accounts | New account shows 0 in USD | Update the FIX to include new account |

## 7. INTERVIEW QUESTIONS

### Beginner
**Q: Why do P&L items and Balance Sheet items use different exchange rates—**
> P&L items (Revenue, Expenses) occur **throughout the month** — they use the **Average rate** (average of all daily rates in the month). Balance Sheet items (Assets, Cash, Liabilities) represent **point-in-time balances** — they use the **Ending rate** (rate on the last day of the month). Percentages and ratios (Profit Margin, Occupancy%) are NOT converted — they're the same in any currency.

### Architect
**Q: Design the currency conversion strategy for Hotel Pvt Ltd reporting in both USD and EUR.**
> (1) **Rate management:** Create an Exchange Rate Entry form for admins to enter monthly INR→USD (Average + Ending) rates. For EUR, either enter INR→EUR directly or triangulate through USD. (2) **Conversion rule:** Two-pass approach: First convert INR→USD using direct rates. Then convert USD→EUR using USD→EUR rates. (3) **Account mapping:** Revenue/Expenses → Average rate. Assets/Liabilities → Ending rate. Ratios → direct copy. (4) **Execution:** Run after every data load and aggregation. Attach as On Save rule on key forms. Schedule nightly for batch. (5) **Validation:** Sum of converted hotels should equal converted total (within rounding tolerance of ±$1).
