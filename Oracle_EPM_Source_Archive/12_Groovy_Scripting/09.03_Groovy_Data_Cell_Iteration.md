# 09.03 — Groovy Data Cell Iteration: Complete Guide

> **Module:** 09_Groovy | **Topic:** DataCell Iterator, Cell Access, Cross-Dimensional Reads
> **Audience:** Service Administrator / Groovy Developer

---

## 1. WHY — What Real-World Problem Does This Solve?

**The problem:** Essbase calc scripts are powerful but limited — you can't send emails, call REST APIs, manipulate strings, or write complex conditional logic. When the CFO says "After approval, send an email AND copy data AND update the Smart List AND log the action" — calc scripts can't do all of that.

**The solution:** Groovy rules iterate over form cells using the `DataCell` iterator, enabling: reading/writing cell values, cross-dimensional lookups, Smart List manipulation, conditional logic, and integration with external systems.

---

## 2. THE DATACELL ITERATOR — HOW IT WORKS

```groovy
/* The iterator walks through every data cell on the form grid */
/* Each cell knows its position: which Account, Entity, Period, etc. */

operation.grid.dataCellIterator().each { DataCell cell ->
    // 'cell' represents one intersection on the form
    // You can read its value, write to it, check its dimension context
}
```

```
Form Grid (what the iterator walks):
┌──────────────────┬──────────┬──────────┬──────────┐
│ Account          │ Jan      │ Feb      │ Mar      │
├──────────────────┼──────────┼──────────┼──────────┤
│ Room_Revenue     │ cell(1)  │ cell(2)  │ cell(3)  │ ← Iterator visits 1,2,3
│ F&B_Revenue      │ cell(4)  │ cell(5)  │ cell(6)  │ ← then 4,5,6
│ Total_Revenue    │ cell(7)  │ cell(8)  │ cell(9)  │ ← then 7,8,9
└──────────────────┴──────────┴──────────┴──────────┘

cell.getMemberName("Account") → "Room_Revenue" (for cell 1)
cell.getMemberName("Period") → "Jan" (for cell 1)
cell.data → 8500000 (the value in the cell)
```

## 3. CELL OPERATIONS — COMPLETE REFERENCE

### Reading Cell Values

```groovy
/* Get numeric value */
double value = cell.data                      // 8500000.0

/* Check if missing */
boolean missing = cell.isMissing()            // false

/* Get dimension member context */
String account = cell.getMemberName("Account") // "Room_Revenue"
String entity = cell.getMemberName("Entity")   // "Mumbai_Hotel"
String period = cell.getMemberName("Period")    // "Jan"
String scenario = cell.getMemberName("Scenario") // "Budget"

/* Get Smart List display value */
String status = cell.getSmartListValue()       // "Approved"

/* Check if cell is read-only */
boolean readOnly = cell.isReadOnly()           // false
```

### Writing Cell Values

```groovy
/* Set a numeric value */
cell.data = 9000000                           // Set to ₹90,00,000

/* Set from calculation */
cell.data = cell.data * 1.05                  // 5% increase

/* Set to zero */
cell.data = 0

/* Clear (set to missing) */
cell.data = Double.NaN                        // Sets to #MISSING
```

### Cross-Dimensional Reads

```groovy
/* Read value from a different Scenario */
double actual = cell.crossDimCell("Scenario#Actual").data
double budget = cell.crossDimCell("Scenario#Budget").data
double variance = actual - budget

/* Read from different Year */
double priorYear = cell.crossDimCell("Year#FY2025").data

/* Read from different Account */
double revenue = cell.crossDimCell("Account#Total_Revenue").data

/* Read from multiple dimensions */
double priorActual = cell.crossDimCell("Scenario#Actual", "Year#FY2025").data

/* Write to a cross-dim cell */
cell.crossDimCell("Account#Variance").data = actual - budget
```

## 4. FILTERED ITERATION

```groovy
/* Iterate only specific members */

/* Single filter — only Room_Revenue cells */
operation.grid.dataCellIterator("Account#Room_Revenue").each { cell ->
    cell.data = cell.data * 1.05  // 5% increase for Room Revenue only
}

/* Multiple filters — specific Account AND Entity */
operation.grid.dataCellIterator(
    "Account#Room_Revenue",
    "Entity#Mumbai_Hotel"
).each { cell ->
    cell.data = cell.data * 1.10  // 10% for Mumbai Room Revenue
}

/* Programmatic filtering */
operation.grid.dataCellIterator().each { cell ->
    if (cell.getMemberName("Account") == "Room_Revenue" &&
        cell.getMemberName("Period") == "Jan") {
        cell.data = cell.data * 1.05
    }
}
```

## 5. COMMON GROOVY PATTERNS

### Pattern 1: Variance Calculation

```groovy
operation.grid.dataCellIterator("Account#Variance").each { cell ->
    double actual = cell.crossDimCell("Scenario#Actual").data
    double budget = cell.crossDimCell("Scenario#Budget").data
    cell.data = actual - budget
}

operation.grid.dataCellIterator("Account#Variance_Pct").each { cell ->
    double actual = cell.crossDimCell("Scenario#Actual").data
    double budget = cell.crossDimCell("Scenario#Budget").data
    cell.data = (budget != 0) ? ((actual - budget) / budget * 100) : 0
}
```

### Pattern 2: Copy with Growth

```groovy
/* RTPS: {RTP_GrowthRate} */
double growth = 1 + (rtps.RTP_GrowthRate as double) / 100

operation.grid.dataCellIterator("Scenario#Budget").each { cell ->
    double actualPY = cell.crossDimCell("Scenario#Actual", "Year#FY2025").data
    if (!cell.crossDimCell("Scenario#Actual", "Year#FY2025").isMissing()) {
        cell.data = actualPY * growth
    }
}
```

### Pattern 3: Smart List Workflow

```groovy
operation.grid.dataCellIterator("Account#Budget_Status").each { cell ->
    String status = cell.getSmartListValue()
    String entity = cell.getMemberName("Entity")
    
    if (status == "In Review") {
        // Auto-approve if variance is within 5%
        double variance = cell.crossDimCell("Account#Variance_Pct").data
        if (Math.abs(variance) <= 5) {
            cell.data = 3  // 3 = Approved (Smart List ID)
            println "Auto-approved ${entity} — variance ${variance}%"
        }
    }
}
```

### Pattern 4: Validation with Veto

```groovy
def errors = []

operation.grid.dataCellIterator("Account#Room_Revenue").each { cell ->
    if (cell.data < 0) {
        String entity = cell.getMemberName("Entity")
        String period = cell.getMemberName("Period")
        errors << "Negative revenue: ${entity}/${period} = ${cell.data}"
    }
}

operation.grid.dataCellIterator("Account#Occupancy_Rate").each { cell ->
    if (cell.data > 100) {
        String entity = cell.getMemberName("Entity")
        errors << "Occupancy > 100%: ${entity} = ${cell.data}%"
    }
}

if (errors.size() > 0) {
    throwVetoException("Validation failed:\n${errors.join('\n')}")
}
```

## 6. SHOW ME — Hotel Pvt Ltd Groovy Rule: Monthly KPI Calculation

```groovy
/* ===== Hotel KPI Calculator ===== */
/* Calculates: RevPAR, GOPPAR, Profit Margin, YoY Growth */
/* RTPS: {RTP_Scenario} {RTP_Year} */

String scenario = rtps.RTP_Scenario.toString()
String year = rtps.RTP_Year.toString()

println "=== Starting KPI Calculation: ${scenario}/${year} ==="

// Calculate RevPAR = Revenue / Available Rooms
operation.grid.dataCellIterator("Account#RevPAR").each { cell ->
    double revenue = cell.crossDimCell("Account#Room_Revenue").data
    double rooms = cell.crossDimCell("Account#Available_Rooms").data
    cell.data = (rooms > 0) ? (revenue / rooms) : 0
}

// Calculate Occupancy Rate = Occupied / Available * 100
operation.grid.dataCellIterator("Account#Occupancy_Rate").each { cell ->
    double occupied = cell.crossDimCell("Account#Occupied_Rooms").data
    double available = cell.crossDimCell("Account#Available_Rooms").data
    cell.data = (available > 0) ? (occupied / available * 100) : 0
}

// Calculate Profit Margin = Net Income / Revenue * 100
operation.grid.dataCellIterator("Account#Profit_Margin").each { cell ->
    double netIncome = cell.crossDimCell("Account#Net_Income").data
    double revenue = cell.crossDimCell("Account#Total_Revenue").data
    cell.data = (revenue > 0) ? (netIncome / revenue * 100) : 0
}

// YoY Growth = (This Year - Prior Year) / Prior Year * 100
operation.grid.dataCellIterator("Account#YoY_Growth").each { cell ->
    double thisYear = cell.crossDimCell("Account#Total_Revenue").data
    double priorYear = cell.crossDimCell("Account#Total_Revenue", "Year#FY2025").data
    cell.data = (priorYear > 0) ? ((thisYear - priorYear) / priorYear * 100) : 0
}

println "=== KPI Calculation Complete ==="
```

## 7. COMMON MISTAKES

| Mistake | Symptom | Fix |
|---------|---------|-----|
| Iterating all cells when only need one Account | Rule runs 10× slower than needed | Use filtered iterator: `dataCellIterator("Account#X")` |
| Not checking for #MISSING before division | NaN values in cells | `cell.isMissing()` or check `!= 0` |
| Writing to read-only cells | Silent failure (no error, no write) | Check `cell.isReadOnly()` |
| Missing RTPS comment header | RTPs not accessible | Add `/* RTPS: {RTP_Name} */` at top |
| Cross-dim to non-existent member | Null pointer exception | Validate member names |

## 8. INTERVIEW QUESTIONS

### Beginner
**Q: How do you read and write cell values in a Groovy rule?**
> Read: `double value = cell.data` returns the numeric value. `cell.getMemberName("Account")` returns the dimension member name. Write: `cell.data = newValue` sets the cell. The iterator `operation.grid.dataCellIterator()` walks through every data cell on the form. You can filter it: `dataCellIterator("Account#Revenue")` to only process Revenue cells.

### Architect
**Q: Calc script vs Groovy — when do you choose Groovy?**
> Use Groovy when: (1) You need external integration (email, REST API). (2) Complex string manipulation or conditional logic. (3) Smart List value comparisons (text-based). (4) Validation with user-friendly error messages (throwVetoException). (5) Cross-cube reads with DataMaps. Use Calc Script when: (1) Simple aggregation and math. (2) Performance-critical calculations (calc scripts are faster for pure math). (3) SET commands (LOCKBLOCK, CALCPARALLEL). (4) AGG, DATACOPY operations. Rule of thumb: Math → Calc Script. Logic → Groovy.
