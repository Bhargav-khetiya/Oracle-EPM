## 1. WHY — What Real-World Problem Does This Solve—

**The problem:** The CFO approves a budget and wants an email notification sent to all hotel GMs. The monthly close process finishes and needs to update a dashboard in another system. A data validation rule fails and should log it to a ticketing system. None of this is possible with Essbase calc scripts.

**The solution:** Groovy rules in Calculation Manager can make HTTP REST API calls and send emails — enabling EPBCS to communicate with external systems.

### GET Request

```groovy
/* Read data from an external API */
HttpURLConnection connection = new URL(
    "https://api.exchangerate-api.com/v4/latest/INR"
).openConnection()

connection.setRequestMethod("GET")
connection.setRequestProperty("Accept", "application/json")

int responseCode = connection.getResponseCode()

if (responseCode == 200) {
    String response = connection.inputStream.text
    println "Exchange rates: ${response}"
    
    /* Parse JSON response */
    def jsonSlurper = new groovy.json.JsonSlurper()
    def rates = jsonSlurper.parseText(response)
    double usdRate = rates.rates.USD
    println "USD rate: ${usdRate}"
}

connection.disconnect()
```

### POST Request

```groovy
/* Send data to an external system */
def url = new URL("https://hooks.slack.com/services/YOUR/WEBHOOK/URL")
HttpURLConnection connection = url.openConnection()

connection.setRequestMethod("POST")
connection.setRequestProperty("Content-Type", "application/json")
connection.setDoOutput(true)

/* Build JSON payload */
def payload = """
{
    "text": "✅ Budget approved for Mumbai Hotel - FY2026",
    "channel": "#finance-alerts"
}
"""

connection.outputStream.write(payload.getBytes("UTF-8"))
connection.outputStream.flush()

int responseCode = connection.getResponseCode()
println "Slack notification sent: ${responseCode}"

connection.disconnect()
```

### Email After Rule Execution

```groovy
/* Send email with rule execution summary */
def results = []
int totalProcessed = 0
int errors = 0

operation.grid.dataCellIterator("Account#Budget_Status").each { cell ->
    String entity = cell.getMemberName("Entity")
    String status = cell.getSmartListValue()
    totalProcessed++
    
    if (status == "Approved") {
        results << "✅ ${entity}: Approved"
    } else if (status == "Rejected") {
        results << "❌ ${entity}: Rejected"
        errors++
    }
}

/* Build email body */
def body = """
Budget Approval Summary
========================
Total entities processed: ${totalProcessed}
Approved: ${totalProcessed - errors}
Rejected: ${errors}

Details:
${results.join('\n')}
"""

/* Send the email */
def emailService = operation.application.getEmailService()
emailService.sendMail(
    "cfo@hotelpvtltd.com",
    "Budget Approval Report - ${new Date().format('yyyy-MM-dd')}",
    body
)

println "Email sent to CFO with ${totalProcessed} results"
```

## 4. REST API TO UPDATE EXTERNAL SYSTEMS

### Post EPBCS Data to External Dashboard

```groovy
/* Push monthly actuals to an external BI dashboard */
import groovy.json.JsonBuilder

def dataPoints = []

operation.grid.dataCellIterator("Account#Total_Revenue").each { cell ->
    String entity = cell.getMemberName("Entity")
    String period = cell.getMemberName("Period")
    double revenue = cell.data
    
    if (!cell.isMissing()) {
        dataPoints << [
            hotel: entity,
            month: period,
            revenue: revenue,
            currency: "INR"
        ]
    }
}

/* Build JSON */
def json = new JsonBuilder([
    timestamp: new Date().format("yyyy-MM-dd'T'HH:mm:ss"),
    source: "EPBCS",
    data: dataPoints
]).toPrettyString()

/* POST to external API */
def url = new URL("https://dashboard.hotelpvtltd.com/api/actuals")
HttpURLConnection conn = url.openConnection()
conn.setRequestMethod("POST")
conn.setRequestProperty("Content-Type", "application/json")
conn.setRequestProperty("Authorization", "Bearer YOUR_API_TOKEN")
conn.setDoOutput(true)

conn.outputStream.write(json.getBytes("UTF-8"))
conn.outputStream.flush()

println "Dashboard updated: HTTP ${conn.getResponseCode()}"
conn.disconnect()
```

### Fetch Exchange Rates and Update Cube

```groovy
/* Pull live exchange rates and update the rate table */
def url = new URL("https://api.exchangerate-api.com/v4/latest/INR")
def connection = url.openConnection()
connection.setRequestMethod("GET")

if (connection.getResponseCode() == 200) {
    def jsonSlurper = new groovy.json.JsonSlurper()
    def rates = jsonSlurper.parseText(connection.inputStream.text)
    
    double usdRate = rates.rates.USD
    
    /* Update the exchange rate cells on the form */
    operation.grid.dataCellIterator("Account#INR_USD_Rate").each { cell ->
        cell.data = usdRate
    }
    
    println "Exchange rate updated: 1 INR = ${usdRate} USD"
}
connection.disconnect()
```

## 5. ERROR HANDLING PATTERNS

```groovy
/* Always wrap REST calls in try-catch */
try {
    def url = new URL("https://api.company.com/endpoint")
    def conn = url.openConnection()
    conn.setConnectTimeout(5000)  // 5 second timeout
    conn.setReadTimeout(10000)    // 10 second timeout
    conn.setRequestMethod("GET")
    
    int code = conn.getResponseCode()
    
    if (code == 200) {
        String response = conn.inputStream.text
        println "Success: ${response}"
    } else {
        println "API error: HTTP ${code}"
        // Don't block rule execution for non-critical API calls
    }
    
    conn.disconnect()
    
} catch (java.net.SocketTimeoutException e) {
    println "API timeout — continuing without external update"
} catch (java.io.IOException e) {
    println "Network error: ${e.message}"
} catch (Exception e) {
    println "Unexpected error: ${e.message}"
}
```

## 6. SHOW ME — Hotel Pvt Ltd Complete Integration Rule

```groovy
/* ===== Monthly Close Notification Rule ===== */
/* Sends Slack notification + email after monthly close */
/* RTPS: {RTP_Scenario} {RTP_Year} */

String scenario = rtps.RTP_Scenario.toString()
String year = rtps.RTP_Year.toString()
def startTime = System.currentTimeMillis()

// Collect summary data
def hotelSummary = []
operation.grid.dataCellIterator("Account#Total_Revenue").each { cell ->
    if (!cell.isMissing()) {
        String hotel = cell.getMemberName("Entity")
        double revenue = cell.data
        double netIncome = cell.crossDimCell("Account#Net_Income").data
        double margin = (revenue > 0) — (netIncome / revenue * 100) : 0
        
        hotelSummary << [
            hotel: hotel,
            revenue: String.format("₹%.2f L", revenue / 100000),
            netIncome: String.format("₹%.2f L", netIncome / 100000),
            margin: String.format("%.1f%%", margin)
        ]
    }
}

// Build summary message
def duration = (System.currentTimeMillis() - startTime) / 1000
def message = "Monthly Close Complete — ${scenario}/${year}\n"
message += "Hotels processed: ${hotelSummary.size()}\n"
message += "Duration: ${duration}s\n\n"
hotelSummary.each { h ->
    message += "${h.hotel}: Rev=${h.revenue}, NI=${h.netIncome}, Margin=${h.margin}\n"
}

// Send email
try {
    def emailService = operation.application.getEmailService()
    emailService.sendMail(
        "cfo@hotelpvtltd.com",
        "Monthly Close Report — ${scenario}/${year}",
        message
    )
    println "Email sent successfully"
} catch (Exception e) {
    println "Email failed: ${e.message}"
}

println message
```

## 7. COMMON MISTAKES

| Mistake | Symptom | Fix |
|---------|---------|-----|
| No timeout on HTTP connections | Rule hangs if API is down | Set connectTimeout and readTimeout |
| No try-catch around REST calls | Rule fails entirely | Always wrap in try-catch |
| Blocking on non-critical API call | Critical rule fails for optional notification | Catch exception and continue |
| Hard-coded URLs | Can't switch environments | Use EPBCS Connection objects |
| Sending email in a loop | 100 emails sent instead of 1 | Collect data, send 1 email with summary |

## 8. INTERVIEW QUESTIONS

### Intermediate
**Q: Can you send emails from EPBCS— How—**
> Yes, using Groovy rules in Calculation Manager. The `operation.application.getEmailService().sendMail(to, subject, body)` method sends emails. Use cases: notifications after budget approval, alerts on validation failures, monthly close completion reports. Always wrap in try-catch so the rule doesn't fail if email service is unavailable.

### Architect
**Q: Design the notification architecture for Hotel Pvt Ltd's budget approval workflow.**
> (1) **Budget approval rule** iterates through entities, checks Smart List "Budget_Status". (2) When status changes to "Approved", collect entity name and key metrics. (3) After processing all entities, build a summary email with: approved/rejected count, total amounts, and per-hotel details. (4) Send one consolidated email to CFO + Finance VPs. (5) Optionally POST to Slack webhook for real-time team notification. (6) Error handling: wrap all external calls in try-catch — rule should complete even if email/Slack fails. (7) Log the notification status to the job log with println.
