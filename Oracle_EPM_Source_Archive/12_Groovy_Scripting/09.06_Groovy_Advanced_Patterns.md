## 1. WHY — Beyond Basic Cell Iteration

Basic Groovy iterates cells on a form. Advanced Groovy does much more: reads from other cubes (DataMaps), builds custom grids (Grid Builder), embeds calc scripts, manipulates metadata, and orchestrates complex multi-step workflows.

---

## 2. PATTERN 1: DATAMAP — CROSS-CUBE DATA ACCESS

### What It Is
DataMaps let a Groovy rule read data from a **different cube** than the one the form is connected to. For example: read Workforce salary data while calculating FinPlan expenses.

```groovy
/* Step 1: Reference a pre-configured Data Map */
DataMap wfpMap = operation.dataMap("WFP_to_FinPlan")

/* Step 2: Use it in cell iteration */
operation.grid.dataCellIterator("Account#Labor_Cost").each { cell ->
    // Read Basic_Salary from Workforce cube via DataMap
    double salary = cell.crossDimCell(wfpMap, "Account#Basic_Salary").data
    double benefits = cell.crossDimCell(wfpMap, "Account#Benefits").data
    
    // Write total labor cost to FinPlan cube
    cell.data = salary + benefits
}
```

### Setting Up the DataMap

```
Navigator → Data Exchange → Data Maps → Create

Name: WFP_to_FinPlan
Source: OEP_WFP (Workforce cube)
Target: OEP_FS (FinPlan cube)

Dimension Mapping:
  Account: Basic_Salary → Labor_Cost
  Entity: (same)
  Scenario: (same)
  Period: (same)
```

## 3. PATTERN 2: GRID BUILDER — CUSTOM DATA RETRIEVAL

### What It Is
Grid Builder creates a custom data retrieval grid programmatically — reading specific intersections that aren't on the current form.

```groovy
/* Read a specific intersection not on the form */
Cube cube = operation.application.getCube("OEP_FS")

def gridDef = cube.getGridDefinitionBuilder()
    .addDimension("Account", "Total_Revenue")
    .addDimension("Entity", "All_Hotels")
    .addDimension("Scenario", "Actual")
    .addDimension("Version", "Final")
    .addDimension("Year", "FY2026")
    .addDimension("Period", "YearTotal")

DataGrid grid = gridDef.build()
double totalCompanyRevenue = grid.dataCellIterator().next().data

println "Total Company Revenue: ${totalCompanyRevenue}"
```

### Multi-Cell Grid

```groovy
/* Read multiple members at once */
Cube cube = operation.application.getCube("OEP_FS")

def gridDef = cube.getGridDefinitionBuilder()
    .addDimension("Account", ["Room_Revenue", "F&B_Revenue", "Spa_Revenue"])
    .addDimension("Entity", "Mumbai_Hotel")
    .addDimension("Scenario", "Actual")
    .addDimension("Version", "Final")
    .addDimension("Year", "FY2026")
    .addDimension("Period", "Aug")

DataGrid grid = gridDef.build()
grid.dataCellIterator().each { cell ->
    String account = cell.getMemberName("Account")
    println "${account}: ${cell.data}"
}

/* Output:
   Room_Revenue: 5200000
   F&B_Revenue: 2100000
   Spa_Revenue: 800000
*/
```

## 4. PATTERN 3: EMBEDDED CALC SCRIPT

### When to Use
Use embedded calc scripts for operations that Groovy can't do natively: AGG, DATACOPY, SET commands, CLEARDATA, CLEARBLOCK.

```groovy
/* Run a full Essbase calc script from Groovy */
String scenario = rtps.RTP_Scenario.toString()
String year = rtps.RTP_Year.toString()

def calcScript = """
SET LOCKBLOCK ON;
SET CALCPARALLEL 4;

FIX("${scenario}", "Working", "${year}")
  FIX(@RELATIVE("All_Hotels", 0))
    "Total_Revenue" = "Room_Revenue" + "F&B_Revenue" + "Spa_Revenue";
    "Total_Expenses" = "Labor" + "Maintenance" + "Utilities";
    "Net_Income" = "Total_Revenue" - "Total_Expenses";
    IF("Total_Revenue" <> 0)
      "Profit_Margin" = "Net_Income" / "Total_Revenue" * 100;
    ENDIF
  ENDFIX
  AGG("Entity");
ENDFIX

SET LOCKBLOCK OFF;
"""

operation.application.getEssbaseServer()
    .getApplication(operation.application.getName())
    .getCube("OEP_FS")
    .executeCalcScript(calcScript)

println "Calc script executed for ${scenario}/${year}"
```

## 5. PATTERN 4: MULTI-STEP WORKFLOW

```groovy
/* ===== Complete Budget Approval Workflow ===== */
/* Step 1: Validate → Step 2: Calculate → Step 3: Update Status → Step 4: Notify */

// --- STEP 1: VALIDATION ---
def errors = []
operation.grid.dataCellIterator("Account#Room_Revenue").each { cell ->
    if (cell.data < 0) {
        errors << "Negative: ${cell.getMemberName('Entity')}/${cell.getMemberName('Period')}"
    }
}
operation.grid.dataCellIterator("Account#Occupancy_Rate").each { cell ->
    if (!cell.isMissing() && cell.data > 100) {
        errors << "Occupancy>100%: ${cell.getMemberName('Entity')}"
    }
}
if (errors.size() > 0) {
    throwVetoException("❌ Validation Failed:\n${errors.join('\n')}")
}

// --- STEP 2: CALCULATE (Embedded Calc) ---
def calcScript = """
SET LOCKBLOCK ON;
FIX("Budget", "Working", "FY2026", @RELATIVE("All_Hotels", 0))
  "Total_Revenue" = "Room_Revenue" + "F&B_Revenue" + "Spa_Revenue";
  "Net_Income" = "Total_Revenue" - "Total_Expenses";
ENDFIX
FIX("Budget", "Working", "FY2026")
  AGG("Entity");
ENDFIX
SET LOCKBLOCK OFF;
"""
operation.application.getEssbaseServer()
    .getApplication(operation.application.getName())
    .getCube("OEP_FS")
    .executeCalcScript(calcScript)

// --- STEP 3: AUTO-APPROVE ---
int approvedCount = 0
operation.grid.dataCellIterator("Account#Budget_Status").each { cell ->
    String status = cell.getSmartListValue()
    if (status == "In Review") {
        double variance = cell.crossDimCell("Account#Variance_Pct").data
        if (Math.abs(variance) <= 5.0) {
            cell.data = 3  // 3 = Approved
            approvedCount++
        }
    }
}

// --- STEP 4: NOTIFY ---
try {
    def body = "Budget processing complete.\n"
    body += "Auto-approved: ${approvedCount} entities\n"
    body += "Timestamp: ${new Date()}"
    
    operation.application.getEmailService().sendMail(
        "cfo@hotelpvtltd.com",
        "Budget Processing Report",
        body
    )
} catch (Exception e) {
    println "Email failed: ${e.message}"
}

println "Workflow complete: ${approvedCount} auto-approved"
```

## 6. PATTERN 5: MEMBER METADATA ACCESS

```groovy
/* Read dimension metadata */
Dimension entityDim = operation.application.getDimension("Entity")

/* Get all level-0 (leaf) members */
def leafMembers = []
entityDim.getEvaluatedMembers("@RELATIVE('All_Hotels', 0)").each { member ->
    leafMembers << member.getName()
}
println "Hotels: ${leafMembers.join(', ')}"

/* Check if a member exists */
boolean exists = entityDim.hasMember("Goa_Hotel")
println "Goa Hotel exists: ${exists}"

/* Get member properties */
def mumbai = entityDim.getMember("Mumbai_Hotel")
println "Parent: ${mumbai.getParent()—.getName()}"
println "Level: ${mumbai.getLevel()}"
```

## 7. PATTERN 6: DATE AND TIME OPERATIONS

```groovy
/* Get current date/time */
def now = new Date()
println "Current: ${now.format('yyyy-MM-dd HH:mm:ss')}"

/* Calculate date differences */
def startDate = Date.parse('yyyy-MM-dd', '2026-01-01')
def endDate = Date.parse('yyyy-MM-dd', '2026-08-13')
def daysBetween = (endDate - startDate)
println "Days elapsed: ${daysBetween}"

/* Set a date cell value (YYYYMMDD format) */
operation.grid.dataCellIterator("Account#Last_Updated").each { cell ->
    cell.data = now.format('yyyyMMdd') as double  // 20260813
}
```

## 8. COMMON MISTAKES

| Mistake | Fix |
|---------|-----|
| DataMap not pre-configured | Create Data Map in Navigator before referencing |
| Grid Builder missing a dimension | Specify ALL dimensions — no defaults |
| Embedded calc with wrong cube name | Use `operation.application.getName()` |
| String interpolation in calc script | Use `"""` triple quotes with `${variable}` |
| No try-catch on email/REST | Always wrap external calls |
| Modifying metadata in Groovy | Limited — use Metadata Import instead |

## 9. INTERVIEW QUESTIONS

### Architect
**Q: Design a multi-step Groovy workflow for Hotel Pvt Ltd's monthly close.**
> Four steps in one Groovy rule: (1) **Validate:** Iterate revenue cells — check for negatives, occupancy > 100%. If errors → throwVetoException with detailed message. (2) **Calculate:** Execute embedded calc script with SET LOCKBLOCK ON + CALCPARALLEL 4 for P&L calcs + AGG. Groovy can't do AGG natively, so embedded calc is required. (3) **Update Status:** Iterate Smart List "Budget_Status" cells — auto-approve entities where variance < 5%. (4) **Notify:** Send consolidated email to CFO with approval summary. Wrap email in try-catch. Log to job console with println. This hybrid approach leverages Groovy for logic + embedded calc for performance-critical math.
