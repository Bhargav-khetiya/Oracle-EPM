# 10.01 — Smart View Architecture and Connections: Complete Guide

> **Module:** 10_Smart_View | **Topic:** Architecture, Installation, Connections, Shared Connections
> **Audience:** Service Administrator / Power User

---

## 1. WHY — What Real-World Problem Does This Solve?

**The problem:** EPBCS web forms are great for standardized data entry, but power users (FP&A analysts, controllers) want to work in Excel — pivot data, build custom reports, create linked workbooks. Without Smart View, they'd export to CSV, manipulate in Excel, and lose the live connection to the database.

**The solution:** Oracle Smart View for Office is an **Excel add-in** that connects directly to EPBCS, enabling live data retrieval, ad hoc analysis, and data submission — all from within Excel.

## 3. CONNECTION TYPES

### Private Connections vs Shared Connections

| Feature | Private Connection | Shared Connection |
|---------|-------------------|-------------------|
| **Created by** | Each user individually | Admin (centrally managed) |
| **Stored** | User's local machine | EPBCS server |
| **Visible to** | Only the creating user | All users with access |
| **Best for** | Ad hoc analysis, testing | Standardized form access |
| **URL format** | `https://instance.oraclecloud.com/HyperionPlanning/SmartView` | Same |

### Setting Up a Connection

```
1. Open Excel → Smart View ribbon → Connections
2. Click "Shared Connections" (or "Private Connections")
3. Enter URL: https://yourinstance.oraclecloud.com/HyperionPlanning/SmartView
4. Login with Oracle Cloud credentials
5. Browse the application tree:
   └── Planning
       └── HotelApp
           ├── OEP_FS (FinPlan cube)
           ├── OEP_WFP (Workforce cube)
           └── OEP_CP (CapEx cube)
6. Select a form or cube → Connect
```

## 4. THREE WAYS TO USE SMART VIEW

### Mode 1: Forms (Structured)

```
Smart View → Shared Connections → Planning → Select Form

Result: The EPBCS form opens in Excel, exactly as designed
  - Same rows, columns, POV, Page
  - Same formatting and validation rules
  - Submit button saves data back to EPBCS
  - Same security (user can only see/edit their data)

Use case: Standard data entry in Excel instead of browser
```

### Mode 2: Ad Hoc Analysis (Flexible)

```
Smart View → Shared Connections → Select Cube → Ad Hoc Analysis

Result: A blank grid connected to the entire cube
  - User can Zoom In/Out on dimensions
  - Pivot dimensions between rows/columns
  - No form definition constraints
  - Full dimensional exploration

Controls:
  Zoom In:   Double-click a member → shows children
  Zoom Out:  Select member → Smart View → Zoom Out
  Pivot:     Move dimension from row to column
  Keep Only: Right-click → Keep Only (filter to selection)
  Remove:    Right-click → Remove Only (hide selection)
```

### Mode 3: Smart View Functions (Cell References)

```
=HsGetValue("ConnectionName", "POV_String")

Example:
=HsGetValue("HotelApp", "Account#Room_Revenue", "Entity#Mumbai_Hotel",
            "Scenario#Actual", "Year#FY2026", "Period#Jan")

Result: Returns the value ₹85,00,000 directly into the Excel cell

Use case: Build custom Excel reports pulling live EPBCS data
```

## 7. SHOW ME — Hotel Pvt Ltd Smart View Workflows

### Workflow 1: Monthly Revenue Entry via Smart View

```
1. Finance team opens Excel
2. Smart View → Shared Connections → Revenue_Entry form
3. Form loads in Excel with same layout as web
4. Team enters data across multiple months (Excel's paste is faster)
5. Clicks Submit → data saves to EPBCS
6. On Save rules execute (aggregation, Smart Push)
7. Team refreshes → sees updated totals
```

### Workflow 2: CFO Ad Hoc Analysis

```
1. CFO wants to compare 3 years of revenue by hotel
2. Smart View → OEP_FS cube → Ad Hoc
3. Starts with top-level: All_Hotels, Total_Revenue, FY2026
4. Zooms In on All_Hotels → sees 5 hotels
5. Zooms In on Period → sees Q1, Q2, Q3, Q4
6. Adds FY2025 and FY2024 to columns (Keep Only)
7. Now sees: 5 hotels × 4 quarters × 3 years
8. Builds Excel charts from the live data
9. Refreshes weekly — charts auto-update
```

## 8. COMMON MISTAKES

| Mistake | Symptom | Fix |
|---------|---------|-----|
| Wrong connection URL | "Cannot connect" error | Verify URL with admin |
| Expired password | Login fails | Reset Oracle Cloud password |
| Submit without Refresh first | Stale data overwrites newer data | Always Refresh before Submit |
| HsGetValue with wrong POV | Returns #NoData | Verify all dimension members are specified |
| Excel version incompatibility | Smart View add-in won't load | Check Oracle's compatibility matrix |
| VPN not connected | Can't reach cloud instance | Connect to VPN first |

## 9. INTERVIEW QUESTIONS

### Beginner
**Q: What is Smart View and how does it connect to EPBCS?**
> Smart View is an Oracle Excel add-in that provides a live connection between Microsoft Excel and EPBCS. It connects via HTTPS to the Oracle Cloud instance. Users can open forms in Excel (same as web but with Excel's power), do ad hoc analysis by drilling into cube data, and use HsGetValue functions for custom reports. Data flows both ways — Refresh pulls data from EPBCS, Submit pushes changes back.

### Intermediate
**Q: A user says "I submitted data in Smart View but it's not showing on the web form." What's wrong?**
> Possible causes: (1) The user submitted to a different POV (different entity, scenario, or period than the web form shows). (2) The user's Submit failed silently — check the Submit status bar message. (3) The web form has an On Load rule that recalculates and may show different values. (4) The user submitted data for a cell that's read-only on the web form (no security issue in Smart View ad hoc, but form design may differ). (5) Cache issue — the web form may need a browser refresh or the form uses a different substitution variable value.
