# 10.03 — Smart View Functions (HsGetValue): Complete Guide

> **Module:** 10_Smart_View | **Topic:** Excel Functions, HsGetValue, HsSetValue, Custom Reports
> **Audience:** Power User / Report Builder

---

## 1. WHY — What Real-World Problem Does This Solve—

**The problem:** The CFO wants a custom Excel report with a specific layout — hotel logos, charts, conditional formatting, and data from 3 different cubes. Standard forms can't deliver this. Ad hoc gives raw data but not the polished layout. The CFO wants live data feeding into a beautifully formatted Excel workbook.

**The solution:** Smart View functions like `HsGetValue` retrieve individual cell values from EPBCS directly into Excel formula cells. Build any layout, pull live data, and refresh with one click.

---

## 2. HSGETVALUE — THE CORE FUNCTION

### Syntax

```excel
=HsGetValue("ConnectionName","Dim1#Member1","Dim2#Member2",...)
```

### Basic Example

```excel
=HsGetValue("HotelApp",
  "Account#Room_Revenue",
  "Entity#Mumbai_Hotel",
  "Scenario#Actual",
  "Version#Final",
  "Year#FY2026",
  "Period#Aug"
)

Result: 8500000 (₹85,00,000)
```

### Rules

```
1. Connection name must match exactly (case-sensitive)
2. Every dimension must be specified — no defaults
3. Format: "DimensionName#MemberName"
4. Dimension names use INTERNAL names (not aliases)
5. Function returns #NoData if intersection has no value
6. Must be connected (logged in) to refresh
```

## 3. ALL SMART VIEW FUNCTIONS

| Function | Purpose | Example |
|----------|---------|---------|
| **HsGetValue** | Retrieve a single cell value | `=HsGetValue("App","Account#Rev",...)` |
| **HsSetValue** | Write a value to a cell | `=HsSetValue(100000,"App","Account#Rev",...)` |
| **HsCurrency** | Get currency for a member | `=HsCurrency("App","Entity#Mumbai")` |
| **HsGetSheetInfo** | Get connection info for sheet | `=HsGetSheetInfo("Connection")` |
| **HsDescription** | Get member description | `=HsDescription("App","Account#Revenue")` |
| **HsAlias** | Get member alias | `=HsAlias("App","Entity#Mumbai_Hotel")` |
| **HsGetVariable** | Get substitution variable | `=HsGetVariable("App","CurrMonth")` |
| **HsLabel** | Get member label | `=HsLabel("App","Account#Revenue")` |

## 4. BUILDING A CUSTOM REPORT

### Step-by-Step

```excel
/* Step 1: Set up the header */
A1: "Hotel Performance Dashboard"
A2: "Period: August 2026"
A3: "Currency: INR (₹)"

/* Step 2: Create the structure */
       B              C              D              E              F
5  Mumbai         Delhi          Bangalore      Kolkata        Chennai
6  Room Revenue   =HsGetValue(...)  =HsGetValue(...)  ...
7  F&B Revenue    =HsGetValue(...)  =HsGetValue(...)  ...
8  Spa Revenue    =HsGetValue(...)  =HsGetValue(...)  ...
9  Total Revenue  =SUM(B6:B8)      =SUM(C6:C8)       ...
10 Total Expenses =HsGetValue(...)  =HsGetValue(...)  ...
11 Net Income     =B9-B10          =C9-C10            ...
12 Profit Margin  =B11/B9*100      =C11/C9*100        ...
```

### Using Cell References for Dynamic POV

```excel
/* Make the report dynamic — change one cell, all data updates */
E1: FY2026        (Year)
E2: Actual         (Scenario)
E3: Final          (Version)

/* HsGetValue with cell references */
B6: =HsGetValue("HotelApp",
      "Account#Room_Revenue",
      "Entity#Mumbai_Hotel",
      "Scenario#"&$E$2,        ← Cell reference for Scenario
      "Version#"&$E$3,         ← Cell reference for Version
      "Year#"&$E$1,            ← Cell reference for Year
      "Period#Aug"
    )

/* Now changing E1 to "FY2025" and clicking Refresh
   updates ALL cells to show FY2025 data! */
```

## 5. HSSETVALUE — WRITING DATA

```excel
/* Write a value to EPBCS from Excel */
=HsSetValue(9000000,
  "HotelApp",
  "Account#Room_Revenue",
  "Entity#Mumbai_Hotel",
  "Scenario#Budget",
  "Version#Working",
  "Year#FY2026",
  "Period#Sep"
)

/* After entering and refreshing, the value 9000000 
   is submitted to the cube */
```

### Caution with HsSetValue

```
⚠️ HsSetValue bypasses form validations and business rules!
   → No On Save rules fire
   → No format/validation rules check the value
   → No security check beyond dimension access
   → Use carefully — mainly for batch updates
```

## 6. HSGETVARIABLE — SUBSTITUTION VARIABLES

```excel
/* Pull current substitution variable values */
=HsGetVariable("HotelApp", "CurrMonth")
→ "Sep"

=HsGetVariable("HotelApp", "CurrYear")
→ "FY2026"

=HsGetVariable("HotelApp", "ForecastStart")
→ "Oct"

/* Use in report headers */
A2: ="Period: "&HsGetVariable("HotelApp","CurrMonth")&" "&HsGetVariable("HotelApp","CurrYear")
→ "Period: Sep FY2026"
```

## 8. PERFORMANCE TIPS

| Tip | Impact |
|-----|--------|
| Limit HsGetValue cells to < 500 | Refresh stays under 10 seconds |
| Use cell references for POV (not hardcoded) | Change once, update everywhere |
| Don't mix HsGetValue with ad hoc on same sheet | Conflicts and errors |
| Refresh once after all changes | Avoid multiple refreshes |
| Use named ranges for dimension members | Easier maintenance |

---

## 9. COMMON MISTAKES

| Mistake | Symptom | Fix |
|---------|---------|-----|
| Missing a dimension in HsGetValue | Returns #NoData or error | Specify ALL dimensions |
| Wrong connection name | "Connection not found" | Match name exactly |
| Not logged in when refreshing | #NoConnection | Log in via Smart View panel |
| HsSetValue without understanding impact | Data corrupted | Use carefully, verify results |
| 1000+ HsGetValue on one sheet | Refresh takes 5+ minutes | Reduce or split into sheets |

## 10. INTERVIEW QUESTIONS

### Beginner
**Q: What is HsGetValue and when would you use it—**
> HsGetValue is a Smart View Excel function that retrieves a single cell value from EPBCS. Syntax: `=HsGetValue("Connection","Dim#Member",...)`. Use it to build custom Excel reports with any layout — pull live EPBCS data into specific cells, add Excel charts, conditional formatting, and logos. Unlike forms or ad hoc, HsGetValue gives complete control over the report layout. Refresh All updates all values.

### Architect
**Q: Build the CFO's executive dashboard in Smart View for Hotel Pvt Ltd.**
> Use HsGetValue for all data cells — Revenue, Expenses, KPIs across 5 hotels. Make it dynamic with cell references for Scenario and Year (dropdowns via Data Validation). Add Excel charts: Revenue bar chart, Profit Margin trend line, Occupancy gauge. Use `HsGetVariable` for the header to show current period. Keep total HsGetValue cells under 200 for 5-second refresh. Distribute the workbook to the board — they just need Smart View installed, login credentials, and click Refresh.
