# 10.04 — Smart View Troubleshooting: Complete Guide

> **Module:** 10_Smart_View | **Topic:** Installation Issues, Connection Problems, Data Errors
> **Audience:** Service Administrator / Support

---

## 1. WHY — The #1 Support Ticket Category

Smart View generates more support tickets than any other EPM component. "Smart View isn't working" could mean 50 different things. This guide covers every common issue with step-by-step resolution.

## 2. INSTALLATION ISSUES

### Smart View Won't Install

```
Problem: Installer fails or hangs
Fixes:
  1. Close ALL Office applications (Excel, Word, Outlook)
  2. Run installer as Administrator
  3. Check .NET Framework 4.7+ installed
  4. Check Excel version: 32-bit vs 64-bit must match Smart View
  5. Uninstall old version first → reinstall
  
Download: Always use the version bundled with your EPBCS instance
  → Settings → Downloads → Smart View
```

### Smart View Ribbon Missing

```
Problem: Installed but no ribbon in Excel
Fixes:
  1. Excel → File → Options → Add-ins
  2. Manage: COM Add-ins → Go
  3. Check: ☑ Oracle Smart View for Office
  4. If not listed → repair installation
  5. If listed but unchecked → check it → OK
  6. If greyed out → Enable Trust Center settings for COM
  7. Last resort: Delete %AppData%\Oracle\SmartView → reinstall
```

### Planning Extension Not Loaded

```
Problem: Smart View loads but no Planning features
Fix:
  1. Smart View ribbon → Options → Extensions
  2. Check if "Oracle Planning and Budgeting Cloud" extension is listed
  3. If not: click "Check for Updates, Install" → enter EPBCS URL
  4. The planning extension auto-installs on first connection
  5. Restart Excel after extension installs
```

## 3. CONNECTION ISSUES

### Can't Connect to EPBCS

```
Problem: "Cannot reach provider" or "Connection refused"

Diagnostic Steps:
  1. Open browser → navigate to:
     https://your-instance.oraclecloud.com/HyperionPlanning/SmartView
     → Should show XML page (not error)
     → If error: instance is down or URL wrong

  2. Check VPN:
     → If company requires VPN → connect first
     → Try ping/traceroute to instance URL

  3. Check Proxy:
     Smart View → Options → Advanced
     → If company uses proxy → configure same proxy as browser
     → Try: "Use Internet Explorer proxy" option

  4. Check SSL/TLS:
     Excel Internet Options → Advanced tab
     → ☑ Use TLS 1.2
     → ☐ Use SSL 3.0 (disable old protocols)

  5. Check Shared Connections URL:
     Smart View → Shared Connections
     → URL should be: https://instance.oraclecloud.com/HyperionPlanning/SmartView
```

### Login Fails

```
Problem: "Authentication failed" or "Invalid credentials"

Fixes:
  1. Verify username is email format: user@company.com
  2. Verify password hasn't expired
  3. Try logging into EPBCS browser first (same credentials)
  4. Check identity domain: must match exactly
  5. Check if account is locked (too many failed attempts)
  6. Clear saved credentials:
     Control Panel → Credential Manager → Remove EPBCS entries
```

### Session Expired

```
Problem: "#NoConnection" after idle time

Fixes:
  1. Smart View default timeout: 30 minutes idle
  2. Re-login: Smart View → Panel → Disconnect → Reconnect
  3. Prevent: Smart View → Options → "Keep sessions alive" ← not always available
  4. Workaround: Refresh periodically to keep session active
```

## 4. DATA ISSUES

### #NoData in Cells

```
Problem: Cells show #NoData after refresh

Diagnostic:
  1. Is the correct POV selected— (Scenario, Version, Year, Period)
  2. Does data exist at this intersection— (Check form in browser)
  3. Does the user have Read access— (Dimension Security)
  4. For HsGetValue: are ALL dimensions specified—
  5. Is the member name exact— (Case-sensitive, no extra spaces)
```

### Data Changed But Submit Fails

```
Problem: "Submit failed" or data doesn't save

Fixes:
  1. Check form permission: Must be Write (not Read)
  2. Check dimension security: Must be Write on all intersecting dims
  3. Check Version: Final = Read for planners
  4. Check Scenario: Actual = Read for planners
  5. Check if cell is Dynamic Calc (can't write to calculated cells)
  6. Try: Refresh first → make changes → Submit
```

### Formatting Lost After Refresh

```
Problem: Excel formatting disappears when refreshing

Fix:
  Smart View → Options → Formatting:
    ☑ Preserve Formatting on Operations
    ☑ Use Cell Styles (preserves your formatting)
    ☐ Use Formatting from Server (overrides your formatting)
    
  After setting → Refresh → formatting should persist
```

## 5. PERFORMANCE ISSUES

| Symptom | Cause | Fix |
|---------|-------|-----|
| Refresh takes > 30s | Too many HsGetValue cells (>500) | Reduce to <200 per sheet |
| Ad hoc zoom freezes Excel | Zoomed into too many members | Zoom one dim at a time |
| Excel crashes on refresh | Memory exceeded | Close other sheets/workbooks |
| Slow initial connection | First-time extension download | Wait — happens once |
| Multiple refreshes stack up | Clicking refresh repeatedly | Wait for first to complete |

## 6. SHOW ME — Hotel Pvt Ltd Support Playbook

```
Tier 1 (Self-Service — User Can Fix):
  □ "Ribbon missing" → Excel Options → COM Add-ins → Enable
  □ "Can't connect" → Check VPN → verify URL in browser
  □ "#NoData" → Check POV dropdowns → refresh
  □ "Session expired" → Disconnect → Reconnect
  □ "Can't save" → Check if form is read-only

Tier 2 (Admin Escalation):
  □ "Login fails" → Check identity domain → reset password
  □ "Missing data" → Check dimension security → grant access
  □ "Submit error" → Check version lock → check scenario security
  □ "Extension not loading" → Re-install from EPBCS download page
  □ "Formatting lost" → Set Preserve Formatting option

Tier 3 (Developer Escalation):
  □ "Wrong data" → Check if AGG ran → verify rule execution
  □ "Slow refresh" → Reduce HsGetValue count → optimize form
  □ "Crash" → Check Excel 32/64 bit match → reinstall
```

## 7. INTERVIEW QUESTIONS

### Beginner
**Q: A user says Smart View isn't connecting. Walk through your troubleshooting steps.**
> (1) **Check URL:** Open the Smart View URL in a browser — should return XML. If error, instance may be down. (2) **Check VPN:** If required, ensure user is connected. (3) **Check credentials:** Try same username/password in browser EPBCS login. (4) **Check proxy:** Match Smart View proxy to browser settings. (5) **Check SSL:** Ensure TLS 1.2 is enabled. (6) **Clear credentials:** Control Panel → Credential Manager → remove old entries. (7) **Reinstall:** If all else fails, uninstall/reinstall Smart View.
