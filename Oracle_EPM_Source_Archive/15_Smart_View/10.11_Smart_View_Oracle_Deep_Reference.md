## 🏗️ Smart View Architecture

```
Excel (Client)
├── Smart View Add-in (.xla)
│   ├── Provider: Oracle Planning and Budgeting Cloud
│   ├── Connection: HTTPS to EPM Cloud
│   └── Authentication: SSO / Basic Auth
└── Server (EPM Cloud)
    ├── Smart View Servlet
    ├── Essbase Engine (BSO/ASO)
    └── Planning Application Layer
```

### Every Form Operation

| Operation | Keyboard | Menu | Description |
|-----------|----------|------|-------------|
| **Refresh** | Ctrl+F5 | Smart View → Refresh | Pull latest data from server |
| **Submit** | — | Smart View → Submit Data | Push changes to server |
| **Undo** | Ctrl+Z | — | Undo local changes (before submit) |
| **Save As** | — | File → Save As | Save locally as Excel |
| **Zoom In** | Double-click member | Smart View → Zoom In | Drill into children |
| **Zoom Out** | — | Smart View → Zoom Out | Roll up to parent |
| **Lock/Unlock** | — | Smart View → Lock | Lock a cell for spreading |
| **Cell History** | — | Smart View → Cell History | See who changed this cell |
| **Cell Comments** | — | Smart View → Comments | Add notes to a cell |
| **Supporting Detail** | — | Smart View → Supporting Detail | Add line-item detail |
| **Adjust** | — | Smart View → Adjust Data | Adjust by value/percentage |
| **Spread** | — | Smart View → Spread | Distribute value across periods |

### Spreading (Mass Allocate)

Spreading distributes a total across children or periods.

| Spread Type | Description | Example |
|-------------|-------------|---------|
| **Proportional Spread** | Distribute based on existing values | Total = 1200 → Jan(100), Feb(200) already → new Jan = 300, Feb = 600 proportionally |
| **Even Spread** | Distribute equally | Total = 1200 → 12 months = 100 each |
| **Fill** | Same value in all cells | Value = 100 → all 12 months = 100 |
| **Custom Spread** | User specifies pattern | Seasonal pattern for hotel revenue |

### 💡 Logic & Purpose
The Smart View cell coloring system (White = Saved, Yellow = Dirty, Green = Read Only) is the primary feedback mechanism for end users. Without it, users typing rapidly across thousands of cells wouldn't know which data was successfully pushed to the server and which data is just sitting in local RAM waiting to be submitted.

### 🌀 Confusion Resolution
> **Misconception:** "I typed a new number into my Smart View form. The cell turned yellow. I hit 'Refresh' to recalculate the grid, but my yellow cell reverted back to the old number!"
> **Reality:** 'Refresh' pulls data *down* from the server. 'Submit' pushes data *up* to the server. If you type a number (cell turns yellow) and then hit Refresh, you are explicitly telling Smart View to wipe out your local unsubmitted changes and pull the last known truth from the server database. You must always hit 'Submit' before you hit 'Refresh'.

### 😈 Twisted Interview Question
**Question:** A user opens a Smart View form. They see a white cell. They type the exact same number into the cell that was already there. What color does the cell turn, and what happens when they click Submit—
> **Answer:** The cell turns Yellow (dirty state). Smart View does not check if the value actually changed mathematically; it only registers that a keystroke edit event occurred on that cell. When the user clicks Submit, Smart View wastes network bandwidth sending the exact same number back to the Essbase server to be processed and saved again.

| Operation | How | What Happens |
|-----------|-----|-------------|
| **Zoom In (Next Level)** | Double-click member | Shows immediate children |
| **Zoom In (All Levels)** | Smart View → Zoom In → All Levels | Shows all descendants |
| **Zoom In (Bottom Level)** | Smart View → Zoom In → Bottom Level | Shows Level 0 only |

### Member Selection Functions

| Function | Description | Example |
|----------|-------------|---------|
| `Children(Entity)` | Direct children only | Entity → Hotel Division, Manufacturing |
| `IChildren(Entity)` | Children INCLUDING Entity | Entity, Hotel Division, Manufacturing |
| `Descendants(Entity)` | All descendants, all levels | All entities at all levels |
| `IDescendants(Entity)` | All descendants INCLUDING Entity | Entity + all children recursively |
| `ILvl0Descendants(Entity)` | Leaf members only | Mumbai, Delhi, Factory1 |
| `Siblings(Mumbai)` | Same-level members | Mumbai, Delhi (same parent) |
| `ISiblings(Mumbai)` | Siblings INCLUDING Mumbai | Mumbai, Delhi |
| `Parent(Mumbai)` | Parent member | Hotel Division |
| `IParent(Mumbai)` | Parent INCLUDING Mumbai | Hotel Division, Mumbai |
| `Ancestors(Mumbai)` | All parents to root | Hotel Division, Entity |
| `IAncestors(Mumbai)` | All parents INCLUDING Mumbai | Mumbai, Hotel Division, Entity |
| `Gen1(Entity)` | Generation 1 members | Entity (root) |
| `Gen2(Entity)` | Generation 2 members | Hotel Division, Manufacturing |
| `Lvl0(Entity)` | Level 0 members | Mumbai, Delhi, Factory1 |

## 📌 HsGetValue — Complete Function Reference

### Syntax

```excel
=HsGetValue("ConnectionName", "Dim1#Member1", "Dim2#Member2", ...)
```

### Rules
1. **ALL dimensions must be specified** — miss one = #NoData
2. Connection name must match exactly (case-sensitive)
3. Dimension#Member format with # separator
4. Refresh sheet to pull latest data

### Common Patterns

```excel
/* Single value */
=HsGetValue("FinPlan","Account#Revenue","Period#Jan","Entity#E10001",
    "Scenario#Actual","Version#Final","Year#FY26","Currency#Local")

/* Using cell references for dynamic reports */
=HsGetValue("FinPlan","Account#"&A5,"Period#"&B$1,"Entity#"&$C$1,
    "Scenario#Actual","Version#Final","Year#FY26","Currency#Local")

/* Where A5 = account name, B1 = period, C1 = entity */
```

### HsSetValue (Write Data)

```excel
=HsSetValue(1000,"FinPlan","Account#Revenue","Period#Jan","Entity#E10001",
    "Scenario#Budget","Version#Working","Year#FY27","Currency#Local")
```

## 🔧 Troubleshooting — Complete Reference

| Issue | Diagnosis Steps | Solution |
|-------|----------------|----------|
| Smart View tab missing in Excel | COM add-in disabled | File → Options → Add-ins → COM → Enable |
| "Cannot connect to provider" | URL wrong or SSL issue | Verify URL, check proxy, try in browser first |
| "Session expired" | Idle timeout | Increase timeout in server settings, re-login |
| #NoData everywhere | Wrong POV or no data | Check all dimensions in HsGetValue |
| #Missing in cells | No data at intersection | Expected — enter data or check form |
| Extremely slow refresh | Grid too large | Reduce members, enable suppression |
| "Unable to submit" | Read-only intersection | Check Data Access permissions |
| Excel crashes on refresh | Memory overflow | Close other workbooks, reduce grid size |
| Login loop | Cookie/cache issue | Clear IE cache (Smart View uses IE engine) |
| "Server not found" | Network/VPN issue | Check VPN connection, DNS resolution |

## 🎓 Interview Questions (Oracle Official Level)

**Q: Explain the complete architecture of Smart View.**
> Smart View is an Excel COM add-in that communicates via HTTPS with the EPM Cloud server. The server runs a Smart View servlet that translates Excel requests into Essbase operations. Authentication goes through Oracle Identity Cloud Service (IDCS) or federated SSO.

**Q: What is Supporting Detail and how is it different from Cell Comments—**
> Supporting Detail allows line-item breakdown of a cell value (like sub-rows that sum to the cell). Comments are free-text notes attached to a cell. Supporting Detail is structural; Comments are informational.

**Q: How does spreading work in Smart View—**
> When you type a value in a parent cell (e.g., YearTotal = 12000), Smart View distributes it to children. Proportional uses existing ratios, Even divides equally, Fill copies the same value. It uses the existing data distribution as the basis for proportional spread.

**Q: What is the difference between Private and Shared connections—**
> Private connections are user-specific — each user creates their own. Shared connections are admin-managed via XML configuration files deployed to all users. Shared connections ensure consistency and are easier to maintain.
