## 🏢 1. Smart View for Mac and Browser (Office 365)

Oracle completely rebuilt Smart View for non-Windows environments using the new Microsoft Office Add-in API.

### Key Differences from Windows Smart View
| Feature | Windows Smart View | Mac / Browser Smart View |
|---------|--------------------|--------------------------|
| **Installation** | .exe installer (IT managed) | Manifest file (`manifest.xml`) deployed via M365 Admin |
| **Technology** | COM Add-in (.NET/C++) | JavaScript / Web Add-in |
| **Capabilities** | 100% full features | ~85% features (No VBA macros, no offline mode) |
| **Updates** | Manual / EPM Automate rollout | Automatic (cloud managed) |

### 🎯 Hands-On: Deploy Mac/Browser Smart View
```
1. Log into EPM Cloud as Admin.
2. Navigate to Downloads → Smart View for Mac and Browser.
3. Click "Create Manifest" → enter the URL of your EPM environment.
4. Download the `manifest.xml` file.
5. In Excel for Web, go to Insert → Office Add-ins → Upload My Add-in (or deploy centrally via Microsoft 365 Admin Center).
```

## 💡 2. Smart View for Google Workspace

For companies using Google Sheets instead of Excel, Oracle provides a dedicated Smart View add-on.

### Architecture & Hidden Things
- **Platform:** Native Google Workspace Add-on.
- **Limitations:** No VBA, highly reliant on Google's cell limits (max 10 million cells per spreadsheet).
- **Hidden Gem:** Ad-hoc analysis works almost identically to Excel, but formatting is handled by Google Sheets' native CSS/styling engine, which can sometimes override Smart View cell styles.

## 🛠 3. Developing Applications for Smart View (SDK)

The Smart View SDK (Software Development Kit) allows VBA developers to programmatically control Smart View.

### Hidden VBA Functions Every Architect Should Know
- `HypConnect()`: Programmatically log in to a cube.
- `HypRetrieve()`: Force a sheet to refresh via macro.
- `HypSetMenu()`: Add custom buttons to the Smart View ribbon.

### 🎯 Hands-On: Write a Smart View Macro
```vba
' 1. Open Excel VBA Editor (Alt + F11)
' 2. Reference the Smart View library (smartview.bas)
' 3. Write a macro to auto-refresh on open:
Sub AutoRefreshEPM()
    Dim vtRet As Variant
    vtRet = HypConnect("Sheet1", "admin", "password", "EPM_Conn")
    If vtRet = 0 Then
        Call HypRetrieve("Sheet1")
    End If
End Sub
```

## ️ 4. Predictive Planning & Strategic Modeling in Smart View

### Predictive Planning (Hidden ML Features)
Predictive Planning uses Machine Learning (ARIMA models) to predict future data based on historical trends.
- **How it works:** You highlight a row of historical data in Smart View, click "Predict", and Oracle generates best-case, worst-case, and base-case forecast numbers for future periods.
- **Hidden Requirement:** You need at least **24 months** of historical data for the ML algorithm to account for seasonality.

### 💡 Logic & Purpose
Predictive Planning bridges the gap between manual data entry and data science. Instead of an analyst looking at historical revenue and arbitrarily typing a 5% increase into next year's budget, the engine runs standard statistical models (ARIMA, Exponential Smoothing) to detect hidden seasonal curves, trend lines, and noise, outputting a mathematically defensible baseline forecast instantly.

### 🌀 Confusion Resolution
> **Misconception:** "I ran Predictive Planning on my new product line, but it threw an error saying 'Insufficient Data'. I have 6 months of actuals, that should be plenty to draw a trendline!"
> **Reality:** A simple trendline (y = mx + b) requires 2 points, but EPM's Predictive Planning requires a minimum of **24 historical periods** by default (or at least two full seasonal cycles) to determine if a spike is an anomaly or a recurring seasonal event (like holiday sales). Six months of data is statistically useless to these specific ML algorithms.

### 😈 Twisted Interview Question
**Question:** A user highlights historical Revenue on a Smart View form and clicks "Predict". The prediction graph generates perfectly. The user closes the prediction window and clicks "Submit Data" on the form. The next day, the manager complains that the forecast is blank. Why didn't the prediction save—
> **Answer:** Clicking "Predict" only runs the ML algorithm in memory and displays the result visually in the pop-up dialogue. To actually write the predicted numbers to the Essbase cube, the user MUST click the "Paste" button inside the Prediction window to paste the calculated values into the Smart View grid cells, and *then* click "Submit Data".

### Strategic Modeling (The "Alcar" Engine)
Strategic Modeling is used for M&A (Mergers & Acquisitions), treasury, and long-range debt modeling.
- **Hidden Architecture:** It does NOT use Essbase. It uses a proprietary financial modeling engine (formerly Hyperion Strategic Finance / Alcar).
- **Key Feature:** Scenario Management (What if interest rates rise by 2%— What if we acquire Company X—).

## 🎓 5. Interview Questions (Specialized SV Tools)

**Q: A client has a mix of Windows, Mac, and Chromebook users. How do you deploy Smart View—**
> Windows users get the standard COM add-in via an IT push (.exe). Mac and Chromebook users use the "Smart View for Office (Mac and Browser)" via Microsoft 365 manifest deployment, or the Google Workspace add-on if they use Google Sheets.

**Q: We want a button in Excel that automatically logs in and refreshes a specific report. Can Smart View do this—**
> Yes, using the Smart View VBA SDK. We can map a button to a macro that calls `HypConnect` to authenticate and `HypRetrieve` to pull the data.

**Q: Why would a client use Strategic Modeling instead of just building rules in the FinPlan cube—**
> Strategic Modeling is built for corporate finance and treasury. It has built-in accounting integrity (the balance sheet always balances automatically) and handles complex debt scheduling, M&A consolidations, and scenario rollups without needing to write complex calc scripts.
