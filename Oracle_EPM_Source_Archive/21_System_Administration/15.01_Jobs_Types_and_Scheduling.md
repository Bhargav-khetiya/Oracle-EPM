# 15.01 — Jobs, Job Types, and Scheduling: Complete Guide

> **Module:** 15_Administration | **Topic:** Job Console, All Job Types, Scheduling
> **Audience:** Service Administrator

---

## 1. WHY — What Real-World Problem Does This Solve?

**The problem:** In a production EPBCS environment, dozens of operations run daily: business rules, data exports, metadata imports, database refreshes, backups. Without monitoring, failed jobs go unnoticed — the month-end close fails because a rule errored at 2 AM and nobody knew.

**The solution:** The Jobs Console is the **centralized monitoring dashboard** for all EPBCS operations. Every action that touches the cube (data loads, rule executions, metadata imports) creates a job that you can track, filter, and troubleshoot.

## 2. WHAT — Every Job Type in EPBCS

### Master Job Type List

| Job Type | Triggered By | Description |
|----------|-------------|-------------|
| **Business Rule** | Form save, manual launch, schedule | Calc script or Groovy rule execution |
| **Ruleset** | Manual launch, schedule | Multiple rules executed in sequence |
| **Refresh Database** | Admin action | Syncs Essbase outline with app metadata |
| **Data Import** | Data Management, EPM Automate | Load data from flat files or ERP |
| **Data Export** | Data Management, EPM Automate | Export data to flat files |
| **Metadata Import** | Data Management, LCM | Import dimension members from files |
| **Metadata Export** | Data Management, LCM | Export dimension members to files |
| **Clear Cell Details** | Admin action | Clear cell-level supporting details |
| **Copy Version** | Admin action | Copy data between versions |
| **Clear Data** | Admin action | Clear data at specific intersections |
| **Restructure Database** | Admin action | Restructure cube after outline changes |
| **LCM Export** | Lifecycle Management | Full or partial application export |
| **LCM Import** | Lifecycle Management | Full or partial application import |
| **Smart Push** | Form save (auto) | Cross-cube data push |
| **Data Map** | Admin/scheduled | Cross-cube bulk data copy |
| **Approvals** | Planning admin | Promote, approve, reject planning units |
| **Audit** | System | Track user actions for compliance |
| **Maintenance** | Oracle Cloud | Daily maintenance window operations |

### Common Error Patterns

| Error in Log | Cause | Fix |
|-------------|-------|-----|
| "Member not found" | Typo in data file or member deleted | Fix member name in source file |
| "Invalid data value" | Non-numeric value in data field | Clean source data (remove "N/A", blanks) |
| "Block too large" | Cube design issue | Reduce dense dimension size |
| "Calc script error" | Syntax error in rule | Fix and re-validate rule |
| "Timeout" | Rule or load takes too long | Optimize rule or split data file |
| "Insufficient access" | User lacks permissions | Grant appropriate access |

## 7. COMMON MISTAKES

| Mistake | Symptom | Fix |
|---------|---------|-----|
| Not checking Jobs Console after batch runs | Failed jobs go unnoticed for days | Set up email alerts on failure |
| Scheduling overlapping rules | Lock contention, one rule blocks another | Stagger schedules by 5-10 minutes |
| No backup before destructive jobs (clear, import) | Data loss with no recovery | Always LCM export before major operations |
| Ignoring "Completed with Warnings" | Data partially loaded | Check warnings — they may indicate skipped records |
| Running rules during business hours | Users experience slowness | Schedule heavy rules for 2-4 AM |

## 8. INTERVIEW QUESTIONS

### Beginner
**Q: Where do you go to see if a business rule completed successfully?**
> Navigator → Monitor and Explore → Jobs (the Jobs Console). You can filter by job type, status, date, and user. Each job shows its status (Success, Error, Running), duration, and you can click to view the full execution log. For failed jobs, the log shows the exact error message and line number.

### Intermediate
**Q: Design the month-end close job sequence for Hotel Pvt Ltd.**
> Sequential execution: (1) Update Substitution Variables (CurrMonth, PriorMonth, ForecastStart). (2) Refresh Database if any dimension changes. (3) Data Import — load actuals from ERP. (4) Run Aggregation rule — aggregate Entity and Department. (5) Run Currency Conversion. (6) Smart Push to Reporting cube. (7) Send notification. Key design decisions: Stagger jobs by 5 minutes to avoid lock contention. Set up email alerts on all jobs. Run at 2 AM for overnight processing, or 8 AM if manual review is needed.
