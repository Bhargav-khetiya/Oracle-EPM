## 🐛 The DRILL Method — Systematic Debugging

```
D — Define the problem precisely
R — Reproduce the issue consistently
I — Isolate the root cause
L — Look at logs and evidence
L — List solutions and test
```

## 📌 Error Categories & Resolution Matrix

### Category 1: Data Errors

| Error | Symptom | Root Cause | Fix |
|-------|---------|-----------|-----|
| Wrong totals | Q1 ≠ Jan+Feb+Mar | Time Balance = Balance instead of Flow | Change Account → Time Balance = Flow |
| Missing data | Form shows #Missing | No block exists for intersection | Load data or SET CREATEBLOCKONEQ ON |
| Doubled data | Revenue shows 2× expected | Data loaded twice (Append instead of Replace) | Clear and reload with Replace |
| Rate showing 90% | Parent = sum of child rates | Rate member using (+) consolidation | Set to Never Share with (~) Ignore |
| Stale aggregation | Parent doesn't reflect child changes | Dynamic Calc not set, AGG not run | Set parent to Dynamic Calc OR run AGG |
| Currency mismatch | USD shows INR values | Exchange rates not loaded | Load rates, run translation rule |
| Actuals ≠ ERP | EPM total < ERP total | Unmapped accounts in Data Management | Check DM log for rejected/unmapped rows |

### 🎯 Hands-On: Data Debugging

```
Exercise 1: Time Balance Diagnosis
1. Set up an account with Time Balance = Balance
2. Enter Jan=100, Feb=200, Mar=300
3. Check Q1 → shows 300 (last month, not sum)
4. Change to Time Balance = Flow
5. Check Q1 → shows 600 (sum) ✅
6. Document: "Time Balance controls quarterly aggregation"

Exercise 2: Implied Sharing Debug
1. Create a parent with exactly ONE child
2. Enter 100 in the child
3. Check parent → shows 100 (implied sharing)
4. Add a second child, enter 200
5. Check parent → shows 300 (sum, implied sharing broken)
6. Document: "One child = implied sharing, two children = aggregation"

Exercise 3: Data Load Reconciliation
1. Prepare a CSV with 10 rows totaling 1,000,000
2. Load via Data Management
3. Check DM process log → how many loaded— How many rejected—
4. Open form → check total → matches CSV total—
5. If not: identify the discrepancy (unmapped members— duplicates—)
```

### Category 2: Calculation Errors

| Error | Symptom | Root Cause | Fix |
|-------|---------|-----------|-----|
| Rule "completes" but no data changes | Silent failure | SET CREATEBLOCKONEQ OFF + new intersection | Add SET CREATEBLOCKONEQ ON |
| Rule fails with error | Error in Job Console | Syntax error or missing member | Check error message, fix script |
| Slow rule (>30 min) | Job Console shows long duration | No FIX or CALC ALL | Narrow FIX scope |
| Wrong calculation result | Revenue × Rate ≠ expected | Cross-dim reference pointing to wrong member | Verify cross-dim addresses |
| Two-Pass not working | Ratios not recalculating at parent | Two-Pass property not set | Enable Two-Pass on the member |

### Debugging Calc Scripts — Step by Step

```
Step 1: Add SET MSG DETAIL (verbose logging)
   SET MSG DETAIL;
   → Check Job Console log for execution details

Step 2: Add diagnostic output
   FIX("E10001", "Budget", "Working", "FY27", "Jan")
       /* What is the current value— */
       "Debug_Account" = "Revenue";
       /* Check: Is data there— */
   ENDFIX

Step 3: Test with smallest possible scope
   FIX("E10001", "Budget", "Working", "FY27", "Jan")
       "Revenue" = "Units" * "Price";
   ENDFIX
   → If this works, gradually expand scope

Step 4: Check each cross-dim reference
   "Revenue" -> "Actual" -> "Final" -> "FY26"
   → Open Smart View, navigate to that exact intersection
   → Is there data there— What value—

Step 5: Verify SET CREATEBLOCKONEQ
   → If copying to new intersections, this MUST be ON
```

### 🎯 Hands-On: Calculation Debugging

```
Exercise 4: Debug a "Silent Failure"
1. Write a DATACOPY rule WITHOUT SET CREATEBLOCKONEQ ON
2. Copy from Actual to a NEW scenario that has no data
3. Run → completes successfully → but check the target → NO DATA
4. Add SET CREATEBLOCKONEQ ON
5. Run again → data appears in target
6. Document: "Without CREATEBLOCKONEQ, copies to non-existent blocks are silently dropped"

Exercise 5: Debug Wrong Calculations
1. Write a rule: "Profit" = "Revenue" - "Expenses"
2. Enter Revenue=1000, Expenses=400
3. Run → check Profit → should be 600
4. If wrong: add SET MSG DETAIL → rerun → read log
5. Check: Is "Profit" Dynamic Calc— If yes, the rule output is overridden
6. Fix: Either remove Dynamic Calc or remove the rule (don't do both)
```

### 💡 Logic & Purpose
The `DRILL` methodology forces administrators to stop guessing and start observing. In a multi-dimensional database, 90% of bugs are caused by the user looking at the wrong intersection. By forcing the admin to isolate the exact POV (Point of View) in Smart View, you confirm whether the data is truly wrong, or if the user simply forgot to select the correct `Version` or `Currency` from the dropdown.

### 🌀 Confusion Resolution
> **Misconception:** "I wrote a rule to copy Q1 data to Q2. It works perfectly on the 'Revenue' account. But when I run it for the 'Net Income' account, Q2 stays blank. The rule must be broken."
> **Reality:** The rule is fine; the metadata is the problem! 'Net Income' is almost always a `Dynamic Calc` member. You cannot run a `DATACOPY` or mathematical assignment (`"Net Income" = 100;`) on a Dynamic Calc member because it doesn't have a physical block to hold the data. Essbase silently drops the calc request. You must calculate the Level 0 children instead!

### 😈 Twisted Interview Question
**Question:** A user submits a form, which triggers a "Calculate Tax" business rule on Save. The user gets a red error popup: `Network timeout - the server did not respond`. The admin checks the server health and sees CPU is at 100%. Did the network drop the connection—
> **Answer:** No, the network is fine. EPM web forms have a hardcoded UI timeout (usually 3 minutes). If a Business Rule attached to "Run on Save" takes 5 minutes to execute, the web browser will timeout and throw a network error, even though the Essbase engine is still happily running the rule in the background (causing the 100% CPU spike). The admin must decouple the rule from the "Run on Save" trigger and run it asynchronously, or optimize the rule to run in under 3 minutes.

### Category 3: Form & UI Errors

| Error | Symptom | Root Cause | Fix |
|-------|---------|-----------|-----|
| Form shows all zeros | No data visible | Wrong POV (wrong scenario/version/year) | Check form POV settings |
| Form is read-only | Can't enter data | Dynamic Calc or Read access | Check member properties and security |
| Form takes >10 seconds | Very slow load | Too many cells, rules on load | Suppress missing, remove load rules |
| User can see wrong data | Security breach | Incorrect data access permissions | Fix entity/scenario security |
| Form error on open | "Error in form" | Invalid member reference or stale metadata | Refresh cube, check member exists |
| Smart List not showing | Dropdown missing | Smart List not assigned to member | Check member Data Type = Smart List |

### 🎯 Hands-On: Form Debugging

```
Exercise 6: Debug "Form Shows All Zeros"
1. Open a form → all zeros
2. Check 1: Is the POV correct— (right scenario, version, year—)
3. Check 2: Switch to a different entity via Pages
4. Check 3: Open Smart View ad-hoc → navigate to same intersection
5. If ad-hoc shows data but form doesn't → form member selection is wrong
6. If ad-hoc also shows zeros → no data at that intersection
7. Document your diagnosis steps
```

### Category 4: Integration Errors

| Error | Symptom | Root Cause | Fix |
|-------|---------|-----------|-----|
| Load rejected | "Target member not found" | Source account not mapped | Add mapping in Data Management |
| Partial load | 80/100 rows loaded | Some rows have issues | Check DM log for rejected rows |
| Load file not found | "File not found" error | Wrong filename or path | Check inbox file name exactly |
| EPM Automate login fails | Exit code 3 | Wrong credentials or URL | Verify user, password file, URL |
| Smart View can't connect | "Unable to connect" | URL/network/VPN issue | Check VPN, URL format, SSL |

### 🎯 Hands-On: Integration Debugging

```
Exercise 7: Debug a Failed Data Load
1. Create a CSV with an intentional error (unmapped account code)
2. Upload and try to load → observe partial failure
3. Navigate to Data Management → Process Details
4. Find the failed process → click for details
5. Read the error log → identify which rows failed and why
6. Fix: Add mapping for the unmapped account
7. Reload → verify 100% success
```

### Category 5: Smart View Errors

| Error | Symptom | Root Cause | Fix |
|-------|---------|-----------|-----|
| Tab missing | No Smart View in Excel | COM add-in disabled | File → Options → Add-ins → Enable |
| Connection refused | "Cannot connect" | Wrong URL or VPN down | Check URL, VPN, proxy |
| #NoData | HsGetValue returns nothing | Missing dimension in formula | Add ALL dimensions to HsGetValue |
| Session expired | Frequent logouts | Idle timeout too short | Increase timeout, refresh periodically |
| Slow refresh | 30+ seconds to refresh | Grid too large | Reduce members, enable suppression |
| Submit fails | "Unable to submit" | Read-only access or Dynamic Calc | Check security and member properties |

### 🎯 Hands-On: Smart View Debugging

```
Exercise 8: Debug HsGetValue #NoData
1. Write an HsGetValue formula with ALL 7 dimensions → should return data
2. Remove the Period dimension → verify you get #NoData
3. Add Period back → data returns
4. Change Entity to one without data → verify #NoData
5. Change Entity back → data returns
6. Document: "HsGetValue requires ALL dimensions. #NoData means missing dim or no data"
```

## 📌 Error Code Reference

### EPM Automate Exit Codes

| Code | Meaning | Debug Steps |
|------|---------|-------------|
| 0 | Success | — |
| 1 | General error | Check command syntax, read error output |
| 2 | Invalid argument | Check command format, parameter spelling |
| 3 | Auth failed | Verify user, password, URL, key |
| 4 | File not found | Check file path, inbox contents |
| 5 | Network error | Check VPN, DNS, firewall |

### Common Job Console Errors

| Error Message | Meaning | Fix |
|---------------|---------|-----|
| "Member [X] not found" | Rule references non-existent member | Check spelling, refresh cube |
| "Syntax error at line N" | Script syntax issue | Check line N in calc script |
| "Cannot lock object" | Another user/rule has the block locked | Wait and retry |
| "Maximum time exceeded" | Rule ran > 30 min timeout | Optimize the rule (narrow FIX) |
| "Insufficient access" | User doesn't have permission | Check security assignments |

## 🎓 Interview Questions

**Q: Walk me through how you debug wrong totals in a report.**
> (1) Define: Which total is wrong— By how much— (2) Check Time Balance property on the account. (3) Check consolidation operators on children. (4) Check if any member has a formula overriding aggregation. (5) Check for Dynamic Calc vs Store inconsistencies. (6) Open Smart View, zoom into each child, manually sum — compare with parent. (7) If manual sum matches but parent doesn't: Time Balance or formula issue.

**Q: A DATACOPY rule completes without error but no data appears in the target. What happened—**
> SET CREATEBLOCKONEQ is OFF (default). When copying to a Sparse intersection that has no existing block, the data is silently lost because there's no block to write to. Fix: Add SET CREATEBLOCKONEQ ON at the top of the script.

**Q: How do you approach a P1 incident where EPM Cloud is unreachable—**
> (1) Check Oracle Cloud Status page. (2) If Oracle issue → raise SR with Severity 1. (3) If NOT Oracle → check VPN, DNS, SSO provider. (4) Communicate to stakeholders immediately with timeline. (5) Document everything for post-incident RCA.
