## 1. WHY — Structured Incident Management

Without a tiered support model, every ticket goes to the most senior person. The architect spends 3 hours fixing "Smart View won't connect" (a 5-minute VPN issue). Tiered support ensures the right person handles the right issue.

## 4. SHOW ME — Hotel Pvt Ltd Support Matrix

```
Support Team:
  L1: IT Help Desk (2 people) — handles VPN, login, basic questions
  L2: EPBCS Admin (Bhargav) — handles config, security, data, rules
  L3: Architect (Consultant, on-call) — handles complex rule fixes

Monthly Ticket Volume:
  L1: 20 tickets/month (avg resolution: 15 minutes)
  L2: 8 tickets/month (avg resolution: 45 minutes)
  L3: 1-2 tickets/month (avg resolution: 4 hours)
  Oracle SR: 0-1 per quarter

Escalation Rules:
  L1 → L2: If not resolved in 30 minutes
  L2 → L3: If requires code change or architecture decision
  L2 → Oracle: If cloud infrastructure issue
  Any → Sev 1: If production down for all users
```
