# 19.01 — EPM Implementation Lifecycle: Complete Guide

> **Module:** 19_Implementation | **Topic:** End-to-End Project Methodology
> **Audience:** Consultant / Project Lead

---

## 1. WHY — Structured Implementation Matters

A 12-week EPBCS implementation costs ₹30-50L in consulting fees. Without a structured methodology, projects overrun by 40-100%. The lifecycle below is proven across 100+ EPBCS implementations.

---

## 2. THE 6-PHASE LIFECYCLE

```
Phase 1: DISCOVER (2 weeks)
├── Requirements workshops with business stakeholders
├── Current state assessment (Excel, legacy systems)
├── Identify pain points, KPIs, reporting needs
├── Define scope: which modules (FinPlan, Workforce, Capital—)
├── Define dimensions: Account, Entity, Scenario, Period, Custom
├── Deliverable: Business Requirements Document (BRD)
└── Deliverable: Solution Design Document (SDD)

Phase 2: DESIGN (2 weeks)
├── Dimension design (hierarchies, properties, aliases)
├── Form layout design (with mockups in Excel)
├── Business rule logic (pseudo-code)
├── Security model (roles, groups, access matrix)
├── Data integration design (source → EPBCS mapping)
├── Deliverable: Technical Design Document (TDD)
└── Sign-off: Client approves design before build

Phase 3: BUILD (4 weeks)
├── Week 1: Dimensions + Members + Database Refresh
├── Week 2: Forms + Smart Lists + Substitution Variables
├── Week 3: Business Rules + Rulesets + Groovy Validation
├── Week 4: Security + Data Integration + Smart Push
├── Daily: Unit testing after each component built
└── Deliverable: Configured EPBCS environment

Phase 4: TEST (2 weeks)
├── System Integration Testing (SIT) — admin validates end-to-end
├── User Acceptance Testing (UAT) — business users validate
├── Performance testing — forms load < 5 seconds
├── Security testing — each role sees correct data
├── Data validation — compare EPBCS vs source system totals
├── Defect tracking: log, prioritize, fix, re-test
└── Deliverable: UAT Sign-off Document

Phase 5: DEPLOY (1 week)
├── Final data migration (historical + current year)
├── Smart View deployment to all users
├── User training: 2 sessions (planners + admins)
├── Quick Reference Guide distribution
├── Go-live cutover (Friday evening)
└── Deliverable: Go-Live Checklist

Phase 6: STABILIZE (1 week + ongoing)
├── War room support (first week post-go-live)
├── Hotfix minor issues (form tweaks, security adjustments)
├── Handover to client admin team
├── Monthly health check (first 3 months)
├── Deliverable: Operations Runbook
└── Deliverable: Knowledge Transfer completed
```

## 4. COMMON MISTAKES

| Mistake | Impact | Prevention |
|---------|--------|-----------|
| Skipping design sign-off | Build-rework cycles | Formal sign-off before Phase 3 |
| Building before dimensions are final | Rebuild forms/rules | Freeze dimensions by end of Week 4 |
| No UAT with real users | Go-live surprises | 2 weeks of UAT with actual planners |
| Training only admins | Users struggle post-go-live | Train ALL user groups |
| No operations runbook | Client can't maintain | Document ALL admin procedures |
