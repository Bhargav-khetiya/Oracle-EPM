# EPM Architect Interview Questions

A collection of technical and architectural questions used to screen candidates for Oracle EPM Architect or Lead Developer roles.

## 1. Architecture & Essbase Engine

**Q: Explain the difference between Dense and Sparse dimensions. How do they impact database size and calculation time—**
*   **Ideal Answer:** Dense dimensions form the data block (array in memory); Sparse dimensions form the index (pointers to blocks). If a dimension has a high probability of data existing for every member combination (like Account or Period), it should be Dense. If you make a large, mostly-empty dimension (like Project) Dense, it creates massive, empty blocks that consume RAM and drastically slow down calculations and data loads.

**Q: In a BSO cube, why is it dangerous to place a Dynamic Calc member inside a FIX statement—**
*   **Ideal Answer:** A `FIX` statement defines the block calculation scope. If you include a Dynamic Calc member, Essbase is forced to execute that dynamic formula block-by-block during the batch process, rather than just calculating it on-the-fly when a user queries it. This can turn a 5-minute aggregation into a 4-hour aggregation.

**Q: What is Hybrid BSO, and how has it changed EPM design—**
*   **Ideal Answer:** Hybrid BSO allows upper-level sparse members to calculate dynamically on the fly (like ASO), while retaining the block structure and calculation scripts at level 0 (like BSO). It eliminates the need for massive overnight aggregation scripts and significantly reduces database size.

## 2. Calculation Manager & Logic

**Q: Explain the difference between a Substitution Variable and a Runtime Prompt (RTP).**
*   **Ideal Answer:** A Substitution Variable (e.g., `&CurMonth`) is a global placeholder updated by an admin; when changed, it updates everywhere instantly. An RTP (e.g., `{rtp_Entity}`) is a dynamic parameter that asks the specific user for an input at the exact moment they execute a Business Rule.

**Q: How do you handle a "Divide by Zero" error in an Essbase calculation script—**
*   **Ideal Answer:** You must use an `IF` statement to check if the denominator is not `#MISSING` and not `0` before executing the division. Alternatively, you can use the `@ISMBR` or `@CalcMgrIF` functions if using CDFs, but standard `IF (Denominator <> 0 AND Denominator <> #MISSING)` is required to prevent `#DIV/0` errors from polluting the cube.

## 3. Data Integration & Security

**Q: A user submits a Help Desk ticket saying their form is entirely grayed out (Read-Only). Walk me through your troubleshooting steps.**
*   **Ideal Answer:** 1. Check IDCS/Native Security (Are they in the right group— Do they have write access to that Entity—). 2. Check Valid Intersections (Is that specific Entity/Account combination blocked—). 3. Check Approval Unit status (Is the budget locked or promoted to their manager—). 4. Check if they are trying to input data into a Parent or Dynamic Calc member.

**Q: What is the "Missing Dependency" trap in Lifecycle Management (LCM) migrations—**
*   **Ideal Answer:** When doing an incremental migration (e.g., migrating a single Form), LCM does not automatically pull in the objects that Form relies on (like a specific Smart List, Business Rule, or Action Menu). If those dependencies don't exist in the target environment, the import fails. You must manually select all dependencies in the export.
