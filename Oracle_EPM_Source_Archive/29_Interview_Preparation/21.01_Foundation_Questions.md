## 📌 Q1. What is Oracle EPM?
> **Answer:** EPM stands for Enterprise Performance Management. It's a system that helps large organizations plan their future financial performance, track actual results, and compare planned vs actual to make better business decisions. Oracle EPM Cloud is the cloud-based platform that includes tools for planning (EPBCS), consolidation (FCCS), reconciliation (ARCS), and more.

**Follow-up:** Why can't companies just use Excel?
> Excel doesn't scale for large organizations. Multiple teams create separate spreadsheets with no single source of truth. EPM centralizes all financial planning data, ensures consistency, automates calculations, and provides real-time consolidated views.

## 📌 Q2. Name the 7 Pillars of Oracle EPM Cloud.
> **Answer:**
> 1. **EPBCS** — Enterprise Planning and Budgeting Cloud Service (Planning & Budgeting)
> 2. **FCCS** — Financial Consolidation and Close Cloud Service
> 3. **ARCS** — Account Reconciliation Cloud Service
> 4. **EDMCS** — Enterprise Data Management Cloud Service
> 5. **NRCS** — Narrative Reporting Cloud Service
> 6. **PCMCS** — Profitability and Cost Management Cloud Service
> 7. **TRCS** — Tax Reporting Cloud Service

## 📌 Q3. What is the difference between Hyperion, PBCS, and EPBCS?
> **Answer:**
> - **Hyperion:** On-premises EPM solution (installed on company servers). Legacy product.
> - **PBCS:** Planning and Budgeting Cloud Service. Basic cloud version with custom applications only.
> - **EPBCS:** Enhanced PBCS. Cloud version with OOTB modules (FinPlan, Manpower, Capital), Strategic Modeling, and enhanced features.

| Feature | Hyperion | PBCS | EPBCS |
|---|---|---|---|
| Deployment | On-premises | Cloud | Cloud |
| OOTB Modules | ❌ | ❌ | ✅ |
| Maintenance | Customer | Oracle | Oracle |
| Updates | Manual | Automatic | Automatic |

## 📌 Q4. What is the difference between a Functional and Technical EPM Consultant?
> **Answer:**
> - **Functional:** Speaks business/finance language. Gathers requirements, writes documentation, designs the solution, tests against business needs.
> - **Technical:** Speaks system/code language. Configures cubes, writes business rules (Groovy, Calc Scripts), sets up integrations, builds forms, manages metadata.

### 😈 Twisted Interview Question
**Question:** A client asks you to build a complex allocation rule that spreads IT expenses across all departments based on headcount. As a Technical Consultant, you know exactly how to write the Groovy script. Should you start coding?
> **Answer:** NO! A true Pro Technical Consultant never starts coding without a Functional specification. You must first ask the Functional consultant (or the business): "What happens if a department has zero headcount? Do we allocate the remainder to Corporate, or does it stay in IT?" Coding without functional edge-case definitions leads to infinite rework.

## 📌 Q6. What is Driver-Based Planning?
> **Answer:** A planning approach where users enter **assumptions (drivers)** and the system automatically calculates results. Example: Number of Employees (driver) × Average Salary = Total Salary Expense. Changing the driver automatically updates the expense.

---

## 📌 Q7. What is a Rolling Forecast?
> **Answer:** A forecast that is continuously updated as new actual data arrives. Instead of a fixed annual forecast, it always looks 12-18 months ahead. Example: In March, Jan-Feb are actuals, and Mar-Dec+ are updated forecasts based on latest trends.

---

## 📌 Q8. What is Variance Analysis?
> **Answer:** Comparing Budget vs Actual to find differences (variances). Example: Budget Revenue = ₹100 Cr, Actual Revenue = ₹95 Cr → Variance = -₹5 Cr (unfavorable). This helps management understand where the business over- or under-performed.

---

## 📌 Q9. What is ERP and how does it relate to EPM?
> **Answer:** ERP (Enterprise Resource Planning) manages day-to-day operations (accounting, payroll, inventory). EPM pulls **actual data from ERP** and uses it for planning, budgeting, and forecasting. The flow is: ERP (Actuals) → EPM (Planning/Forecasting) → Reports (Decision Making).

---

## 📌 Q10. What is the difference between Budget, Forecast, and Actual?
> **Answer:**
> - **Budget:** The financial plan for a future period (usually annual). Set once, rarely changed.
> - **Forecast:** An updated prediction based on latest data. More dynamic than budget.
> - **Actual:** Real numbers from completed periods (loaded from ERP).
