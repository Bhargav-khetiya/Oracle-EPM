## 📌 Q1. What is a Form in EPBCS?
> **Answer:** A Form is a data entry screen (like an Excel sheet) that provides a structured view of the Essbase cube. It shows specific dimensions on rows, columns, pages, and POV — allowing users to enter or view financial data like budgets, forecasts, and actuals.

---

## 📌 Q2. What are the 4 areas of a Form layout?
> **Answer:**
> 1. **POV (Point of View):** Fixed filters at the top — rarely changed (Scenario, Version, Year)
> 2. **Pages:** Switchable filters — users can switch between values (Entity, Department)
> 3. **Rows:** Left-side headers — typically Account members
> 4. **Columns:** Top headers — typically Period members (Jan, Feb, Mar...)

---

## 📌 Q3. What is the difference between POV and Pages?
> **Answer:**
> - **POV** = dimensions that are fixed for the form's purpose and rarely changed (like Scenario=Budget, Year=FY26)
> - **Pages** = dimensions that users frequently switch between (like Entity, Department)
> Both filter data, but Pages allow easy switching while POV is more static.

---

## 📌 Q4. What is the Anchor Dimension?
> **Answer:** When multiple dimensions are placed on rows (or columns), the Anchor Dimension determines which one controls the primary layout/nesting. If Account is the anchor, accounts appear first with other dimensions nested inside. If Department is the anchor, departments appear first.

```
Anchor=Account:          Anchor=Department:
Revenue                  HR Department
  → HR Dept                → Revenue
  → IT Dept                → Expense
Expense                  IT Department
  → HR Dept                → Revenue
  → IT Dept                → Expense
```

## 📌 Q5. What does "Suppress Missing Data" do?
> **Answer:** Hides rows/columns where all cells are #MISSING. This makes forms cleaner by only showing rows that have data. Without it, forms may show many empty rows displaying "#MISSING".

**Follow-up:** What about "Suppress Missing Blocks"?
> This is a performance optimization. It prevents Essbase from searching for blocks that don't exist. However, it can actually DEGRADE performance if very few rows are suppressed — always test.

### 😈 Twisted Interview Question
**Question:** An admin turns on "Suppress Missing Data" for the rows on a form. A user opens the form and complains that they cannot enter their budget for the "Travel" account. The admin checks their security, and the user has full Write access. Why can't the user enter data?
> **Answer:** Because the user has never budgeted for Travel before, the intersection is `#MISSING` (no data exists). Because the admin turned on "Suppress Missing Data", the empty Travel row is completely hidden from the form! The user literally cannot see the row to type the number in. The admin must either uncheck suppression, or the user must use a Smart View ad-hoc grid to submit the first piece of data to un-suppress the row.

---

## 📌 Q6. What is the difference between "Suppress Missing Data" and "Display Missing Values as Blank"?
> **Answer:**
> - **Suppress Missing Data:** Completely HIDES rows/columns with all #MISSING values
> - **Display Missing Values as Blank:** Shows the rows but displays empty cells instead of "#MISSING" text

---

## 📌 Q7. What are Validation Rules in Forms?
> **Answer:** Rules that check user inputs for data quality before submission. Example: "Revenue must be greater than 0" — if a user enters 0, they see an error message.

---

## 📌 Q8. What are Menus in Forms?
> **Answer:** Right-click options or toolbar buttons that let users perform actions directly from a form. Common actions: Run Business Rule, Launch URL, Open Another Form, Drill Through.

---

## 📌 Q9. What are Substitution Variables?
> **Answer:** Global placeholders whose values can be changed without modifying the application. Example: `&CurrentYear = FY26`. All forms using `&CurrentYear` automatically update when the variable is changed. This avoids editing 50 forms individually.

---

## 📌 Q10. When would you make a form read-only?
> **Answer:** When the form is for reporting/viewing only (not data entry). Examples: summary dashboards, actual data views (actuals come from ERP, not user entry), or forms showing Dynamic Calc members that can't be edited anyway.

---

## 📌 Q11. What is "Enable Calc On the Fly"?
> **Answer:** A form property that lets users see member formula results immediately on hover and calculates values without submitting the form. Useful for real-time feedback during data entry.

---

## 📌 Q12. What is a Global Assumptions Form?
> **Answer:** A form that stores assumption values (like tax rates, growth rates) that are shared across environments. Enabling the Global Assumptions property allows these values to be transferred when migrating between DEV/TEST/PROD environments.
