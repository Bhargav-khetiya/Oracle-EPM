# 22.03 — Lab: Build Executive Dashboards

> **Module:** 22_Labs | **Topic:** Dashboards, Infolets, Charts
> **Duration:** 2-3 hours | **Level:** Intermediate

---

## 1. LAB OBJECTIVE

Build 3 executive dashboards for Hotel Pvt Ltd: Revenue Dashboard, P&L Summary, and KPI Scorecard — using EPBCS dashboard components, charts, and tiles.

---

## 2. PRE-REQUISITES

```
✅ Completed Lab 22.01 and 22.02 (app with data + rules)
✅ Test data entered for at least 3 months, 3 hotels
```

---

## 3. DASHBOARD 1: Revenue Overview

### Build the Underlying Forms

```
Form 1A: DB_Revenue_ByHotel
  Purpose: Revenue by hotel (for bar chart)
  Rows: Entity (@CHILDREN("All_Hotels"))
  Columns: Account (Total_Revenue)
  POV: Scenario (Budget), Version (Working), Year (&CurrYear), Period (&CurrMonth)
  Properties: Read Only, Suppress Missing

Form 1B: DB_Revenue_Trend
  Purpose: Revenue trend by month (for line chart)
  Rows: Period (Jan, Feb, Mar, Apr, May, Jun, Jul, Aug, Sep, Oct, Nov, Dec)
  Columns: Scenario (Actual, Budget)
  POV: Account (Total_Revenue), Entity (All_Hotels), Version (Final), Year (&CurrYear)
  Properties: Read Only, Suppress Missing
```

### Build the Dashboard

```
Navigator → Create and Manage → Dashboards → Create

Dashboard Name: Revenue_Overview

Layout: 2 columns
  Left Column (50%):
    ├── Tile: "Revenue by Hotel"
    │   Type: Bar Chart
    │   Data Source: Form DB_Revenue_ByHotel
    │   X-axis: Entity
    │   Y-axis: Total_Revenue
    │   Color: Gradient (green = high, red = low)
    │
    └── Tile: "Revenue Summary"
        Type: Data Grid (form)
        Data Source: Form DB_Revenue_ByHotel

  Right Column (50%):
    ├── Tile: "Revenue Trend"
    │   Type: Line Chart
    │   Data Source: Form DB_Revenue_Trend
    │   X-axis: Period
    │   Lines: Actual vs Budget
    │   Color: Actual = blue, Budget = orange (dashed)
    │
    └── Tile: "YoY Growth"
        Type: KPI Tile (single number)
        Data: HsGetValue for YoY Growth %
        Format: Arrow up (green if positive)
```

## 4. DASHBOARD 2: P&L Summary

### Build the Underlying Form

```
Form 2A: DB_PnL_Matrix
  Purpose: P&L matrix by entity
  Rows: Account (Total_Revenue, Total_Expenses, Net_Income, Profit_Margin)
  Columns: Entity (@CHILDREN("All_Hotels"), All_Hotels)
  POV: Scenario (&POV), Version (Working), Year (&CurrYear), Period (&CurrMonth)
  Properties: Read Only, Suppress Missing
  Formatting:
    Net_Income row: Bold, Green if positive
    Profit_Margin row: Percentage format
```

### Build the Dashboard

```
Dashboard Name: PnL_Summary

Layout: Full width
  Row 1 (30% height):
    ├── KPI Tile: Total Revenue (₹12.5 Cr)
    ├── KPI Tile: Net Income (₹2.35 Cr)
    ├── KPI Tile: Profit Margin (18.8%)
    └── KPI Tile: Hotels Profitable (5/5)

  Row 2 (70% height):
    ├── Left (60%): P&L Matrix (form grid)
    │   Data Source: Form DB_PnL_Matrix
    │
    └── Right (40%): Profit Margin by Hotel (pie chart)
        Data Source: Form DB_Revenue_ByHotel
        Metric: Net_Income per hotel
```

## 5. DASHBOARD 3: KPI Scorecard

### Build the Underlying Forms

```
Form 3A: DB_KPI_Scorecard
  Rows: Account (RevPAR, Occupancy_Rate, ADR, Profit_Margin)
  Columns: Entity (@CHILDREN("All_Hotels"))
  POV: Scenario (Actual), Version (Final), Year (&CurrYear), Period (&CurrMonth)

Form 3B: DB_Variance_Report
  Rows: Account (Total_Revenue, Total_Expenses, Net_Income)
  Columns: Scenario (Actual, Budget), Custom "Variance" column (Actual - Budget)
  POV: Entity (All_Hotels), Version (Final), Year (&CurrYear), Period (&CurrMonth)
```

### Build the Dashboard

```
Dashboard Name: KPI_Scorecard

Layout: 3 columns
  Column 1: KPI tiles (4 gauges)
    ├── RevPAR: ₹5,200 (vs target ₹5,000) ✅
    ├── Occupancy: 78% (vs target 75%) ✅
    ├── ADR: ₹8,500 (vs target ₹8,000) ✅
    └── Margin: 18.8% (vs target 20%) ⚠️

  Column 2: KPI table (form grid)
    Data Source: Form DB_KPI_Scorecard
    Conditional formatting:
      Green if >= target
      Red if < target

  Column 3: Variance chart
    Type: Waterfall chart
    Data: Revenue variance, Expense variance → Net Income variance
    Green: Favorable, Red: Unfavorable
```

## 6. INFOLETS (HOME PAGE TILES)

```
Navigator → Home → Edit

Add Infolet tiles:
  Tile 1: "Revenue" → ₹12.5 Cr → Links to Revenue_Overview dashboard
  Tile 2: "Net Income" → ₹2.35 Cr → Links to PnL_Summary dashboard
  Tile 3: "Occupancy" → 78% → Links to KPI_Scorecard dashboard
  Tile 4: "Budget Status" → 3 of 5 Approved → Links to Approval dashboard

Each tile shows:
  Large number (current value)
  Trend arrow (up/down from prior month)
  Click to navigate to detailed dashboard
```
