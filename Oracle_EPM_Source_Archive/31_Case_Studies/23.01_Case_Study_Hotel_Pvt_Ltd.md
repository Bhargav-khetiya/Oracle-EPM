# 23.01 — Case Study: Hotel Pvt Ltd — Complete EPBCS Implementation

> **Module:** 23_Case_Studies | **Topic:** End-to-End Implementation Case Study
> **Audience:** Architect / Consultant

---

## 1. THE CLIENT

```
Company: Hotel Pvt Ltd
Industry: Hospitality — 5-star hotel chain
Geography: India (5 cities)
Revenue: ₹26 Cr/year
Hotels: 5 properties, 500 rooms total
Employees: 2,000+

Executive Team:
  CEO: Overall strategy
  CFO: Financial planning and reporting
  5 GMs: One per hotel
  VP Finance: Consolidated reporting
  HR VP: Workforce planning
```

---

## 2. THE PROBLEM (Before EPBCS)

```
Pain Points:
  ❌ 47 Excel spreadsheets for budgeting (no single source of truth)
  ❌ Budget cycle takes 3 months (target: 4 weeks)
  ❌ No real-time consolidated P&L
  ❌ Month-end close takes 5 business days
  ❌ No variance analysis (Actual vs Budget)
  ❌ Currency conversion manual (INR → USD for investors)
  ❌ No audit trail (SOX compliance risk)
  ❌ 2 FTEs dedicated to data consolidation
  
Annual Cost of Current Process:
  ₹40L in manual labor (2 FTEs × ₹20L each)
  ₹15L in errors and re-work
  ₹10L in delayed decision-making
  Total: ₹65L/year lost to manual budgeting
```

---

## 3. THE SOLUTION — EPBCS DESIGN

### Application Architecture

```
Application: HotelApp (EPBCS Enterprise)

Cubes:
  OEP_FS (FinPlan)    → Revenue, Expenses, P&L (Hybrid BSO)
  OEP_WFP (Workforce) → Headcount, Salary, Benefits (Hybrid BSO)
  OEP_REP (Reporting) → Consolidated reporting (ASO)

Dimensions:
  Account:  200 members (Revenue, Expenses, KPIs)  — Dense
  Period:   17 members (12 months + 4 quarters + Total)  — Dense
  Entity:   12 members (5 hotels + Corporate + regional)  — Sparse
  Scenario: 3 members (Actual, Budget, Forecast)  — Sparse
  Version:  3 members (Working, Final, Variance)  — Sparse
  Year:     5 members (FY2024 → FY2028)  — Sparse
  Currency: 3 members (Local, USD, EUR)  — Dense
  Department: 8 members (Front Office, F&B, etc.)  — Sparse
```

### Forms (35 total)

```
Data Entry Forms:
  FIN_Revenue_Entry (per hotel, monthly revenue)
  FIN_Expense_Entry (per hotel, monthly expenses)
  FIN_CapEx_Entry (capital expenditure projects)
  WF_Headcount_Entry (per hotel, monthly headcount)
  WF_Salary_Entry (salary details)

Summary Forms:
  RPT_PnL_Summary (consolidated P&L)
  RPT_Revenue_Dashboard (revenue by hotel, by category)
  RPT_KPI_Scorecard (RevPAR, Occupancy, ADR, Margin)
  RPT_Variance_Analysis (Actual vs Budget with drill)

Admin Forms:
  ADM_Exchange_Rate_Entry (monthly INR→USD rates)
  ADM_Budget_Status (Smart List tracking per hotel)
```

### Business Rules (15 rules in 4 Rulesets)

```
RS_OnSave_Revenue:
  1. VAL_Revenue_NonNegative (Groovy validation)
  2. CALC_Revenue_Totals
  3. CALC_PnL
  4. AGG_Entity

RS_OnSave_Expense:
  1. VAL_Expense_Limits (Groovy)
  2. CALC_Expense_Totals
  3. CALC_PnL
  4. AGG_Entity

RS_Monthly_Close:
  1. CALC_Revenue_Totals
  2. CALC_Expense_Totals
  3. CALC_PnL
  4. CALC_KPIs
  5. CALC_Currency_Conversion
  6. ALLOC_Corporate_Cost
  7. AGG_Entity
  8. PUSH_to_Reporting (Smart Push to ASO)

RS_Annual_Budget_Seed:
  1. CLEAR_Budget_Data
  2. COPY_Actual_to_Budget
  3. APPLY_Growth_Rates
  4. CALC_PnL
  5. AGG_Entity
```

## 4. IMPLEMENTATION TIMELINE

```
Week 1-2:  Requirements gathering + design workshops
Week 3-4:  Environment setup, dimensions, members
Week 5-6:  Forms and data entry templates
Week 7-8:  Business rules and rulesets
Week 9:    Data integration (PMS → EPBCS)
Week 10:   Security, testing, Smart View setup
Week 11:   UAT (user acceptance testing)
Week 12:   Go-live + training

Total: 12 weeks (3 months)
Team: 1 Lead Consultant, 1 Developer, 1 Client Admin
```

## 5. RESULTS (After 6 Months)

```
BEFORE                          AFTER
──────────────────────────────────────────────────────
47 Excel spreadsheets    →      1 EPBCS application
3-month budget cycle     →      4-week budget cycle (75% reduction)
5-day month-end close    →      1-day close (80% reduction)
No real-time reporting   →      Live dashboards + Smart View
Manual consolidation     →      Automatic AGG (real-time)
No variance analysis     →      Actual vs Budget at every intersection
Manual currency conv.    →      Automated (15 seconds)
No audit trail           →      Full audit (SOX compliant)
2 FTEs consolidating     →      0 FTEs (reallocated to analysis)

ROI:
  Implementation cost:     ₹25L (license) + ₹30L (consulting)
  Annual savings:          ₹65L (labor + errors + time)
  Payback period:          ~10 months
  3-year ROI:              240%
```

## 6. LESSONS LEARNED

```
✅ What Worked:
  1. Starting with EPBCS modules (not FreeForm) — pre-built forms saved weeks
  2. Hybrid BSO — no AGG needed, forms always show correct totals
  3. Rulesets — 3× faster than individual On Save rules
  4. EPM Automate automation — monthly tasks scripted

⚠️ Challenges:
  1. Users resistant to leaving Excel → Solved with Smart View training
  2. PMS data format mismatched EPBCS → Built Python ETL script
  3. Block explosion during testing → Fixed SET CREATEBLOCKONEQ OFF
  4. Seasonal revenue patterns → Built custom seasonal spread weights

💡 Key Decisions:
  1. Hotel Pvt Ltd scenario: Full EPBCS (not PBCS) for pre-built modules
  2. Hybrid BSO over pure BSO → eliminated AGG maintenance
  3. Groovy for validation, Calc Script for math → optimal performance
  4. ASO reporting cube for executive dashboards → instant queries
```
