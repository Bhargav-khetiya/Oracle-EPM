# 23.03 — Case Study: Multi-Currency Consolidation

> **Module:** 23_Case_Studies | **Topic:** INR/USD/EUR Currency Architecture
> **Audience:** Architect / Finance Consultant

---

## 1. THE PROBLEM

```
Hotel Pvt Ltd — Currency Challenges:

1. All hotels report in INR (Local currency)
2. US investors need reports in USD
3. European partner needs reports in EUR
4. Exchange rates change monthly
5. Balance Sheet: closing rate (end of month)
6. P&L: average rate (monthly average)
7. Historical: locked at transaction rate
8. Manual conversion in Excel → 40 formulas → errors every month
```

---

## 2. THE SOLUTION — EPBCS CURRENCY DESIGN

### Dimension Setup

```
Currency Dimension:
  Local       (reporting currency per entity)
  USD         (US Dollar — investor reporting)
  EUR         (Euro — partner reporting)

Exchange Rate Table:
  Type        | Use For           | Example (Aug 2026)
  Average     | P&L items         | 1 USD = ₹83.50
  Ending      | Balance Sheet     | 1 USD = ₹83.80
  Historical  | Equity items      | 1 USD = ₹75.00 (locked)
```

### Account Properties for Currency

```
Account           | Type    | Exchange Rate Type
───────────────────┼─────────┼───────────────────
Room_Revenue       | Revenue | Average
F&B_Revenue        | Revenue | Average
Labor              | Expense | Average
Total_Revenue      | Revenue | Average (inherits)
Total_Expenses     | Expense | Average (inherits)
Net_Income         | Revenue | Average (calc)
Cash               | Asset   | Ending
Accounts_Receivable| Asset   | Ending
Fixed_Assets       | Asset   | Historical
Share_Capital      | Equity  | Historical
```

### Currency Conversion Rule

```essbase
/* Currency Conversion: INR → USD → EUR */
SET LOCKBLOCK ON;

/* Step 1: Get exchange rates from Exchange Rate Table */
VAR v_AvgRate_USD;
VAR v_EndRate_USD;
VAR v_AvgRate_EUR;
VAR v_EndRate_EUR;

FIX("Exchange_Rates", "Actual", "Final", &CurrYear, &CurrMonth)
  v_AvgRate_USD = "Avg_Rate_USD";     /* 83.50 */
  v_EndRate_USD = "End_Rate_USD";     /* 83.80 */
  v_AvgRate_EUR = "Avg_Rate_EUR";     /* 91.20 */
  v_EndRate_EUR = "End_Rate_EUR";     /* 91.50 */
ENDFIX

/* Step 2: Convert P&L (Average Rate) */
FIX("Actual", "Final", &CurrYear, &CurrMonth)
  FIX(@RELATIVE("All_Hotels", 0))
    
    /* Revenue and Expense accounts → Average rate */
    FIX(@DESCENDANTS("Total_Revenue"), @DESCENDANTS("Total_Expenses"))
      IF(v_AvgRate_USD <> 0)
        "USD" = "Local" / v_AvgRate_USD;
      ENDIF
      IF(v_AvgRate_EUR <> 0)
        "EUR" = "Local" / v_AvgRate_EUR;
      ENDIF
    ENDFIX
    
    /* Balance Sheet accounts → Ending rate */
    FIX(@DESCENDANTS("Total_Assets"), @DESCENDANTS("Total_Liabilities"))
      IF(v_EndRate_USD <> 0)
        "USD" = "Local" / v_EndRate_USD;
      ENDIF
      IF(v_EndRate_EUR <> 0)
        "EUR" = "Local" / v_EndRate_EUR;
      ENDIF
    ENDFIX
    
    /* Equity accounts → Historical rate (fixed) */
    FIX(@DESCENDANTS("Total_Equity"))
      "USD" = "Local" / 75.00;
      "EUR" = "Local" / 82.00;
    ENDFIX
    
  ENDFIX
ENDFIX

SET LOCKBLOCK OFF;
```

## 3. THE RESULTS

```
BEFORE (Manual Excel):
  40 formulas across 5 sheets
  Errors: 2-3 per month (wrong rate applied)
  Time: 4 hours per close
  Audit trail: None

AFTER (EPBCS):
  1 business rule: 15 seconds execution
  Errors: 0 (systematic, same rule every month)
  Time: 15 seconds (automated in monthly close)
  Audit trail: Full (which rate, when, who triggered)
```
