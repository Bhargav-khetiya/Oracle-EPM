## 🏢 1. The EPM Cloud Interface Hierarchy

Every Oracle EPM Cloud application follows a strict 3-tier visual architecture:
```
┌─────────────────────────────────────────────────────────────┐
│ 1. CLUSTERS (The Top-Level Tabs on the Springboard)         │
│    ├── 2. CARDS (The Large Square Tiles inside a Cluster)   │
│    │    └── 3. TABS / SUB-VIEWS (Vertical/Horizontal Tabs)  │
└─────────────────────────────────────────────────────────────┘
```

When an interviewer asks: *"Where do you configure X?"*, an elite architect answers with exact visual paths:
> *"You navigate to the **Application** cluster, open the **Settings** card, and check the **System Properties** tab."*

## 💡 2. Complete Springboard & Navigator Tile Map

Below is the definitive catalog of every Cluster and Card available across EPBCS / Planning Enterprise applications.

### A. Cluster: Application (The Admin Engine Room)
This cluster is restricted to Service Administrators and Power Users.

| Card (Tile) | Primary Purpose | Hidden / Advanced Architect Use Cases |
| :--- | :--- | :--- |
| **Overview** | Application properties, cube dimensions, activity reports | • Check exact Essbase block count, density, and page/index size.<br>• Download **Activity Reports** (`/interop/...`) to debug slow requests.<br>• View cube storage type (BSO vs ASO vs Hybrid). |
| **Settings** | Global application configuration | • **Number of Daily Maintenance Backups:** Set between 1-3 (default 1).<br>• **User Display Name:** Switch between First/Last vs User ID.<br>• **SMART VIEW Behavioral Settings:** Enable cell formatting persistence across refreshes. |
| **Migration (LCM)** | Backup, restore, and snapshot management | • Download daily maintenance snapshots (`Artifact Snapshot`).<br>• Migrate specific artifacts (e.g., *only* Calc Manager rules or *only* Data Maps) between Dev and Prod.<br>• Inspect `LCM_Export.log` for exact XML diffs during deployment failures. |
| **Jobs** | Job scheduling and execution console | • Monitor long-running Business Rules, Data Maps, and EPM Automate tasks.<br>• Schedule recurring rule execution without external cron servers.<br>• View detailed error stacks (`Job Console Logs`) for failed aggregation jobs. |
| **Validations** | Rule and form structure validation | • Check for orphan dimension members, broken runtime prompts, and circular member formula references before deployment. |
| **Configure** | OOTB Module Activation & Setup | • Enable frameworks: Financials, Workforce, Capital, Projects.<br>• Map custom dimensions to OOTB slots (e.g., mapping `Custom1` to `Channel`).<br>• **Architect Warning:** Once a module or dimension slot is enabled here, it **CANNOT** be disabled or renamed without recreating the application from scratch! |

### B. Cluster: Tools (System Operations & Utilities)
Used by Administrators for daily maintenance, user preferences, and diagnostics.

| Card (Tile) | Primary Purpose | Hidden / Advanced Architect Use Cases |
| :--- | :--- | :--- |
| **Daily Maintenance** | Automated patching & backup window | • Set the 1-hour maintenance window (e.g., 2:00 AM UTC).<br>• **Architect Tip:** Schedule EPM Automate jobs at least 2 hours outside this window, as the environment freezes completely during maintenance. |
| **Appearance** | Branding, logos, and theme colors | • Custom CSS injection for enterprise branding.<br>• Set default landing pages per role or user group (e.g., forcing executives directly to a specific KPI Dashboard upon login). |
| **Announcements** | Banner alerts on the user home page | • Broadcast upcoming downtime or financial close deadlines (`Severity: Critical`). |
| **Access Control** | Identity Domain security & groups | • Assign Application Roles (`Service Administrator`, `Power User`, `User`, `Viewer`).<br>• Audit User Login History and Failed Authentication logs.<br>• **Architect Rule:** Never assign security directly to users; always assign to **AD/IDCS Groups** (`GRP_EPM_FIN_READ`, `GRP_EPM_ADMIN`). |
| **User Preferences** | Individual display, time zone, aliases | • Set **Number Formatting** (`Thousands Separator`, `Negative Color`).<br>• Toggle **Accessibility Mode** ON for screen readers (linearizes grid HTML).<br>• Set default Alias Table (`English` vs `Local Currency`). |
| **Variables** | Substitution Variables (`&CurYr`) & User Vars | • Create system-wide substitution variables used inside `FIX(...)` scripts.<br>• User Variables (`{UserEntity}`) allow a single form to dynamically show different departments depending on who opens it. |
| **Connections** | Remote environment & ERP links | • Configure REST API connection endpoints for cross-instance Smart Push or Groovy HTTP requests.<br>• Set up Oracle Cloud Financials / Fusion General Ledger direct drill-through URLs. |

### C. Cluster: Create and Manage (Metadata & Rules Design)
Where the structural and calculation elements of the application are built.

| Card (Tile) | Primary Purpose | Hidden / Advanced Architect Use Cases |
| :--- | :--- | :--- |
| **Dimensions** | Web-based metadata editor | • Add/Edit members, aliases, consolidation operators (`+`, `-`, `~`), and formulas.<br>• **Architect Tip:** Do not perform large bulk edits here; use EPM Automate `importMetadata` or EDMCS instead to prevent web timeout locks. |
| **Forms** | Grid design and layout | • Configure Composite Forms, Master-Detail grids, and Flex Forms.<br>• Attach Business Rules (`Run on Save`, `Run on Load`).<br>• Set Smart View Grid Properties (`Enable Grid Gridlines`, `Suppress Missing/Zero`). |
| **Rules (Calc Mgr)** | Calculation Manager launchpad | • Design Calc Scripts, Groovy scripts, and Rule Sets.<br>• Create custom Templates (`Design-Time Prompts`) for reusable business logic across dozens of cubes. |
| **Smart Lists** | Custom dropdown menus inside cells | • Map numerical IDs stored in Essbase (`1`, `2`, `3`) to text labels (`Draft`, `Submitted`, `Approved`).<br>• Use inside Groovy rules to drive conditional workflows based on dropdown selection. |
| **Data Maps** | Cross-cube data movement definitions | • Map BSO input cubes (`FinPlan`) to ASO reporting cubes (`Reporting`).<br>• Enable **Smart Push** (`Push Data on Save`) inside forms for sub-second synchronization. |

## 🛠 3. Deep-Dive: `Navigator -> Application -> Settings` (The Architect's Checkbox Matrix)

Many consultants never look inside the **Application -> Settings** screen. Elite architects know that the checkboxes right here can either double your application performance or cause mysterious calculations failures.

### Table of Obscure System Settings & When to Change Them

```
[System Settings Screen]
├── Cube Storage Properties
│   ├── Enable Hybrid Mode (BSO cubes) .............. [X] ALWAYS ON (Modern EPM)
│   ├── Dynamic Calc & Store Memory Allocation ...... [ ] NEVER USE (Legacy bottleneck)
│   └── Suppress Missing Blocks during Copy ......... [X] ALWAYS ON (Prevents explosion)
├── Calculation & Smart View Behavior
│   ├── Enable Smart View Ad-Hoc Behavior ........... [Standard / Native] -> Set Native
│   ├── Allow User-Defined Attributes (UDAs) ........ [X] Set to ON for dynamic filtering
│   └── Maximum Number of Rows for Smart View ....... Set to 1,000,000 (Default is 50,000)
```

| Setting Name | Default Value | Recommended Architect Setting | Why? (The Technical Justification) |
| :--- | :--- | :--- | :--- |
| **Smart View Ad-Hoc Behavior** | `Standard` | `Native (Excel-based)` | `Standard` forces the web grid rendering engine onto Excel, causing slow rendering and breaking custom Excel formula links (`HsGetValue`). `Native` unleashes high-speed COM rendering. |
| **Enable Hybrid Mode for BSO** | `True` (on new apps) | `True` | Transforms BSO cubes into Hybrid cubes. Upper-level sparse members dynamically calculate on the fly (like ASO) without requiring massive `AGG` calculation jobs. Saves hours of night-time batch processing. |
| **Maximum Rows/Columns in Smart View** | `50,000` rows<br>`255` columns | `500,000` rows<br>`1,000` columns | Large corporate planners extracting trial balances will constantly hit the 50K limit and complain about truncated data. Increase this, but warn users about Excel memory saturation above 500K rows. |
| **Number of Daily Maintenance Backups** | `1` | `3` | Retains rolling snapshots for 3 days directly in EPM Cloud storage. If a bad metadata script corrupts the hierarchy on Friday night, you can roll back to Thursday easily without raising a Severity 1 Oracle SR. |
| **Enable Cell Formatting Persistence** | `False` | `True` | Allows planners to highlight cells in yellow/red in Smart View and have that formatting save directly to the relational database layer, showing up for other managers who open the same form on the web. |
| **Show User Display Name** | `User ID` | `First and Last Name` | Shows `John.Smith@company.com` instead of encrypted/long identity strings (`idcs-1928391823`) on audit trails, cell history, and workflow approvals. |

### 💡 Logic & Purpose
The System Settings screen is the master toggle board for the Essbase kernel. Changing a single drop-down here (like Hybrid Mode) fundamentally alters how the C++ binaries allocate RAM on the cloud server. An architect must know these toggles because fixing a performance issue is often a 1-second click here, rather than 40 hours of rewriting calc scripts.

### 🌀 Confusion Resolution
> **Misconception:** "I can just turn on Hybrid Mode, and my application will magically get 100x faster with no downside."
> **Reality:** While Hybrid mode makes *retrievals* incredibly fast by calculating aggregations dynamically, it has strict rules. If your upper-level sparse members have complex member formulas (cross-dimensional pointers) instead of standard `+` consolidation operators, Hybrid mode can sometimes fail to calculate them or cause severe query timeouts as it tries to resolve circular logic on the fly. You must audit your formulas before enabling Hybrid.

### 😈 Twisted Interview Question
**Question:** A developer claims they can't save cell formatting (yellow highlights) in Smart View. You check the Application Settings and see that "Enable Cell Formatting Persistence" is checked. You also verify the user is clicking "Save Formatting" in the Smart View ribbon. Why is the formatting STILL disappearing when they refresh?
> **Answer:** The form itself is missing a property! Even if the global Application Setting is enabled, the specific web form must *also* have the "Enable Formatting" property checked in its Grid Layout properties. Both the global server toggle and the local form toggle must be ON.

## ️ 4. Architect Edge: Hidden UI Diagnosing (URL Hack Commands)

An elite architect knows how to bypass the standard UI clicks using direct URL parameters to access diagnostic pages that are not listed on the Springboard.

### 1. Directly Launching the Essbase Administration Services (Lite) Screen
In older Hyperion days, administrators used EAS console. In Cloud EPM, you can access hidden diagnostic status screens by appending parameters to your tenant URL:
```url
https://your-domain.epm.us-phoenix-1.ocs.oraclecloud.com/HyperionPlanning/servlet/AdminService?action=viewActivityReport
```

### 2. Inspecting Relational vs Essbase Cache
When forms load slowly, append this parameter to force EPM to dump its relational metadata cache:
```url
https://your-domain.epm.us-phoenix-1.ocs.oraclecloud.com/HyperionPlanning/servlet/HspEpmCacheServlet?action=clearCache
```
*(Note: Requires Service Administrator rights. Use during UAT when metadata updates don't immediately reflect in web forms).*

## 📝 5. Summary Matrix: What Tile Solves Which Business Problem?

| If the Business Problem is... | Go to Cluster -> Card | And Execute... |
| :--- | :--- | :--- |
| "Our web forms take 45 seconds to open after a patch." | `Application -> Overview -> Activity Reports` | Download the top 5 slowest request logs to identify which specific Calc Script triggered on form load. |
| "We need to add 350 new Cost Centers by tomorrow morning." | `Application -> Jobs -> Schedule Job` | Run the `Import Metadata` job pointing to a pre-uploaded CSV file from EPM Automate. |
| "A user changed a cell from $10M to $100M by accident." | `Application -> Overview -> Action Audit` *(or Cell History)* | Query the exact cell intersection and timestamp to identify the user and revert the value. |
| "We need to push data from P&L to our ASO Executive Dashboard." | `Create and Manage -> Data Maps` | Select the `FinPlan_to_Reporting` Data Map and click **Synchronize**. |
| "Executives only want to see their specific department when logging in." | `Tools -> User Preferences -> User Variables` | Assign the `Department` user variable to each executive (`Dept_100`, `Dept_200`). |
