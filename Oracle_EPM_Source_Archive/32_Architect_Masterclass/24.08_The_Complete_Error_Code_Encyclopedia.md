## 🏢 1. EPM Automate (`EPMAT-xxx`) Error Dictionary

When EPM Automate batch scripts fail during overnight processing, elite architects diagnose the exact error code instantly without consulting Oracle documentation.

| Error Code | Error Message Summary | Exact Technical Root Cause | Elite Architect Fix |
| :--- | :--- | :--- | :--- |
| **`EPMAT-1`** | Invalid command or syntax. | Command name misspelled or required parameter omitted (`e.g., typing importmetadata instead of importMetadata — commands are case-sensitive!`). | Verify exact camelCase spelling against EPM Automate reference (`epmautomate --help`). |
| **`EPMAT-7`** | Session not authenticated or session expired. | Script attempted to run a command without executing `login` first, or the 30-minute idle session token expired during a long script pause. | Ensure `epmautomate login` runs at the start of every shell execution loop. |
| **`EPMAT-9`** | Insufficient privileges to execute command. | The user account used for login (`User` or `Power User`) lacks `Service Administrator` privileges required for admin jobs (`restructureCube`, `importMetadata`). | Re-authenticate using a Service Administrator Identity Domain service account (`svc_epm_admin`). |
| **`EPMAT-11`** | Cannot perform operation. Database is locked by another process. | Concurrent write collision! Another EPM Automate job, data load, or calculation script holds an active write-lock on the target BSO cube blocks (`.pag`). | Sequence jobs linearly in your scheduler (`Load -> Calculate -> Backup`). Check `Jobs Console` and kill stuck user tasks. |
| **`EPMAT-14`** | File not found on local filesystem or EPM Cloud Inbox. | The target file (`e.g., actuals.csv`) does not exist in the working directory during `uploadFile`, or is missing from Cloud Inbox during `importData`. | Run `epmautomate listFiles` to verify remote file presence. Use absolute file paths (`C:/data/actuals.csv`) locally. |
| **`EPMAT-18`** | Daily Maintenance window is currently in progress. | Script ran during the 1-hour mandatory Oracle maintenance window (`e.g., 2:00 AM - 3:00 AM UTC`). All REST/CLI calls are blocked (`HTTP 503 Service Unavailable`). | Reschedule batch jobs to execute at least 90 minutes outside the configured Daily Maintenance window (`Tools -> Daily Maintenance`). |
| **`EPMAT-10023`** | Encryption key mismatch or corrupted password file. | The `.epw` encrypted password file was copied to a different server OS or user profile than the one that generated it using `epmautomate encrypt`. | Re-generate the `.epw` file directly on the target execution server under the exact service account context executing the cron job. |

### 💡 Logic & Purpose
EPM Automate is a wrapper around the Oracle EPM REST API. When you see an `EPMAT-xxx` error, it usually means the CLI tool itself failed before it could even talk to the Essbase kernel. The goal of mastering these is to instantly isolate whether an overnight failure was caused by an IT network issue (EPMAT) or a financial logic issue (1012xxx).

### 🌀 Confusion Resolution
> **Misconception:** "If I get an EPMAT error, I should immediately restart the EPM Cloud environment."
> **Reality:** EPMAT errors are almost exclusively client-side or orchestration-side (bad passwords, bad syntax, missing local files, locked block states). Restarting the target environment does nothing but anger users. Always check the local execution server's logs and file paths first.

### 😈 Twisted Interview Question
**Question:** Your overnight batch script runs `epmautomate importData LoadActuals`. It returns `EPMAT-7: Session not authenticated`. However, you look at the script, and the line directly above it is `epmautomate login svc_epm...` which returned `Success`. How is it possible to be unauthenticated 1 millisecond after successfully logging in—
> **Answer:** Concurrent script execution! EPM Automate stores the active session token in a hidden `.prefs` file in the user's home directory (`C:\Users\svc_epm\.prefs`). If two different scripts run simultaneously under the same Windows service account, Script A logs in, then Script B logs in (overwriting the token), then Script A logs out. When Script B tries to run its next command, its token is dead! You must either sequence scripts sequentially, or use the `COMMAND_PAYLOAD` structure for true parallel execution.

## 💡 2. Essbase Kernel (`1012xxx` / `1020xxx`) Calculation & Block Errors

These errors originate from the underlying native C++ Essbase database kernel when calculation scripts (`FIX/ENDFIX`) or member formulas breach physical memory boundaries.

| Error Code | Error Message Summary | Exact Technical Root Cause | Elite Architect Fix |
| :--- | :--- | :--- | :--- |
| **`1012004`** | Invalid member name or alias in formula/FIX. | A string inside quotes (`"CC_9999"`) does not match any existing member name or alias in the cube's active outline. Often caused by trailing spaces (`"CC_9999 "`). | Open `Create and Manage -> Dimensions` and verify exact character spelling. Use member names, never aliases, inside production scripts! |
| **`1012401`** | Calculation aborted: Formula circular reference detected. | Member Formula A references Member B, while Member B references Member A (`A = B + 10; B = A * 2;`), trapping the engine in an infinite recursion loop. | Break the circular dependency. Move one side of the equation out of dynamic member formulas and into a scheduled sequential Calc Script (`BSO`). |
| **`1012700`** | Dynamic calculation memory allocation exceeded (`Data cache buffer overflow`). | A `Dynamic Calc` member formula attempted to evaluate a complex cross-dimensional tree (`@SUMRANGE across 100,000 sparse intersections`) on the fly during a web query. | Convert complex cross-dimensional calculations from `Dynamic Calc` to `Store` and pre-calculate via Calc Script, OR increase `Dynamic Calc Cache Size` in `Cube Properties`. |
| **`1012704`** | Block creation failed: Block density limit or space exhausted. | `CREATEBLOCKONEQ ON` triggered a block explosion across billions of sparse intersections, exhausting disk space or breaching the 32-bit $2^{32}$ index limit. | Immediately kill the calculation job (`Job Console -> Cancel`). Rewrite script with strict `IF / WHERE` conditional guards and run `CLEARBLOCK EMPTY;`. |
| **`1020005`** | Database lock timeout: Unable to acquire exclusive access. | An administrative job (`Cube Refresh`, `Restructure`, `CLEARBLOCK`) failed because users have open, un-submitted data forms or Excel Smart View ad-hoc sessions holding active read/write blocks. | Broadcast an announcement alert, log out active users via `Access Control -> Manage Users -> Force Logout`, and re-run the admin job. |
| **`1020010`** | Restructure failed: Outline contains duplicate member names across dimensions. | Two independent dimensions (`e.g., Entity and Cost Center`) contain an identical member name (`e.g., both contain a member named "Total_US"`). | EPM Cloud Planning requires **unique member names across all dimensions**. Rename one member (`Entity: E_Total_US`, `Cost Center: CC_Total_US`). |

## 🛠 3. Web & Relational (`HSP-xxx`) Planning Errors

These errors occur in the Hyperion Planning Java relational layer during web form rendering, metadata updates, or security evaluation.

| Error Code | Error Message Summary | Exact Technical Root Cause | Elite Architect Fix |
| :--- | :--- | :--- | :--- |
| **`HSP-10101`** | Form definition is invalid or corrupted. | A member hardcoded into the form's layout definition (`Forms -> Layout -> Rows/Columns`) was deleted from the metadata outline during a recent migration. | Open the form in edit mode, inspect `Rows` and `Columns` for red/broken member tokens (`#InvalidMember`), remove them, and re-save the form. |
| **`HSP-10115`** | Cell is read-only (`#NoAccess` or `#ReadOnly`). | User attempted to submit data to: (1) A `Dynamic Calc` or `Label Only` member, (2) An upper-level parent in BSO (`Total Entity`), or (3) An intersection blocked by Cell-Level Security (`Valid Intersections`). | Verify that all selected members on the form POV and grid are `Level 0 (Leaf)` and `Store`. Audit user group security assignments under `Dimensions -> Assign Security`. |
| **`HSP-10145`** | Smart Push (Data Map) synchronization failed. | The target ASO cube has a missing member, OR the user triggering the Smart Push lacks Read/Write security permissions on the target ASO reporting intersections. | Verify target cube outline sync (`Cube Refresh`). Ensure all users running forms with Smart Push have `Read/Write` access to the target ASO cube members. |
| **`HSP-10180`** | Runtime Prompt (RTP) validation failure. | User entered a parent member (`Total_Company`) into a runtime prompt configured to accept only `Level 0` leaf members (`[Entity]` restricted to `@RELATIVE(..., 0)`). | Educate user to select leaf members only, OR update the Calc Manager variable limits (`Design -> Variables`) to enforce strict validation rules. |

## ️ 4. Smart View Client (`SV-xxx` / COM) Excel Errors

| Error Code | Error Message Summary | Exact Technical Root Cause | Elite Architect Fix |
| :--- | :--- | :--- | :--- |
| **`Cannot connect to provider. The server is unknown or unreachable.`** | DNS or SSL handshake failure. | EPM Cloud URL connection string is incorrect, corporate VPN/Zscaler firewall is stripping SSL certificates, or basic authentication is disabled. | Verify exact URL (`.../HyperionPlanning/SmartView`). In Excel, go to `Smart View Options -> Advanced` and toggle `Route message to Smart View provider` ON. |
| **`The number of rows/columns exceeds the maximum allowed limit.`** | Grid truncation error (`e.g., stopping at 50,000 rows`). | The query returned more rows than the default threshold set inside `Navigator -> Application -> Settings -> Maximum Number of Rows for Smart View`. | Increase the system setting in `Application -> Settings` to `500,000` rows. In Smart View Excel options, set `Number of rows/columns` to `Maximum`. |
| **`HsGetValue / HsSetValue returns #NO CONNECTION or #VALUE!`** | Broken formula link or un-established private connection. | The formula references a connection name (`"EPBCS_Prod"`) that is not currently opened and logged into within the active Excel session panel. | Open `Smart View -> Panel -> Private Connections`, double-click the connection name, log in, and press `Refresh All` (`Ctrl + Alt + R`). |

## 📊 5. Groovy Sandboxed Exceptions (`java.lang.*` / `VetoException`)

| Exception Stack | Exact Technical Root Cause | Elite Architect Fix |
| :--- | :--- | :--- |
| **`java.lang.OutOfMemoryError: Java heap space`** | Groovy rule allocated $> 512 \text{ MB}$ of JVM RAM (`e.g., calling cube.dataGridBuilder() across 100,000 entities without pagination`). | Implement **Streaming Chunk Architecture** (`collate(100)` batches) and call `grid.close()` explicitly after every batch to free heap memory. |
| **`java.lang.InterruptedException: Timeout exceeded (300s)`** | Groovy script executed for $> 5 \text{ minutes}$, triggering the cloud container's hard thread termination watchdog. | Optimize internal loops. Move heavy multi-million block calculations into native C++ Essbase scripts, or split the Groovy job into async background tasks using `/interop/rest/v11/jobs`. |
| **`java.security.AccessControlException: access denied`** | Script attempted unauthorized OS/network operations (`new File()`, `new Socket()`, `System.exit()`, reflection calls). | Remove forbidden Java classes. Use only official `oracle.epm.api.*` wrappers and pre-registered `Connection` objects (`Tools -> Connections`) for HTTP REST. |
| **`groovy.lang.VetoException: [Custom Message]`** | **Normal/Expected Architect Behavior!** The Groovy script intentionally intercepted a user form save violation ($> \$10M budget) and aborted the transaction cleanly. | No bug! Ensure the `VetoException` message string is clean, polite, and provides actionable guidance (`"Please reduce your planned budget below $10M before saving."`). |
