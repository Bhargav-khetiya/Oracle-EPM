# 25.02 — Essbase Calc Script Syntax Cheat Sheet

> **Quick Reference** | Print-friendly | Bookmark this

---

## FIX / ENDFIX

```essbase
FIX("Budget", "Working", &CurrYear)
  FIX(@RELATIVE("All_Hotels", 0))
    /* formulas here */
  ENDFIX
ENDFIX
```

## Assignment

```essbase
"Total" = "A" + "B" + "C";                /* Simple sum */
"Margin" = "Profit" / "Revenue" * 100;     /* Percentage */
"Target" = "Source" * 1.05;                /* Growth */
```

## IF / ELSE / ENDIF

```essbase
IF("Revenue" > 0)
  "Margin" = "Profit" / "Revenue" * 100;
ELSEIF("Revenue" == 0)
  "Margin" = 0;
ELSE
  "Margin" = #MISSING;
ENDIF
```

## Cross-Dimensional (->)

```essbase
"Budget" = "Revenue" -> "Actual";                 /* Cross Scenario */
"YoY" = "Revenue" - "Revenue" -> "FY2025";        /* Cross Year */
"Alloc" = "Total" -> "Corporate_HQ" * 0.02;       /* Cross Entity */
"MoM" = "Revenue" - "Revenue" -> @PRIOR("Period"); /* Prior Period */
```

## SET Commands

```essbase
SET LOCKBLOCK ON;              /* Lock blocks in memory */
SET LOCKBLOCK OFF;
SET CREATENONMISSINGBLK ON;    /* Allow new block creation */
SET CREATENONMISSINGBLK OFF;
SET CREATEBLOCKONEQ ON;        /* Create blocks on assignment */
SET CREATEBLOCKONEQ OFF;
SET CALCPARALLEL 4;            /* Parallel threads */
SET MSG DETAIL;                /* Verbose logging */
```

## Data Operations

```essbase
CLEARDATA "Budget";                           /* Clear all Budget data */
CLEARBLOCK ALL;                               /* Remove empty blocks */
DATACOPY "Actual" TO "Forecast";              /* Copy data */
AGG("Entity");                                /* Aggregate dimension */
AGG("Entity", "Department");                  /* Aggregate multiple dims */
```

## Variables

```essbase
VAR v_Rate = 0.10;                            /* Declare variable */
VAR v_Count;                                  /* Declare without value */
v_Count = v_Count + 1;                        /* Update variable */
```

## Member Functions

```essbase
@CHILDREN("All_Hotels")          /* Immediate children */
@ICHILDREN("All_Hotels")         /* Including parent */
@DESCENDANTS("All_Hotels")       /* All descendants */
@IDESCENDANTS("All_Hotels")      /* Including parent */
@RELATIVE("All_Hotels", 0)       /* Level-0 (leaf) members */
@SIBLINGS("Mumbai_Hotel")        /* Same-level members */
@PARENT("Mumbai_Hotel")          /* Parent member */
@ANCESTORS("Mumbai_Hotel")       /* All ancestors */
@PRIOR("Period")                 /* Previous member */
@NEXT("Period")                  /* Next member */
@RANGE("Period", "Jan", "Jun")   /* Range of members */
@MEMBER("DimName"."MemberName")  /* Qualified member */
```

## Aggregation Functions

```essbase
@SUM("A", "B", "C")             /* Sum of members */
@AVG("A", "B", "C")             /* Average */
@MIN("A", "B", "C")             /* Minimum */
@MAX("A", "B", "C")             /* Maximum */
@COUNT("A", "B", "C")           /* Count */
```

## String/Attribute Functions

```essbase
@CONCATENATE("FY", "2026")      /* Build string: "FY2026" */
@SUBSTRING("FY2026", 2, 4)      /* Extract: "2026" */
@NAME(@CURRMBR("Entity"))       /* Current member name */
@ISMBR("Mumbai_Hotel")          /* Check if current member */
@ISANCEST("All_Hotels")         /* Check if ancestor */
@ISLEV("Entity", 0)             /* Check if level-0 */
```

## Common Patterns

```essbase
/* ===== Pattern 1: Safe Division ===== */
IF("Revenue" <> 0)
  "Margin" = "Profit" / "Revenue" * 100;
ELSE
  "Margin" = 0;
ENDIF

/* ===== Pattern 2: Copy with Growth ===== */
FIX("Budget", "Working", "FY2027")
  DATACOPY "Actual"->"FY2026" TO "Budget";
ENDFIX
FIX("Budget", "Working", "FY2027", @RELATIVE("All_Hotels", 0))
  "Total_Revenue" = "Total_Revenue" * 1.05;
ENDFIX

/* ===== Pattern 3: Clear and Reload ===== */
FIX("Forecast", "Working", &CurrYear)
  CLEARDATA "Forecast";
ENDFIX
CLEARBLOCK ALL;
FIX("Forecast", "Working", &CurrYear)
  DATACOPY "Actual" TO "Forecast";
ENDFIX

/* ===== Pattern 4: Allocation ===== */
VAR v_Total;
FIX("All_Hotels", "Budget", "Working", &CurrYear, "YearTotal")
  v_Total = "Total_Revenue";
ENDFIX
FIX(@RELATIVE("All_Hotels", 0), "Budget", "Working", &CurrYear)
  IF(v_Total <> 0)
    "Corp_Allocation" = "Corp_Overhead" * ("Total_Revenue" / v_Total);
  ENDIF
ENDFIX

/* ===== Pattern 5: Timestamp ===== */
FIX("Budget", "Working", &CurrYear)
  "Last_Calculated" = @CalcMgrGetCurrentDate();
ENDFIX
```

## Quick Rules

| Rule | Remember |
|------|----------|
| End every formula with `;` | Semicolon required |
| Match every FIX with ENDFIX | Count pairs |
| Match every IF with ENDIF | Count pairs |
| Use `<>` not `!=` for "not equal" | Essbase syntax |
| Use `==` for comparison | Not `=` (assignment) |
| Dense dims on rows = fast | Account, Period |
| Sparse cross-dim = slow | Avoid `->` on Entity |
| Always FIX before calculating | Never process entire cube |
| CLEARBLOCK after CLEARDATA | Remove empty blocks |
| Validate before deploying | Catches typos early |
