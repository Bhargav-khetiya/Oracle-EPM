## Storage Types

| Type | Read? | Write? | Query Speed | Best For |
|------|-------|--------|-------------|----------|
| **BSO** | ✅ | ✅ | Medium | Data entry, calculations |
| **ASO** | ✅ | ❌ (load only) | Fast | Reporting, large queries |
| **Hybrid BSO** | ✅ | ✅ | Fast | Modern default — best of both |

## Dense vs Sparse

| Classification | Stored | Block Impact | Best Candidates |
|---------------|--------|-------------|-----------------|
| **Dense** | Inside blocks | Determines block SIZE | Account, Period, Currency |
| **Sparse** | Defines blocks | Determines block COUNT | Entity, Scenario, Year, Version |

## Block Mechanics

```
Block = one unique combination of sparse members
  Address: (Mumbai_Hotel, Budget, Working, FY2026)
  Content: All dense member intersections (Account × Period × Currency)

Block Size = Product of all dense member counts × 8 bytes
  Example: 200 accounts × 17 periods × 3 currencies = 10,200 cells
  Size: 10,200 × 8 = 81,600 bytes (before compression)
```

## Key Metrics

| Metric | Healthy | Warning | Action |
|--------|---------|---------|--------|
| Block Density | > 20% | < 5% | Move dense dims to sparse |
| Fragmentation | < 20% | > 30% | Restructure database |
| Block Count | Expected | 2× expected | CLEARBLOCK ALL |
| Cache Hit Ratio | > 90% | < 80% | Increase cache |

## Calculation Algorithms

| Algorithm | Speed | Triggered By |
|-----------|-------|-------------|
| **Bottom-Up** | ⚡ Fast | Within-block formulas, FIX statement |
| **Top-Down** | 🐌 Slow | Cross-dim on sparse, no FIX, @PARENTVAL |

## Data Storage Properties

| Property | What Users Enter | Essbase Stores |
|----------|-----------------|----------------|
| **Store** | Input cells | Physical data |
| **Dynamic Calc** | Nothing (calculated on read) | Formula only |
| **Label Only** | Nothing | No data (heading) |
| **Shared** | Points to another member | Pointer |

## Member Consolidation Operators

| Operator | Symbol | Meaning |
|----------|--------|---------|
| Addition | `+` | Add to parent |
| Subtraction | `-` | Subtract from parent |
| Multiplication | `*` | Multiply into parent |
| Division | `/` | Divide into parent |
| Percent | `%` | Percentage of parent |
| Ignore | `~` | No consolidation |
| Never | `^` | Never consolidate |

## Essbase Commands Quick Reference

```essbase
AGG("Entity");                    /* Aggregate dimension */
DATACOPY "Actual" TO "Budget";    /* Copy data */
CLEARDATA "Forecast";             /* Clear data */
CLEARBLOCK ALL;                   /* Remove empty blocks */
SET LOCKBLOCK ON;                 /* Lock blocks in memory */
SET CALCPARALLEL 4;               /* Parallel threads */
SET CREATENONMISSINGBLK ON;       /* Allow block creation */
```

## Application Statistics Location

```
Calc Manager → Essbase → Database Properties → Statistics

Key stats: Block count, Block size, Density, Fragmentation, Cache hit ratio
```
