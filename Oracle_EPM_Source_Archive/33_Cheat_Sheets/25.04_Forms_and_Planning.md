# 25.04 — Forms and Planning Cheat Sheet

> **Quick Reference** | Print-friendly | Bookmark this

---

## Form Axes

| Axis | Purpose | Best For |
|------|---------|----------|
| **POV** | Fixed — user can't change | Scenario, Version, Year |
| **Page** | Dropdown — user toggles | Entity, Department |
| **Rows** | Vertical grid axis | Account (Dense) |
| **Columns** | Horizontal grid axis | Period (Dense) |

## Golden Rules

```
1. Account → Rows (always)
2. Period → Columns (always)
3. Entity → Page (User Variable)
4. Scenario/Version/Year → POV
5. Never 2 sparse dims on rows
6. Max cells < 5,000
7. Enable Suppress Missing Data on all summary forms
8. Display Missing as Blank (always)
```

## Form Properties Quick Reference

| Property | Default | Recommended |
|----------|---------|-------------|
| Suppress Missing Data | ☐ Off | ☑ On (summary forms) |
| Suppress Missing Blocks | ☐ Off | ☑ On (summary forms) |
| Display Missing as Blank | ☐ Off | ☑ On (always) |
| Enable Grid Spread | ☐ Off | ☑ On (entry forms) |
| Make Form Read-Only | ☐ Off | ☑ On (dashboard forms) |
| Enable Flex Form | ☐ Off | ☑ On (Smart View power users) |
| Precision (Currency) | 6 | 0-2 |
| Precision (Percentage) | 6 | 1 |

## Member Selection Functions

```
@CHILDREN("Parent")         → Immediate children
@ICHILDREN("Parent")        → Including parent
@DESCENDANTS("Parent")      → All levels below
@IDESCENDANTS("Parent")     → Including parent
@RELATIVE("Parent", 0)      → Level-0 (leaf) only
@SIBLINGS("Member")         → Same-level peers
```

## Variable Types

| Type | Symbol | Set By | Used In |
|------|--------|--------|---------|
| Substitution | `&CurrMonth` | Admin | Forms + Rules |
| User Variable | `[UserEntity]` | Each user | Forms only |
| Runtime Prompt | `{RTP_Scenario}` | User at runtime | Rules only |

## Form Types

| Type | What | When |
|------|------|------|
| Simple Form | Standard grid | Data entry, summaries |
| Composite Form | Multiple forms | Cross-cube visibility |
| Dashboard | Forms + Charts + Tiles | Executive summaries |
| FreeForm | Custom dimensions | Non-standard data |

## Form Business Rules

| Trigger | When | Use Case |
|---------|------|----------|
| On Load | Before form opens | Refresh calcs |
| On Save | After user saves | Aggregate totals |
| Manual | User clicks Actions | Optional: copy, clear |

## Performance Quick Fixes

| Problem | Fix | Impact |
|---------|-----|--------|
| Slow load (>10s) | Suppress Missing + move sparse to Page | 50-80% |
| Too many rows | Reduce member selection | 40-60% |
| Heavy On Load rule | Move to On Save or batch | 50-90% |
| Many format rules | Reduce to 5-8 | 20-30% |
