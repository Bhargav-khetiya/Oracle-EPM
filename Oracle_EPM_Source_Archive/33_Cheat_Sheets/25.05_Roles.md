## Application Roles

| Role | Access | Create Artifacts | Data Entry | Run Rules | Manage Security |
|------|--------|-----------------|------------|-----------|----------------|
| **Service Admin** | Full | ✅ | ✅ | ✅ | ✅ |
| **Power User** | Advanced | ✅ | ✅ | ✅ | ❌ |
| **Planner** | Standard | ❌ | ✅ | ✅ (assigned) | ❌ |
| **Viewer** | Read-only | ❌ | ❌ | ❌ | ❌ |
| **Ad Hoc** | Smart View | ❌ | ✅ (ad hoc) | ❌ | ❌ |

## Security Layers

```
Layer 1: Identity Domain    → Can they log in?
Layer 2: Application Role   → What features do they see?
Layer 3: Dimension Security  → What data can they access?
Layer 4: Form Permissions   → Which forms can they open?
```

## Dimension Security

| Access | See? | Edit? | Inherited by Children? |
|--------|------|-------|----------------------|
| **Write** | ✅ | ✅ | ✅ Yes |
| **Read** | ✅ | ❌ | ✅ Yes |
| **None** | ❌ | ❌ | ✅ Yes |
| **No Access** | ❌ | ❌ | ❌ Explicit only |

## Security Best Practices

```
✅ DO                          ❌ DON'T
Always use groups               Assign to individual users
Secure Actual = Read            Let planners edit Actuals
Use Power User for PAs          Give everyone Admin role
Review access quarterly         Set and forget
Restrict salary accounts        Show salary to all users
```

## Standard Groups

```
Admin_Team              → Service Administrator
Finance_Controllers     → Power User
Hotel_{Name}_Planners   → Planner (per-entity Write)
HR_Team                 → Planner (Workforce cube only)
Executive_Board         → Viewer (read-only everywhere)
```

## Dimension Security Quick Reference

```
Entity:     Each hotel group → Write to their hotel only
Scenario:   Actual → Read for non-admins (no edits!)
            Budget/Forecast → Write for planners
Account:    Salary → None for non-HR (confidential)
Version:    Final → Read for non-admins (locked)
            Working → Write for planners
```

## Troubleshooting Access Issues

| Symptom | Check |
|---------|-------|
| User can't log in | Identity Domain → user exists? |
| User sees no forms | Application Role assigned? |
| User sees form but empty | Dimension Security → Entity = None? |
| User can see but can't edit | Form permission = Read? Or Dim Security = Read? |
| User can edit wrong entity | Dim Security wrong — check inheritance |
