# 25.06 — Business Rules Cheat Sheet

> **Quick Reference** | Print-friendly | Bookmark this

---

## Rule Lifecycle

```
Create → Design → Validate → Set Deployable → Deploy → Run
```

## FIX Best Practices

```essbase
/* ALWAYS scope with FIX — never calculate the entire cube */

/* Good: Tight FIX */
FIX("Budget", "Working", &CurrYear, @RELATIVE("All_Hotels", 0))
  "Total" = "A" + "B";
ENDFIX

/* Bad: No FIX = processes entire cube */
"Total" = "A" + "B";
```

## SET Commands

| Command | Purpose | Default |
|---------|---------|---------|
| `SET LOCKBLOCK ON/OFF` | Keep blocks in memory | OFF |
| `SET CALCPARALLEL N` | Use N threads | 1 |
| `SET CREATENONMISSINGBLK ON/OFF` | Allow new block creation | OFF |
| `SET CREATEBLOCKONEQ ON/OFF` | Create blocks on = | OFF |
| `SET MSG DETAIL` | Verbose logging | SUMMARY |

## Data Operations

```essbase
DATACOPY "Actual" TO "Budget";       /* Copy scenario */
DATACOPY "Working" TO "Final";       /* Lock version */
CLEARDATA "Forecast";                /* Clear data */
CLEARBLOCK ALL;                      /* Remove empty blocks */
AGG("Entity");                       /* Aggregate dimension */
AGG("Entity", "Department");         /* Aggregate multiple */
```

## Cross-Dimensional (->) Patterns

```essbase
"Budget" = "Revenue" -> "Actual";              /* Cross scenario */
"YoY" = "Revenue" - "Revenue" -> "FY2025";     /* Cross year */
"MoM" = "Revenue" - "Revenue" -> @PRIOR("Period"); /* Prior period */
```

## Safe Division

```essbase
IF("Revenue" <> 0)
  "Margin" = "Profit" / "Revenue" * 100;
ELSE
  "Margin" = 0;
ENDIF
```

## Optimization Checklist

| # | Check | Impact |
|---|-------|--------|
| 1 | FIX statement present— | 90%+ |
| 2 | FIX on Scenario + Version + Year— | 50-80% |
| 3 | @RELATIVE("Parent", 0) for leaf only— | 30-50% |
| 4 | No cross-dim on sparse— | 80-95% |
| 5 | SET LOCKBLOCK ON— | 20-40% |
| 6 | SET CALCPARALLEL 4— | 2-4× |
| 7 | Dense calc before AGG— | 50% |
| 8 | Ruleset instead of multiple On Save— | 2-3× |

## Common Patterns

```essbase
/* Pattern: Clear → Copy → Calculate → Aggregate */
FIX("Budget", "Working", &CurrYear)
  CLEARDATA "Budget";
ENDFIX
CLEARBLOCK ALL;
FIX("Working", &CurrYear, @RELATIVE("All_Hotels", 0))
  DATACOPY "Actual" TO "Budget";
ENDFIX
FIX("Budget", "Working", &CurrYear, @RELATIVE("All_Hotels", 0))
  "Total_Revenue" = "Total_Revenue" * 1.05;
ENDFIX
FIX("Budget", "Working", &CurrYear)
  AGG("Entity");
ENDFIX
```

## Algorithms

| Algorithm | Triggered By | Speed |
|-----------|-------------|-------|
| **Bottom-Up** | Within-block formulas, FIX | ⚡ Fast |
| **Top-Down** | Cross-dim on sparse, no FIX | 🐌 Slow |

## Error Quick Fixes

| Error | Fix |
|-------|-----|
| "Unknown member name" | Fix typo or update after member rename |
| "Syntax error" | Match FIX/ENDFIX, IF/ENDIF pairs |
| "Divide by zero" | Add IF(denom <> 0) check |
| "Timeout" | Tighten FIX, remove cross-dim on sparse |

## Rule Triggers

| Trigger | When | Best For |
|---------|------|----------|
| On Load | Before form opens | Refresh calcs, currency conv |
| On Save | After save | Aggregate, totals |
| Manual | User clicks | Copy, clear, special ops |
| Scheduled | Cron job | Overnight aggregation |
