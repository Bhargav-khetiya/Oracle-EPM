## Security Layers (4 Layers)

```
Layer 1: Identity Domain    → User authentication (login)
Layer 2: Application Roles  → Feature access (Admin/Planner/Viewer)
Layer 3: Dimension Security → Data access (which entity/account)
Layer 4: Form Permissions   → UI access (which forms)
```

## Application Roles

| Role | Data Entry | Create Forms | Manage Security |
|------|-----------|-------------|----------------|
| Service Admin | ✅ | ✅ | ✅ |
| Power User | ✅ | ✅ | ❌ |
| Planner | ✅ | ❌ | ❌ |
| Viewer | ❌ | ❌ | ❌ |

## Dimension Security Levels

| Level | See? | Edit? | Inherits Down? |
|-------|------|-------|---------------|
| Write | ✅ | ✅ | ✅ |
| Read | ✅ | ❌ | ✅ |
| None | ❌ | ❌ | ✅ |

## Quick Setup Pattern

```
1. Create Groups (never assign to individuals)
   Mumbai_Planners, Delhi_Planners, Finance_Controllers...

2. Assign Application Roles to groups
   Mumbai_Planners → Planner
   Finance_Controllers → Power User

3. Set Dimension Security
   Entity: Mumbai_Planners → Write on Mumbai_Hotel, None on others
   Scenario: Planners → Read on Actual, Write on Budget/Forecast
   Account: All users → None on Salary (confidential)

4. Set Form Permissions
   Revenue_Entry → Mumbai_Planners: Write
   Admin_Forms → Admin_Group only: Write
```

## Provisioning (EPM Automate)

```bash
epmautomate assignrole "user@email.com" "Planner"
epmautomate unassignrole "user@email.com" "Planner"
epmautomate provisionreport "Report.csv"
```

## Troubleshooting

| Issue | Check |
|-------|-------|
| Can't log in | Identity Domain user exists? |
| No forms visible | Application role assigned? |
| Form empty | Dimension security on Entity? |
| Can't edit | Form perm = Read? Or Dim = Read? |
| Sees wrong data | User Variable set correctly? |
