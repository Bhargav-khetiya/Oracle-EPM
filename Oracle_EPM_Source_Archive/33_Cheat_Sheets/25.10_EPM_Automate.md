# 25.10 — EPM Automate Cheat Sheet

> **Quick Reference** | Print-friendly | Bookmark this

---

## Login / Logout

```bash
# Login
epmautomate login admin@company.com password https://instance.oraclecloud.com domain

# Login with encrypted password file
epmautomate login admin@company.com passwordfile.epw https://instance.oraclecloud.com domain

# Encrypt password (first time)
epmautomate encrypt password keyfile passwordfile.epw

# Logout
epmautomate logout
```

## File Operations

```bash
# Upload file to EPBCS
epmautomate uploadfile "C:\data\Aug_Actuals.csv"

# Upload to specific folder
epmautomate uploadfile "C:\data\Aug_Actuals.csv" inbox

# Download file
epmautomate downloadfile "Report_Aug.csv"
epmautomate downloadfile "Report_Aug.csv" "C:\reports\"

# Delete file
epmautomate deletefile "old_backup.csv"

# List files
epmautomate listfiles
```

## Data Operations

```bash
# Import data (run a data load rule)
epmautomate importdata "DL_Revenue_Actuals"

# Import data with file override
epmautomate importdata "DL_Revenue_Actuals" "Aug_Actuals.csv"

# Export data (run a data export rule)
epmautomate exportdata "DE_Revenue_Export"

# Import metadata (load dimension members)
epmautomate importmetadata "MD_Entity_Load"

# Export metadata
epmautomate exportmetadata "MD_Entity_Export"

# Clear data at intersection
epmautomate cleardata "ClearRule1"
```

## Business Rules

```bash
# Run a business rule
epmautomate runbusinessrule "Calculate_PnL"

# Run with RTP parameters
epmautomate runbusinessrule "Calculate_PnL" "Scenario=Budget" "Year=FY2026"

# Run a ruleset
epmautomate runbusinessrule "Monthly_Close_Ruleset"
```

## Substitution Variables

```bash
# Set substitution variable
epmautomate setsubstvars "OEP_FS" "CurrMonth=Sep"

# Set multiple variables
epmautomate setsubstvars "OEP_FS" "CurrMonth=Sep" "PriorMonth=Aug" "ForecastStart=Oct"

# Set on all cubes
epmautomate setsubstvars "ALL" "CurrYear=FY2026"
```

## Application Maintenance

```bash
# Refresh database (after metadata changes)
epmautomate refreshcube

# Refresh specific cube
epmautomate refreshcube "OEP_FS"

# Restructure database
epmautomate restructurecube "OEP_FS"

# Compact database
epmautomate compactcube "OEP_FS"
```

## LCM (Lifecycle Management)

```bash
# Export full application snapshot
epmautomate exportsnapshot "HotelApp_Backup_Aug2026"

# Import snapshot
epmautomate importsnapshot "HotelApp_Backup_Aug2026"

# List snapshots
epmautomate listsnapshots

# Delete snapshot
epmautomate deletesnapshot "OldBackup"

# Copy snapshot to another instance (migration)
epmautomate copysnapshot "HotelApp_Backup" targeturl targetuser targetpassfile
```

## Daily Maintenance

```bash
# Run daily maintenance
epmautomate runDailyMaintenance

# Skip maintenance
epmautomate skipdailymaintenance

# Replay operations after maintenance
epmautomate replay "2026-08-12T10:00:00"
```

## Jobs and Monitoring

```bash
# List running jobs
epmautomate listjobs

# Get job status
epmautomate getjobstatus jobId

# Cancel a job
epmautomate canceljob jobId
```

## Provisioning (User Management)

```bash
# Assign role
epmautomate assignrole "user@company.com" "Planner"

# Unassign role
epmautomate unassignrole "user@company.com" "Planner"

epmautomate getassignedusers

epmautomate provisionreport "ProvReport.csv"
```

## Common Automation Scripts

### Monthly Close Script (Windows Batch)

```batch
@echo off
REM ===== Hotel Pvt Ltd Monthly Close =====
SET EPM=epmautomate

REM Step 1: Login
%EPM% login admin@hotelpvtltd.com pass.epw https://instance.oraclecloud.com HotelDomain

REM Step 2: Update substitution variables
%EPM% setsubstvars "ALL" "CurrMonth=Sep" "PriorMonth=Aug" "ForecastStart=Oct"

REM Step 3: Upload and load actual data
%EPM% uploadfile "C:\data\Sep_Actuals.csv"
%EPM% importdata "DL_Revenue_Actuals" "Sep_Actuals.csv"

REM Step 4: Refresh database
%EPM% refreshcube "OEP_FS"

REM Step 5: Run aggregation
%EPM% runbusinessrule "Full_Aggregation" "Scenario=Actual" "Year=FY2026"

REM Step 6: Run currency conversion
%EPM% runbusinessrule "Currency_Conversion"

REM Step 7: Backup
%EPM% exportsnapshot "Backup_Sep_2026"

REM Step 8: Logout
%EPM% logout

echo Monthly close completed successfully!
```

### Linux/Mac Shell Script

```bash
#!/bin/bash
EPM="./epmautomate.sh"

$EPM login admin@hotelpvtltd.com pass.epw https://instance.oraclecloud.com HotelDomain
$EPM setsubstvars "ALL" "CurrMonth=Sep" "PriorMonth=Aug"
$EPM uploadfile "/data/Sep_Actuals.csv"
$EPM importdata "DL_Revenue_Actuals" "Sep_Actuals.csv"
$EPM refreshcube "OEP_FS"
$EPM runbusinessrule "Full_Aggregation" "Scenario=Actual" "Year=FY2026"
$EPM exportsnapshot "Backup_Sep_2026"
$EPM logout

echo "Monthly close completed!"
```

## Error Handling

```batch
REM Check return code after each command
%EPM% importdata "DL_Revenue_Actuals"
IF %ERRORLEVEL% NEQ 0 (
    echo ERROR: Data import failed!
    %EPM% logout
    exit /b 1
)
```

## Quick Reference: Return Codes

| Code | Meaning |
|------|---------|
| 0 | Success |
| 1 | General error |
| 2 | Authentication failed |
| 3 | File not found |
| 4 | Network error |
| 5 | Timeout |
| 9 | Already running |

## Quick Rules

| Do | Don't |
|----|-------|
| ✅ Encrypt passwords | ❌ Hardcode passwords in scripts |
| ✅ Check return codes | ❌ Assume commands succeed |
| ✅ Logout after scripts | ❌ Leave sessions open |
| ✅ Backup before destructive ops | ❌ Import snapshots without testing |
| ✅ Use task scheduler for automation | ❌ Run heavy loads during business hours |
