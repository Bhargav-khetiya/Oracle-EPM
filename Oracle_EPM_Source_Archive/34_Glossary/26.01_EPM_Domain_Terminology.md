# EPM Domain Terminology and Full Forms

A comprehensive glossary of Oracle EPM professional jargon, acronyms, and domain-specific knowledge.

## EPM Architecture & Engines
*   **EPM:** Enterprise Performance Management. The umbrella term for the software suite.
*   **Essbase:** Extended Spread Sheet Database. The core multidimensional (OLAP) database engine powering EPM Cloud.
*   **BSO:** Block Storage Option. The Essbase engine optimized for complex allocations, calculations, and driver-based planning. Requires strict Dense/Sparse tuning.
*   **ASO:** Aggregate Storage Option. The Essbase engine optimized for massive reporting, massive dimensionality, and instant aggregation.
*   **Hybrid BSO:** A modern Essbase engine that combines the calculation power of BSO with the aggregation speed of ASO at upper levels.
*   **OLAP:** Online Analytical Processing. The architecture of a cube, as opposed to OLTP (Online Transaction Processing) used by ERPs.

## Modules & Products
*   **PBCS / EPBCS:** (Enterprise) Planning and Budgeting Cloud Service. The classic name for Planning.
*   **FCCS:** Financial Consolidation and Close Service. Designed for statutory reporting, IFRS/GAAP compliance, and complex eliminations.
*   **ARCS:** Account Reconciliation Cloud Service. Automates balance sheet reconciliations.
*   **PCMCS / HPCM:** (Enterprise) Profitability and Cost Management. An ASO-based tool designed for massive, multi-step allocation processes.
*   **EDMCS:** Enterprise Data Management Cloud Service. A centralized hub for managing and synchronizing metadata (dimensions) across different applications (e.g., keeping the ERP chart of accounts synced with EPM).
*   **EPRCS / Narrative Reporting:** Used for combining data with narrative text (annual reports, 10-Ks) in a secure, audited workflow.

## Technical Terms
*   **POV (Point of View):** The specific data intersection a user is currently looking at (e.g., Scenario: Actual, Year: FY24, Entity: IT).
*   **LCM:** Lifecycle Management. The framework used for migrating artifacts (Snapshot backups) between Test and Prod environments.
*   **UDA:** User Defined Attribute. A text tag placed on a member for filtering in Calc Scripts or Smart View.
*   **RTP:** Runtime Prompt. A variable that asks the user for input when executing a rule.
*   **SubVar:** Substitution Variable. A global placeholder (e.g., `&CurMo`).
*   **MDX:** MultiDimensional eXpressions. The query language used for ASO calculations and Smart View retrieves.
*   **MaxL:** Multidimensional Access Language. The classic administrative scripting language for on-premise Essbase (mostly replaced by EPM Automate in the cloud).
*   **EPM Automate:** The command-line utility used by administrators to schedule and automate cloud tasks (loading data, backing up snapshots).
*   **IDCS / OCI IAM:** Identity Cloud Service / Oracle Cloud Infrastructure Identity and Access Management. The authentication layer for Oracle Cloud.
