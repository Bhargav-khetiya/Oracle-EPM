## 3. KEY ACTIONS FROM THIS SCREEN

| Action | What It Does | When to Use |
|--------|-------------|-------------|
| **Refresh Database** | Restructure cube after metadata changes | After adding/removing members |
| **Create Cube** | Add a new Plan Type | When adding Workforce/Capital modules |
| **Application Settings** | Configure fiscal year, currencies, etc. | During initial setup |
| **Manage Dimensions** | Open Dimension Editor | To add/edit members |

---

## 4. INTERVIEW QUESTION

**Q: What can you see on the Application Overview screen—**
> The Application Overview shows: application name and type, list of cubes (Plan Types) with storage type and member counts, dimension list with Dense/Sparse classification, application settings (fiscal year, base currency, sandboxes), and action buttons (Refresh Database, Create Cube, Application Settings). It's the admin's starting point for understanding the application structure.
