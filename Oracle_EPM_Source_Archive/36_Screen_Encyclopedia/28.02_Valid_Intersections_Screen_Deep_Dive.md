## 3. HOW VALID INTERSECTIONS WORK

| Setting | Behavior | Use When |
|---------|----------|----------|
| **Allow** | Only listed combinations are valid | Restrict entry to specific combos |
| **Deny** | Listed combinations are invalid | Block specific combos |
| **Anchor** | Base dimension for the rule | Which dim drives the rule |
| **Target** | Filtered dimension | Which dim is restricted |

## 4. HOTEL PVT LTD EXAMPLES

```
Rule: Planners can't enter Actual data at entity level
  Anchor: Scenario = Actual
  Target: Entity = Only "All_Hotels" (consolidated)
  Effect: Actual + Mumbai_Hotel = Invalid (blocked)
          Actual + All_Hotels = Valid (read-only total)

Rule: Workforce accounts only in WFP cube
  Anchor: Account = @DESCENDANTS("Salary_Details")
  Target: Plan Type = OEP_WFP only
  Effect: Salary accounts don't appear in FinPlan forms
```
