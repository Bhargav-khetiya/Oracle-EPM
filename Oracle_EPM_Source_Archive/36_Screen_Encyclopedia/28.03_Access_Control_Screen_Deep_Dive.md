## 3. KEY ACTIONS

| Action | What It Does |
|--------|-------------|
| **Assign Access** | Set Read/Write/None per dimension member per group |
| **Manage Groups** | Create groups, add/remove users |
| **Provisioning** | Assign application roles (Admin/Planner/Viewer) |
| **Export Report** | Download CSV of all access assignments |

## 4. EFFECTIVE ACCESS RULE
```
Multiple dimensions: Most RESTRICTIVE wins
  Entity=Write + Scenario=Write + Account=None → NO ACCESS
  
Inheritance: Parent cascades to children unless overridden
  All_Hotels=Write → Mumbai=Write (inherited)
  All_Hotels=Write + Delhi=None → Delhi blocked (explicit override)
```
