# 28.04 — Data Management Setup Screens

> **Navigation:** Navigator → Data Exchange → Data Management

## Screen Layout
```
┌── Data Management ─────────────────────────────────────────┐
│ Tabs: [Setup] [Workflow] [Data Load] [Data Export]         │
│                                                             │
│ Setup Tab:                                                  │
│  ├── Target Application: HotelApp (OEP_FS)                │
│  ├── Import Format: [Create] [Edit] [Delete]               │
│  ├── Data Load Rule: [Create] [Edit] [Delete]              │
│  └── Data Load Mapping: Source → Target member mapping     │
│                                                             │
│ Import Format Settings:                                     │
│  File Type: Delimited │ Delimiter: Comma │ Header: 1 row   │
│  Column Mapping:                                            │
│   Col 1 → Account  │ Col 2 → Entity  │ Col 3 → Amount     │
│  Fixed Values:                                              │
│   Scenario=Actual │ Version=Final │ Year=&CurrYear         │
│                                                             │
│ Data Load Rule:                                             │
│  Name: DL_Revenue_Actuals                                   │
│  Source: File (CSV)                                         │
│  Import Format: IF_Revenue                                  │
│  Load Method: Replace (not Accumulate!)                    │
└─────────────────────────────────────────────────────────────┘
```

## Key Settings

| Setting | Options | Impact |
|---------|---------|--------|
| Load Method | Replace / Accumulate | Replace overwrites; Accumulate adds |
| Delimiter | Comma/Tab/Pipe/Semicolon | Must match source file |
| Header Rows | 0-N | Rows to skip before data |
| Fixed Values | Dim=Member | Hardcode dims not in file |
