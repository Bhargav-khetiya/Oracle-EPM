# 29.01 — Dimension Properties: Complete Reference

> **Module:** 29_Property_Encyclopedia | **Topic:** Every Dimension-Level Property

---

## 1. DIMENSION-LEVEL PROPERTIES

| Property | Options | Impact | Default |
|----------|---------|--------|---------|
| **Dimension Type** | Accounts, Time, Entity, Scenario, Version, Year, Currency, Custom | Determines system behavior, aliases, account types | Set at creation |
| **Dense/Sparse** | Dense, Sparse | Dense = within block (fast calc), Sparse = across blocks (memory efficient) | Depends on type |
| **Alias Table** | Default, Custom1, Custom2... | Alternative display names | Default |
| **Sort Order** | None, Ascending, Descending | Member display order in forms | None |
| **Two-Pass Calc** | Enabled/Disabled | Allows Dynamic Calc parents to use results of other Dynamic Calc members | Disabled |
| **Solve Order** | 0-127 | Calculation priority for MDX-based calcs | 0 |

## 2. MEMBER-LEVEL PROPERTIES (ALL DIMENSIONS)

| Property | Options | Impact |
|----------|---------|--------|
| **Data Storage** | Store, Dynamic Calc, Dynamic Calc & Store, Label Only, Shared, Never Share | How data is stored/calculated |
| **Consolidation** | + (Add), - (Subtract), * (Multiply), / (Divide), % (Percent), ~ (Ignore) | How member rolls up to parent |
| **Alias** | Text string | Display name on forms |
| **Formula** | MDX/Member formula | Custom calculation logic |
| **UDA** | Text tags | User Defined Attributes for rule targeting |
| **Smart List** | Smart List name | Associates drop-down with member |
| **Data Type** | Currency, Non-Currency, Percentage, Smart List, Date, Text | How value is stored/displayed |
| **Plan Type** | Valid plan types | Which cubes this member exists in |
| **Comment** | Text | Documentation |

## 3. DATA STORAGE DECISION MATRIX

```
Question: Does this member store user-entered data—
  YES → Store
  NO → Is it a parent with children—
    YES → Dynamic Calc (calculates on the fly from children)
    NO → Is it a label/grouping only—
      YES → Label Only
      NO → Is it shared from another hierarchy—
        YES → Shared Member
        NO → Never Share
```
