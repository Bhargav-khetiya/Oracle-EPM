# 29.02 — All Form Properties: Exhaustive Reference

> **Module:** 29_Property_Encyclopedia | **Topic:** Every Form-Level Property

---

## 1. FORM LAYOUT PROPERTIES

| Property | Options | Impact |
|----------|---------|--------|
| **Plan Type** | OEP_FS, OEP_WFP, etc. | Which cube form reads/writes |
| **Rows** | Dimension + member selection | What appears on rows |
| **Columns** | Dimension + member selection | What appears on columns |
| **POV** | Dimension + member selection | Fixed context (not visible in grid) |
| **Page** | Dimension + member selection | User-selectable dropdown above grid |

## 2. DISPLAY PROPERTIES

| Property | Default | Impact |
|----------|---------|--------|
| **Suppress Missing Data** | ❌ Off | Hides rows with all #MISSING (50-80% fewer rows) |
| **Suppress Missing Blocks** | ❌ Off | Skips empty blocks (faster query) |
| **Suppress Invalid Data** | ❌ Off | Hides invalid intersections |
| **Display Missing as Blank** | ❌ Off | Shows blank instead of #MISSING |
| **Display Missing as Zero** | ❌ Off | Shows 0 instead of #MISSING |
| **Enable Grid Spread** | ❌ Off | Allows mass-fill/grid spread shortcuts |
| **Enable Cell-Level Security** | ❌ Off | Per-cell read/write control |
| **Show Currency** | ❌ Off | Display currency symbol |

## 3. PRECISION & FORMATTING

| Property | Options | Impact |
|----------|---------|--------|
| **Minimum Precision** | 0-10 | Minimum decimal places shown |
| **Maximum Precision** | 0-10 | Maximum decimal places shown |
| **Thousands Separator** | On/Off | Display comma grouping |
| **Negative Style** | Minus, Parentheses, Red | How negative numbers display |
| **Scale** | None, Thousands, Millions, Billions | Divide display value |

## 4. BUSINESS RULE PROPERTIES

| Property | Options | Impact |
|----------|---------|--------|
| **On Load Rules** | List of rules | Execute when form opens (slow form!) |
| **On Save Rules** | List of rules | Execute when user clicks Save |
| **Manual Rules** | List of rules | User launches from menu |
| **Smart Push** | Push configuration | Auto-push data to other cubes on save |
| **Run rules before Save** | On/Off | Execute before or after data commit |

## 5. PERFORMANCE IMPACT TABLE

| Property | Performance Impact | Recommendation |
|----------|-------------------|----------------|
| Suppress Missing Data | ⚡⚡⚡ Huge improvement | ✅ Always enable |
| Suppress Missing Blocks | ⚡⚡ Large improvement | ✅ Always enable |
| Enable Grid Spread | ⚡ Minor overhead | Enable only if needed |
| On Load Rules | 🐌🐌🐌 Major slowdown | ⚠️ Avoid heavy rules |
| Cell-Level Security | 🐌 Minor slowdown | Use only when required |
| Two sparse dims on rows | 🐌🐌🐌 Cartesian explosion | ❌ Move one to Page |
