# 29.02 — UDA and Attribute Configuration

> **Module:** 29_Property_Encyclopedia | **Topic:** User Defined Attributes and Attribute Dimensions

---

## 1. USER DEFINED ATTRIBUTES (UDAs)

UDAs are text tags attached to members. They have NO data storage — they're labels used by calc scripts to dynamically select members.

### How to Set UDAs
```
Navigator → Dimensions → Select Member → Properties → UDA
Add tag: "Premium" or "Economy" or "Flagship"
```

### UDA Properties

| Property | Description |
|----------|------------|
| **Name** | Text string (e.g., "Premium", "Budget_Enabled") |
| **Assigned To** | One or more members |
| **Scope** | Dimension-level (Entity UDAs only apply to Entity members) |
| **Data Storage** | None — UDAs store no data |

### Using UDAs in Calc Scripts
```essbase
/* Apply 10% premium surcharge to Premium hotels only */
FIX(@UDA("Entity", "Premium"))
  "Room_Revenue" = "Room_Revenue" * 1.10;
ENDFIX

/* Hotel Pvt Ltd UDAs:
   Entity: Premium (Mumbai, Delhi), Business (Bangalore), Economy (Kolkata, Chennai)
   Account: KPI (RevPAR, Occupancy, ADR), Financial (Revenue, Expense)
*/
```

## 2. ATTRIBUTE DIMENSIONS

Attribute dimensions are linked to a base dimension. They allow alternate analysis without adding sparsity.

| Property | Standard Dimension | Attribute Dimension |
|----------|-------------------|-------------------|
| **Data Storage** | Stores data | No data (derived) |
| **Aggregation** | Has own blocks | Aggregates from base |
| **Dense/Sparse** | Either | Always sparse |
| **Members** | Independent | Linked to base members |
| **Use Case** | Main hierarchies | Analysis/filtering |

### Example
```
Base Dimension: Entity
  Mumbai_Hotel (Attr: Region=West, Tier=Premium, Rooms=120)
  Delhi_Hotel (Attr: Region=North, Tier=Premium, Rooms=100)

Attribute Dimension: Region
  North, South, East, West → linked to Entity members

Benefit: Report by Region without creating a Region parent in Entity
```

## 3. UDA vs ATTRIBUTE — WHEN TO USE WHICH

| Feature | UDA | Attribute Dimension |
|---------|-----|-------------------|
| Reporting axis | ❌ Can't put on row/column | ✅ Can use as row/column |
| Calc script targeting | ✅ @UDA function | ✅ @ATTRIBUTE function |
| Smart View drill | ❌ No | ✅ Yes |
| Impact on blocks | None | None (no new blocks) |
| Setup complexity | Simple (text tag) | Medium (new dimension) |
| **Use when** | Rule targeting only | Need to report/filter by attribute |
