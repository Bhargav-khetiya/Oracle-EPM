# 30.01 — Essbase Calculation Functions: Complete Reference

> **Module:** 30_Function_Reference | **Topic:** @Functions, SET Commands, Calc Commands
> **Audience:** Rule Developer

---

## 1. MEMBER SELECTION FUNCTIONS

| Function | Returns | Example | Result |
|----------|---------|---------|--------|
| `@CHILDREN("X")` | Direct children | `@CHILDREN("All_Hotels")` | Mumbai, Delhi, B'lore, Kolkata, Chennai |
| `@ICHILDREN("X")` | X + its children | `@ICHILDREN("All_Hotels")` | All_Hotels, Mumbai, Delhi, B'lore, Kolkata, Chennai |
| `@DESCENDANTS("X")` | All descendants | `@DESCENDANTS("Total_Revenue")` | Room_Rev, F&B_Rev, Spa_Rev |
| `@IDESCENDANTS("X")` | X + descendants | `@IDESCENDANTS("Total_Revenue")` | Total_Revenue, Room_Rev, F&B_Rev, Spa_Rev |
| `@RELATIVE("X", N)` | Members at level N | `@RELATIVE("All_Hotels", 0)` | All level-0 (leaf) members |
| `@PARENT("X")` | Parent of X | `@PARENT("Mumbai_Hotel")` | All_Hotels |
| `@SIBLINGS("X")` | Siblings of X | `@SIBLINGS("Mumbai_Hotel")` | Delhi, B'lore, Kolkata, Chennai |
| `@ISIBLINGS("X")` | X + siblings | `@ISIBLINGS("Mumbai_Hotel")` | Mumbai, Delhi, B'lore, Kolkata, Chennai |
| `@LEVEL("X", N)` | Members at level N in dim X | `@LEVEL("Entity", 0)` | All level-0 members |
| `@RANGE("Dim", "A", "B")` | Members from A to B | `@RANGE("Period", "Jan", "Mar")` | Jan, Feb, Mar |
| `@UDA("Dim", "Tag")` | Members with UDA tag | `@UDA("Entity", "Premium")` | Members tagged "Premium" |
| `@ANCESTORS("X")` | All ancestors of X | `@ANCESTORS("Mumbai_Hotel")` | All_Hotels |
| `@LIST("A","B","C")` | Explicit list | `@LIST("Jan","Feb","Mar")` | Jan, Feb, Mar |
| `@MATCH("X","pattern")` | Wildcard match | `@MATCH("Entity","*_Hotel")` | All members ending in _Hotel |

## 2. DATA FUNCTIONS

| Function | Purpose | Example |
|----------|---------|---------|
| `@SUM(range)` | Sum of members | `@SUM(@CHILDREN("Total_Revenue"))` |
| `@AVG(range)` | Average | `@AVG(@CHILDREN("Total_Revenue"))` |
| `@MAX(range)` | Maximum value | `@MAX(@CHILDREN("Total_Revenue"))` |
| `@MIN(range)` | Minimum value | `@MIN(@CHILDREN("Total_Revenue"))` |
| `@COUNT(range)` | Count of non-missing | `@COUNT(@CHILDREN("All_Hotels"))` |
| `@PRIOR("Period", N)` | Value N periods ago | `@PRIOR("Period", 1)` → prior month value |
| `@NEXT("Period", N)` | Value N periods ahead | `@NEXT("Period", 1)` → next month value |
| `@PARENTVAL("Dim")` | Value at parent level | `@PARENTVAL("Entity")` |
| `@MDSHIFT("Dim", N)` | Shift along dimension | `@MDSHIFT("Period", -1)` |
| `@CONCATENATE(a,b)` | Concatenate strings | `@CONCATENATE("Budget","_Final")` |
| `@TODATE(format,date)` | Convert to date | `@TODATE("mm-dd-yyyy","08-13-2026")` |

## 3. CONDITIONAL FUNCTIONS

| Function | Purpose | Example |
|----------|---------|---------|
| `@ISMBR("X")` | True if current member = X | `IF(@ISMBR("Mumbai_Hotel"))` |
| `@ISUDA("X", "Tag")` | True if member has UDA | `IF(@ISUDA("Entity", "Premium"))` |
| `@ISLEV("Dim", N)` | True if member at level N | `IF(@ISLEV("Entity", 0))` |
| `@ISGEN("Dim", N)` | True if member at gen N | `IF(@ISGEN("Entity", 2))` |
| `@ISPARENT("X")` | True if member is parent of X | `IF(@ISPARENT("Mumbai_Hotel"))` |
| `@ISCHILD("X")` | True if member is child of X | `IF(@ISCHILD("All_Hotels"))` |
| `@ISANCEST("X")` | True if ancestor of X | `IF(@ISANCEST("Mumbai_Hotel"))` |
| `@ISDESC("X")` | True if descendant of X | `IF(@ISDESC("Total_Revenue"))` |

## 4. SET COMMANDS

| Command | Purpose | Default |
|---------|---------|---------|
| `SET LOCKBLOCK ON/OFF` | Lock blocks in cache during calc | OFF |
| `SET CALCPARALLEL N` | Enable N parallel threads | 1 (serial) |
| `SET CREATEBLOCKONEQ ON/OFF` | Create blocks on = assignment | OFF |
| `SET CREATENONMISSINGBLK ON/OFF` | Create blocks for non-missing data | OFF |
| `SET MSG SUMMARY/DETAIL/NONE` | Calc message level | SUMMARY |
| `SET NOTICE LOW/HIGH` | Notice level | LOW |
| `SET UPDATECALC ON/OFF` | Intelligent calc tracking | OFF |
| `SET AGGMISSG ON/OFF` | Aggregate missing values | ON |
| `SET FRMLBOTTOMUP ON/OFF` | Force bottom-up calc | OFF |

---

## 5. CALC COMMANDS

| Command | Purpose | Example |
|---------|---------|---------|
| `AGG("Dim")` | Aggregate dimension | `AGG("Entity")` |
| `CALC DIM("Dim")` | Calculate dimension | `CALC DIM("Account")` |
| `CALC ALL` | Calculate entire cube | `CALC ALL` (avoid in production) |
| `CLEARDATA` | Clear data in scope | `CLEARDATA "Budget"` |
| `CLEARBLOCK ALL` | Remove empty blocks | `CLEARBLOCK ALL` |
| `DATACOPY` | Copy data | `DATACOPY "Actual" TO "Budget"` |
| `FIX...ENDFIX` | Scope calc to members | `FIX("Budget", "Working")` |
| `IF...ENDIF` | Conditional logic | `IF("Revenue" > 0)` |
| `VAR x` | Declare variable | `VAR v_Total` |
| `ARRAY x[N]` | Declare array | `ARRAY a_Months[12]` |

## 6. OPTIMIZATION PATTERNS

```essbase
/* Standard optimized rule template */
SET LOCKBLOCK ON;
SET CALCPARALLEL 4;
SET MSG SUMMARY;

FIX("Budget", "Working", &CurrYear)
  FIX(@RELATIVE("All_Hotels", 0))
    
    /* Dense calcs (within-block — fast) */
    "Net_Income" = "Total_Revenue" - "Total_Expenses";
    
    /* Safe division */
    IF("Total_Revenue" <> 0)
      "Profit_Margin" = "Net_Income" / "Total_Revenue" * 100;
    ENDIF
    
  ENDFIX
  
  /* Sparse aggregation (cross-block) */
  AGG("Entity");
  
ENDFIX

SET LOCKBLOCK OFF;
```
