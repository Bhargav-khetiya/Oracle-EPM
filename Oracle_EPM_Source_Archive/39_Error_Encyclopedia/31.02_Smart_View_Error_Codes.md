# 31.02 — Smart View Error Codes and Resolutions: Complete Guide

> **Module:** 31_Error_Encyclopedia | **Topic:** Smart View Errors
> **Audience:** Service Administrator / Support

---

## 1. ALL SMART VIEW ERRORS

### Connection Errors

| Error | Message | Cause | Fix |
|-------|---------|-------|-----|
| SV-1001 | "Cannot connect to provider" | Wrong URL or instance down | Verify URL, check instance status |
| SV-1002 | "Login failed" | Wrong credentials | Reset password, check username |
| SV-1003 | "SSL handshake failed" | Certificate issue | Update Root CA certificates |
| SV-1004 | "Connection timed out" | Network/VPN issue | Check VPN, firewall, proxy |
| SV-1005 | "Session expired" | Idle timeout | Re-login |
| SV-1006 | "Maximum sessions exceeded" | Too many open connections | Close other Excel instances |

### Data Errors

| Error | Message | Cause | Fix |
|-------|---------|-------|-----|
| SV-2001 | "#NoData" in cells | No data at intersection | Verify POV members exist |
| SV-2002 | "#No Connection" | Disconnected during refresh | Re-connect and refresh |
| SV-2003 | "Submit failed" | Write access denied or cell locked | Check security + version lock |
| SV-2004 | "#Invalid" | Formula error in HsGetValue | Check all dimension#member syntax |
| SV-2005 | "Data validation error" | Value exceeds limits | Check data type (numeric only) |

### Add-In Errors

| Error | Message | Cause | Fix |
|-------|---------|-------|-----|
| SV-3001 | "Smart View add-in not loaded" | COM add-in disabled | Enable in Excel Options → Add-ins |
| SV-3002 | "Incompatible Excel version" | Version mismatch | Check Oracle compatibility matrix |
| SV-3003 | "Smart View ribbon missing" | Installation issue | Reinstall Smart View |
| SV-3004 | "Extension not loaded" | Planning extension missing | Install Planning extension |

### HsGetValue Errors

| Error | Message | Cause | Fix |
|-------|---------|-------|-----|
| — | "#NoData" | Missing dimension in POV | Specify ALL dimensions |
| — | "#No Connection" | Not logged in | Connect first |
| — | "#Invalid Member" | Member doesn't exist | Verify member name |
| — | "#Error" | Connection name wrong | Match exact connection name |

## 2. TROUBLESHOOTING GUIDE

```
Smart View Not Loading:
  1. Close all Excel instances
  2. Open Excel → File → Options → Add-ins
  3. Manage: COM Add-ins → Go
  4. ☑ Oracle Smart View for Office
  5. Click OK → Smart View ribbon should appear

Can't Connect:
  1. Check URL: https://instance.oraclecloud.com/HyperionPlanning/SmartView
  2. Try URL in browser → should show XML response
  3. Check VPN connected (if required)
  4. Check proxy settings: Tools → Options → Advanced → Proxy
  5. Try: Smart View → Options → Advanced → Reset connection

Refresh Returns #NoData:
  1. Check POV — all dimensions specified?
  2. Check member names — exact match required
  3. Try ad hoc on same cube → does data exist?
  4. Check dimension security — does user have Read access?

Submit Fails:
  1. Check if cells are read-only (form permission = Read?)
  2. Check dimension security (Write on entity/scenario?)
  3. Check version (Final = Read for planners?)
  4. Try refreshing first, then making changes, then submit
```
