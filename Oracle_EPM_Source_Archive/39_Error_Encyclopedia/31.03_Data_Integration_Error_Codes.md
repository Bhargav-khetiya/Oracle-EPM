# 31.03 — Data Integration Error Codes and Resolutions: Complete Guide

> **Module:** 31_Error_Encyclopedia | **Topic:** Data Load/Export Errors
> **Audience:** Service Administrator

## 1. DATA LOAD ERRORS

### File Errors

| Error | Message | Cause | Fix |
|-------|---------|-------|-----|
| DI-1001 | "File not found" | File not uploaded or wrong name | Upload file first; check exact filename |
| DI-1002 | "Invalid file format" | Wrong delimiter or encoding | Check delimiter setting; save as UTF-8 |
| DI-1003 | "Empty file" | File has no data rows | Add data rows below header |
| DI-1004 | "Header row not found" | No header or wrong skip count | Set correct header row count |
| DI-1005 | "Column count mismatch" | Row has extra/missing delimiters | Fix the row; check for commas in data |

### Member Errors

| Error | Message | Cause | Fix |
|-------|---------|-------|-----|
| DI-2001 | "Member not found: MUMBAI" | Member name doesn't match | Fix source or add mapping rule |
| DI-2002 | "Member ambiguous" | Same name in multiple dims | Use qualified name or fix mapping |
| DI-2003 | "Shared member cannot accept data" | Loading to shared member | Load to base member instead |
| DI-2004 | "Member is Label Only" | Can't store data on label | Load to Store member |
| DI-2005 | "Dynamic Calc member" | Can't load to dynamic member | Load to Store inputs instead |

### Data Value Errors

| Error | Message | Cause | Fix |
|-------|---------|-------|-----|
| DI-3001 | "Invalid data value: N/A" | Non-numeric in data column | Replace with blank or 0 |
| DI-3002 | "Invalid data value: ₹85,00,000" | Currency symbol in data | Remove symbols: 8500000 |
| DI-3003 | "Numeric overflow" | Value too large | Check for extra digits |
| DI-3004 | "Duplicate intersection" | Same cell loaded twice | De-duplicate source data |

### Import Rule Errors

| Error | Message | Cause | Fix |
|-------|---------|-------|-----|
| DI-4001 | "Import format not found" | Rule references deleted format | Recreate import format |
| DI-4002 | "Dimension not mapped" | Column not mapped to dimension | Map all columns in import format |
| DI-4003 | "Target application not found" | Wrong app name in rule | Verify application name |
| DI-4004 | "Cube not available" | Cube in maintenance | Wait for maintenance to complete |

## 2. RESOLUTION PATTERNS

### Pattern: Fix Member Not Found

```
Step 1: Open the job log → find the exact member name causing error
Step 2: Search EPBCS Dimension Editor for that member
Step 3: If not found → it's a typo or unmapped name
Step 4: Fix options:
  Option A: Fix the source data file
  Option B: Add a mapping rule in Data Management
  Option C: Add the missing member to the dimension
Step 5: Re-upload file and re-run the load
```

### Pattern: Fix Data Quality Issues

```
Before loading:
  ☐ Open CSV in text editor (not Excel — Excel hides formatting)
  ☐ Check for commas inside text fields (use pipe delimiter instead)
  ☐ Check for currency symbols in numeric columns
  ☐ Check for "N/A", "null", "#N/A" → replace with blank
  ☐ Check for trailing blank rows
  ☐ Check encoding = UTF-8 (not ANSI)
  ☐ Verify member names match EPBCS exactly
```
