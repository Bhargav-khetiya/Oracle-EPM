# 31.04 — Calc Manager Validation Errors: Complete Guide

> **Module:** 31_Error_Encyclopedia | **Topic:** Calc Manager Errors
> **Audience:** Rule Developer

---

## 1. VALIDATION ERRORS (Caught Before Deployment)

| Error | Message | Cause | Fix |
|-------|---------|-------|-----|
| CM-V001 | "Syntax error at line N" | Invalid keyword, missing semicolon | Check syntax at line N |
| CM-V002 | "Unknown member [Name]" | Member doesn't exist in cube | Verify spelling in Dimension Editor |
| CM-V003 | "Unknown function [@Name]" | Function name misspelled | Check @ function name |
| CM-V004 | "Unmatched FIX/ENDFIX" | FIX without ENDFIX or vice versa | Count pairs |
| CM-V005 | "Unmatched IF/ENDIF" | IF without ENDIF | Count pairs |
| CM-V006 | "Variable not defined" | RTP not created or typo | Create variable or fix name |
| CM-V007 | "Duplicate variable name" | Two variables with same name | Rename one |
| CM-V008 | "Invalid Plan Type" | Rule assigned to wrong cube | Check Plan Type assignment |
| CM-V009 | "Component not deployable" | Component not set as deployable | Right-click → Set as Deployable |

---

## 2. DEPLOYMENT ERRORS

| Error | Message | Cause | Fix |
|-------|---------|-------|-----|
| CM-D001 | "Rule not validated" | Validation didn't pass | Fix errors → Validate → Deploy |
| CM-D002 | "Rule modified since deployment" | Rule changed but not redeployed | Re-validate → Re-deploy |
| CM-D003 | "Deployment target unavailable" | Cube in maintenance | Wait for maintenance |
| CM-D004 | "Rule already deployed" | Attempting double-deploy | Undeploy first, then redeploy |

---

## 3. RUNTIME ERRORS (After Deployment)

| Error | Message | Cause | Fix |
|-------|---------|-------|-----|
| CM-R001 | "Member renamed/deleted since deploy" | Metadata changed after deploy | Re-validate → Re-deploy |
| CM-R002 | "Divide by zero at line N" | Denominator = 0 or #MISSING | Add IF(denom <> 0) check |
| CM-R003 | "Insufficient memory" | Rule processes too much data | Tighten FIX scope |
| CM-R004 | "Execution timeout" | Rule too slow | Optimize (see Performance) |
| CM-R005 | "Lock conflict" | Another user/rule has cube lock | Wait or cancel conflicting job |
| CM-R006 | "Groovy compilation error" | Java syntax error in Groovy | Fix Groovy syntax |
| CM-R007 | "NullPointerException" | Groovy accessing null object | Add null checks |

---

## 4. GROOVY-SPECIFIC ERRORS

| Error | Cause | Fix |
|-------|-------|-----|
| "Missing RTPS comment" | `/* RTPS: {RTP_Name} */` not at top | Add comment header |
| "Cannot resolve class DataCell" | Wrong import or context | Use `operation.grid.dataCellIterator()` |
| "groovy.lang.MissingMethodException" | Method name wrong | Check API documentation |
| "java.net.SocketTimeoutException" | REST API call timed out | Add timeout settings, try-catch |
| "throwVetoException not found" | Wrong context (not a form rule) | Only works in On Save rules |

---

## 5. QUICK DIAGNOSTIC FLOW

```
Rule Failed?
├── Validate button shows error → Fix syntax/member name
├── Deploy fails → Validate first, check Plan Type
├── Runtime error:
│   ├── "Unknown member" → Member renamed since last deploy → re-deploy
│   ├── "Divide by zero" → Add IF check
│   ├── "Timeout" → Optimize FIX scope
│   ├── "Lock conflict" → Check Jobs Console for running jobs
│   └── Groovy error → Check job log for stack trace
└── Rule succeeds but wrong results → Logic error → Add trace messages
```
