## WHY This Module Exists

When you sit in front of EPBCS, you need to know:
- "What does THIS button do?"
- "How do I get to THAT screen?"
- "What are ALL the options on this page?"
- "What happens if I click THIS setting?"

This Encyclopedia answers ALL of those questions. Every screen is documented with:
1. **Navigation path** (exact click sequence to reach it)
2. **ASCII diagram** of the screen layout
3. **Every element** documented with purpose
4. **Do's and Don'ts** from Oracle's own guidance
5. **Hotel Pvt Ltd scenario** applied to make it real

## 🧭 Navigation Concepts

### Three Ways to Navigate EPBCS

| Method | How | Best For |
|--------|-----|----------|
| **Home Page Cards** | Click a card icon on the Work Area | Quick access to main areas |
| **Navigator Menu** | Click ≡ (hamburger icon) top-left | Full sitemap / finding obscure screens |
| **Breadcrumbs** | Click the path shown at top of each page | Going back up a hierarchy |

### Two Interface Modes

| Mode | When | Key Difference |
|------|------|----------------|
| **Standardized (Current)** | All new environments post Oct 2025 | Unified artifact pages, Dashboard 2.0 only |
| **Legacy** | Existing envs that haven't migrated | Composite forms visible, Dashboard 1.0 available |

> ⚠️ **Critical Gotcha:** As of October 2025 (update 25.10), **Forms 1.0, Dashboard 1.0, and Infolets** are de-supported. New environments cannot create them. All new EPBCS work should use Forms 2.0 and Dashboard 2.0.

## 🎭 Role-Based Access Overview

Different roles see different things in the navigation:

| Role | Sees |
|------|------|
| **Service Administrator** | Everything — all cards, all admin menus |
| **Power User** | Data, Rules, Approvals, Reports + assigned forms |
| **User** | Only forms/dashboards they've been given permission to |
| **Viewer** | Read-only access to assigned forms/dashboards |
