# 🔧 33.05 — Administration Menu: Complete Navigation Encyclopedia

> **Source:** Oracle® Fusion Cloud EPM Administering Planning (Aug 2026)
> **Navigation:** Home → Navigator (≡) → under "Administration" section
> **Who sees it:** Service Administrators only
> **What it is:** All administration functions for managing the EPBCS environment

---

## 1. WHY — What Problem Does the Admin Menu Solve—

**The problem:** EPBCS has dozens of administrative functions — user management, environment settings, daily maintenance, audit logs, backups. Without a central administration hub, admins would waste hours navigating to find these functions.

**The solution:** The Navigator's Administration section provides a single menu for all environment-level operations that go beyond application design.

## 3. EVERY ADMIN FUNCTION — DETAILED

### 3.1 Manage Approvals
```
Path: Navigator → Workflow → Manage Approvals

What it does: Controls the budget approval workflow
Key actions:
  - Start/stop plan cycles
  - View approval status by entity
  - Change ownership of approval units
  - View promotional paths
  - Force promote/reject
```

| Action | Description |
|--------|-------------|
| **Start Process** | Initiates the budget cycle for a scenario/version |
| **View Status** | Shows Process Status, Level Status, Group Status, Tree View |
| **Promote** | Moves approval unit to next reviewer |
| **Reject** | Sends approval unit back to previous owner |
| **Force Promote** | Admin overrides — pushes approval forward regardless of status |
| **Sign Off** | Final approval — locks data |
| **Freeze** | Prevents changes but doesn't promote |

### 3.2 Application Monitoring
```
Path: Navigator → Administration → Application Monitoring

What it does: Real-time performance monitoring
Key views:
  - Active users count
  - Rule execution times
  - Form load times
  - Memory utilization
  - Top slow-running artifacts
```

| Graph | What It Shows |
|-------|-------------|
| **Active Sessions** | Number of concurrent users |
| **Top Rules by Duration** | Slowest business rules |
| **Top Forms by Load Time** | Slowest forms |
| **Essbase Queries** | Database query performance |

### 3.3 Audit
```
Path: Navigator → Administration → Audit

What it does: Tracks who changed what and when
Auditable actions:
  - Data changes (cell values)
  - Metadata changes (member adds/deletes)
  - Security changes (permission modifications)
  - Rule launches
  - Form modifications
```

| Audit Category | What's Tracked |
|---------------|----------------|
| **Data Audit** | Cell value changes: old value, new value, user, timestamp |
| **Metadata Audit** | Member additions, deletions, property changes |
| **Security Audit** | Permission grants/revokes, role assignments |
| **Artifact Audit** | Form, rule, dashboard changes |

### 3.4 Daily Maintenance
```
Path: Navigator → Administration → Daily Maintenance

What it does: Configure the daily maintenance window
Settings:
  - Start time (UTC)
  - Duration (typically 1-2 hours)
  - What runs: backup, optimization, cleanup
```

> ⚠️ **Important:** During the maintenance window, the application is UNAVAILABLE. Schedule it during off-hours for your organization.

### 3.5 Announcement
```
Path: Navigator → Administration → Announcement

What it does: Display a banner message to ALL users on the home page
Use cases:
  - "Budget cycle closes Friday at 5 PM"
  - "System maintenance scheduled Sunday 2-4 AM"
  - "Submit FY2027 budgets by Oct 15"
```

| Setting | Description |
|---------|-------------|
| **Message** | Up to 500 characters of text |
| **Start Date** | When the announcement appears |
| **End Date** | When the announcement disappears |
| **Enabled** | Toggle on/off |

### 3.6 Currency
```
Path: Navigator → Administration → Currency (or Application → Currencies)

What it does: Manage currencies and exchange rates
Key sections:
  - Currency list (USD, INR, EUR, etc.)
  - Exchange rate tables (triangulation, direct)
  - Rate entry (period-by-period exchange rates)
```

## 4. INTEGRATION SECTION

### 4.1 Data Integration
```
Path: Navigator → Integration → Data Integration

What it does: FDMEE-based data loading and mapping
Key functions:
  - Create import formats
  - Map source columns to target dimensions
  - Run data loads
  - View load status and error logs
  - Schedule recurring loads
```

### 4.2 Data Exchange
```
Path: Navigator → Integration → Data Exchange

What it does: Simple file-based import/export
Key functions:
  - Import metadata (CSV format)
  - Import data (CSV format)
  - Export metadata/data
  - View import/export status
```

### 4.3 EPM Automate
```
Path: Navigator → Integration → EPM Automate (documentation link)

What it does: Command-line automation utility
Key commands:
  - importData / exportData
  - importMetadata / exportMetadata
  - runBusinessRule
  - refreshCube
  - createSnapshot / restoreSnapshot
  - importSnapshot / exportSnapshot
```

## 5. TOOLS SECTION (Admin-Related)

### 5.1 Access Control
```
Path: Navigator → Tools → Access Control

What it does: Manage users, roles, and permissions
Key tabs:
  - Roles: View predefined roles (Service Admin, Power User, Planner, Viewer)
  - Users: See user list and role assignments
  - Provisioning: (Done via Identity Domain / OCI IAM)
```

### 5.2 Migration
```
Path: Navigator → Tools → Migration

What it does: Backup and restore via snapshots
Key actions:
  - Create Snapshot → backs up entire app (metadata, data, artifacts, security)
  - Restore Snapshot → restores from a snapshot
  - Import Snapshot → import from another environment
  - Export Snapshot → export for transfer
```

| Action | Use Case |
|--------|----------|
| **Create Snapshot** | Before major changes (backup) |
| **Restore Snapshot** | Rollback after a mistake |
| **Export + Import** | Migrate from Dev to Prod |
| **Clone** | Create a copy of the environment |

### 5.3 Jobs Console
```
Path: Navigator → Tools → Jobs

What it does: View and manage all background jobs
Job types shown:
  - Business rule executions
  - Data imports/exports
  - Refresh database
  - Clear cube jobs
  - Snapshot operations
  - Scheduled recurring jobs
```

## 6. HOTEL PVT LTD EXAMPLE

### Monthly Admin Workflow
```
1st of every month:
  1. Navigator → Variables → Substitution Variables
     → Update CurrMonth, ForecastStart
  2. Navigator → Administration → Announcement
     → Post: "Budget data entry for [Month] is now open"
  3. Navigator → Integration → Data Exchange
     → Import actual data from Hotel PMS
  4. Navigator → Rules
     → Run "Calculate Form" rule for Actual scenario
  5. Navigator → Workflow → Manage Approvals
     → Start budget cycle for the month

End of every quarter:
  6. Navigator → Tools → Migration
     → Create Snapshot (quarterly backup)
  7. Navigator → Administration → Audit
     → Review data changes for compliance
  8. Navigator → Administration → Application Monitoring
     → Check for slow forms/rules, optimize
```

## 7. INTERVIEW QUESTIONS

### Beginner
**Q: Where do you go to create a backup of an EPBCS application—**
> **A:** Navigator → Tools → Migration → Create Snapshot. This creates a full backup containing metadata, data, security settings, and all artifacts (forms, rules, etc.). Snapshots can be exported to Object Storage for safekeeping or imported into another environment for migration.

### Intermediate
**Q: A user reports they accidentally deleted some data in a form. How do you find out what the original values were—**
> **A:** Navigator → Administration → Audit. In the audit viewer, filter by: (1) User who made the change, (2) Date/time range, (3) Form name or dimension members. The audit trail shows the old value, new value, user, and timestamp for each cell change. Note: Audit must have been ENABLED before the change happened — go to Application → Settings → Enable Audit to turn it on. If audit wasn't enabled, the only recovery option is to restore from a snapshot.
