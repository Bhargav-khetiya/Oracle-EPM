# ⚙️ 33.07 — Settings and Actions Menu: Complete Encyclopedia

> **Source:** Oracle® Fusion Cloud EPM Administering Planning (Aug 2026)
> **Navigation:** Top-right corner — Settings Gear (⚙) and Actions menu on each page
> **Who sees it:** All users (with role-filtered options)
> **What it is:** Context-sensitive actions available on every EPBCS page plus global settings

---

## 1. WHY — What is the Settings & Actions Menu—

Every EPBCS page has an **Actions** menu (☰ or ⋮) and the global **Settings Gear** (⚙). The Actions menu provides context-specific operations for the current page (e.g., form-specific actions). The Settings Gear provides global user settings.

---

## 2. SETTINGS GEAR (⚙) — GLOBAL OPTIONS

```
Location: Top-right corner of every page (next to user avatar)

⚙ Settings Gear
├── User Preferences        → Language, display, user variables
├── Appearance              → Theme selection (Redwood, Dark)
├── Sandbox                 → Create/manage sandboxes (if enabled)
├── Set as Home Page        → Make current page the default landing
├── About                   → Version info, patch level
├── Help                    → Oracle documentation links
└── Sign Out                → Log out of the application
```

See [33.06 Tools Menu](./33.06_Tools_Menu_Navigation.md) for detailed User Preferences options.

## 3. ACTIONS MENU — CONTEXT-SPECIFIC

The Actions menu changes based on which page you're on:

### 3.1 Home Page Actions

| Action | Description |
|--------|-------------|
| **Refresh** | Reload the home page |
| **Switch Navigation Flow** | Change active navigation flow |
| **Set as Home Page** | Pin current view as default landing |

### 3.2 Form/Data Entry Page Actions

| Action | Description |
|--------|-------------|
| **Save** | Save data and run on-save rules |
| **Refresh** | Reload data from Essbase |
| **Business Rules** | Launch attached business rules |
| **Adjust** | Adjust cell value by amount or percentage |
| **Grid Spread** | Spread value to children (proportional/even/fill) |
| **Mass Allocate** | Allocate using allocation rules |
| **Lock/Unlock** | Lock cells from spreading |
| **Supporting Details** | Add line-item breakdowns |
| **Cell History / Audit** | View change history for a cell |
| **Attachments** | Add files to a cell |
| **Comments** | Add text comments to a cell |
| **Copy Version** | Copy data between versions |
| **Export to Excel** | Download grid to Excel |
| **Open in Smart View** | Open form in Smart View |
| **Ad Hoc Analysis** | Switch to ad hoc mode |
| **Print** | Print the form |
| **Edit** | Toggle edit/read mode |
| **Pivot** | Swap rows and columns |

### 3.3 Dimension Editor Actions

| Action | Description |
|--------|-------------|
| **Add Member** | Add a new member to the dimension |
| **Add Sibling** | Add a member at the same level |
| **Add Child** | Add a member as a child |
| **Delete Member** | Remove selected member |
| **Move** | Move member to a different parent |
| **Sort** | Sort children alphabetically |
| **Show Usage** | See where member is used (forms, rules) |
| **Assign Access** | Set security permissions |
| **Edit Properties** | Open member properties dialog |
| **Refresh Database** | Refresh Essbase (after changes) |

### 3.4 Forms/Rules/Dashboard Listing Actions

| Action | Description |
|--------|-------------|
| **Create** | Create new form/rule/dashboard |
| **Edit** | Edit selected artifact |
| **Delete** | Delete selected artifact |
| **Copy** | Duplicate an artifact |
| **Move** | Move to different folder |
| **Rename** | Change artifact name |
| **Permissions** | Assign access (read/write/none) |
| **View Properties** | View artifact properties |
| **Preview** | Preview (forms only) |

### 3.5 Jobs Console Actions

| Action | Description |
|--------|-------------|
| **Schedule** | Create a new scheduled job |
| **Cancel** | Cancel a running job |
| **Delete** | Remove job from history |
| **Duplicate** | Copy schedule settings |
| **View Log** | See execution details |
| **Download** | Download export output files |

## 4. RIGHT-CLICK CONTEXT MENUS (In Forms)

When right-clicking a data cell in a form:

```
Right-click cell → Context Menu
├── Cut / Copy / Paste
├── Adjust Data...
│   ├── By Value: [+/- amount]
│   ├── By Percentage: [+/- %]
│   └── Spread: [proportional/even/fill]
├── Supporting Details...
├── Cell Information
│   ├── Member intersections
│   ├── Data storage type
│   └── Cell status (locked/editable)
├── Comments...
├── Attachments...
├── Lock / Unlock Cell
├── Action Menu Items (if configured)
│   ├── [Custom action 1]
│   ├── [Custom action 2]
│   └── [Custom URL/form/rule]
└── Cell History...
```

See [28.20 Action Menus Screen](../28_Screen_Encyclopedia/28.20_Action_Menus_Screen_Complete.md) for custom right-click menu configuration.

## 5. HOTEL PVT LTD EXAMPLE

### Common Actions by User Type

**Mumbai Planner (daily workflow):**
```
1. Opens Revenue form → enters data
2. Right-click → Adjust Data → +5% (adjust forecast up)
3. Right-click → Supporting Details → add line items
4. Actions → Save (runs Calculate rule)
5. Actions → Business Rules → "Hotel_Rollup"
6. Actions → Export to Excel (for local analysis)
```

**Admin (weekly workflow):**
```
1. Dimensions → Actions → Add Member (new room type)
2. Actions → Refresh Database
3. Forms → Actions → Edit (add new member to form)
4. ⚙ → Sandbox → Create (test changes)
5. Jobs → Actions → Schedule (nightly backup)
```
