# 🧭 33.08 — Navigator Complete: Master Reference

> **Source:** Oracle® Fusion Cloud EPM Administering Planning (Aug 2026), Chapter 25
> **Navigation:** Click ≡ (hamburger icon) in top-left corner of any EPBCS page
> **Who sees it:** All users (with items filtered by role)
> **What it is:** The complete menu system for accessing every EPBCS function

---

## 1. WHY — What is the Navigator—

The Navigator (≡ hamburger menu) is the **master menu** of EPBCS. It lists every function organized by category. Items visible depend on the user's role — Service Admins see everything; Planners see only their relevant items.

---

## 2. COMPLETE NAVIGATOR MAP — EVERY ITEM

```
Navigator (≡)
│
├── HOME (returns to Home Page)
│
├── CREATE AND MANAGE
│   ├── Forms               → Create, edit, manage data entry forms
│   ├── Dashboards          → Create visual dashboards (Charts, KPIs)
│   ├── Infolets            → Small info cards for Home Page
│   ├── Rules               → Open Calculation Manager (business rules)
│   ├── Reports             → Financial Reporting Studio
│   ├── Task Lists          → Create guided checklists for users
│   ├── Smart Lists         → Create dropdown value lists
│   ├── Action Menus        → Configure right-click context menus
│   ├── Navigation Flows    → Customize the UI layout and tabs
│   ├── Dimensions          → Add/edit dimension members (Simplified Editor)
│   ├── Variables            
│   │   ├── Substitution Variables → Global named variables (&CurrMonth)
│   │   └── User Variables         → Per-user variables (UserEntity)
│   ├── Alias Tables        → Manage alias (display name) tables
│   ├── Valid Intersections  → Define which member combos are valid
│   └── Data Maps           → Cross-cube data push mappings
│
├── APPLICATION
│   ├── Overview            → App summary (cubes, dims, settings)
│   ├── Evaluate Support     → Diagnostic evaluation
│   └── Consolidation       → (FCC only — not in EPBCS)
│
├── WORKFLOW
│   ├── Manage Approvals    → Budget approval status and actions
│   ├── Approval Unit       → Create/edit approval hierarchies
│   └── Import and Export   → Import/export approval hierarchies
│
├── INTEGRATION
│   ├── Data Integration    → FDMEE/Data Management Console
│   ├── Data Exchange       → Simple file import/export
│   └── EPM Automate        → Documentation for command-line automation
│
├── ADMINISTRATION
│   ├── Application Monitoring → Performance dashboards
│   ├── Audit               → Change tracking and audit logs
│   ├── Daily Maintenance   → Set maintenance window time
│   ├── Announcement        → Post system-wide user messages
│   ├── Map Reporting App   → Link to Financial Reporting app
│   └── Currency            → Exchange rate management
│
├── TOOLS
│   ├── Jobs                → Job scheduler and execution history
│   ├── Migration           → Snapshot backup/restore/import/export
│   ├── Access Control      → User roles and permissions
│   └── Connections         → External system connections
│
├── ACADEMY
│   └── Videos & Tutorials  → Oracle learning resources
│
└── SETTINGS (via gear icon ⚙, not Navigator)
    ├── User Preferences    → Language, date/number format, user vars
    ├── Appearance          → Theme (Redwood/Dark)
    ├── Sandbox Management  → Create/publish/delete sandboxes
    ├── About               → Version information
    ├── Help                → Documentation
    └── Sign Out            → Logout
```
