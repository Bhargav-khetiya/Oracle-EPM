# 01 — EPM Cloud Foundation

## What This Folder Teaches
- What Oracle EPM Cloud is and its architecture
- How to set up and navigate an EPM Cloud environment
- Oracle's official design best practices for dimensions, cubes, and applications
- How to establish an EPM Center of Excellence

## Why It Matters
Everything in EPM Cloud builds on these fundamentals. Skip this and every later topic will feel like guesswork.

## Prerequisites
None — this is where you start.

## Study Order
1. `CORE/01_Getting_Started_Guide_for_Administrators.pdf` — Environment setup, admin basics
2. `CORE/02_Getting_Started_Guide_for_Users.pdf` — End-user perspective
3. `CORE/03_Design_Best_Practices.pdf` — Oracle's design patterns
4. `REFERENCE/01_Creating_and_Running_an_EPM_Center_of_Excellence.pdf` — Governance

## After This Folder You Should Be Able To
- Log into EPM Cloud and navigate all major screens
- Explain EPM Cloud architecture to a colleague
- Understand the difference between Planning, FreeForm, and other EPM modules
- Know Oracle's recommended design patterns
