## 1. Core Financial Planning Workflows & Task Lists <a name="workflows"></a>

Financial planners execute structured monthly forecasting and annual budgeting through **EPM Tasks (`Navigation -> Tasks`)**. Each task links directly to a specific form, calculation rule, or approval sign-off gate.

---

## 2. Data Form Features: Cell Notes, Attachments & Action Menus <a name="form-features"></a>

- **Supporting Detail:** Allows building multi-line arithmetic breakdowns directly within a single form cell.
- **Action Menus (`Right-Click Context Menu`):** Planners right-click a cell (`e.g., Total Salary`) and select `Run Workforce Calculation` or `Push Data to Reporting` directly without leaving the form.

---

## 3. Sandbox Planning & What-If Simulations <a name="sandbox-planning"></a>

**Sandbox Planning (`Sandboxes`)** allows planners to create private, isolated cube slices (`Sandbox_1`, `Sandbox_2`) where they can test major expense cuts (`What-If Analysis`) without impacting the shared `Working` budget visible to other departments. Once finalized, planners click `Publish Sandbox` to merge changes back to the base version.
