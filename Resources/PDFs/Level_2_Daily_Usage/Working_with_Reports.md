## 1. Interactive Report Viewer Features <a name="interactive-viewer"></a>

Modern **EPM Reports (`Reports -> Reports`)** render using high-speed HTML5 canvases.
- **Dynamic POV Selection:** Dropdown bars at the top of the report allow 1-click toggling between Cost Centers, Currency, and Scenario without reloading page frames.

---

## 2. Drill-To-Content & Cell Attachments <a name="drill-to-content"></a>

- **Drill-Through:** Clicking a blue hyperlinked number (`$1,250,000 Total Revenue`) drills down into the underlying sub-accounts OR opens the raw ERP journal transaction lines (`Drill-to-Source` via Data Integration).
- **Notes & Narrative Boxes:** Displays dynamic text boxes where controllers enter month-end variance explanations alongside numbers.

---

## 3. Exporting to Excel, PDF & Snapshot Binders <a name="exporting"></a>

- **Excel Export:** Unlike legacy FR which exported broken text blocks, EPM Reports exports **True Native Excel Formulas** (`=SUM(B4:B12)`) and preserves exact borders and font styling.
