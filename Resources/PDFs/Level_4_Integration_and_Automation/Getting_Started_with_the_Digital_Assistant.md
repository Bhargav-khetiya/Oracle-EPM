## 1. Oracle Digital Assistant (`ODA`) Architecture <a name="oda-architecture"></a>

Oracle Digital Assistant (`ODA`) runs on Oracle Cloud Infrastructure (`OCI`) as an AI-powered conversational platform. It links to EPM Cloud using pre-built **Application Skills**.

---

## 2. EPM Cloud Conversational Skills (`Financials`, `Consolidation`) <a name="skills"></a>

- **Financials Skill:** Allows planners to ask natural language questions: *"What is my Q3 travel budget balance?"* or *"Submit $5,000 for Office Supplies in CC_109."*
- **Consolidation Skill:** Allows controllers to query journal statuses and intercompany balances on the go.

---

## 3. Configuring Teams & Slack Channels <a name="channels"></a>

- Connects via **Webhooks and OAuth channels** directly to corporate Slack, Microsoft Teams, or web widget interfaces.
