# 03 — Oracle Essbase

## What This Folder Teaches
- Essbase fundamentals: the OLAP engine behind Planning and FreeForm
- BSO, ASO, and Hybrid storage types
- Dense/sparse dimensions, blocks, aggregation
- Calculation concepts, MDX, MaxL scripting
- Cube design and performance

## Why It Matters
Essbase IS the calculation and storage engine. Understanding it deeply separates good consultants from great ones.
