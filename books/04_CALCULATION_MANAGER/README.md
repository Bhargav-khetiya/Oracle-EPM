# 04 — Calculation Manager

## What This Folder Teaches
- How to create, validate, deploy, and launch business rules
- Calc scripts, MDX scripts, Groovy scripts
- System templates, script components, templates
- Variables: runtime prompts, substitution variables

## Why It Matters
Business rules are how EPM applications calculate budgets, forecasts, allocations, and aggregations. This is core technical work.
