# 05 — Oracle Smart View for Office

## What This Folder Teaches
- How to use Smart View (Excel add-in) with EPM Cloud
- Ad-hoc analysis, data retrieval, data submission
- HsGetValue, HsSetValue functions
- Smart View for Mac, Browser, and Google Workspace

## Why It Matters
Smart View is how power users and finance teams interact with EPM data through Excel. Every EPM project uses it.
