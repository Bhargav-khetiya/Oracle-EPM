# 06 — Oracle Cloud EPM FreeForm

## What This Folder Teaches
- FreeForm application creation and administration
- Direct Essbase cube management (BSO, ASO, Hybrid)
- Data Maps, Smart Push, multi-cube architecture
- Forms, dashboards, and data entry in FreeForm

## Why It Matters
FreeForm gives you direct Essbase access without Planning's pre-built structure. Essential for custom OLAP solutions.

## Prerequisites
- 02_PLANNING complete
- 03_ESSBASE (Getting Started + DB Admin Guide)

## Study Order
1. `CORE/01_Administering_FreeForm.pdf` — App creation, cubes, dimensions
2. `CORE/02_Working_with_FreeForm.pdf` — End-user workflows

## After This Folder You Should Be Able To
- Create FreeForm applications with multiple cubes
- Configure BSO, ASO, and Hybrid cubes directly
- Set up Data Maps and Smart Push between cubes
- Design FreeForm-specific forms
