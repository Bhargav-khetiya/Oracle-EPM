# 07 — Data Integration / Data Management

## What This Folder Teaches
- How to load data into EPM Cloud from external sources
- Import/export formats, mappings, transformation rules
- EPM Integration Agent for on-premises sources
- Data Management (FDMEE/DM) workflows

## Why It Matters
No EPM system exists in isolation. Data must flow in from ERP, HR, and other systems. Integration is a critical skill.

## Prerequisites
- 02_PLANNING or 06_FREEFORM (at least one)

## Study Order
1. `CORE/01_Administering_Data_Management.pdf` — Full DM/FDMEE guide
2. `CORE/02_Getting_Started_with_Integration.pdf` — Integration overview

## After This Folder You Should Be Able To
- Set up data import from flat files and databases
- Configure import/export formats and mappings
- Use the EPM Integration Agent
- Troubleshoot data load errors
