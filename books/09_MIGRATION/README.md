# 09 — Migration (LCM)

## What This Folder Teaches
- Lifecycle Management (LCM) for EPM Cloud
- Snapshots: creating, downloading, uploading
- Migrating artifacts between environments (Dev → Test → Prod)
- Backup and restore strategies

## Why It Matters
Every real project has multiple environments. Migration is how you move work between them.

## Prerequisites
- 02_PLANNING, 08_SECURITY

## Study Order
1. `CORE/01_Administering_Migration.pdf`

## After This Folder You Should Be Able To
- Create and manage snapshots
- Migrate artifacts between environments
- Understand the migration audit trail
- Handle selective migration of specific artifacts
